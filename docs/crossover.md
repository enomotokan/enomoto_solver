# 内点法 + クロスオーバー (`root_solver="ipm_crossover"`)

傾き・切片双対二段解法と比べるために、前処理後の問題を内点法で解き、その (頂点とは限らない) 最適解から
最適基底解を作るクロスオーバーを実装した。クロスオーバーは

> T. Liu and H. Lu, "A New Crossover Algorithm for LP Inspired by the Spiral Dynamic of PDHG",
> arXiv:2409.14715 (INFORMS Journal on Computing, 2025)

の方式に従い、段の構成は著者の参照実装 (github.com/MIT-Lu-Lab/crossover、`src/iterates.jl`) に合わせた。

```python
sol = model.solve(root_solver="ipm_crossover")
```

前処理と後処理は単体法 (`"simplex"`) と同じものを使い、求解の部分だけが入れ替わる。内点法が収束せず
最良の反復点も粗すぎる場合や、基底が作れない場合は、傾き・切片双対二段解法で解き直す
(節目 `crossover_fallback` が記録される)。

## 全体の流れ

1. **前処理** (`build_std_form_presolved`、単体法と共通): `A z = b, lb <= z <= ub` の標準形 (各行にスラック列)。
2. **内点法** (`src/interior_point/boxed.rs`): 固定列 (等式行のスラック) を除いた問題を、箱型制約を直接扱う
   PIQP 型の近接内点法 (IP-PMM) で解く。主解 `x`、双対 `y`、被約費用 `s = c - A^T y` を得る。
3. **主の押し出し**、4. **双対の押し出し**、5. **一次独立性の検査** (`src/simplex/crossover.rs`)。
6. **仕上げ**: 得られた基底から `polish_with_true_bounds` (有界双対単体法、双対実行不能なら主単体法へ引き継ぐ)。
   基底が既に最適なら反復なしで返る。
7. **後処理** (単体法と共通)。

各段の終わりの時刻を `_core.last_solve_events()` に記録する (`ipm_end`、`primal_push_end`、`dual_push_end`、
`basis_end`、`cleanup_end`)。

## 内点法 (PIQP の箱型制約版)

既存の `interior_point::solve` (PIQP を P = 0 に特化、`A x = b, G x <= h`) は変数の上下限を `G` の行として
持つ。今回は PIQP 本来の扱いにならって境界を直接扱う版を加えた。境界の行のスラック・乗数を Newton 系から
消去して上段対角に畳み込む (`[ρI + Σ, A^T; A, -δI]`、`Σ_jj = 1/W_l + 1/W_u`、`W = S/Z + δ`) ので、反復の
式は `G` 行の版と同じだが、系の次元が `n + p + (境界の数)` から `n + p` に減る。次の点も変えた。

- **1 反復 1 回の分解**: 予測子と修正子は同じ行列なので、数値分解を 1 回にした (既存版は 2 回)。
- **正規方程式**: Newton 系は既定で正規方程式 `(A D^{-1} A^T + δI) dy = ...` を疎 Cholesky (AMD 順序、動的正則化)
  で解く。準定値の拡大系の LDLᵀ は δ ≈ 1e-10 になると順序によってはピボットが崩れて NaN になった
  (greenbea、pilot4)。稠密な列があって正規方程式の三つ組が多すぎるときだけ拡大系を使う。反復改良を 3 回まで行う。
- **大きさの正規化**: `x = β x'` (β = max(1, ‖b‖∞))、`c = γ c'` (γ = ‖c‖∞) にそろえてから解く。前処理後の
  右辺・暗黙の境界と費用の大きさの差 (pilot4 で ‖b‖ ≈ 3e4、‖c‖ ≈ 0.05) で初期ギャップが 1e11 を超えていた。
- **正則化の更新**: 相補性の相対減少率 `r` を [0, 0.999] に収めた (既存版は絶対値を取り、ギャップが増えた反復で
  r > 1 になって ρ, δ が一気に下限へ落ち、早すぎる Farkas 判定を招いた: adlittle)。
- **Farkas 判定は停滞してから**: 正則化が下限に達し、しかも残差が 2 反復改善しないときだけ試す。
- **最良の反復点**: 反復上限・数値的破綻で止まったときは、相対残差の最も小さい反復点を返す。クロスオーバーは
  その相対残差が許容値の 1e4 倍 (相対 1e-4 程度) 以内なら進む (最後の単体法が残りの誤差を直す)。

## クロスオーバー (論文との対応)

記号は標準形 `min c^T x, A x = b, l <= x <= u` (A は全列)。

| 段 | 論文・参照実装 | この実装 |
|---|---|---|
| 非基底の検出 | `detect_and_fix_nonbasic!`: `x_j - l_j <= max(γ s_j, tol)` で下限、`u_j - x_j <= max(-γ s_j, tol)` で上限、固定列は `s` の符号 | 同じ (γ = 1、tol = 1e-8) |
| 主の押し出し | `move_x_to_vertex!`: 乱数で摂動した費用 `c̃` の `null(A_B)` への射影 `v = -(c̃_B - A_B^T ŷ)` の向きに比率テスト、ブロックした列を非基底へ。`|B| <= m` で `|B|` が減らなくなるまで | 同じ。射影は下記の拡大系で解く |
| 双対活性集合 | `cal_dual_active!`: 基底 ∪ 被約費用 ≈ 0 の列 (下限だけの列は `s <= tol`) | 基底 ∪ `|s_j| <= tol` の列 (下記) |
| 双対の押し出し | `move_y_to_vertex!`: 摂動した右辺 `b̃` の `null(A_D^T)` への射影 `v_y = b̃ - A_D x̂` の向きに `y` を動かし、被約費用が 0 に達した列を `D` へ。`|D|` が増えなくなるまで | 同じ |
| 一次独立性の検査 | `linear_independence_check!`: `A_B` の LU、残りの行の Schur 補行列を `D \ B` の列で LU | 優先順 (B → D \ B → スラック列) の左から順の疎 LU (Gilbert–Peierls) で m 列を選ぶ |
| 仕上げ | `cleanup!`: 基底から `x_B`, `y` を解き直す | 基底から有界双対単体法 (必要なら主単体法) で最適性を保証 |

参照実装は乱数の摂動の大きさ `δ = 1`、費用・右辺を `‖·‖∞ + 1` で割ってから加える。これも同じにした。
参照実装の「補助 LP」(PDLP で押し出しの補助問題を解く `P_HYBRID`/`D_HYBRID`) と「実行可能性の回復」は使わない
(既定の `P_OLS`/`D_OLS` に相当)。

## 計算の効率化

参照実装は射影 (最小二乗) を毎回 QR か反復法で一から解く。ここでは次のようにした。

- **射影は 1 種類の拡大系で解く**: 主は `[diag(t) A^T; A -εI][v; ŷ] = [-c̃; 0]` (`t_j = 1`: 基底候補、`t_j = 1e12`:
  非基底 = 実質的に列を消す)、双対は `[diag(h) A^T; A -I][x; q] = [0; b̃]`、`v_y = -q` (`h_j = ε`: `D` の列、`1e12`:
  `D` の外)。どちらも非零パターンは全列の `A` で決まるので、AMD 順序と記号分解は 1 回だけ (`AugKkt`)。
- **縁取りによる更新**: 1 歩で `B`/`D` は 1 列ずつしか変わらないので、数値分解し直さずに、主では非基底に移った列に
  制約 `v_j = 0` (縁 `e_j`)、双対では `D` に加わった列を新しい変数 (縁 `[0; a_j]`) として加え、`k x k` の Schur
  補行列 `S = C - U^T K^{-1} U` だけを密に解く (`S` は縁を足すたびに広げる)。縁の処理の累計時間が数値分解 1 回の
  時間を超えたら (またはメモリの上限で) 分解し直す。
- **右辺をエポックで固定**: 摂動 (`c̃`, `b̃`) は分解し直すたびに引き直し、その間は同じものを射影し続ける。
  `K^{-1} r` は分解の直後に 1 回だけ計算し、各歩は新しい縁 1 本の求解と `O(k·dim)` の補正だけで向きが得られる
  (参照実装は毎歩摂動を引き直すが、エポック内で固定しても射影の向きは一般の位置にあり、ブロックの同点は起きない)。
- **基底の選択**: スラック列 (単位列) は消去なしで受理でき、`B` と `D \ B` は列の非零数の昇順に試す。

## 数値上の安全策 (論文からの変更点)

射影を正則化付きの拡大系で解くので、厳密な射影からのずれ (`A_B v = ε ŷ`、`A_D^T v_y = ε x̂`) が残る。
これに対して次の策を入れた (論文は QR による厳密な射影なので不要)。

- **向きの受理条件**: 主の向きは `‖A v‖∞ <= 1e-6 ‖v‖∞`、双対の向きは `‖A_D^T v_y‖∞ <= 1e-3 ‖v_y‖∞` のときだけ
  採用し、満たさなければ押し出しを終える。論文の「`‖v‖ > ε_zero` なら進む」の数値版で、A_B が列フルランクに
  なった後の丸め誤差 (blend で `|v| ≈ 4e-7`) を向きと誤認して θ ≈ 1e7 で進み、`A x = b` を壊すのを防ぐ。
- **双対の比率テストの雑音閾値**: `D` の列での `|a_j^T v_y|` (厳密には 0) の 10 倍以下の `|a_j^T v_y|` は
  0 とみなす (加えても階数が増えない列を `D` に入れない)。
- **ずれの補正**: 1 歩のずれ (`θ ‖A v‖`、`θ max_{j∈D} |a_j^T v_y|`) が 1e-9 を超えた歩と、分解し直したとき・
  押し出しの終わりに、`A_B δ = b - A x` (主) / `A_D^T δ = s_D` (双対) の最小ノルム解を足して戻す。
- **双対活性集合**: 参照実装は下限だけの列を `s_j <= tol` で活性にする (負の `s` も入る) が、負に外れた列を `D` に
  入れると `A_D^T y = c_D` が両立しなくなる (degen3) ので、向きによらず `|s_j| <= tol` の列だけを加える。
- **正則化**: `ε = 1e-12` (主・双対とも)。

これらで、仕上げに渡す基底の主・双対実行不能の数は Netlib の多くの問題で 0 になった (scfxm1、bandm、stair、
ship04s、80bau3b の双対側など)。残る実行不能は仕上げの単体法が直す。

## 内点法の効率化と改良案の比較 (2026-10-05)

結果を変えない効率化として次を入れた (内点法の部分で fit2p 40 秒 → 0.3 秒、osa-60 5.6 秒 → 3.2 秒など)。

1. 稠密な列 (非零数が max(50, 平均の 10 倍) 超) を正規方程式から外し、Sherman–Morrison–Woodbury で扱う
   (行数 1000 以上で、稠密な列の組の数が他の列の 4 倍以上のときだけ。fit1p のような小さな問題では外すと
   残りの行列の条件が悪くなって収束しなくなったため)。
2. 反復改良は残差が十分小さければ打ち切る。
3. 反復の終わりに計算した新しい点の残差を次の反復で使い回す。
4. 上下限ごとのループを列ごとの並列ループにする (1 タスクの最小の長さ 4096)。
5. 正規方程式の値を CSC の値の配列に直接足し込む。

反復の経路が変わる改良案は、Netlib 93 問 + Kennington 16 問 (内点法 + クロスオーバー、3 回の中央値) で比べた
(`benchmarks/crossover/ab/`、`scripts/crossover_bench/compare_ab.py`)。

| 案 | 解けた数 | 幾何平均 | 10 秒ずらした幾何平均 | 退行 |
|---|---|---|---|---|
| 基準 (上の 1〜5) | 109/109 | 0.190 秒 | 1.648 | ― |
| Gondzio の多重中心性補正子 2 回 (`ENOMOTO_T_IPM_GONDZIO=2`) | 109/109 | 0.176 秒 | 1.751 | なし |
| 近接中心の毎反復更新 (`ENOMOTO_T_IPM_PROX_ALWAYS=1`) | 108/109 | 0.143 秒 | 2.040 | pds-20 |
| 停止の許容誤差 1e-6 (`ENOMOTO_T_IPM_EPS=1e-6`) | 108/109 | 0.173 秒 | 1.888 | pds-20 |

判定: いずれも採用しない (基準のまま)。Gondzio はずらさない幾何平均は改善するが大きめの問題で遅くなり、
近接中心の毎反復更新と許容誤差 1e-6 は pds-20 で退行した。調整用の環境変数として残す (既定は無効)。

### 第 7〜8 回 (正則化の下げ方)

### 第 11 回 (同時実行で二段解法の下界を内点法に渡す)

同時実行の間、二段解法は段階 B で今の基底の双対 `y` (真の費用) から元の問題の最適値の厳密な下界
`L(y) = b·y + Σ_j min_{l_j<=x_j<=u_j} (c - A^T y)_j x_j` を 100 反復ごとに計算して共有し、内点法は主目的値と
この下界の相対差が閾値以下で主残差が小さければクロスオーバーに渡す。同時実行の閾値を 0 にして 109 問を
すべて同時実行で比べた (`benchmarks/crossover/ab11/`)。

| 案 | 109 問の比 | Netlib | Kennington | 内点法側が勝った数 | 誤り |
|---|---|---|---|---|---|
| 下界なし | 1.000 | 1.000 | 1.000 | 20 | 0 |
| 相対差 1e-6 で渡す | 0.952 | 0.939 | 1.033 | 22 | 0 |
| 相対差 1e-4 で渡す | 0.987 | 0.986 | 0.991 | 19 | 0 |

1e-6 を既定にした。ただしこの大きさの問題では二段解法がほとんど先に終わり、どちらが勝つかは実行ごとに
揺れるので、差は計測の揺れと同程度である。効果は内点法側が勝つ大きな問題 (Mittelmann) で確かめる必要がある。

### 第 13 回 (仕上げを二段解法の主ループで行う)

二段解法の主ループに、与えた基底から始める入口を加え (非基底列は被約費用の符号が好む側、無限の側は記号的な M。
M で置けないスラック列は費用をずらす)、クロスオーバーの仕上げを polish からこれに替えた
(`ENOMOTO_T_XO_CLEANUP_MAIN`、`benchmarks/crossover/ab13/`)。

### 因子の非零数の上限 (ex10)

既定 `auto` (同時実行) で ex10 (前処理後 63,012 行 × 15,932 列) を解くと、二段解法側は約 190 秒で最適に達するが、
内点法側が 63K 次元の正規方程式を組み、AMD 後の nnz(L) が 7.5 億 (因子だけで 6 GB、数値分解 1 回 ≈ 400 秒) になって
常駐 9.9 GB に達していた。メモリ上限 12 GB 前後の環境ではプロセスごと落ち、「解けない」になる
(`analysis/fable_ex10_dual_two_stage_20261006.md`)。拡大系にしても nnz(L) 1.02 億・1 反復 26 秒で、収束は見込めない。

記号分解の後で因子の非零数を見て、`MAX_FACTOR_NNZ` (1 億、`ENOMOTO_T_IPM_MAX_FACTOR_NNZ`) を超えるなら
正規方程式 → 拡大系の順に諦め、どちらも超えるなら内点法は反復せずに `NotSolved` を返す (節目 `ipm_factor_too_large`)。
同時実行では二段解法だけが残り、`ipm_crossover` 単独では二段解法へ戻る (`crossover_fallback`)。
Netlib・Kennington・scpm1 など内点法が勝つ問題の因子はこれより桁違いに小さく、経路は変わらない。

| ex10 (4 コア Xeon 2.8 GHz、HEAD 比較) | 変更前 | 変更後 |
|---|---|---|
| `auto` | 193.7 秒、最適、最大常駐 9.9 GB | 216.5 秒、最適、最大常駐 1.46 GB (内点法は 41 秒で撤退) |
| `ipm_crossover` | 600 秒で時間切れ (常駐 9.8 GB) | 255.3 秒、最適 (42 秒で二段解法へ戻る)、最大常駐 1.35 GB |
| `simplex` (参考) | 191.7 秒 | 同じ経路 |

同じ計算機で HiGHS 1.15.1 は双対単体法 156.6 秒、IPM (IPX、双対化して 16 反復) + クロスオーバー 75.6 秒。
`auto` の 216 秒と 194 秒の差は、撤退までの 41 秒の記号分解 (三つ組 3,650 万、AMD) が二段解法と計算機を
分け合うことによる揺れの範囲。内点法を ex10 で効かせるには HiGHS のような双対化 (p ≫ n で 16K 次元の系にする)
が要る (報告の策 2、未実装)。

### 内点法の双対化

単体法が双対化する問題 (`src/simplex/dualize.rs` の判定: 前処理後の行数 5 万以上、行数 ≥ 3.5 × 構造列数、構造列の平均非零数 45 以下、
双対 LP の初期配置で無限の側に置かれる列が行数の 4 倍以下) は、内点法 + クロスオーバーでも双対 LP を解く
(`crossover::solve_ipm_crossover`、節目 `xo_dualized`)。Newton 系の次元が行数から構造列数に減る (supportcase10: 105,209 → 8,955、
nnz(L) 1,614 万・設定 2.2 秒)。仕上げの単体法の最適基底の行の双対 `π` から `x'_j = -π_j` で元の解を戻し、元の問題の制約を
満たさなければ元の問題を内点法で解く (`xo_dualized_failed`)。`ENOMOTO_T_XO_DUALIZE=0` で双対化しない。

| 内点法 + クロスオーバー単独 (600 秒、`benchmarks/crossover/ab14/`) | 双対化なし | 双対化 |
|---|---|---|
| supportcase10 | 時間切れ | **193.4 秒** (最適、3.3839236661380037) |
| neos | 時間切れ | **339.2 秒** (最適、225425492.2047545) |
| graph40-40・neos3・neos-5251015・physiciansched3-3・rmine15 | 時間切れ | 時間切れ |

### 正則化の初期値・下限と発散の打ち切り (第 15 回)

Clarabel との比較 (`analysis/fable_ipm_vs_clarabel_20261006.md`) で、enomoto の内点法は分解が重い問題では 1 反復が Clarabel の
1/2〜1/7 で速い (正規方程式は `p` 次元、Clarabel は `n + p + 境界数` 次元の準定値系) が、反復数で負けていた (Netlib 小 60 問で
1.14 倍、perold・pilot4 は 200 反復で収束しない)。原因は正則化 ρ・δ の初期値 0.1 (PIQP は 1e-6・1e-4) が序盤〜中盤で Newton 方向を
歪めて中心性を失わせること、下限 1e-10 が終盤に主残差の床 `δ‖λ − y‖` を作りギャップが 1e-7 で止まること。

- 初期値を `BOX_REG0 = 1e-4`、下限を `BOX_REG_MIN = 1e-13` にした (`ENOMOTO_T_IPM_REG0`・`ENOMOTO_T_IPM_RHO_MIN`・`ENOMOTO_T_IPM_DELTA_MIN`)。
  旧来の内点法 (`interior_point.rs`) の定数は変えていない。
- 下限 1e-13 では収束間際に正規方程式の精度が落ちて主残差が跳ね上がり、戻らないことがある (wood1p: 29 反復目の主残差 2e-10 →
  30 反復目 1.7e-2、200 反復まで回る)。正則化が下限に達した後、最良の反復点の相対残差の最悪値が 1e3 以下なのにいまの点が
  その 1e3 倍を超えたら、最良点に戻して打ち切る (`BOX_BLOWUP`、`ENOMOTO_T_IPM_BLOWUP=0` で無効、節目 `ipm_blowup`)。
- Gondzio の多重中心性補正子 (2 回) は反復数をさらに減らすが、クロスオーバー後の仕上げが長引く問題が出たので既定では使わない
  (`BOX_GONDZIO = 0`)。

#### 正則化の下限の比較 (第 16 回、`benchmarks/crossover/ab16/`)

下限 1e-13 で正規方程式が悪条件になり収束後に発散する (`D⁻¹ = (ρ + z/s)⁻¹` が最大 `1/ρ` になる) 対策として、下限を上げる案を
