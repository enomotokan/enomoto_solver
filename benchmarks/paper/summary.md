# 求解時間の比較: ENOMOTO・HiGHS・CLP・SoPlex

## 計測環境と設定

- CPU: AMD Ryzen 7 5700U with Radeon Graphics
- 論理 CPU 数: 16、メモリ: 11.7 GB、OS: Linux-6.6.87.2-microsoft-standard-WSL2-x86_64-with-glibc2.35
- 計測ホスト: V
- ENOMOTO: git eb6b4a9f589d (None)、HiGHS 1.15.1 (highspy)、CLP 1.17.11、SoPlex 8.1.0
- 設定: 各ソルバーの既定値 (時間制限とスレッド数のみ設定)。スレッド数: ENOMOTO・HiGHS は 16 (論理 CPU 数 16)、CLP・SoPlex は 1 (逐次のソルバー)。ENOMOTO は実行不能と非有界を区別する設定
- 制限時間 600 秒。各問題を 3 回解いて中央値 (1 回目が 300 秒以上、または解けなかったときは 1 回)。1 回の求解ごとに新しいプロセス、繰り返しの間でソルバーの順番を回す
- 1 回目が 1 秒未満の問題は、その 1 回をウォームアップとして捨てて測り直す
- 時間は求解のみ (MPS の読み込みとモデル構築は含まない)、単位は秒
- 解けた = 期待どおりの状態で、最適なら目的関数値が基準値と相対 1e-06 以内。解けなかった問題は制限時間として平均・総時間に含める
- 幾何平均・シフト付き幾何平均 (shift 10 秒)・総時間
- 集計から除いた問題: Dual2_5000, L2CTA3D, dlr2, thk_48
- MPS の名前に空白を含むなどで元のファイルを読めなかったため、HiGHS で読み直して名前を付け直した MPS で解いたもの: forplan (SoPlex)
