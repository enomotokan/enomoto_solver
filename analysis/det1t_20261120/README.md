# det1t: 1 スレッド・同じ種でも結果が再現しない元 (利用者の依頼、2026-11-20)

発端: neos-933966 を既定・1 スレッド・同じ種・同じ時間上限で 2 回流すと、170 ノード・158 秒で解ける回と 3265 ノードで時間切れの回に分かれる
(analysis/p2inf_20261119 8 節)。1 スレッドでも時間で決まる所を突き止め、手間で決める形にする。既定の動きは変えない (試作は環境変数)。

## 1. 道具
- `pair.py 問題 秒 回数 [環境変数=値 ...]`: 同じ種で 2 回を順に解き、ノードの最初の LP の記録 (`ENOMOTO_MIP_MEMBQ_DIAG` の外側の求解の行と、
  足した `MEMBQ_PRE` = 解く前の基底・列の境界・DSE 重み・通算の反復のハッシュ) を並べて最初の食い違いを出す (`pair.jsonl`、食い違えば `logs/`)。
- `firstdiff.py a.log b.log`: 2 つのログの最初の食い違いの行 (秒・時刻・経過の行を伏せる)。
- 診断 `ENOMOTO_MIP_DET_DIAG`: 根のカットの各巡・CUTSEL_PROBE・根のヒューリスティクスの後のスレッドの手間 (ticks) と、サブ MIP の止め方 (手間の予算か時間か)。
- `p58.py 名前 秒 [環境変数=値 ...]`: P の 58 問を 1 スレッド・種 1 で 2 回ずつ解き、記録と結果が一致するか (`p58_<名前>.jsonl`)。

## 2. 見つけた元 (事実)
- **根の乱択丸め (OBJPROBE `r`) の枠が壁時計**: カットのループの巡ごとに、使った秒の和が 0.02 × 時間上限に収まる間だけ回す。neos-933966 は 1 回 1.6〜1.7 秒で、
  90 秒の上限の枠 1.8 秒の際にあり、2 巡目に入るかが回で変わる (カットの巡 1 と 2 の間に入る回と入らない回)。
- **サブ MIP の手間の予算の基準が残り時間**: 外側のサブ MIP は手間 (ticks) の期限で止まる (`ENOMOTO_MIP_TICKS` の `u`、既定) が、予算 = 割合 × (時間上限 − 手間の経過) の
  時間上限が「前処理の後の残り時間」(壁時計) なので、手間が同じでも予算が変わる (neos-933966 で 4.471 と 4.489、SUBFIX RENS が 78・79 ノードで止まる)。
  元の時間上限を使う既存の試作 `ENOMOTO_MIP_TIMEDEP=b` で直る。
- **手間の期限の中のサブ MIP が壁時計で先に止まる**: 木の大近傍探索 (`TICKS` の `n`) のサブ MIP は手間の期限の中で解くが、時間の上限 (秒) も同じ大きさで付き、
  壁時計で先に止まる (neos-1456979 の SUBFIX tree RINS が 2.41 秒・8608 反復と 2.25 秒・6449 反復で止まった)。
- **LP の中の並列の計算**: neos-1456979 の 501 ノード目の LP は、解く前の状態 (基底・境界・DSE 重み・通算の反復) が同じでも反復が 3720 と 3560 に分かれる
  (行き着く基底は同じ)。`RAYON_NUM_THREADS=1` では起きない。どの部品かはまだ絞っていない (FTRAN の並列・x_B の更新の並列はコメントでビット一致とある)。
- **根の interior rounding の内点法の時間の上限 (約 3 秒)**: neos-1456979 で内点法が 3.01 秒で失敗する回と 2.17 秒で成功する回がある。
- 根のヒューリスティクスの終わりまで、スレッドの手間は 2 回で一致する (neos-933966・neos-1456979、`DET_DIAG`)。

## 3. 試作 `ENOMOTO_MIP_DET1T` (既定では使わない)
- `o`: 乱択丸めの枠を使った手間 (ticks × 1e-9 秒) で数える。
- `n`: 手間の期限の中で解くサブ MIP は、時間の上限を 10 倍の安全網にする。
- (既存) `ENOMOTO_MIP_TIMEDEP=b`: 割合で決める量の基準を元の時間上限にする。

## 4. 結果
- neos-933966 (90 秒、2 回ずつ 3 組): 既定は 3 組とも記録の 4〜18 行目で分かれる。`TIMEDEP=b` + `DET1T=o` は 3 組とも時間切れまで同じ。
- P の 58 問 (60 秒、種 1、2 回): 既定 54 / 58 が一致 (mc11・mzzv42z・supportcase26・neos-1456979 が食い違い)、`b` + `o` も 54 / 58
  (roll3000・supportcase26・cvs16r128-89・neos-1456979)。どちらも 1 組だけなので、回によって出る・出ない食い違いは数えきれない。
- neos-1456979 (60 秒、3 組) は `b` + `on` + `RAYON_NUM_THREADS=1` で 2 組が時間切れまで同じ、1 組は interior rounding の内点法の時間で分かれる。
- `b` + `on` と `b` + `on` + `RAYON_NUM_THREADS=1` の P の 58 問を回している (`p58_bon.jsonl`・`p58_bonR.jsonl`)。
