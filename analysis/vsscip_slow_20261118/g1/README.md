# 群 1: SCIP が数秒で決着する問題の原因と対策 (2026-11-18、VSSCIP セッション)

対象 (analysis/vsscip_slow_20261118/BRIEF.md の群 1): graph20-20-1rand (scip 4.6 秒、当方は 2 設定とも 600 秒)、neos-787933 (scip 2.3 / def 291.7 / t1 TL)、
bnatt400 (scip 141.6、当方は解なし)、bnatt500 (3 者とも解なし)、neos-3381206-awhea (scip 1.2 / def 3.2 / t1 18.5)。

## 結論 (先に)

1. **neos-787933 は前処理の双対の集約の差** (事実)。SCIP は x_j := y_k (費用 0 の 0-1 列 x を、その上向きの錠になっている
   変数上界の行の 0-1 列 y に置き換える) で 236376 列を 1764 列・439 行にし、根の LP 値が最適値 30 になって 1 ノードで閉じる。
   当方は x を残し (畳み込みの後 63602 列)、根の LP 値 8.1 から含意の境界のカットで少しずつ上げるので遅い。
   **試作 `ENOMOTO_MIP_VUBAGG=1`** (既定は不変) で **291.7 秒 → 0.44 秒** (4 スレッド、根で最適、手元 1 回)。
2. **graph20-20-1rand は対称性の扱いの差** (事実)。群は SCIP と当方で同じ (生成元 36、52×37 の完全オービトープ) だが、SCIP は行が
   パッキング・分割なのでオービトープを静的 (orbitope_pp) に扱い、前処理で x_{i,c} = 0 (c > i) を固定する。当方の既定は動的な
   orbitopal fixing で、根の下界 −37 (最適 −9) のまま 600 秒で閉じない。**試作 `ENOMOTO_MIP_ORBPP=1`** (パッキングの行が 3 行以上の
   オービトープだけ静的、ほかは動的のまま。van Doornmalen・Hojny の 5.1 節の成分ごとの使い分け) で **TL → 64.7 秒で最適**、
   根の下界 −37 → −17 (4 スレッド、手元 1 回。既存の `ENOMOTO_MIP_ORBITOPE_STATIC=1` (全オービトープを静的) でも 51.2 秒)。
3. neos-3381206-awhea: SCIP の決め手はカット (切ると 120 秒で解けない)。当方 def は 3.2 秒で根で解き SCIP と大差ない。遅いのは
   1 スレッド (18.5 秒、根の下界 447.9 で 4 スレッドの 452.25 より弱い) なので、この群では扱わない (群 2・3 の「根のカット」の側)。
4. bnatt400: SCIP の切り分けは 300 秒の上限で既定も解けない回があり (計測の 141.6 秒より遅い。ビルドと同時に回したため)、決め手が
   1 つに絞れない (衝突を切ると解なし、伝播を切ると解なし、カットを切ると 110.9 秒で速い)。当方は解なし・下界 0。実行可能解を探す
   問題で、衝突解析・伝播の差と見られる (推測)。今回は扱わない。bnatt500 (実行不能、3 者とも決着せず) も同じ。
5. 正しさ: 形を狙った fuzz (`fuzz_g1.py`) と既存の fuzz、cargo test (下の「確かめ」)。広い計測の台本 (M・P・T) を用意した。

## 2. neos-787933 の構造と VUBAGG

- 元の問題: y_k (費用 1) 1764 本、x_j (費用 0、0-1) 234612 本。行は `Σ_{j∈S_k} x_j − 133 y_k ≤ 0` (1764 本、|S_k| = 133) と
  被覆の行 `Σ x ≥ 3` (133 本)。x のうち 172668 本はこの行にしか出ない (上向きの錠 1 つだけ)、61944 本は被覆の行にも出る (下向きの錠)。
- 当方の既定: 畳み込み (FOLD) が 236376 → 63602 列に畳み、前処理で 61838 列・1895 行。根の LP 値 8.1、含意の境界のカット
  (`x_j ≤ y_k` の形、毎ラウンド 50〜60 本) で上げていく。600 秒の def は 291.7 秒・3031 ノード、1 スレッドは TL。
- **規則** (`vub_dual_agg_pairs`、src/mip/mod.rs): 行 `Σ a_j x_j − M y ≤ 0` (≥ 0 の形は符号を反転、右辺 0、y と x_j は 0-1、a_j > 0、
  `Σ a_j ≤ M`) は y = 0 なら x = 0、y = 1 なら冗長なので `x_j ≤ y` と同じ。x_j の費用が 0 以下で上向きの錠がこの行だけなら、x_j を y まで
  上げても実行可能で目的は悪くならないので `x_j = y` の最適解がある (列ごとに独立)。y が別の組の x なら、その組は使わない (連鎖を作らない)。
- **置き場所**: 畳み込みの前 (`solve` の入口、サブ MIP では使わない)。x_j を全ての行で y に置き換え、費用を y に移し、x_j を 0 に固定した問題を
  解き、解の x_j を y の値で埋める (`vub_dual_agg_problem`)。前処理 (`presolve_mip`) の中に置くと、畳み込みが平行な x を 0〜109 の列に
  束ねた後で、形 (x が 0-1、`Σ a ≤ M`) が崩れて 1 本も見つからなかった。
- 結果 (4 スレッド): VUBAGG 234612 組 → 畳み込み 1375 列・131 行 → 根で最適 30、**0.44 秒** (既定 291.7 秒、SCIP 2.3 秒)。
  畳み込みを止めても (`ENOMOTO_MIP_FOLD=0`) 前処理で 1764 列・131 行、1.54 秒。

## 3. graph20-20-1rand と ORBPP

- 当方の既定の対称性: 生成元 36、52 軌道 / 1924 列、1 つの完全オービトープ 52×37 (彩色の色の入れ替え)。動的な orbitopal fixing
  (分枝した行の順。HiGHS と同じ) で、根の下界 −37 のまま。600 秒で def 43124 ノード・下界 −35、1 スレッド 12273 ノード・−34。
- **規則** (`ENOMOTO_MIP_ORBPP=1`、src/mip/mod.rs の対称性の後): オービトープごとに、パッキング・分割の行に含まれる行が過半かつ
  3 行以上 (`ENOMOTO_T_MIP_ORBPP_MIN_ROWS`) の 0-1 のオービトープを、その行だけのオービトープにして静的に扱う (根で x_{i,c} = 0 (c > i)、
  木では全ての行を固定の順で orbitopal fixing、オービトープの分枝はしない)。ほかのオービトープは動的なまま。オービトープどうしは列が
  交わらないので成分ごとに違う規則の代表を残してよい (群が直積に分かれる。論文の 5.1 節、SCIP も成分ごとに使い分ける)。静的にした
  ときは根のカットの対称な像 (`ENOMOTO_MIP_SYM_CUTS`) を止める。`Orbitope` に `static_pp` の印を足し、`orbitope_propagate`・
  `orbitope_branching_column` が見る。
- 結果 (4 スレッド、120 秒): 666 列を固定、根の LP 1961 → 1295 列、根の下界 −37 → −17、**64.7 秒で最適 −9** (既定は 120 秒で下界 −35)。
  SCIP はさらに固定の後の前処理で 340 列まで縮む (当方は固定の後に前処理をかけ直さない。次の一手の候補)。
