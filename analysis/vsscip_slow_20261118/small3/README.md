## 2. 原因 (ログからの事実と、推測は推測と書く)

- **neos8** (前処理): 早いプロービングで 21400 列を固定した後、プロービング (1656 → 1460 → 1124 個の 0-1 列) を 3 周、2.5 + 2.0 + 1.3 秒。
  どの周も固定・締め付けは 0 で、見つけた同値な組を代入して前処理をかけ直すたびに次の周が走る (`ENOMOTO_T_MIP_PROBE_EQUIV_ROUNDS` 既定 2)。根は 0.2 秒で閉じる。
  SCIP は knapsack・gateextraction (and 制約) の前処理で 558 列まで減らしてからプロービング 0.58 秒、前処理全体 1.5 秒。
- **exp-1-500-5-5** (根のヒューリスティクス): カットのループ 84 ラウンド・3.0 秒 (下界 65829、最適 65887)、3.1 秒に randomized rounding で最適解
  (間隙 8.8e-4) が出た後、RENS 2.2 秒・RINS 1.2 秒を回して何も見つけず、その後の再スタートで決着。SCIP は 41 ラウンド・3.1 秒で根で閉じる
  (aggregation = cmir 1088 本・flowcover 579 本)。
- **mc11・beasleyC3** (根のカットのループの長さ): mc11 は当方のカットのループ 1.0 秒で下界 11041 (最適 11689)、木で 4300 ノードを回してから再スタート。
  SCIP は根でカット 86 ラウンド・約 5000 本、14 秒で 11560、根で再スタート 2 回 (3040 → 1670 列) の後 22.7 秒で決着。beasleyC3 は当方 2.7 秒で 749.1、
  SCIP は 15.7 秒で 751.2・再スタート後 753.2。→ カットのループの長さは featconst_20261118/cutlen の担当なので、データを渡した。
- **hypothyroid-k1** (LP の大きさ): 2512 行が「45y + Σ x_i ≤ 45」(x の係数 1・2) の大 M の集約行、2517 行が被覆の行。非零 43 万。当方は根の LP に 3067 反復・4.9 秒、
  カットのループ 11.7 秒 (1 スレッド)。SCIP は前処理で集約行をクリーク (11 万) に分けて表に移し、LP の行は 1345 行、根の LP 182 反復。
- **neos-1171448・app1-1** (主側): 根の LP の値がすでに最適値 (-309、-3) なのに解が出ない。neos-1171448 の 1 スレッドは根の RENS (130 ノードの上限) が -308 を出して終わり、
  木で 530 秒 (1 ノード 0.15 秒)。4 スレッドの回では RENS が -309 を出して 18 秒。SCIP は根の RENS で 11.8 秒に -309。
- **seymour1・swath1** (木): ノード数の差 (seymour1 は 1 スレッド 11268 / SCIP 1552) が主で、群 2 寄り。seymour1 は根のヒューリスティクス (interior rounding・RENS・RINS) にも約 30 秒。

## 3. 試作 (既定は変えない)

- **S3GAP** (`ENOMOTO_MIP_S3GAP=<g>`、src/mip/solver.rs の `s3_smallgap_skip`): 外側の根で暫定解があり、根の下界との相対の間隙が g 未満なら、
  重い根のヒューリスティクス (RENS・RINS・ダイビング・Feasibility Pump・interior rounding など、`rootcap_heavy`) を回さない。
  exp-1-500-5-5 (g = 0.002): 4 スレッド 4.7 → 3.9 秒、1 スレッド 6.9 → 3.9 秒。
- **er1** (既存の `ENOMOTO_T_MIP_PROBE_EQUIV_ROUNDS=1`): neos8 は 4 スレッド 5.1 → 4.0 秒、1 スレッド 8.0 → 6.0 秒 (`=0` なら 3.1・4.3 秒だが、同値な組を使わなくなる)。

## 12. hypothyroid-k1 の大 M の集約行 (案 E、2026-11-20 に見送り)

- 案 E: 前処理で「45y + Σ x_i ≤ 45」(2512 行) を 2 変数の衝突 (y + x_i ≤ 1) に分けて衝突グラフ (クリーク表) にだけ入れ、元の集約行は LP から外す
  定式化の置き換え。根の LP (3067 反復・4.9 秒) とカットのループ (11.7 秒) を軽くする狙い。
- LAZYFRAC 担当 (session_01HrNYnHsTCUJu9iuaa4Scxm) の返事 (2026-11-20、事実):
  - CLQ_LAZY・LAZYFRAC の `cs` は、固定されていない列が全部 2 値で係数 ±1・右辺 1 (文字の和 ≤ 1) の行だけを候補にするので、45y + Σ x_i ≤ 45
    (係数がそろわない) は拾わない。GENLAZY なら knap の種類として外す候補になりうる。
  - P (種 4〜6) の hypothyroid-k1 は 3 種とも根で解けて木に入らず、門の診断の行が出ていない (比 gs 1.00・cs 1.03・g1 1.01、どの設定も何も外していない)。
  - どの lazy も「木に入るときに LP から外す」仕組みなので、根の LP とカットのループは軽くならない。
  - 作るなら当方 (前処理の置き換え) で。使い回せるのは LP の行の境界を両側無限にする形 (`set_row_bounds_many`) だけ。注意: 外した行は `self.p` に残り
    暫定解の確かめは元の行で行われる。クリークで置き換えると LP の緩和が元の行と変わる (強くも弱くもなりうる) ので、クリークカット・衝突グラフからの
    分離が働くことを fuzz (`scripts/mip_fuzz_genlazy.py`、analysis/lazyfrac_20261117/fuzz.sh の形) で確かめる必要がある。
- BIGM_SPLIT との違い: 先の試作 `ENOMOTO_MIP_BIGM_SPLIT=1` は分けた y + x_i ≤ 1 を **LP の行として** 足す (113122 行、根の LP 54 秒、全体 28.5 → 115.8 秒、
  analysis/scipslow_20261119 の 2 節)。案 E は LP には足さず衝突グラフにだけ入れ、元の行も LP から外す形で、別物。
- **見送り (親・利用者の方針)**: 「1 問に合わせた対策はしない」に当たり、全体への効きも小さい見込み (推測。同じ形の集約行を持つ問題を
  58 問・M で数えてはいない)。作っていない。
