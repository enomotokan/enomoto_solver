## 2. 試作 `ENOMOTO_MIP_MODKVB` (`src/mip/modkvb.rs`、呼び出しは `separation.rs` の `separate`、根だけ)

HiGHS (`HighsModkSeparator.cpp`・`HighsTransformedLp.cpp`・`HighsGFkSolve.h`) との対応:

- 列の置き換え (`HighsTransformedLp` のコンストラクタと `transform`):
  - 連続列: 単純な上下限と連続列の変数上下限 (`VarBounds::vub`/`vlb`) のうち LP の点で一番近いものからの距離が feastol (1e-6) を超えれば、その列を
    含む行は使わない (HiGHS の `skipRow`)。境界にあれば定数に、変数上下限なら相手の 0-1 列の項 (係数 a d) に置き換える (余りは LP で 0 なので連立に
    入らない)。単純な上下限も 0 の距離なら単純な上下限を使う (HiGHS は `preferVbds` で変数上下限を選ぶことがある。違い)。
  - 一般整数列 (幅 > 1.5): LP 値が整数で単純な上下限の内側、一般整数列の変数上下限 (`ivub`/`ivlb`、`add_int_vbs`) がちょうど効いていれば置き換える
    (HiGHS と同じ条件)。そうでなければ近い方の単純な上下限 (同点は上限)。
  - 連立に入れるのは置き換えの後の整数列のうち LP 値 (境界からの距離) が feastol を超えるもの。行の整数列の数が `1000 + n/10` を超える行は使わない。
  - 係数と右辺を整数にする倍率 (HiGHS の `integralScale` の簡略版: 最小の係数で割ってから連分数で分母を探す、1e6 まで)。
- 行: LP の行すべて (元の行と LP に入っているカットの行)、LP で等号の向き (`<=` 側を先に)。
- GF(k) の消去: HiGHS は軸の入れ替えで別の解を列挙するが、ここでは行を 1 本ずつ前の軸の行で消し (軸の時刻の順に消すので消えた列が戻らない)、
  列が全部消えて右辺が残れば解、残れば出る数の一番少ない列を軸にする。行の順を変えて 3 回 (1 回目は連立の列の数の少ない順、2・3 回目は乱数)。
  組の行が 40 本を超えたものは捨てる。1 本だけの解 (列が全部 k で割り切れて右辺が割り切れない行) は別に 150 本まで。
- 集約: HiGHS と同じ 2 通り (`((k-1) w mod k) / k`、`w / k` で符号を反転。k = 2 は前者だけ)。LP の行は論理変数 (列 n + i、境界は行の上下限) つきの
  等式で足すので、どちらの向きでも妥当。非零が `1000 + n/10` を超える集約行は使わない (nw04 で 1 本 4 万非零のカットになり根が 9 → 48 秒になった)。
- カット: `vb_cover_cut` と `generate_cuts` (一般整数列の変数上下限の置き換えはモード 3)。解ごとに `keep_best` で 1 本。ある k でカットが出れば
  次の k は試さない (HiGHS と同じ)。
- 有効性: 総当たりの単体テスト `modkvb_cuts_valid` (乱数の小さい問題 3000 問、x0・一般整数列 w と変数上下限・連続列 c と `c <= 2 zc`、データの行を
  LP 点で等号に、`>=`・等式も混ぜる。カット 3204 本 (論理変数を含む 1490 本) を延べ 40 万点 (連続列は 0.5 刻み) で確かめる)。集約で論理変数の項を
  落とす変異を入れると落ちることを確かめた (確かめた後で元に戻した)。ほかに `integral_scale_basic`・`gfk_finds_pair`。
- 他の人の試作 `ENOMOTO_MIP_SNFMODK` (ブランチの 156837f5) がこの連立を使う口 (`SNFMODK=v`) を足している (記録の取りまとめのときに rebase で
  ログの行を合わせた)。

## 6. zerohalf との重なり

wheel は `/tmp/pyw6` (35ec5a71 + `pyw6_from_35ec5a71.patch` = pyw5 に診断を足したもの、`tools/diag6.py` で入れた)。
- `ENOMOTO_MIP_MODKVB_ZHCMP` (`mk50z`、動きは mk50 と同じ): 分離の回ごとに、試作の候補 (解ごとに `keep_best` で残した 1 本、`finish_cut` の後の
  構造変数の式) と同じ LP 点の zerohalf の候補の係数の向きを比べる (最大の絶対値で割って 1e-6 に丸めた係数の並びが同じなら平行)。
- `ENOMOTO_MIP_MODKVB_CG` (`mk50cg` = CG の式だけ、`mk50cgb` = CG の式 + 従来): 解の重み ((k-1) w mod k)/k の非負の乗数で向きをそろえた行を足し、
  単純な上下限で x' >= 0 に移して係数と右辺を切り下げる mod-k の CG カット (変数上下限の置き換えを含む解・x' の係数が負の連続列が残る解は作らない)。
  単体テスト `modkvb_cuts_valid` を CG=both で通し (3650 本・延べ 40 万点)、右辺を 1 下げる変異で落ちることを確かめた。
- `ENOMOTO_MIP_MODKVB_SKIPZH` (`mk50skz`): zerohalf と平行な試作の候補を除く。
- main のソース (`src/mip/modkvb.rs`) には解ごとの印と CG の形だけを入れた。数え上げ・SKIPZH は呼び出し側 (`separation.rs`) が他の試作
  (hnfcut) で書き換わっているので、計測の wheel の差分にだけある。
