## 中身

`src/mip/symmetry.rs` の `detection_copy` (検出に渡す写しを作る) と、`src/mip/mod.rs` の `add_symmetry_rows` での呼び分け。
3 つのどれかが立つと、既定の `ENOMOTO_MIP_HO3_SYMNORM` の写しの代わりにこの写しを使う (向きのそろえは必ず含む)。

- **向きのそろえ (3 つ共通)**: `HO3_SYMNORM` と同じく (下限, 上限, 係数を並べた列) と (-上限, -下限, -係数) の小さい方の向きにする。
  ただし **-0.0 を 0.0 にそろえて比べる**。既定の `HO3_SYMNORM` は `total_cmp` で比べるので -0.0 < 0.0 となり、
  **右辺 0 の等式 (`a + b - c = 0` など) は係数によらず必ず反転され、向きがそろわず、同点にもならない** (調べている途中で見つけた穴。
  初めの形では 58 問で同点の行が 0 本だった)。`ENOMOTO_MIP_SYMZERO` はこの直しだけ。
- **SYMSIGN (穴 1、同点の行)**: 向きをそろえても -1 倍で形が変わらない行 (同点の行。`-2 <= a+b-c-d <= 2`、`a+b-c-d = 0` など) に、
  -1 倍した行を写しに足す (二重にする)。足した行は冗長なので写しの実行可能な集合は元と同じで、写しの対称性 (行の多重集合を保つ列の置換)
  は元の問題の対称性。列の置換が同点の行 r を r' の -1 倍に写すとき、写しでは r → (r' の -1 倍)、(r の -1 倍) → r' と対応するので、
  係数をそのまま比べる今の細分化・探索・確かめ (`verify`) がそのまま使える (符号つきの置換を行の側で扱うのと同じ)。見つけた置換は
  必ず写しの上の `verify` (行の多重集合が置換で保たれること) を通る。
  - 同点の行を二重にした分だけ `verify` の手間が増え、手間の上限 (`ENOMOTO_T_MIP_PRESOLVE_WORK_SYM`) に早く届いて試す組が減った
    (初めの形で neos-827175 57 → 46 個、rail01 137 → 130、satellites2-60-fs 146 → 144)。上限を外すと既定も sign も neos-827175 で
    121 個・同じ軌道だったので、同点の行があるときは手間・時間の上限を写しの大きさ (非零 + 行) の比で広げる形にした (以下の数はこの形)。
- **SYMSCALE (穴 2、正の倍率)**: 写しの各行を係数の絶対値の最大で割り (正の倍率なので実行可能な集合は同じ)、係数と有限の左右辺の仮数を
  40 ビットに丸める (`snap40`)。2 倍・1/3 倍で写る行が同じ係数になる。丸めで相対 1e-12 ほどより近い値は同じとみなすので、
  **見つかる置換はその誤差の範囲での対称性** (確かめも丸めた写しの上)。gcd で割る形は整数でない行と倍率がそろわないので使わなかった。
- 単体テスト 3 本 (`symmetry.rs`): 同点の行 `-2 <= a+b-c-d <= 2` と `-2 <= -e-f+g+h <= 2` が -1 倍で写る例 (向きのそろえだけでは
  a と e が別の軌道、SYMSIGN では同じ軌道、生成元が元の行を ±1 倍の行に写すことも確かめる)、右辺 0 の等式の向き、1/3 倍・2 倍の行。
- 診断用 `ENOMOTO_MIP_DEBUG_STOP_AFTER_SYM`: 最初の対称性の検出の直後にプロセスを終える (検出だけの数え用)。

## 推測

- 58 問の +1.3% は揺れの範囲とみる: 検出の結果が変わるのは neos-827175 (時間は変わらない) だけで、h80x6320d (対称性なし) と noswot
  (生成元の数が同じ) の差は 4 スレッドの非決定性によるものだろう。ただし noswot は写しの行を割るので、生成元の数が同じでも置換そのものが
  同じかは確かめていない。写しを作る時間は 58 問では数十ミリ秒以下とみている (測っていない)。
- 同点の行は Mittelmann で 49 問にあるのに、生成元が増えるのは 3 問だけ。多くの問題では同点の行の -1 倍の対応が、既にある対称性
  (係数をそのまま写すもの) と同じ軌道しか作らないのだろう。
- SYMSCALE が何も変えないのは、前処理が行の倍率をそろえていない問題で、もともと倍率の違う行が同じ形にならない (違う形の行) か、
  58 問・Mittelmann の模型がもともと倍率をそろえて書かれているからだろう (確かめていない)。
- neos859080 の効き目は、実行不能を示す木の探索で 80×2 のオービトープの固定が効くからとみる (ノードが 1〜2 桁減る)。
