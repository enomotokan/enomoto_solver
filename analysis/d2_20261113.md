# D2: 待ち行列のノードの基底の不一致を防ぐ試作 (D2a・D2b) (2026-11-13)

analysis/highsloss2_20261113.md の D2 (ノードの切り替えの重さ) の続き。待ち行列から取り出したノードの保存した基底は、保存の後に
その基底で効いていた (非基底の) カットの行が LP から消えていると基底変数の数が合わず、既定 (木の中の分離 `tree_sep`) では戻さずに
直前のノードの基底から解き直す (neos-3627168-kasai で 1 本約 390 反復、復元の 43〜49%)。これを防ぐ試作を 2 つ入れた (既定では使わない)。

## 試作 `ENOMOTO_MIP_HL2_D2` = 文字 (separation.rs の `hl2_d2`)

- `b` (**D2b**): LP の行を消すとき (`delete_lp_rows`・`replace_cut_rows`)、待ち行列のノードの保存した基底で効いているもの (保護の参照のあるカット)
  の中身 (係数・下限・上限) をカットの番号で取っておく (`d2b_store_deleted`)。ノードを取り出して基底を置く前に、保存した基底で効いていて今の LP に
  無いカットを LP の最後に足し直し、番号を元のものに戻し、その行の状態を保存した基底での状態にする (`d2b_readd`、`restore_node_basis` の頭)。
  同じ番号のカットが前の足し直しで LP にあれば足さずに状態だけ合わせる。足した行は効いていなければ次の分離のラウンドの一括削除で外れるので、
  行は常時は増えない。保存した基底の非基底のカットの行とノードの効いていたカットの番号 (`prot`、ノードを作るときに同じ LP の状態から作る) は
  同じ順なので、番号と状態を対応させられる。数が合わなければ足さない (計数 `protection count mismatch`)。共有の待ち行列 (別スレッド) のノードには使わない。
- `a` (**D2a**): ノードの分離の前の効いていないカットの一括削除 (`inactive_cut_mask`) で、待ち行列のノードの保存した基底で効いているカットを外さない。
  ただし守るのは年齢 (効いていない回数) が `ENOMOTO_T_MIP_HL2_PROT_AGE` (30) 以下のものだけ、本数は max(`ENOMOTO_T_MIP_HL2_PROT_ROWS` (0.5) × 元の行, 50)
  まで (年齢の若い順)。前回の F2 (`p`、全部守る、`ENOMOTO_MIP_HL2_PROTECT_INACTIVE` と同じ) が neos-911970 で行を増やした害を抑える形。
- `p`: 全部守る (前回の F2)。
- どの文字でも保護のデータ (ノードの効いていたカットの番号と待ち行列の参照数) を作る。年齢での削除 (`remove_aged_cuts`) が保護を守るのは従来どおり
  `ENOMOTO_MIP_PROTECT_QUEUE_CUTS` のときだけ (`prot_aging`)。`b` のときは取り出したノードの番号を参照数を外した後もノードに残す (queue.rs の `remove`)。
- 終わりの統計 (`ENOMOTO_MIP_LOG`): `MIP: HL2_D2: protected inactive cuts kept .. (dropped by the D2a limits ..); D2b: rows stored .., restores with re-added rows .. (.. rows), failed for missing rows .., protection count mismatch .., still mismatched ..`

## 結論

- D2b は狙い (待ち行列のノードの基底の不一致 0、切り替えの反復の減少) を果たし、木が大きく切り替えの重い kasai では 600 秒で 1.8 倍速い。
- しかし 58 問では中立〜わずかに悪く (+1.1%、解けた 132 → 129)、既定にする根拠はない。D2a は不一致を減らさず効き目がない (−0.4%、解けた 128)。
- **既定にはしない** (試作 `ENOMOTO_MIP_HL2_D2` は残す)。次に効かせるなら、切り替えの重い問題だけで D2b を使う形 (例: 待ち行列のノードの最初の LP の反復が潜りの子の k 倍以上・不一致の割合が高いと分かった時点で入れる) が候補。58 問の悪化 (noswot・roll3000・physiciansched6-2) の中身は未調査。
