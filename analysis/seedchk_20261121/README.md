# 種の揺れの確かめ (2026-11-21)

vsscip_20261120 の M で 11/17 より遅く出た comp07-2idx・ran14x18-disj-8 と、slowm_20261119 の CM2 14 で pe が大きく遅かった fiball について、
種を変えて回し、遅れが「種で二山 (運)」か「どの種でも遅い」かを見る。

- ビルド: 51eb84ae0 (古い wheel を消して `sh analysis/revisit_20261112/build.sh`、0.1.10)。
- 回し方: `python analysis/seedchk_20261121/run.py` (analysis/slowm_20261119/run.py の run() と同じ呼び方。
  `scripts/run_miplib_benchmark.py --worker-ours`、ENOMOTO_MIP_THREADS=4・ENOMOTO_T_MIP_SEED=s、600 秒)。結果は res.jsonl (18 行、crash 0)。
- 設定: def = 今の既定、pe = def + `ENOMOTO_MIP_CONFLICT_PROOF_EXPLAIN=1`。

## 1. comp07-2idx (def、種 1〜5)

参考: 11/17 の def (種 1) は 23.8 秒で最適、11/20 の def (種 1) は時間切れ (暫定解 37)。

- 下界は根で 6 (最適値) に届くが、暫定解 6 を見つけられないと時間切れになる。解けた種 4 も根で閉じたのではなく 433 ノードで 6 を見つけた。
- 5 種中 4 種が時間切れで、二山ではあるが今の既定では「解けない側」が多い。11/17 の 23.8 秒 (根で閉じた) は運のよい側と見られる。
  遅れは種の運が大きいが、今の既定で解ける割合が 11/17 の版より下がっている可能性は残る (11/17 の版を種 2〜5 で回していないので切り分けられない)。

参考 (種 1): CM2 14 は def 17.3 秒・pe 98.7 秒、11/20 vsscip の def 29.5 秒、11/17 の def 34.2 秒。

- 根の下界はどの回も 138 (最適値) で、最初の解は 0.4〜0.6 秒。あとは 138 の解を見つけるまでの探索の運で、ノード数と時間がほぼ比例する。
- def も 17〜600 秒 (同じ種 1 でも 17.3 / 105.7 秒) と大きく揺れ、pe が速い種 (2・3) も遅い種 (1・4) もある。
  def と pe の SGM (shift 1 秒、時間切れは 600 秒) は 4 種で def 103.1 秒・pe 92.4 秒 (pe/def 0.90)。
- CM2 14 の 5.45 倍は運 (種で二山どころか一様に大きく揺れる問題)。pe が「どの種でも遅い」わけではない。
