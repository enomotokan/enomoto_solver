# GATE: sw・vbis の選び方をシグモイドで入り切りできるかの見込み (2026-11-17)

課題 (親の指示): パラメータを問題の特徴の連続 (シグモイド) 関数にする方針で、(A) sw (`ENOMOTO_T_MIP_SUBWAIT=0.5`) の倍率 k、
(B) vbis のうちカットの選び方の変更 (IMPLBD_SELECT・MIN_REL 0.1・200 本・60 ラウンド・第 2 段階、VB_IMPL は除く) の入り切りを、
速い群と遅い群を分ける特徴で決められるか。まず既存の結果とログで特徴を数え、見込みを報告する。

- 台本: `feat_tab.py SET ALT` (slow2 の res_* から問題ごとの比と結果に出ている特徴)、`rootfeat.py <ログ>` (ログから根の特徴: 根の LP、
  カットの後の目的値・ラウンド数・本数、閉じた割合、根の LP の大きさ)、`one.sh` (slow2 の写し)、`batchA1.sh` (課題 A のログ集め)。
- 機械: 4 CPU のコンテナ、4 スレッド、ソルバーは同時に 1 つ。ビルドは 2b2fddba7 の 1 つ前 (src は 9ee198b80 と同じ)。

- hypothyroid-k1 (P 0.51・M 0.67 で一番効いた問題) の sel は、0 ラウンド目に 50 本入れた LP の点で randomized rounding が最適解 −2851 を当て、
  目的値のプロービングで閉じて 1 ラウンドで終わった (`hypothyroid-k1_p60sel_s1.log` の 18.56 秒)。カットで下界が上がったからではない。
- 遅くなる問題は、ラウンドが 4〜5 倍に延び (60 ラウンド・第 2 段階)、根で閉じる小さな問題では延びた根の時間がそのまま全体に乗る。
  良くなるのは nubu (木 811 → 73 ノード) くらいで、木の大きい neos17 は閉じた割合が上がっても遅く、timtab1 は変わらない。
- → 根の時点で取れる特徴 (閉じた割合・大きさ・整数の割合) で「延ばすと得をする」問題を分ける手がかりは、この 11 問では nubu 1 問しかない。
  見込みは低い。

## 結論と次 (親の方針、2026-11-17)

- B (選び方の変更のシグモイドの入り切り) は**打ち切り**。一番の得 (hypothyroid-k1) は 0 ラウンド目の LP の点で丸めが最適解を当てた
  ことによるもので、カットの強さではない。延ばして得をする問題を根の特徴で分ける根拠がない。
- A (sw) は**ゲートを作らず**、k=0.5 のまま、slow2 で使っていない種で測り直す (遅い群では止めが入らず、遅れは揺れと見たため)。

## 対の比べ (sw、別の種)

- 設定は `cfg.py` (def・sw)。分担表は `python plan.py 12 4 sw` で作った `shards_PSW.json`・`shards_MSW.json`
  (`plan.py`・`run.py`・`summ.py` は slow2 の写しで、種だけ変えた)。
- ビルドの基点: この節を足したコミット (README の更新と同時)。準備: `pip install maturin highspy==1.15.1 && pip install -e .`。
- P: 58 問 × 種 4〜6 × {def, sw}、60 秒、4 分担 (各約 0.74 時間): `python run.py PSW K` (K = 0〜3)。
- M: 48 問 × 種 3・4 × {def, sw}、600 秒、12 分担 (各約 1.4 時間): `python run.py MSW K` (K = 0〜11)。
- 集計: `python summ.py PSW sw > summ_PSW.txt`・`python summ.py MSW sw > summ_MSW.txt`。

### P の結果 (種 4〜6、`summ_PSW.txt`、分担 0・1 はこのセッション、2・3 は別のセッション)

- sw/def **+0.3% [−2.8%, +4.0%]** (どちらかが解けた 45 問)、解けた数 135 対 135、食い違い 0、crash 0、最大 RSS 1715 → 1634 MB。
- 全種で 1.25 倍超遅い問題なし。目立つのは 10teams 1.70 [0.75, 5.44, 1.2] (slow2 の種 1〜3 では 0.41 で逆向き。揺れ)、
  timtab1 0.86、noswot 0.68。slow2 の P (−1.6% [−7.1, +2.8]) と合わせて、P では中立。M (種 3・4) は親が割り振り中。

### M の結果と結論 (種 3・4、`summ_MSW.txt`、親が集計)

- sw/def −2.4% [−9.5%, +4.8%]、解けた数 67 → 67。全種で遅いのは CMS750_4 1.66 (種 1・2 では 0.58 の全種で速)。
  種 1〜4 を通して遅いのは kasai (1.61・1.48・1.72・1.16) と pg5_34 (1.27・1.28・1.34・1.07)。
- 種 1 の回のログでは、kasai・pg5_34 とも sw の止めは入っていない (pg5_34 は根の並列のサブ MIP を出さない)。sw の判定は
  `join_submips` の待ちの中で止めの条件を見るだけで、止めなければ動きは変わらないので、この 2 問の遅れは揺れの重なりと見る
  (48 問から 4 種そろって同じ向きの問題が 2 問出るのは不思議ではない)。
- **sw は不採用で確定** (親の判断、2026-11-18)。中立で、効く問題 (neos-662469 で根の待ち −44 秒) はあるが全体を動かさない。
