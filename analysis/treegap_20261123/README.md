## 8. まとめ

- 3 問 (30n20b8・dano3_5・mcsched) の木の差は、どれも分枝の選び方から来ている。
  SCIP の relpscost は木を 5 倍以上小さくしているが、当方の強分枝 + 擬似費用は 1.0〜1.4 倍しか効いていない (2・3 節)。
- 量 (強分枝の LP の回数・反復) は足りている。足りないのは強分枝から得る情報の使い方。
- 候補 1: SCIP の probingbounds に当たるもの (7 節の試作)。swath1 と dano3_5 に効き、30n20b8 は悪くなる。
- 候補 2: 始めのうちの衝突の点数 (5 節)。mcsched と swath1 に大きく効くが、30n20b8 を悪くする。一律の床としては使えない。
- 30n20b8 は、どの手でも当方が SCIP に近づかない。SCIP が衝突と木の中の伝播を外すと時間切れになることから、衝突制約の効き (SCIP は 696 本を全体に入れる) を次に見る候補とする。
- pg は解探しの差で、木の問題ではない。traininstance6 は HiGHS だけが解き、ノードの速さも 3.7 倍違う。分枝・木の型としては切り分けていない。

## 9. 試作 `ENOMOTO_MIP_SB_PROBEBD=2` (置いた境界からノードで伝播して連鎖させる、45ff9c148、`plan_chain`)

利用者の案。7 節の両方の子に共通の境界をノードに置いたあと、ノード (元の問題) でもう一度伝播をかけて連鎖させる。

### 9.1 今の `=1` で伝播は回り直しているか (コードを読んだ事実)

- 回っている。境界を置くと `bound_changes` が正になる。候補を見終わるか 5 個たまると、強分枝は `Resolve` を返す。
- 呼び出し側 (`BranchAction::Resolve =>`) は次の順に進む。
  1. `dom.propagate` (行と含意) をかける。矛盾なら衝突解析をしてノードを刈る。
  2. 矛盾がなければ `sync_lp` してノードの LP を解き直し、強分枝を初めからやり直す。
- これは SCIP の relpscost が probingbounds のあとに domain reduction を返し、LP を解き直すのと同じ流れ。
- 違いは 2 つ。この伝播は行と含意だけで、目的の伝播と衝突の組 (`lit_prop`) はかけない。また、伝播がかかるのは候補を見終わってから。

### 9.2 `=2` で足したもの

- 境界を置いた直後に、ノードで `dom.propagate`・`propagate_objective`・`lit_prop` をかける。
- 矛盾ならその場でノードを刈る。締まった境界は定義域に残り、そのあとは `=1` と同じく `Resolve` で LP を解き直す。
- 連鎖で締まった境界の数と刈ったノードの数をログに出す (`chained by node propagation`・`nodes pruned (=2)`)。新しい閾値はない。

### 9.3 計測 (1 スレッド、上限 600 秒、種 1。「普段」は打ち切り値なし、「打ち切り」は最適値 + 1e-6 の打ち切り値つき)

### 9.4 わかったこと

- **連鎖で締まる境界は、全部の回で 0。刈ったノードも 0。** これは理屈どおり。
  - 子の伝播は、ノードと同じ伝播 (行・含意・目的・衝突の組) を固定点までかけている。
  - 伝播は単調。小さい定義域からは小さい結果になる。
  - 置いた境界 H は、両方の子の固定点 D0・D1 の和 (外包)。D0 ⊆ H なので、prop(H) ⊇ prop(D0) = D0。D1 も同じなので prop(H) ⊇ H、つまり H はもう固定点。
  - 新しい情報が出るのは LP を解き直したとき (被約費用の固定、新しい強分枝)。これは 9.1 の `Resolve` の経路で、`=1` でもう回っている。
- **`=2` と `=1` の道筋が変わった回がある** (noswot、30n20b8)。連鎖の境界が 0 なのに変わる。`propagate_objective`・`lit_prop` を呼ぶ副作用 (内部の状態や衝突の組の扱い) によるものと考えている (推測、確かめていない)。速くも遅くもなる。
- **`=1` 自体の判断:**
  - 効く回: swath1 (打ち切りで 2.6 倍少ないノード)、dano3_5、mcsched (普段の形で時間切れから 547 秒)。
  - 悪くなる回: 10teams の普段の形 (2.3 倍遅い)、30n20b8 の打ち切り (時間切れ)。
  - 10teams・mcsched では共通の境界が 0 なので、差は子の伝播 (`SB_PROP` の部分) から来ている。
- **結論:** 連鎖 (`=2`) は足しても何も締まらないので、残す意味はない。差を生んでいるのは、子の伝播で子の LP と評価が変わる部分。
