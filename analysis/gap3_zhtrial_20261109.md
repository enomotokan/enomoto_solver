# GAP3: zerohalf を問題ごとに選ぶ (2026-11-09)

bench に使う環境変数: `ENOMOTO_MIP_LOG=1 ENOMOTO_MIP_THREADS=4 ENOMOTO_T_MIP_SEED=s` (s = 1, 2) に、設定ごとに
def = なし (今の既定、zerohalf を使わない)、zh = `ENOMOTO_MIP_NO_ZEROHALF=0`、zhroot = `ENOMOTO_MIP_NO_ZEROHALF=0 ENOMOTO_MIP_ZH_ONLY=root`、
zhtree = `ENOMOTO_MIP_NO_ZEROHALF=0 ENOMOTO_MIP_ZH_ONLY=tree`、zhlog = `ENOMOTO_MIP_ZH_TRIAL=log`、zhr = `ENOMOTO_MIP_ZH_TRIAL=r`。
13 問は問題ごとの時間 (ns1830653・mzzv42z・comp07-2idx・wachplan 400 秒、n2seq36q 200 秒、hypothyroid-k1・physiciansched6-2 150 秒、ほか 100 秒)、
58 問 (`analysis/cbcimpl_20261029/probs.py`) は 60 秒。計測は `gap3_zhtrial_20261109/bench.py` (ソルバーは同時に 1 つ)、表は `table.py`・`summ.py`・`rep58.py`。
4 コアの計算機 (このセッションのコンテナ)。

## 結論 (先に)

- **根の指標で「効く問題」と「害のある問題」は見分けられなかった** (事実は 2 節)。根のループを zerohalf なしで回し終えた LP で zerohalf を
  3 ラウンド試した伸び (`ENOMOTO_MIP_ZH_TRIAL=log`) は 12 問すべてで根のギャップの 1% 未満で、効く側 (hypothyroid-k1・comp07-2idx・wachplan・10teams) は
  ほぼ 0、害の側 (misc07・eil33-2・neos-860300) の方がむしろ大きい (misc07 は g_z / ループの伸び = 1.17)。zerohalf のカットの密度 (元の行の 0.5〜30 倍)・
  元になれる行の割合・分数の列の数の変化も、効く側と害の側で重なる。
- **効き目と害は下界ではなく「道」から来ている** (事実と推測は 3 節):
  - 効く側: hypothyroid-k1 は根で閉じるまでの裏のカットのスレッドの時間 (68 → 30 秒)、comp07-2idx は根の解 (zerohalf なしは根の下界 6.0 = 最適値なのに
    暫定解が見つからず 394 秒・時間切れ。zerohalf ありは根の下界 5.20 でも根のヒューリスティクスが解 6 を見つけて 23 秒)、10teams・n2seq36q (種 1) は根で解ける。
  - 害の側: neos-860300 は zerohalf を最初から使うと根のループの伸びが大きくなり、**clique の fallback の判定 (g_c > 0.5 g_d) が「使わない」に変わる**
    (既定は clique を使い根で閉じる、14 秒 → 31〜36 秒)。misc07・eil33-2・ns1830653 は根の下界は上がる (misc07 1425 → 1524) のに、LP に残る zerohalf の
    カットでノードの LP が重くなり (misc07 の平均の行 305 → 568、反復/LP 16 → 40)、ノードも減らない。
- **場所を分けると、根だけで使う形 (zhroot) が 13 問で一番良い**: def に対する幾何平均の比 zh 0.83・**zhroot 0.70**・r 形 0.83 (表 1、zhtree は種 1 だけで 10teams 3.4 倍・ns1830653 時間切れ)。
  効き目 (hypothyroid-k1・mzzv42z・wachplan・10teams・neos5) は根から来て、木で使う害 (10teams 3.4 倍・ns1830653・n2seq36q) は消える。
  ただし zhroot でも neos-860300 (clique の判定の変化) と misc07 (根で入れた密なカットが木に残る) の害は残る。
- **試作 `ENOMOTO_MIP_ZH_TRIAL`** (既定では使わない): `1` = 試しの伸びが根のギャップの 10% 以上なら根の続きと木で使う (上の通り 13 問どれも使わない
  と判定 = 既定と同じ動き、見分けにならない)。`r` = 試しの LP をせず、zerohalf なしの根のループと clique の判定が終わってから根の続き・裏のカット (と
  サブ MIP の根) だけで zerohalf を使い、木では使わない。r 形は neos-860300 (14・14 秒) と physiciansched6-2 の害を消すが、10teams (35・21 秒、def 9・7) と
  hypothyroid-k1 (63・86 秒) では zerohalf を最初から使う効き目を取り戻せず、13 問の比は zh と同じ 0.83。**「両方の良い方に寄る」とは言えない**。

## 3. 効き目と害の元 (事実と推測)

事実 (ログ):
- hypothyroid-k1: def・zh とも根で閉じる (ノード 0)。根の終わりの下界は def の方が高い (-2877.5 対 -2886.0)。差は裏のカットのスレッドが打ち切り値まで閉じる時刻
  (def 68 秒、zh 30 秒)。zhroot (根と裏のカットで zerohalf) で 42・38 秒、zhtree で 80 秒。r 形は 63・86 秒。
- comp07-2idx: def の根の下界は 6.0 (= 最適値) だが暫定解が 47 のまま (60 秒の zhlog)、400 秒で 394 秒・時間切れ。zh・zhroot は根の下界 5.20 で、根で解 6 が
  見つかって閉じる (20 秒前後)。zhtree (根の LP には zerohalf なし) も 20 秒で、根の下界 6.0 のまま解が見つかる。r 形も 24・30 秒。
- neos-860300: def は clique の fallback が「使う」(g_c 2.9e-2 > 0.5 x g_d 2.1e-2) で根の続きに clique カットを入れ、再スタート 2 回で根で閉じる (14 秒)。
  zh は根のループの伸びが g_d 1.8e-1 と大きく、clique は「使わない」(g_c 2.2e-2)。根の下界が低く (2821 対 3200) ノードが要る (31〜36 秒)。r 形は clique を使ったまま 14 秒。
- misc07: zh で根の下界 1425 → 1524、根のループの後に LP に残るカット 5 → 21 本・プール 184 → 900 本、ノードの LP の平均の行 305 → 568・反復/LP 16 → 40、
  ノードは 6200〜6500 → 9900〜11500。zhtree は 4 秒 (def と同じ)、zhroot は 14・10 秒。
- 10teams: zh・zhroot は根で解ける (5 秒、ノード 0)。zhtree は 29 秒 (ノード 22000)、r 形も 35・21 秒 (ノード 12000〜27000)。
- ns1830653: zhtree・zh で時間切れが出る (反復/LP 209 → 310)。zhroot は 378・176 秒。

推測:
- zerohalf の効き目の多くは、最初から入れたときの根のループ全体の道 (どのカットが残り、どの頂点でヒューリスティクスが回るか) から来ていて、
  根のループの終わりに足す形 (r 形・試しの LP) では取り戻せない (10teams・hypothyroid-k1)。だから「終わりに試して伸びで決める」型の判定は原理的に弱い。
- 害は 2 つの型に分かれる: (a) ほかの判定 (clique の fallback) を変える (neos-860300)、(b) 密なカットが LP に残り木を重くする (misc07・ns1830653・eil33-2)。
  (a) は r 形で消え、(b) の木での分離は zhroot で消えるが、根で入れたカットが木に残る分は消えない。
