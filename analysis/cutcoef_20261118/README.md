# cutcoef: カットの評価関数の係数を問題の特徴で変える (2026-11-18)

BRIEF.md の担当の記録。

## 道具
- `src/mip/separation.rs` の `cut_quality` の 2 つの係数を tunable にした: `ENOMOTO_T_CUTSEL_W_OBJPAR` (目的との平行度、既定 0.1)・
  `ENOMOTO_T_CUTSEL_W_INTSUP` (整数の割合、既定 0.1)。既定は不変 (p200x1188c 種 1 で o1i1 にすると根の下界が 15052 → 14607 に変わることで効きを確かめた)。
  `cut_quality` は選び (`cut_score`) と、集約行 1 本の候補から 1 本を残す `keep_best` の両方で使うので、係数は両方に効く。
- `cfg.py` (11 組)・`plan.py` (分担表)・`run.py` (分担を回す、featconst_20261118/cutlen/run.py の写し)。

## 段 1: 伸びしろと、最良の係数の種をまたいだ安定さ
- 格子: (wo, wi) ∈ {0, 0.1, 1}² を α = 0 で 9 組 + α ∈ {0.5, 1} を (0.1, 0.1) で 2 組 = 11 組。BRIEF の 27 組 (3×3×3) は 4 コアでは 1 回り約 12 時間になるので、
  α は既定の係数のときだけにした (α の効きが大きければ段 1 の 2 回り目で組み合わせを足す)。fraccut は段 1 で区切り (親より) なので非整数の台の項は入れない。
  1 ラウンドの上限本数 (featconst 3 の見立て) は評価関数の係数ではないので格子に入れない。
- 問題: P の中で既定が 1〜60 秒で解ける 18 問 (根が退化 roll3000・mc11、固定費用型 sp150x300d・p200x1188c、密なカット qiu・rout など)。
  unitcal_7 などの 60 秒で解けない問題は時間だけでは比べにくいので外した。
- 種 1〜3、4 スレッド・60 秒。`python plan.py 8` で 8 分担 (1 分担 約 0.63 時間)、`python run.py G K`。
