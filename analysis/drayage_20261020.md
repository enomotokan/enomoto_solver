# drayage-25-23・drayage-100-23 を HiGHS がほぼ一瞬で解く理由の調査 (2026-10-20)

- 環境: クラウドのコンテナ (専用)、**CPU 4**。基準のコミット develop bc89ad1 (このブランチ inv/drayage-20261020 の 75accdf と
  ソースは同じ)。試作はこのブランチのコミット (末尾の「コミット」)。HiGHS 1.15.1 (highspy、計測用パッチ版
  `scripts/highs_instrument.patch` も使用)。
- **計測はすべて 4 スレッド** (ENOMOTO は `ENOMOTO_MIP_THREADS=4`・`m.solve(..., 4, log=True)`、HiGHS は `threads=4`)、
  時間上限 60 秒。ソルバーは同時に 1 つだけ動かした。前の調査 (1 スレッド・CPU の取り合いあり) の数値は使っていない
  (`drayage_runs/1thr/` に残す)。
- 実行のスクリプトとログ: `analysis/drayage_runs/` (`eno_run.py`・`highs_run.py`・`side.sh` (副作用の比較)・`summ.py`、
  ログは `4thr/`、HiGHS の計測用パッチ版の抜き出しは `highs_instr/`、比較の結果は `*.tsv`)。

## 0. 要約

**主因は根の下界: ENOMOTO はクリークカットを既定で使わない。** HiGHS の根の下界 (99718.79 → 100121.99) はクリークカットと
implied bound カットの組で上がる (計測用パッチでどちらかを止めると根で動かない)。ENOMOTO は既定でクリークカットを分離しない
(`ENOMOTO_MIP_CLIQUE_CUTS` で有効。以前の 40 問の計測で 10teams などが悪くなったため)。有効にすると根の 1 ラウンド目で
100121.99 (HiGHS と同じ) になり、drayage-25-23 は 60 秒で解けない (下界 99718.79 のまま) → 18〜21 秒で最適 (`=1`/`=root` の
6 回中 5 回。1 回は時間切れ)、対称性の検出も止めると 5 回とも 11〜15 秒。drayage-100-23 は 27.7 秒 → 8〜10 秒 (4 回)。
ただし 40 問の副作用 (30n20b8 が解なしになるなど) で、既定にする候補にはならない (5・6 節)。

1. **根のカット (主因、事実)**: ENOMOTO の既定は根のカット 7 ラウンドで下界 99718.79 から全く動かず、木 2.5 万ノードでも動かない
   (60 秒で 101344、下界 99718.79)。クリークカットを足すと根で 100121.99、再スタート後の根で 1010xx〜1012xx まで上がり最適を証明する。
2. **前処理の大きさは主因ではない (事実)**: 前の調査の候補 (1)。ENOMOTO の probing は時刻 (連続列) の境界を締めるが、その後に
   前処理をかけ直さないので big-M の行が残る (3212 行)。かけ直す試作 (`ENOMOTO_MIP_PROBE_REPRESOLVE`) で **HiGHS と同じ 732 行・
   7745 列** になるが、根の下界は動かず (99718.79 のまま)、暫定解はむしろ遅くなった (失敗、4 節)。
3. **良い解が遅い・揺れが大きい (事実と推測)**: クリークカットを足しても、HiGHS が 1.3 秒に出す 101344 (根のサブ MIP「L」) を
   ENOMOTO は 9〜12 秒に clique のサブ MIP と RINS で出す (根のカットに約 5 秒、根のヒューリスティクスに約 5 秒)。また対称性の
   検出は時間で打ち切るので生成元の数が回ごとに 47〜55 と変わり、lex-leader の行が暫定解を前処理後の問題で不可能にして落とす
   (「the start solution is not feasible in the presolved problem; dropped」)。対称性の検出を止めるとクリークありの揺れが減る
   (推測: lex-leader の行が再スタート後の根のカットと木を不安定にする)。

試作 (どれも既定では使わない):
- `ENOMOTO_MIP_CLIQUE_CUTS=auto` (新規): 根で一度だけクリークカットだけを入れた LP を解き、下界の伸びが目的値の 1e-3 倍
  (`ENOMOTO_T_MIP_CLIQUE_AUTO_GAIN`) を超える問題でだけクリークカットを使う。再スタート後は最初の判定を引き継ぐ。
- `ENOMOTO_MIP_CLIQUE_CUTS=root` (新規): 根の分離でだけ使う (ノードでは使わない)。
- `ENOMOTO_MIP_PROBE_REPRESOLVE` (新規、失敗): probing の後に前処理をかけ直す。

## 1. 問題の構造 (事実)

drayage-25-23: 4630 行・11090 列 (0-1 が 11025、連続 65 (時刻)、目的関数は 0-1 列だけ)。drayage-100-23 も同じ形
(同じ大きさで係数が違う)。
- 210 本: 割当の等式 (0-1 が 105 本、係数 1、右辺 1)
- 4160 本: big-M の時間の行 `a x_a - 60000 x_k - t_u + t_v >= rhs` (0-1 が 2 本・連続 2 本)
- 130 本: 時刻 1 本だけの行 (時間窓。例 `t >= 22225`・`t <= 29425`、幅 7200)。65 本: `t + 38400.6 sum x >= 0` (常に成り立つ)。
  65 本: 0-1 が 1 本の行 (`-16898 x >= -16898.19`、常に成り立つ)
- 時刻の窓は元の問題で 1 列の行として与えられている。前の調査のメモの「時刻の境界が [0, inf) から幅 7200 に締まる」は前処理が
  この行を境界に移しただけ。

## 2. HiGHS (4 スレッド、事実)

| | drayage-25-23 | drayage-100-23 |
|---|---|---|
| 前処理後 | 732 行・7745 列 (連続 35) | 686 行・7716 列 (連続 32) |
| 根の LP | 99718.79 | 103333.87 (= 最適値) |
| カット後の根 | 100121.99 (分離 4〜5 ラウンド目で 99843 → 100122) | 103333.87 |
| 最初の解 | 0.1 秒 FJ 264620 | 0.2 秒 FJ 299137 |
| 暫定解の推移 | 1.3 秒「L」(根のサブ MIP) 101344 → 再スタート (24.2% の列が固定、493 行・5838 列) → 1.8 秒「H」101282.65 | 0.6 秒「H」103333.87 |
| ノード | 1 (1.76 秒で最適) | 1 (0.61 秒で最適) |

- 「H」は HiGHS の RENS/RINS の中の LP つきダイブ (`HighsSearch` を `setHeuristic(true)` で回す) で LP 解が整数になったときの解。
- **計測用パッチで分離器を止めた結果 (drayage-25-23、`highs_instr/`)**: tableau (`HIGHS_SKIP_SEP=0`)・経路集約 (1)・mod-k (2) を
  止めても根の下界は 100121.99 まで上がり 1.8〜2.5 秒で解ける。**implied bound (`HIGHS_NO_IMPLB`) を止めると 16 ラウンド下界が
  動かず 7.3 秒、クリーク (`HIGHS_NO_CLQ`) を止めると 20 ラウンド動かず 17.4 秒・3078 ノード**。根の下界はクリークカットと
  implied bound カット (相手が連続の時刻の列のもの: `x = 1 ⇒ t <= b` から `t <= u - (u - b) x`) の組で上がる。
- HiGHS も最初の 3 ラウンドは下界が動かない (LP の目的値が退化していて、カットで頂点が動いても値が変わらない)。

## 3. ENOMOTO (4 スレッド、事実)

### 3.1 既定 (基準)

| | drayage-25-23 | drayage-100-23 |
|---|---|---|
| 前処理後 | 3212 行・7775 列 (1.08 秒) | 3159 行・7749 列 |
| 対称性 | 52 生成元・lex-leader 559 行 | 50 生成元・479 行 |
| 根の LP | 99718.79 | 103333.87 |
| カット後の根 | **99718.79 (6 ラウンド・平均の非零 2、4.2 秒)** | 103333.87 |
| 最初の解 | 3.47 秒 FJ 304636 | 3.56 秒 FJ 278964 |
| 暫定解の推移 | 5.2 秒 clique 110852、5.3 秒 RINS 102112 → 再スタート (1150 行) → 19.4 秒 101344 | 7.6 秒 clique 111938 → 再スタート → 17.9 秒 103333.87 |
| 60 秒の時点 | 101344.27・下界 99718.79 (25346 ノード、時間切れ) | 27.7 秒で最適 (18221 ノード) |

- 再スタートの前処理で初めて 3873 → 1150 行に減る (probing で締めた時刻の境界が前処理に入るため。4 節)。
- 再スタートの直後に「the start solution is not feasible in the presolved problem; dropped」と出る: 前の暫定解 102112 は
  lex-leader の行 (対称性) を満たさず、再スタート後の問題に渡されない (打ち切り値としては渡る)。

### 3.2 クリークカットの効果

根だけ (`ENOMOTO_MIP_NODE_LIMIT=1`) で: `ENOMOTO_MIP_CLIQUE_CUTS=1` → 根の 1 ラウンド目で 99718.79 → **100121.99** (HiGHS と同じ)。
衝突グラフは 637551 辺 (行から 636136、probing の含意を足して 1415 増える)。implied bound を 0-1 どうしにも広げても
(`ENOMOTO_MIP_IMPLBD_CUTS`) 同じ 100121.99。ENOMOTO の既定の implied bound カット (相手が連続の列のもの) はすでに入っている。

60 秒・4 スレッドの通し (結果の時間、`*.tsv` と `4thr/`):

| 設定 | drayage-25-23 | drayage-100-23 |
|---|---|---|
| 既定 | 60 (時間切れ 101344、下界 99718.79)。ほかに既定と同じ動きの回 (`PROBE_REPRESOLVE` の 1 回) も 60 (同) | 27.7 |
| `CLIQUE_CUTS=1` | 19.4 | 8.5 |
| `CLIQUE_CUTS=root` | 60 (時間切れ、101344・下界 101000)、18.1、17.9、20.8、21.2 | 8.6、10.1 |
| `CLIQUE_CUTS=root` + `RENS_DIVE` | 23.7、61 (時間切れ、101282.65・下界 101208) | 8.6、10.3 |
| `CLIQUE_CUTS=auto` | 60 (時間切れ、101282.65・下界 101208)、18.1、60 (時間切れ、101282.65・下界 100733) | 20.5、15.0、27.2 (判定で使わない) |
| `CLIQUE_CUTS=auto` + `CUT_STALL_ONE` | 29.8、27.1、26.7 | — |
| `NO_SYMMETRY` | 60 (時間切れ、下界 99718.79)、60 (同) | 14.9、22.4 |
| `CLIQUE_CUTS=1` + `NO_SYMMETRY` | **13.6、11.0** | **7.9、8.1** |
| `CLIQUE_CUTS=auto` + `NO_SYMMETRY` | **14.5、14.5、14.9** | 58.7、13.1 (判定で使わない) |

- クリークありの成功の回の流れ (drayage-25-23、`eno_c_`): 根のカット 4.6 秒で 100121.99 → 根のヒューリスティクス (被約費用・
  LP face のサブ MIP が 3.8 秒ずつ時間切れ) → 12.0 秒 clique のサブ MIP 103334、RINS 101344 → 再スタート (1856 列を固定、927 行) の
  根のカットで 101003 → FP 101282.65 → 再スタート 2 回目の根で下界が最適値に届き 0 ノードで終わる。
- **失敗の回 (時間切れ) は再スタート後の根のカットのループが 6 ラウンドで止まり、下界が 100121.99 から上がらない**
  (成功の回は 13 ラウンド回り、4 ラウンド目から 100339 → 101003 と上がる。HiGHS も最初の 3 ラウンドは動かない)。ENOMOTO の
  停滞の判定は、目的値も分数の列の数も減らないラウンドを 2 回分と数え 10 回分で止める。`ENOMOTO_MIP_CUT_STALL_ONE` (1 回分と
  数える) では 3 回とも解けるが 27〜30 秒。
- 対称性の検出は 0.3 秒で打ち切るので、生成元の数が回ごとに 47〜55・lex-leader の行が 359〜679 本と変わる。これが同じ設定でも
  経過が変わる一因 (推測)。対称性を止めると (`ENOMOTO_MIP_NO_SYMMETRY`) クリークありの回はどれも 11〜15 秒で解ける。
- drayage-100-23 は根の LP 値が最適値なので、クリークカットは下界ではなく LP 解を変えて効く (カット後の LP 解で根の RENS が
  7.3 秒に最適解を見つける)。auto の判定 (下界の伸び) では使われない。分数の列の数の減り方で判定する案
  (`ENOMOTO_T_MIP_CLIQUE_AUTO_FRAC`) は、根の LP の頂点が回ごとに違い (分数の列 164 → 145 の回と 128 → 152 の回がある) 使えなかった。

## 4. 前処理の大きさ (事実)

- 前の調査で未確認だった点: ENOMOTO の probing は「2210 bounds tightened」と出るとおり、時刻の列の境界を締める (x_k = 0 と 1 の
  両方で締まる境界)。しかし probing は前処理の最後なので、締めた境界で冗長になった big-M の行・強められる係数はそのまま残る。
  再スタートの前処理ではこの境界が入るので 3873 → 1150 行に減る。
- 試作 `ENOMOTO_MIP_PROBE_REPRESOLVE` (probing が境界を締めたら前処理をかけ直す、最大 2 回): drayage-25-23 で
  3212 → **732 行・7745 列 (HiGHS と同じ)**、drayage-100-23 で 686 行・7716 列 (HiGHS と同じ)。しかし
  - 根の下界は 99718.79 のまま (カットの非零が平均 2 → 50〜100 に増えるだけ)。60 秒で 101344・下界 99718.79 (既定と同じ)。
  - 対称性の lex-leader の行が 559 → 1599 本に増え、並列の FJ が解を見つけなくなり、最初の解が 3.5 秒 FJ 304636 → 5.4 秒 trivial 985825 に遅れた。
  - クリークと組み合わせても drayage-25-23 は 32.8 秒 (クリークだけは 19.4 秒)、drayage-100-23 は 7.9 秒 (8.5 秒)。
  → **主因ではない。採用しない**。LP は小さくなる (根の 1 ラウンドの分離 0.7 秒は変わらない) が、効かない。

## 6. 既定にする候補か・見込み

- **クリークカット (`ENOMOTO_MIP_CLIQUE_CUTS=1`/`root`/`auto`) はこのままでは既定にしない**。drayage の 2 問には大きく効く
  (drayage-25-23 は 60 秒で解けない → 11〜21 秒、drayage-100-23 は 15〜28 秒 → 8〜10 秒) が、常に使うと misc07 が 7 → 10 秒、
  auto で判定しても 30n20b8 が解なしになり (既定は 402)、timtab1・beavma が悪くなる。良くなるのは neos-860300・dcmulti。
  40 問の残りの 32 問では auto は使わない (動きは既定と同じ、判定の手間は 0.7 秒以下) ので、auto の 40 問での差は上の 8 問で決まる:
  良くなる 2 問 (neos-860300 −6 秒・dcmulti −0.4 秒) と悪くなる 3〜4 問 (30n20b8・timtab1・beavma、neos-1456979 は揺れ) で、
  解けた数は変わらず、主ギャップの和は 30n20b8 の解なしで大きく悪くなる見込み。
- 30n20b8・timtab1 の悪化は根の下界ではなく暫定解 (根の LP 解が変わり、根の RENS などが解を見つけなくなる。30n20b8 は既定でも
  47 秒に 1 回だけ解が出る問題) と見られる (推測。ログは取っていない)。主側の弱さ (mip_primal_weakness_20261016.md) が直れば
  クリークカットを既定にできる可能性がある。
- `ENOMOTO_MIP_PROBE_REPRESOLVE` は HiGHS と同じ大きさの前処理になるが効かず、暫定解が遅れるので候補にしない。
- 揺れの元として、対称性の検出の打ち切り (0.3 秒、`ENOMOTO_T_MIP_SYM_TIME`) で生成元の数が回ごとに変わることと、再スタート後の
  根のカットのループの停滞の判定 (動かないラウンドを 2 回分と数える) が drayage-25-23 の成否を分けている。どちらも既定を変える
  前に 40 問で見る必要がある (以前の調査で `CUT_STALL_ONE` は misc07 などを悪くしている)。

## 7. 確かでない点

- 再スタート後の根のカットのループが 6 ラウンドで止まる回と 13 ラウンド回る回の差が何で決まるか (対称性の行の数か、
  前の根の LP 解の違いか) は確かめていない。
- 対称性の行が経過を不安定にする仕組み (暫定解が落ちること以外) は推測。HiGHS 1.15.1 はこの問題のログに対称性を出さない。
- HiGHS が 1.3 秒に 101344 を出す「L」がどのサブ MIP (RENS か RINS か) かは確かめていない。ENOMOTO の根のヒューリスティクスは
  被約費用・LP face のサブ MIP が 3.8 秒ずつ時間切れで、良い解が出るまで 5 秒かかる。
