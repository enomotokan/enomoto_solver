## mzzv42z

### 事実 (既定 3 回・HiGHS 2 回、`log/mzzv42z_{def_s*,highs*}.txt`)

| 段 | HiGHS | ENOMOTO (既定) |
|---|---|---|
| 前処理 | 10460 行・11717 列 → **6139 行・6980 列** (21 秒。Enumeration 1076 列固定・probing で 2276 列を消す・支配列 126) | **10460 → 10460 行、11717 → 11717 列** (何も減らない)。プロービングの固定 355 列などは境界にだけ当たる (大域に固定 1024 列) |
| 根の LP | -21414 (前処理後の模型) | -21534 |
| 根のカットの後 | -20738 (最初の根) | -20826〜-20797 (裏のカットの後) |
| 最適値 -20540 | 23.4 秒 (根のサブ MIP) | 63 秒 (s0、再スタート後の根の RINS) / **460 秒** (s1、木) / 141 秒 (s2、木) |
| 再スタート | 2 回 (29 秒・40 秒、固定 14.6%・4.3%)、模型 4129 行・5086 列 | 1 回 (40〜42 秒)、模型 9334〜9415 行・9163〜9213 列 |
| 木 | 1 ノード (根の強分枝 11202 反復で閉じる) | 55 / 583 / 105 ノード。ノードの最初の LP が 1 回 3619〜4043 反復 |

- 遅い回 (s1・s2) は、根の終わりの暫定解が -20500 で、再スタートの前処理で「前処理後の模型で実行不能」として捨てられ (`dropped (kept as the RINS reference)`)、
  再スタート後の根の発見法の多くが `skipped (no solution before the restart)`、根の被約費用のサブ MIP は 6 秒の上限で 0 ノード。木は暫定解なし (`ub inf`) で
  ALNS も役のスレッドも動かず、-20540 は木の丸め (`other thread (tree)`) が 141 秒・460 秒に見つけた。これは前の調べ (analysis/fragility_20261105/mzzv42z.md)
  と同じ型 (暫定解の型)。
- 揺れ (事実): 同じ機械・既定で 130〜600 秒。前の調べでは種 0〜10 で 108〜600 秒 (中央値 221 秒)。それでも 3 回とも HiGHS (48 秒) の 2.7 倍以上なので系統的な差。

## neos-957323

### 事実 (`log/neos-957323_{def_s*,highs*}.txt`)

- 3 回ともほぼ同じ経路: 根の LP -237.757408 (14445 反復、3.5 秒)、26 秒に LP face のサブ MIP が最適値 -237.756681 を見つける。根の下界は -237.757075 で
  相対ギャップ 1.66e-6。そこから **再スタート 4 回** (27 秒・+23.5 秒・+29.8 秒・+21.0 秒) で、4 回目の後の根の LP が暫定解に一致して 0 ノードで終わる。
- 再スタート 1 回の中身 (restart 1 の後の根、s0): 前処理・プロービング・クリーク拡張 約 3 秒、根の LP 2.5 秒、主のカットのループ 9 秒 (6 ラウンド。目的値が動くのは
  1 ラウンド目だけ: -237.75707531 → -237.75697464、以後同じ)、根の発見法 1 秒、**裏のカットの待ち 7.8〜12.3 秒** (裏のカットが -237.756975 → -237.756858 と上げ、
  これで被約費用の固定が 3119 列増えて次の再スタートになる)。
- HiGHS: 根の LP 約 10 秒、カット 41 秒まで (下界 -237.757408 のまま)、61 秒にサブ MIP で -234.763、木で 70〜88 秒に最適値と証明 (168 ノード、強分枝の反復 0)。
  **対称性を切っても 84.0 秒・101 ノード** (`highs_nosym`) なので、HiGHS の決め手は対称性ではない。
- ENOMOTO の対称性の検出は手間の上限 (2.5e7) で止まり 1 個の orbitope (1644 列) だけ。G6 の試作 (`HO6_SYMWORK` など) で 8 個・57319 列を見つけるが、
  経路は同じで 133.2 秒 (`sym_s0`)。対称性は敗因ではない。
- **木では閉じない** (事実、試作 `S4_TINYGAP=1` で 1 回目の再スタートの後に木へ進めた回 `tg1_s0`): 600 秒・3628 ノード (主のスレッド) で下界 -237.756858 のまま。
  開いたノードがノード数とほぼ同じ速さで増える (刈れない)。`branching: 2972 selections, 2971 without strong branching for dual degeneracy` で、
  ほぼ全ノードで双対退化 (非基底の被約費用 0 の割合 0.8 以上か、列と行の比 2 以上) を理由に強分枝を飛ばしている。
  既存の `ENOMOTO_MIP_SB_NO_DEGEN_SKIP=1` を足すと (`tg1nds_s0`) **807 ノード・164.9 秒で閉じる** (強分枝 298 回)。
- 推測: HiGHS も強分枝の反復が 0 なので、HiGHS が 168 ノードで閉じる理由は強分枝ではなく、擬似費用の初期化かノードの選び方の違い。確かめていない。

### 試作と効き目

| 設定 | 結果 | 回 |
|---|---|---|
| 既定 | 128.5 / 125.6 / 120.5 | 3 |
| `S4_TINYGAP=1` (この記録の試作: 相対ギャップ 1e-5 以下なら 2 回目以降の再スタートをせず木へ) | **時間切れ** (下界 -237.756858) | 1 (明らかに悪いので 2・3 回目は止めた) |
| `S4_TINYCUT=1` (この記録の試作: 再スタート後の根でギャップが小さければ主のカットのループを 1 ラウンドに) | **時間切れ**: 再スタート 1・2 は 23.5 → 15.6 秒・→ 18.1 秒と短くなるが、裏のカットの上げ幅が変わって再スタート 2 の後の固定が閾値に届かず 3 回目の再スタートが起きず木に入る | 1 (同上) |
| `S4_TINYGAP=1` + `SB_NO_DEGEN_SKIP=1` | 164.9 (木 807 ノードで閉じる) | 1 |
| `SB_NO_DEGEN_SKIP=1` だけ | 125.1 (木に入らないので既定と同じ経路) | 1 |
| 対称性の試作 (G6 の設定) | 133.2 | 1 |

- 判断: 再スタートの連鎖は「裏のカット → 被約費用の固定 → 再スタート」がかみ合って初めて進み、どこかを削ると木に落ちて (木が閉じないので) 大きく負ける。
  短くするには木そのもの (退化したノードでの分枝の選び方) を直す必要がある。`S4_TINYGAP`・`S4_TINYCUT` は使わない。

## cod105

### 事実 (`log/cod105_{def_s*,highs*}.txt`)

- 1024 行・1024 列・57344 非零の密な 0-1 問題。前処理は両方とも何も減らさない。HiGHS は「目的関数は刻み 1 の整数」、対称性の生成元 11 個 (ENOMOTO も 11 個)。
- ENOMOTO の時間の使い方 (s0、3 回とも ±2 秒で同じ):

| 段 | 秒 |
|---|---|
| 前処理の LP プロービング (根の LP 10.1 秒 + 子の LP 6 本 20 秒、固定 0) | 30.4 (求解の時計の外) |
| 根の LP (基底を受け取り 1 反復)・0.35 秒に oneopt で **最適値 -12** | 0.3 |
| カット選択の試し (カット 1 本、利得 2e-13) と 1 ラウンド目 (LP が上限で外す) | 18.6 |
| 根の発見法: 内点法の丸め 2.9 秒、**RINS のサブ MIP 76.2 秒** (固定率 0.32、700 列が自由、113 ノードでノード上限、外側の暫定解を良くしない) | 79.4 |
| 根の強分枝 (74 回) | 22.4 |
| 木 (主 85 ノード、全体 337) | 48.5 |
| 計 | 200.5 |

- HiGHS: 根の LP 約 8 秒、22.5 秒に -3、40.8 秒にサブ MIP で -12、木 41〜111 秒 (103 ノード)。ENOMOTO の木 (48 秒) は HiGHS の木 (70 秒) より速く、
  差は根の前段 (ENOMOTO 約 152 秒 対 HiGHS 約 41 秒) にある。
- RINS を切る (既存の `NO_ROOT_RINS=1`、3 回): 159.4 / 157.7 / 166.7 秒。今度は **裏のカットの待ちが 38 秒** (`waited 37.99s`、1 ラウンド 5〜8 秒の 6 ラウンドとも
  -18.2857 のまま。既定では RINS の 76 秒の裏で回っていたので待ちは 0 秒だった)。裏のスレッド自身の停滞の判定が窓 5 ラウンドなので、6 ラウンド回るまで止まらない。
- 既存の `ENOMOTO_T_MIP_SUBMIP_NOSOL_CAP=50` (解のないサブ MIP を 50 ノードで止める) は効かない (200.8 秒): RINS のサブ MIP は -2 (外側の暫定解 -12 より悪い)
  を見つけていて「解なし」に当たらない (サブ MIP が外側の打ち切り値より悪い解を持つ理由は確かめていない)。
- LP プロービングを切る (既存の `NO_LP_PROBE=1`、1 回): 182.6 秒 (-18 秒)。600 秒では LP プロービングの予算が時間の上限の 5% (30 秒) で、
  固定 0 のまま 20 秒使う。
