## 1. 定義 (SCIP と同じにした)

SCIP の `SCIProwGetLPSolCutoffDistance` (`src/scip/lp.c`) と `cutsel_hybrid.c` のソースで確かめた:

- d̂ = (x* − x) / ‖x* − x‖ (x: 今の LP 解、x*: 暫定解、全列)。s = a·d̂、|s| < 1e-6 なら 1e-6。
  **DCD = (a·x − b) / |s|**。正しいカットは x* で成り立つので DCD = t·‖x* − x‖ (t ∈ (0, 1] は線分のうち切り落とす割合)、
  |s| <= ‖a‖ なので DCD >= 効き目。
- SCIP のスコア: 効き目の重み × 効き目 + DCD の重み × max(DCD, 効き目) + 0.1 × 目的との平行度 + 0.1 × 整数割合。
  暫定解がない (か DCD の重みが 0) なら (効き目の重み + DCD の重み) × 効き目 + …。既定の重みは効き目 1・DCD 0・平行度 0.1・整数 0.1。

試作 (`src/mip/separation.rs`、根のカットのループの選択。固定費用型の緩めた選択・第 2 段階・`CUTSEL_HIGHS` の方が優先。裏のカットのループでも働く):

| 環境変数 | 中身 |
|---|---|
| `ENOMOTO_MIP_CUTSEL_DCD=<w>` | 上の SCIP の式 (`select_cuts_hybrid_dcd`)。効き目の重みは `ENOMOTO_T_CUTSEL_EFFW` (1) |
| `ENOMOTO_MIP_CUTSEL_NORM=1` | 効き目と DCD をそのラウンドの候補の最良で割って 0〜1 にしてから同じ式 |
| `ENOMOTO_MIP_CUTSEL_DCD_PROD=1` | 暫定解があれば積の形: b = max(DCD, 効き目) / 非零の数^α (`ENOMOTO_T_CUTSEL_DCD_DENS_EXP`、0.5)、b が最良の 0.5 倍未満は捨て、b × (1 − 採ったカットとの |cos| の最大) の大きい順に 1 本ずつ採る (|cos| > 0.7 は捨てる)。暫定解がなければ既定とまったく同じ (`select_cuts_dcd_prod`) |
| `ENOMOTO_MIP_CUT_KEEP_DCD=θ` | 緩んだカットを外すとき、暫定解があれば、x → x* の線分の上で超平面に当たる割合 t = (b − a·x)/(a·d̂)/‖x* − x‖ が θ 以下のものを t の小さい順に `ENOMOTO_T_MIP_CUT_KEEP_DCD_MAX` (50) 本まで残す (`remove_inactive_cuts_root`) |
| `ENOMOTO_MIP_CUTSEL_DCD_SOL=ファイル` | 診断用: 暫定解の代わりにこの点 (1 行 1 値、前処理なしのときだけ列が合う) へ向かう方向を使う |
| `ENOMOTO_MIP_DEBUG_CUTSEL` | `CUTSEL_DCD:` (DCD/効き目の分位) などを出す |

足切り (最良の 0.5 倍)・平行度 0.3 (良いカット 0.7)・50 本はどれもそのまま。

## 2. 結論

事実:

1. **roll3000 の 1 ラウンド (HiGHS のラウンド k の LP、前処理なし) で、DCD を入れると密なカットが採られ HiGHS に追いつく**。
   k = 3 で HiGHS の次のラウンドのカット 22 本だけを候補に (only): 既定 9 本 11349 → DCD=1 で 12〜14 本 **11646** (HiGHS 11648、閾値なしは 11648)。
   ENOMOTO 自身の候補だけ (none) でも 11359 → 11652 (HiGHS の最適解へ)、11842 (ENOMOTO の根の暫定解へ)。k = 6 none: 11789 → 12153〜12163 (HiGHS 11893)。
2. **生の DCD はスコアをほぼ独占する**。DCD はラウンドの中で t·‖x* − x‖ (roll3000 k = 3 で ‖x* − x‖ = 2224〜2885)、効き目は 0.1〜0.4。
   DCD/効き目の中央値は 1.7〜1.8 万倍。重み 0.5 と 1 の結果はすべて同じ。選択は「t の大きい順 (暫定解の近くを通るカット)、足切りは t が最良の半分以上」になる。
3. 0〜1 にそろえる版 (NORM) と、密度で割る積の形 (α = 0.5) は伸びが小さい。α = 0.5 は既定と同じ値に戻る (k = 3: 11349、k = 6: 11789)。
   積の形 α = 0 (DCD × (1 − 平行度)) は生の和の形と同程度 (勝ち負けあり)。
4. **根のループ全体 (roll3000、前処理なし、1 スレッド、25 ラウンド、暫定解を最初から与える)**: 既定 11827 → DCD 選択 **12434** (HiGHS の 25 ラウンド目 12360、最後 12494)。
   外す基準だけ 11887〜11896、両方 12425〜12499 (2 回目のループで 12505〜12518)。LP に残るカット 139 → 185〜278 本。
5. **60 秒 (4 スレッド) では、どの設定も既定にできる結果ではない** (§4)。roll3000 は根の最初のループに暫定解がない (最初のラウンドで方向なし)
   ので 4 の伸びは出ない。生の DCD は neos-911970 (35・26 → 17・19 秒、根 47.26 → 51.8、ループの途中 0.36 秒で FJ の暫定解)・beasleyC3
   (38・TL → 17・16)・10teams (23・10 → 7・5) が速く、mik-250 (5〜6 → 13〜15)・mc11 (23・56 → TL・TL) が悪い。積の形 α = 0 は
   mik-250 7〜9・misc07 9・mc11 36〜43 と悪化が小さいが、10teams 25〜26・beasleyC3 TL・TL・h80x6320d 47〜48 (既定 37〜46) で良さもない。

推測:

- 生の DCD (`DCD=1`) の 60 秒の結果のうち、暫定解がないときの扱い ((1 + w) × 効き目、平行度・整数割合の重みが相対的に半分) が効いている
  部分が大きい。roll3000 (12373 → 12210〜12265)、qnet1 (15814 → 15650〜15661)、misc07 (1534 → 1571) の根の下界は、最初のループに暫定解がない
  のに変わる。DCD そのものの効果と分けるには、暫定解がない間は既定のまま (積の形と同じ) の和の形を作って比べる必要がある (未実施)。
- 1 ラウンドの結果からは、DCD は「退化した LP で効き目が下界の伸びを表さない」問題をよく解く。実際の求解で効くかは、根のループの間に
  良い暫定解があるかで決まる (neos-911970 はある、roll3000 はない)。
