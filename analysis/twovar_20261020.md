機械は 4 CPU (`nproc` = 4、専用コンテナ)。基準はブランチ `inv/twovar-20261020` の起点 `300600f` (develop + 9 つの調査の試作)。
試作はすべて環境変数で有効にし、既定は変えていない。**計測はすべて 4 スレッド** (ENOMOTO は `ENOMOTO_MIP_THREADS=4`・

## 1. 結論

事実:

1. **「2 変数の ±1 の不等式 4190 本 (HiGHS 562 本)」は、クリーク行の拡張 (CLIQUE_EXTEND) の前の数**だった。
   `ENOMOTO_MIP_DEBUG_DUMP_PRESOLVED` は `extend_clique_rows` の前に書き出す。拡張の後 (新しく足した
   `ENOMOTO_MIP_DEBUG_DUMP_PRESOLVED2` で書き出す) では 2 変数の行は **549 本** (詰め込み 214・含意 334・被覆 1) で、
   HiGHS の 562 本 (詰め込み 215・含意 347) と数がほぼ同じ。**HiGHS の 562 本のうち 554 本は ENOMOTO の前処理後にも
   同じ行がある**。拡張の前の 4190 本も、衝突グラフ (2 変数の行だけ) の三角形に入るのは 69 本・含意の強連結成分は 0・
   推移的に冗長は 24 本で、残りは長いクリーク行に含まれる (1052 本) か拡張で長い行に吸収される。HiGHS の前処理後も
   三角形 0・強連結成分 0。よって課題の (a) クリーク被覆・(b) 強連結成分は効く余地がなく、作らなかった。
2. 拡張の後に残る差は **0-1 列の数** (ENOMOTO 5435 本、HiGHS 4185 本。ENOMOTO にだけ残る 0-1 列 1277 本) と 3 変数の行。
   HiGHS の規則を 1 つずつ切ると、この差の大半 (915 列、うち 0-1 列 839) は HiGHS の **Probing** が消している。
   ENOMOTO のプロービングを HiGHS の Probing を切った前処理後の問題にかけても、固定 0・締め付け 23・同値 8 組しか出ず、
   衝突グラフの上の 1 段の推論 (x と ¬x の両方と衝突、対の同値、強連結成分) では 1 本も説明できない。
3. 違いはプロービングの伝播: HiGHS はプロービングで見つけた含意 (`x_j = 1 ⇒ x_k = 0`) をクリーク表に入れ、後の列の
   プロービングの伝播に使う。行の伝播では含意の対偶 (`x_k = 1 ⇒ x_j = 0`) が見えないことがある。同じことを ENOMOTO の
   プロービングに入れる (`ENOMOTO_MIP_PROBE_CLIQUE`) と、physiciansched6-2 で **同値な 0-1 列の組が 8 → 1084 組**、
   前処理後が **11896 × 5991 → 9868 × 4977** (HiGHS 8861 × 4608) になる。根の LP は 48583.1 のまま (2.0〜2.2 秒、
   all4 は 4.8 秒)。60 秒 2 回で解はまだ出ない。
4. FJ が通るかの境目は、HiGHS の **Sparsify** と支配される列の固定だった。新しい前処理後 (pc) に HiGHS の前処理を
   かけると FJ が 3 回とも解を出す (51329、2.3 秒。前の調査で同じことを all4 の後にしたときは 3 回中 1 回)。HiGHS の
   規則を 1 つずつ切ると、**Sparsify を切ったときだけ FJ が解を出せない** (違反 21 行)。Sparsify が書き換えたのは長い行
   4 本だけで、たとえば勤務の数の行 `Σ (77 列) ≤ 26` から、その列の部分集合の互いに素な等式 18 本 (各 `Σ = 1`、計 66 列)
   を引いて `Σ (11 列) ≤ 8` にする。
5. Sparsify (`ENOMOTO_MIP_SPARSIFY`) と支配される 0-1 列の固定 (`ENOMOTO_MIP_DOMCOL`) を ENOMOTO に入れると前処理後は
   9522 × 4731 になるが、FJ は違反 16〜18 行で止まり、60 秒 2 回で解なし。ENOMOTO の疎化の後に HiGHS の前処理
   (Sparsify を切って) をかけると FJ は解を出す (50427) が、HiGHS の基本の縮約 (規則を全部切る) だけでは違反 1〜2 行。
   HiGHS はこの段でさらに支配される列を 33〜72 本固定する (ENOMOTO の DOMCOL より広い。§2.6)。

推測:

- FJ を通すには HiGHS の前処理に含まれる複数の縮約 (含意を使うプロービング・Sparsify・支配される列・その後の
  かけ直し) が全部要り、単独で FJ を通す規則はない (前の調査の「単独で FJ を通す規則はない」と同じ)。ENOMOTO は
  3 つを足して違反 18 行前後までで、残りは支配される列の固定の広さ (連続列・整数列との比較、HiGHS の
  "implied" の判定) と、HiGHS の Probing がする他の縮約 (クリーク表の置き換えなど) と見ている。
- 2 変数の行が FJ を止めている主因ではない (2 変数の行の数は HiGHS と同じになった後も FJ は通らない)。

## 2. 調べたこと

### 2.1 2 変数の ±1 の不等式の内訳 (`twovar_census.py`)

physiciansched6-2、all4 の前処理後。形は「文字の和 ≤ 1」に直したもの。`tri2` = 2 変数の行だけの衝突グラフで辺が三角形に入る、
`triA` = 長いクリーク行も含めたグラフで三角形に入る、`dom` = 両端を含む長いクリーク行がある、`scc` = 含意の有向グラフ
(辺 {a,b} は a → ¬b、b → ¬a) で a と ¬b が同じ強連結成分、`trans` = 長さ 2 の別の道で導ける。

| 前処理後 | 形 | 本数 | tri2 | triA | dom | scc | trans |
|---|---|---|---|---|---|---|---|
| ENOMOTO all4 (拡張の前) | 詰め込み `x+y≤1` | 3833 | 69 | 1121 | 1052 | 0 | 24 |
| | 含意 `x−y≤0` | 356 | 0 | 0 | 0 | 0 | 0 |
| | 被覆 `x+y≥1` | 1 | 0 | 0 | 0 | 0 | 0 |
| ENOMOTO all4 (拡張の後) | 詰め込み | 214 | 0 | 0 | 0 | 0 | 0 |
| | 含意 | 334 | 0 | 0 | 0 | 0 | 0 |
| | 被覆 | 1 | 0 | 0 | 0 | 0 | 0 |
| HiGHS | 詰め込み | 215 | 0 | 0 | 0 | 0 | 0 |
| | 含意 | 347 | 0 | 2 | 2 | 0 | 0 |

含意の有向グラフの自明でない強連結成分はどの問題でも 0。2 変数の行だけの辺の貪欲なクリーク被覆は 4144 個で、3 個以上の
クリークは 23 個 (どれも 3 個) だけ。拡張の後の 549 本を HiGHS の前処理後と列の名前で突き合わせると、詰め込み 214 本・
含意 332 本は HiGHS にも同じ行があり、含意 2 本・被覆 1 本は HiGHS では片方の列が消えている (`twovar_vs_highs.py`)。

### 2.3 HiGHS の Probing が消す列 (`probe_gap.py`)

HiGHS の前処理で Probing だけを切った問題 P0 (9570 × 5523) と既定 (8861 × 4608) を比べると、Probing が消すのは 915 列
(0-1 列 839)。HiGHS のログは「4775 probing evaluations: 96 deleted rows, 755 deleted columns, 1783 lifted nonzeros」。
P0 の行から作った衝突グラフ (19120 辺) の上で、消える 839 本について「文字が x と ¬x の両方と衝突 (偽に固定)」「対の
同値 (x と y、¬x と ¬y が衝突)」「強連結成分」を数えるとどれも 0。P0 を ENOMOTO (all4) にかけると、プロービングは
5001 列を試して固定 0・締め付け 23・同値 8 組、前処理後 9525 × 5492。

### 2.4 含意を使うプロービング (`ENOMOTO_MIP_PROBE_CLIQUE`)

`probe` で 1 列を試すたびに、見つけた衝突の組 (含意) を `Domain::add_implications` で定義域の含意の伝播 (既存の
`ENOMOTO_MIP_IMPL_PROP` と同じ仕組み) に足し、後の列のプロービングの伝播に使う。HiGHS のクリーク表の伝播に当たる。

physiciansched6-2 (all4 と併用): プロービング 5444 列 (0.05 → 0.08 秒)、含意 77450 → 98038、同値な組 8 → **1084**。
同値の代入 (`PROBE_EQUIV`) の後 9868 × 4977 (非零 35876)。2 回目のプロービングで新しい同値は 0。

### 2.6 疎化 (`ENOMOTO_MIP_SPARSIFY`) と支配される 0-1 列 (`ENOMOTO_MIP_DOMCOL`)

- 疎化: 等式の行の列がすべて行 r に含まれるとき、r から等式の倍数を引く (フィルインなし。倍率は消える列の最も多いもの、
  整数の行では整数の倍率だけ)。最初の版は 1 行に 1 本の等式だけ引いたため、77 列の行に先に 4 列の等式を 1 本引いて
  終わり、HiGHS の形にならなかった (FJ の違反 29〜42 に悪化)。1 行から複数の等式を引けるように直した (書き換えた行は
  等式として使わず、等式として使った行は書き換えない)。physiciansched6-2 では最初の前処理の後に 81 行を疎にする。
- 支配される 0-1 列: 文字 (`x` か `1 − x`) どうしで、費用と全行の係数で y_j が y_k を支配し、(a) y_j と y_k が衝突する、
  か (b) y_j の上限 1 が 1 本の行から導けるなら y_k = 0 に固定する (Gamrath ら 2015、HiGHS の dominated columns の 0-1 列
  どうしの場合)。最初の版は (a) の、否定のない文字だけで、physiciansched6-2 で 48 列。否定と (b) を足して、その
  前処理後にさらに 13 列。HiGHS は ENOMOTO (full) の前処理後でさらに 33 列 (Sparsify の後なら 72 列) を固定する
  (連続列・整数列との比較や、行の活動の範囲から導く "implied" の判定を含むためと見ている。確かめていない)。
- full の前処理後は 9522 × 4731。FJ は違反 16〜18 行。ENOMOTO の疎化の後の問題に HiGHS の前処理 (Sparsify を切る)
  をかけると FJ は解を出す (50427)。HiGHS の基本の縮約だけでは違反 1〜2 行。

## 3. 試作 (既定では使わない)

## 4. 既定にする候補か

- `ENOMOTO_MIP_PROBE_CLIQUE`: physiciansched6-2 では同値を 8 → 1084 組にし前処理後を 2 割小さくする (根の LP が 4.8 → 2.1 秒)。

  pcsd には `PROBE_EQUIV` が入っておらず PROBE_CLIQUE は含意の数を変えるだけなので、これが原因とは言えない)。
  `PROBE_EQUIV` と組で既定の候補 (前の調査の `MERGE_REPRESOLVE`・`PROBE_EQUIV` と一緒に 40 問で確かめる)。
- `ENOMOTO_MIP_DOMCOL`: fiber の根を上げ (390913〜392977 → 400577)、30n20b8 の根も上げる (138.4 → 150.0、pcsd)。代わりに
  集合分割の大きな問題で前処理が 0.4〜0.6 秒延びる (air03・nw04)。最適解を減らす縮約なので、既定にするなら 40 問 + 16 問での
  確認と、対称性・サブ MIP との組み合わせの確認が要る。候補だが優先は低め。
- `ENOMOTO_MIP_SPARSIFY`: 40 問の多くで行を書き換えるが、効果も悪化もはっきりしない。physiciansched6-2 では HiGHS の形には
  なるが単独では FJ を通さない。候補にしない (HiGHS と同じ選び方にするまで)。
- どれも physiciansched6-2 で解を見つけるには至っていない。

## 5. 確かでない点・うまくいかなかったこと

- 課題の (a) クリーク被覆・(b) 含意の強連結成分は、内訳 (三角形 69 本・強連結成分 0) から効かないと判断して作らなかった。
- FJ が ENOMOTO 単独で解を出すところまでは届かなかった。HiGHS の前処理をかければ通るが、どの縮約の組み合わせが
  最小で足りるのかは特定していない (HiGHS の規則は 1 つ切っても通る、Sparsify だけは要る、基本の縮約 + Sparsify では足りない)。
- 疎化の最初の版 (1 行に 1 本) は FJ を悪くした (違反 29〜42)。複数の等式を引く版でも、HiGHS が書き換えない行 (連続列を含む
  5 列の行を 1 列にするなど、physiciansched6-2 で 81 行) まで書き換える。どの行を書き換えるかの選び方で FJ が変わりうる。
- `DOMCOL` は最適解を減らす縮約。単体テストと副作用の問題で最適値が変わらないことは確かめたが、対称性の行
  (`add_symmetry_rows`、前処理の後に作る) やサブ MIP との組み合わせを理論的に詰めてはいない (前処理の後の問題で対称性を
  見つけるので順に正しいはず)。
- HiGHS の支配される列の固定がなぜ ENOMOTO (DOMCOL) より多いのか (33〜72 本) は確かめていない。
