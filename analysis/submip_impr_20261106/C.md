# 担当 C: 暫定解を改善するサブ MIP (RENS・RINS・被約費用) の固定の仕方を HiGHS に寄せる (2026-11-06)

bench に使う環境変数: `ENOMOTO_MIP_SUBFIX=ritc` (設定名 `fix`: 根の RENS・根の RINS・木の RINS をダイブ + 目標の固定率 + 空振りのやり直し、被約費用も共通の統計) /
`ENOMOTO_MIP_SUBFIX=rtch` (設定名 `fixh`: HiGHS の呼び方。根の RENS・木の RINS をダイブにし、**根の RINS を呼ばない**)。既定 (`def`) は何も付けない。

- 機械: 4 CPU (`nproc` = 4)。ソルバーは同時に 1 つ (`C/queue.sh` の待ち行列)。ENOMOTO は 4 スレッド (`ENOMOTO_MIP_THREADS=4`)、`ENOMOTO_MIP_LOG=1`、
  種は `ENOMOTO_T_MIP_SEED` (1・2)。
- ビルド: ブランチ ccr-1beed81b-ex0uhq の 956d0fce (試作の最初の版) と、その後の 1 行の直し (根の RINS のダイブにも既定の `S4_RINSRATE` を当てる、
  「cod105」の項)。8 問の 1 回目の physiciansched6-2〜cod105 の `fix` は直す前 (cod105 の `fix` 1 回目だけが影響を受ける)、cod105 の `fixh` 1 回目は
  ビルドと重なった (2.5 分 CPU を取り合った)。それより後と 58 問はすべて直した後のビルド。
- 台本: `C/run1.py` (1 回、`A/run1.py` の写し)、`C/queue.sh` (待ち行列、`A/queue.sh` の写し)、`C/cfgs.txt` (設定の名前)、`C/summ.py` (集計、SUBFIX の列を足した)、
  `C/bench58.py`・`C/cmp58.py` (58 問、A の写し)。結果は `C/res.jsonl` (8 問)・`C/bench58.jsonl` (58 問)、ログは `C/logs/<設定>_<問題>_s<種>.log.gz`、
  8 問の表は `C/summ8.md`。
- 担当 A (`ENOMOTO_MIP_SUBA_*`) の `SUBA_RATE` は、一致する列の固定を**伝播だけで** (LP を解き直さずに) 目標の固定率で止める形 (`capped_fixings`)。
  ここでは HiGHS と同じく**段ごとに LP を解き直すダイブ**にした (別の関数 `src/mip/heur_subfix.rs`、環境変数は `ENOMOTO_MIP_SUBFIX`)。A の変数とは重ならない
  (両方付けたときは SUBFIX の分岐が先に効く)。

## 1. 試作の中身 (`src/mip/heur_subfix.rs`、既定では使わない)

`ENOMOTO_MIP_SUBFIX=<文字>` (値 `1` は `ritc`):

| 文字 | 中身 |
|---|---|
| `r` | 外側の根の RENS (暫定解があるとき。既定は LP で整数値の列を全部固定する `rens_old` を並列のサブ MIP で) を **ダイブ** ([`Solver::subfix_dive`]) にする。暫定解のない根の RENS (既定のダイビング式、目標 0.8) は変えない |
| `i` | 外側の根の RINS (既定は `rins_highs`: 一致する列を全部伝播しながら固定) を同じダイブにする (一致する列を固定)。既定の `S4_RINSRATE` (固定率 0.5 未満ならサブ MIP にしない) も当てる |
| `t` | 木の中の RINS (ALNS の RINS の腕) を同じダイブにする |
| `h` | 外側の根で RINS を呼ばない (HiGHS の `evaluateRootNode` は根で RENS だけ。`r` と合わせる) |
| `c` | 根の被約費用のサブ MIP (既定で固定率 0.3 未満はやらない) の固定率と結果も共通の記録に入れる |

ダイブ (HiGHS v1.15.1 の `HighsPrimalHeuristics::RENS`・`RINS` に倣う):

1. 自由な整数列を lock の積 ((ε + 下) × (ε + 上)) の大きい順 (同点は乱数) に並べる (HiGHS の `setupIntCols`)。
2. 目標の固定率 = HiGHS の `determineTargetFixingRate` (初め 0.6、実行不能だった固定率の平均 × 0.9 を上の端、解を見つけた固定率の平均の 0.9〜1.1 倍を
   含む範囲の乱数)。記録は**外側の求解の全スレッドで共通** (静的な `STATS`、外側の求解の始めに消す)。RENS・RINS・被約費用 (`c`) で共通。
3. 段: 今の LP 解で、RENS は列を [切り下げ, 切り上げ] に締め (整数値なら固定)、RINS は LP 解と暫定解が一致する列を固定する。1 列ごとに伝播し、
   固定率が `min(目標, 1 − (1 − 今の率) × 0.9)` (残りの自由な列の 1 割) に達したら段を終えて LP を解き直す。
4. 締める列が尽きたら (RINS は固定率 0.25 未満のときだけ)、分数の列を `getFixVal` (根の LP 解からの変化 ≥ 0.4 ならその向き、でなければ費用の悪くなる向き、
   費用 0 なら近い整数) で、丸め幅の小さい順に丸め幅の和 0.5 まで固定する。根の LP 解は外側の根で RENS・RINS を呼んだときの LP 解 (共通の記録に置く)。
5. 段の LP が実行不能か打ち切り値以上なら、その段の固定を捨てて段の幅を半分にする (10 回まで)。伝播の矛盾は最後の 1 列だけ戻す。
   (HiGHS は最後の分枝を逆にする深さ優先の戻り。ここは簡略化。)
6. 目標の固定率に達したら (固定率 < 0.1 ならサブ MIP にしない。HiGHS は深さ優先の探索 10 回)、その定義域でサブ MIP (ノード上限 500、時間・停滞・成果連動の
   打ち切りは既定のまま) を解く。
7. **空振りのやり直し**: サブ MIP が 1 ノード以下で実行不能なら、目標を「達した固定率 × 0.5」にし、ダイブの深さ (締めた回数) の半分まで戻って 3 から
   やり直す (深さの半分 ≤ 1 か `ENOMOTO_T_MIP_SUBFIX_TRIES` (既定 5) 回でやめる)。
8. やり直しにはサブ MIP の結果が要るので、**根の RENS・RINS のサブ MIP は主のスレッドで解く** (既定の根の RENS は別スレッドの並列のサブ MIP)。

ログ: `MIP:   SUBFIX <RENS|RINS|tree RINS> try k: target …, fixing rate …, depth …, … free integer columns …, status …, nodes …, accepted …` と、
終わりの `MIP: SUBFIX summary: dives … sub-MIPs … accepted … root-infeasible retries … ; success … (mean rate …), infeasible … (mean rate …)`
(木のスレッドの分も数える。木の RINS の 1 行ずつのログは主のスレッドの分だけ)。

チューニングの変数: `ENOMOTO_T_MIP_SUBFIX_RATE0` (初めの目標 0.6)、`ENOMOTO_T_MIP_SUBFIX_TRIES` (5)、`ENOMOTO_T_MIP_SUBFIX_ITERS_MULT` (ダイブの LP 反復の上限、
ノードの平均の 20 倍 + 1 万)。

## 2. 8 問 (4 スレッド・300 秒、種 1・2)

(表の全体は `C/summ8.md`。「根の SUBFIX」は E = RENS・I = RINS の固定率、`*` は解を受け入れた回。)

| 問題 | def (種 1 / 2) | fix (種 1 / 2) | fixh (種 1 / 2) | 根の SUBFIX (fix の種 1 / fixh の種 1) |

事実:

- **physiciansched6-2**: 根の RINS のダイブは固定率 0.66 で 0 ノードで実行不能 (既定の全部固定の 0.88 で空振りするのと同じ形)、やり直しの 0.34 (自由な整数列 3005) で
  最適値 49324 を根で出す (fix 種 1)。fixh は RENS が 0.60 で実行不能、やり直しの 0.31 で 49324。4 回とも根の後の暫定解が 49324、解けた時間は 19〜31 秒
  (既定は 27・72 秒。既定の 2 回目は 49324 を 65 秒に木で見つけた)。fix の種 2 は根のヒューリスティクスの前に 12 秒で 49324 が見つかり、SUBFIX は動かなかった。
- **neos-933966**: 根の RENS のダイブ (固定率 0.60、自由な整数列 2943、201 ノード 22 秒) が 4 回とも解を出す。既定の根の後の暫定解 8386・5385 に対し、
  試作は 1337・382・7372・382。300 秒の最後は fix 1337・最適、fixh 3370・最適、既定 3379・388。
- **thor50dday**: 根の RENS のダイブのサブ MIP (自由な整数列 21242) が残り時間を全部使い (286 秒、`SUBMIP_HIGHS` の `t` で時間の上限が残り時間)、最後に
  72621・76015 を出す。既定は 86020・190078。ただし 286 秒の間、主のスレッドは根で止まっている (下界は 4175 のまま、どの設定も同じ)。
- **cod105**: 試作で遅くなる (163・154 秒 → 176〜262 秒)。根の RENS のダイブ (固定率 0.60、自由な整数列 409、密な行) のサブ MIP が 53 ノード 26 秒で解なし
  (成果連動の打ち切りで止まる)。既定は全部固定の RENS を別スレッドで解くので、根の終わりが 32 秒 → 64 秒に延びる。fix の 1 回目は根の RINS (固定率 0.32、
  一致する列が尽きた) が既定の `S4_RINSRATE` の判定を通らず 87 秒回って 262 秒になった → 直した (試作の根の RINS にも同じ判定、2 回目は飛ばして 176 秒)。
- **nexp-150-20-8-5**: 試作のサブ MIP (固定率 0.60、自由な整数列 6500) は 8 本とも解なし (ノード上限・時間)。最後の暫定解の差 (248・244 vs 250・246) は揺れの大きさ。
- **trento1**: 300 秒では根のヒューリスティクス (Pump・ダイビングなど) が 295 秒まで続き、試作の RENS・RINS に届かない回が多い。差は揺れ。
- **drayage-25-23**: 根の RENS のダイブが固定率 0.60 で解を出す (既定の全部固定は以前 229 列しか残らず実行不能、analysis/mip_primal_weakness_20261016.md)。
  ただし既定でも 5 秒で解けていて、差は 1 秒以内。
- 共通の記録: 木の RINS の目標は根の結果で動く (neos-933966 で 0.58〜0.64)。physiciansched6-2 では実行不能の平均 0.60〜0.66 で上の端が 0.54〜0.59 になる。

推測:

- 効いているのは「全部固定 → 目標 0.6 で止める」ことによる近傍の広さ (neos-933966・thor50dday・physiciansched6-2) と、根で実行不能のときのやり直し
  (physiciansched6-2 の 0.6 → 0.3)。根の RINS をやめる `h` は、根の RENS が当たる問題では差がない (neos-933966・thor50dday)。
- 害は主に**根のサブ MIP を主のスレッドで解くこと** (cod105 で +30 秒、thor50dday で根が 286 秒止まる)。HiGHS も逐次だが、HiGHS のサブ MIP は 200 ノードで止まり、
  時間の上限ではない。ENOMOTO の `SUBMIP_HIGHS` の `t` (根のサブ MIP の時間の上限 = 残り時間) と合わさると、重いサブ MIP が根を長く塞ぐ。
