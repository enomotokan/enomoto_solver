# combb (二段解法の尺度の調整 + 安全モードの前向き Harris + 雑音の行の作り直し) を根の LP が重い問題で 600 秒で比べる (2026-11-06)

bench に使う環境変数: combb = `ENOMOTO_SIMPLEX_SCALE=1 ENOMOTO_T_SIMPLEX_SCALE_MIN_M=10000 ENOMOTO_T_SIMPLEX_SCALE_MIN_RANGE=1e4 ENOMOTO_SIMPLEX_HARRIS2=r ENOMOTO_SIMPLEX_NOISE_RESET=0.1 ENOMOTO_SIMPLEX_NOISE_RESET_W=e`
(`analysis/halve_submip_20261030/run.py` の CFGS の "combb")。既定 = 環境変数なし ("def")。
切り分けの組 (`combb_600_20261106/run.py` の CFGS): **comb** = combb から雑音の作り直しを外したもの (`ENOMOTO_SIMPLEX_SCALE=1 ENOMOTO_T_SIMPLEX_SCALE_MIN_M=10000 ENOMOTO_T_SIMPLEX_SCALE_MIN_RANGE=1e4 ENOMOTO_SIMPLEX_HARRIS2=r`、
`rootlp_simplex_fail_20261105.md` の 7 節の comb と同じ)、scaleonly = 尺度の調整の 3 つだけ、h2only = `HARRIS2=r` だけ、nronly = `NOISE_RESET=0.1 NOISE_RESET_W=e` だけ、
noscale = h2 + nr、m17k = combb で `MIN_M=17000`。

## 結論 (短く)

- **効き目** (事実、2 回とも同じ向き。12 問とも時間切れなので解けた数は 0 対 0、差は根の終わりとギャップ):
  - momentum1: 既定は 2 回とも根の LP が 600 秒で終わらない (下界 −inf・解なし)。combb は根の LP 14.6・14.8 秒で、ギャップ 72.2%・69.4%
    (解 346,859・314,708、下界 96,256。前の 600 秒の HiGHS は解なし・下界 96,317)。**効くのは `HARRIS2=r`** (h2only だけで根の LP 14.5 秒、ほかの部品だけでは終わらない)。
  - satellites2-40: 根の終わり 151・154 → 97・96 秒 (既定は LP プロービングの最初の LP が 30 秒で止まり、根の LP が 66〜68 秒)。最後のギャップはどちらも 100%。
    **効くのは尺度の調整** (scaleonly だけでプロービングの LP 5.9 秒)。
  - neos-873061: ギャップ 9.6%・7.2% → 5.8%・5.8%。ただし根の LP の差ではなく、根の reduced cost の部分 MIP が 185 秒 (109 ノード) → 87 秒 (55 ノード) と短くなり
    根が早く終わってカットが進んだため (主の値は 115.66 → 117.26 と少し悪い)。LP プロービングの最初の LP が 30 秒で止まる回が設定によらず混ざり (揺れ)、comb の 1 回はそれに当たってギャップ 10.8%。
- **害** (事実): supportcase42 の根の終わりが 2 回とも 32 → 80・87 秒 (RINS の部分 MIP が 5.5・5.9 → 54.2・58.4 秒)。最後のギャップは 8.2% で変わらない。
  `HARRIS2=r` と `NOISE_RESET` の**組み合わせ**で根の LP の頂点が変わり (LP プロービングの根の LP 3,409 → 9,263 反復)、RINS の固定の割合が 0.78 → 0.74 になって部分 MIP が重くなる。
  片方だけ・尺度の調整だけでは起きず、**comb (雑音の作り直しなし) でも起きない** (根 31 秒)。
- ほかの 8 問 (uccase12・uccase9・snp-02-004-104・sing44・sing326・thor50dday・rail01・opm2-z10-s4) は根の LP の時間がほぼ同じで、最後のギャップの差は揺れの範囲 (推測を含む、1 節の表)。
  二段解法だけの診断で大きく効いた uccase12 (時間切れ → 5.3 秒)・supportcase42 (Error → 29.8 秒) は、MIP の中では既定でも根の LP が 5〜25 秒で終わっていて差が出ない。
- timtab1 (60 秒、5 回ずつ): 既定・combb とも 5 回中 3 回解ける。**揺れ** (事実)。combb の部品は尺度の調整・雑音の作り直しが 0 回、前向き Harris が 24,929 回の LP のうち 2 回だけ働いた。
- 判断: **既定にする価値はある。形は combb ではなく comb (尺度の調整 + `HARRIS2=r`、雑音の作り直しは試作のまま)**。
  momentum1 (何も出ない → 解と下界)・satellites2-40 (根が 55 秒早い) の得を保ち、supportcase42 の害が出ない。雑音の作り直しは MIP の中では得が見えず、害の片方の原因。
  既定にする前に 58 問・Mittelmann の 60 秒で comb を 3 回ほど回したい (comb そのものは 60 秒の bench で回していない)。形と戻し方は 5 節。

### 1.2 neos-873061 の差 (ログ)

- 根の reduced cost の部分 MIP (131,409 列が自由): 既定 2 回とも NodeLimit 109 ノード・187.3・184.1 秒・解 115.86、combb 2 回と comb は 55 ノード・86.8・88.3・87.4 秒・解 117.77。

- 根が早く終わると、背景のカットの続きの主のカットのループが既定 (回 1) より多く回り、根の下界が 107.3 → 110.5 になる。

  下界 104.6 で木に入るのが 376 秒。ギャップ 10.8% は既定の回 0 (同じく止まった回) と同じ程度。
- 推測: 部分 MIP の差は、部分 MIP の中の冷えた LP (1 万行以上・係数の幅 1e4 以上なら尺度の調整が働く) か `HARRIS2=r` で経路が変わったもの。得とも揺れとも決めにくい。

### 1.3 momentum1 の combb の根 (ログ)

- 根の LP 14.6 秒、カットの後の根の発見的解法が 357 秒かかる (vector length diving 136.6 秒・coefficient diving 129.8 秒・fractional diving 42.5 秒、

## 5. 既定にするなら (案、コードは変えていない)

- 形: comb を既定にする。
  - `src/simplex/mip_lp.rs` の `scale_cold_on()` を「`ENOMOTO_SIMPLEX_SCALE` が `0` でなければ使う」にし、`ENOMOTO_T_SIMPLEX_SCALE_MIN_M` の既定を 10000、
    `ENOMOTO_T_SIMPLEX_SCALE_MIN_RANGE` の既定を 1e4 にする (冷えた LP = 基底のない `TwoStageLp::solve_once` だけ。部分 MIP の根の LP も条件に当たれば調整される)。
  - `src/simplex/slope_intercept_dual.rs` の `harris2_mode` を、`ENOMOTO_SIMPLEX_HARRIS2` がなければ `r` (安全モードのときだけ) にする。
    これは MIP の外の LP (二段解法を使うすべての求解) にも効くので、LP の bench でも確かめる。`rootlp_simplex_fail_20261105` の 7 節では `r` なら他の 8 問の反復数が既定と一致。
  - `ENOMOTO_SIMPLEX_NOISE_RESET` は試作のまま (既定では使わない)。
- 戻し方: `ENOMOTO_SIMPLEX_SCALE=0 ENOMOTO_SIMPLEX_HARRIS2=0`。`analysis/halve_submip_20261030/run.py` の CFGS に "precomb" として足し、既定化の前後を比べられるようにする。
- 既定にする前に: 58 問 (4 スレッド・60 秒) を comb と既定で 3 回、Mittelmann 186 問を 1〜2 回 (bench27 の combb と同じ組)。
  combb は 60 秒で 58 問 +1.6%・Mittelmann +0.9% (揺れの範囲) だったが、comb そのものは回していない。
