# combb (二段解法の尺度の調整 + 安全モードの前向き Harris + 雑音の行の作り直し) を根の LP が重い問題で 600 秒で比べる (2026-11-06)

bench に使う環境変数: combb = `ENOMOTO_SIMPLEX_SCALE=1 ENOMOTO_T_SIMPLEX_SCALE_MIN_M=10000 ENOMOTO_T_SIMPLEX_SCALE_MIN_RANGE=1e4 ENOMOTO_SIMPLEX_HARRIS2=r ENOMOTO_SIMPLEX_NOISE_RESET=0.1 ENOMOTO_SIMPLEX_NOISE_RESET_W=e`
(`analysis/halve_submip_20261030/run.py` の CFGS の "combb")。既定 = 環境変数なし ("def")。切り分けの組 (`combb_600_20261106/run.py` の CFGS):
scaleonly = 尺度の調整の 3 つだけ、h2only = `HARRIS2=r` だけ、nronly = `NOISE_RESET=0.1 NOISE_RESET_W=e` だけ、noscale = h2 + nr、m17k = combb で `MIN_M=17000`。

## 結論 (短く)

- **効き目** (事実、2 回とも同じ向き): 既定の MIP で根の LP (LP プロービングの最初の LP を含む) が詰まる問題で効く。
  - momentum1: 既定は 2 回とも根の LP が 600 秒で終わらない (下界 −inf・解なし)。combb は根の LP 14.6・14.8 秒で、ギャップ 72.2%・69.4%
    (解 346,859・314,708、下界 96,256。HiGHS は 600 秒で解なし・下界 96,317)。
  - neos-873061: 既定は LP プロービングの最初の LP が 30 秒の上限で止まり、根の終わり 247・233 秒、ギャップ 9.6%・7.2%。
    combb は 7.1 秒で根の LP が終わり、根の終わり 138・140 秒、ギャップ 5.8%・5.8% (下界 104.6・107.3 → 110.5)。
  - satellites2-40: 根の終わり 151・154 → 97・96 秒 (既定は LP プロービングの最初の LP が 30 秒で止まり、根の LP 66〜68 秒)。最後のギャップはどちらも 100% (主の値の当たり外れ)。
- **害** (事実): supportcase42 の根の終わりが 2 回とも 32 → 80・87 秒 (RINS の部分 MIP が 5.5・5.9 → 54.2・58.4 秒)。最後のギャップは 8.2% で変わらない。
  原因は尺度の調整ではなく (scaleonly は既定と同じ経路)、`HARRIS2=r` と `NOISE_RESET` の**組み合わせ**で根の LP の頂点が変わり (LP プロービングの根の LP 3,409 → 9,263 反復)、
  RINS の固定の割合が 0.78 → 0.74 になって部分 MIP が重くなること (片方だけでは起きない)。経路の違いで、小さな直しは見当たらない。
- ほかの 7 問 (uccase12・uccase9・snp-02-004-104・sing44・sing326・thor50dday・rail01・opm2-z10-s4 のうち) は根まで同じか揺れの範囲で、最後のギャップの差も揺れの範囲 (推測を含む、下の表)。
- timtab1 (60 秒、5 回ずつ): 既定・combb とも 5 回中 3 回解ける。**揺れ** (事実)。combb の部品は尺度の調整・雑音の作り直しが 0 回、前向き Harris が 24,929 回の LP のうち 2 回だけ働いた。
- 判断: **combb を既定にする価値はある** (根の LP が詰まる問題で「何も出ない → 解と下界が出る」まで変わり、害は根が 50 秒遅れる 1 問で最後の結果は同じ)。
  形と戻し方は 5 節。

### 1.2 momentum1 の combb の根 (ログ)

- 根の LP 14.6 秒、カットの後の根の発見的解法が 357 秒かかる (vector length diving 136.6 秒・coefficient diving 129.8 秒・fractional diving 42.5 秒、
  どれも `dive ran out of budget`、根の reduced cost・RENS の部分 MIP 3 つが 334 秒で Infeasible)。解は vbounds (loose) の部分 MIP (401 秒) と RINS (408 秒)。
- 推測: combb の害ではなく、根の LP を越えて初めて見える既存の重さ (潜り込みの予算を根の LP の反復数 23,344 から決めていて、1 回の LP が重い)。別の課題。

## 2. supportcase42 の害の切り分け (600 秒、回 0、根まで)

| 組 | プロービングの根の LP (反復) | RINS の固定の割合 | RINS の部分 MIP | 根の終わり |
|---|---|---|---|---|
| 既定 (2 回) | 24.5・24.4 秒 (3,409) | 0.78 | 5.5・5.9 秒 (143 ノード) | 33・32 秒 |
| combb (2 回) | 23.4・23.6 秒 (9,263) | 0.74 | 54.2・58.4 秒 (201 ノード) | 80・87 秒 |
| m17k (根は調整、部分 MIP は調整なし) | 23.5 秒 (9,263) | 0.74 | 54.9 秒 | 82 秒 |
| noscale (h2 + nr) | 22.1 秒 (9,263) | 0.74 | 55.6 秒 | 83 秒 |
| scaleonly | 25.4 秒 (3,409) | 0.78 | 5.4 秒 | 32 秒 |
| h2only | 26.1 秒 (26,382) | 0.78 | 3.4 秒 | 30 秒 |
| nronly | 26.1 秒 (3,392) | 0.78 | 5.5 秒 | 31 秒 |

- 事実: 尺度の調整は supportcase42 では働いていない (scaleonly は既定と同じ反復数。係数の幅 4.2e3 < 1e4)。
- 事実: 診断の出力 (`ENOMOTO_DEBUG_EXT_ITERS=1`、40 秒、`logs/supportcase42_*_dbg.log.gz`) では、既定・combb ともプロービングの LP で
  「broken-basis bailout → safe_pivot で解き直し」が起き (ここで `HARRIS2=r` が働く)、combb では雑音の作り直しが 1 回 (5,472 反復目、作り直した後の実行不能な行 5,813)。
- 事実: h2 だけ・nr だけでは RINS は重くならない。2 つが両方働いたときの頂点 (9,263 反復) で RINS の部分問題が重くなる。
- 推測: 「どの頂点に着くか」の違いで、部品の誤りではない。RINS の部分 MIP は NodeLimit で止まるのに 1 ノード 0.27 秒 (既定 0.04 秒) かかる。
  時間で止める上限がないことの方が問題で、combb を外しても別の問題で起きうる。最後の結果には響いていない (8.2% は既定と同じ)。

## 3. timtab1 (4 スレッド・60 秒、5 回ずつ)

| 回 | 既定 | combb |
|---|---|---|
| 0 | 時間切れ (下界 738,216) | 57.6 秒 |
| 1 | 56.9 秒 | 時間切れ (下界 732,770) |
| 2 | 時間切れ (主 772,428) | 32.9 秒 |
| 3 | 57.7 秒 | 52.3 秒 |
| 4 | 32.0 秒 | 時間切れ (主 772,421) |

- 事実: どちらも 5 回中 3 回解け、解けた時間も 32〜58 秒に散る。最適値はどれも 764,772。bench27 で combb だけ 2 回時間切れだったのは揺れ。
- 事実 (部品が働いたか、1 スレッド・60 秒・診断の出力つき、`logs/timtab1_*_t1_dbg.log.gz`): 前処理の後 193 行なので尺度の調整は条件 (1 万行) に当たらない。
  雑音の作り直しは 0 回。前向き Harris は combb の 24,929 回の LP のうち 2 回 (ノードの LP で特異な分解から安全モードに入った後、費用のずらし 29・13 個)。既定の 37,809 回の LP では 0 回。

- 推測: 2 回の Harris で木の経路が変わることはあるが、もともと揺れる問題で、系統的な害ではない。
