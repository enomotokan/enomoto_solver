# 並列の分枝限定法がスレッド数ほど速くない理由の切り分け (2026-11-22、利用者の問い)

問い: 「並列の分枝限定法がスレッド数ほど速くないのは、最初に良い暫定解がないからか」。
背景: analysis/vsscip_20261120 (0.1.10 相当) の 4 スレッド/1 スレッドの SGM は P 0.811 [0.740, 0.888]、M 0.735 [0.683, 0.791] (1.2〜1.4 倍)。

## 測り方

- (a) 暫定解の効き: 既知の最適値から作った打ち切り値 (`ENOMOTO_MIP_CUTOFF`) を与えた回 (t1c・t4c) と与えない回 (t1・t4) を、1・4 スレッドで。
  cutoff あり同士の比 (t4c/t1c) が暫定解の差を除いた並列の速さ、t1c/t1・t4c/t4 がスレッド数ごとの暫定解を与えたときの得。
- (b) 根と木の分け: どの回も `ENOMOTO_MIP_LOG=1` で解き、stderr の最後の `TRSTAT: tree start outer X` を根の秒 (前処理〜木に入るまで、
  再スタートがあれば最後の木の始まりまで)、全体の秒からそれを引いたものを木の秒とする。ノードは結果の nodes (4 スレッドは全スレッドの和)。
  TRSTAT の行がない回は根で終わった回として別に数える。
- 対象 (plan.py): P の 58 問のうち、vsscip_20261120 の 1 スレッドが種 1〜3 の中央値で 3 秒以上かかり、1 か 4 スレッドで 60 秒以内に解けた回がある 32 問。
  種 1〜3、120 秒 (1 スレッドで 60 秒を超える問題があるため)。384 回、3 分担 (各 1.26 時間の見積り)、`python run.py P K` (K = 0〜2)。
- 今の既定 (ブランチの先頭) のビルド。ログを出す手間は全組に同じだけ乗る (misc07 の 1 スレッドでログなし 5.34 秒・あり 5.63 秒)。

### 打ち切り値の決め方 (cfg.py・run.py)

- `ENOMOTO_MIP_CUTOFF` は元の目的の向きで与え (src/mip/mod.rs、`sense_sign` を掛ける)、木の刈りの上限 `prune_limit_of` の `cutoff` に入る
  (暫定解がなければ上限はこの値、あれば暫定解から作った上限との小さい方)。この 32 問はどれも最小化 (MPS に OBJSENSE なし)。
- 値は 最適値 (scripts/miplib2017-v31.solu の =opt=) - 1e-6 max(1, |最適値|) にした (最適値の少し下)。
  - 最適値の暫定解 z を持つと、刈りの上限は z - 1e-9 max(1,|z|) (相対ギャップの既定 0) か目的の刻みの格子の点になる。少し下の打ち切り値は
    これとほぼ同じ刈り方になる (1e-6 は solu の値の丸めの余裕)。
  - 打ち切り値より悪い (= 最適値の) 解も暫定解としては受け取るので、状態は optimal で終わる (misc07 で確かめた: 2809.997 を与えて optimal 2810)。
  - 最適値の少し上 (+ 余裕) にすると、最適解を見つけるまで下界 ≈ 最適値のノードを刈れない (整数の目的では下界の切り上げで最適値と同じになる
    ノードが多く残る)。「暫定解を持って始める」の写しとしては少し下の方が近い。misc07 の 1 スレッド種 1: なし 3968 ノード 5.6 秒、
    少し下 (2809.997) 3319 ノード 5.1 秒、少し上 (2810.003) 3477 ノード 5.1 秒。
- 打ち切り値つきの回の終わり方 (分担 2 で分かった): 打ち切り値より良い解がないことを示した時点で終わり、そのとき持っている暫定解
  (最適値より悪いこともある。打ち切り値以上の解は暫定解の更新に使われても刈りの上限は打ち切り値のまま) を optimal として返す。
  解を 1 つも持たなければ infeasible。つまり t1c・t4c の時間は「最適値が分かっているときの証明の時間」で、最適解を見つける時間は含まない
  (暫定解を最適値で与えたのと同じ意味)。summ.py は infeasible も解けたとして数え、目的値の確かめは t1・t4 だけで行う。
- 台本の確かめ (misc07 種 1、120 秒): t1 5.59 秒 3968 ノード (根 0.62 秒)、t1c 4.90 秒 3299 (0.56)、t4 2.35 秒 1875 (0.72)、t4c 2.80 秒 1977 (0.67)。
