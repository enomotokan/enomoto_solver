# CUTSTOP: 根のカットのループを、もう 1 ラウンドの得と損を同じ単位 (手間) で比べて止められるか (2026-11-22、利用者の依頼)

背景: analysis/rootstop_20261121 (長く回すと根の下界は上がるが全体は遅い問題がある。得・損を分ける 1 つの特徴は見つからず、試作 ROOTSTOP は閉じた)。
あわせて analysis/rootcutoff_20261121 §7 (停滞の判定 相対 1e-4・+2・10 で swath1 の再スタート後の根が 5 ラウンドで止まる。`ENOMOTO_T_MIP_CUT_STALL=30` で速い) も見た。

## 0. 結論

- **得・損を手間で比べる見積りは、続けて得な問題と損な問題を分けない。試作は作らない (P の分担表も作らない)。** 木の側の量 (1 ノードの手間・ノード数・
  暫定解) を事後の答えから入れた (実際の判定より有利な) 見積りでも外れる。
- 外れ方は 3 通り (§3):
  1. **下界が上がっても木が小さくならない** (roll3000: 長く回すと根の下界 12445 → 12556 で、ノード 4328 → 6310、時間 1.74 倍)。得の前提が崩れる。
  2. **1 ノードの手間の増え方が LP の非零の増え方から読めない** (neos17: 非零 1.16 倍に対して 1 ノードの手間 1.52 倍、ノード 0.75 倍で時間 2.18 倍)。
  3. **小さな下界の伸びで木が大きく縮む** (swath1 の再スタート後: 340.59 → 342.90 (間隙の 6%) でノード 4557 → 775、時間 0.59 倍)。
     見積りは「得 < 損」(直近 5 巡 0.30) で止めると言い、外れる。
- 1・3 は向きが逆で、根の下界の伸びと木の大きさの関係が問題ごとに違う (間隙だけで決まる指数の模型 N ∝ exp(G/κ) では両方を説明できない)。
  根の中から木の大きさの効き方を読む手がかり (例: 強分枝の伸び) が要るが、カットのループの間にはまだない。
- 停滞の判定 (stall30) の側も同じ: swath1 は得 (35.7 → 21.0 秒)、neos-911970 (22.3 → 37.2 秒)・neos-1582420 (38.4 → 45.1 秒)・h80x6320d (27.8 → 28.7 秒) は損。
  見積りは swath1 も neos-1582420 も「止める」と言う。
- 1 スレッドの結果は、rootstop の 4 スレッドの得・損の分け方と一部違う: mc11 (0.97)・timtab1 (0.83)・mik-250-20-75-4 (0.78) は 1 スレッドでは長く回して損でない。

## 1. 診断 (`ENOMOTO_MIP_CUTSTOP_LOG=1`、解き方は変えない)

- `CUTTK` の行 (根のラウンドの初め) に、LP の行の数・非零・全体の手間・秒を足した (src/mip/separation.rs)。
- `TREETK` の行を足した (src/mip/solver.rs): 主の木のノード数が 2 の冪 (16 以上) のときに、秒・全体の手間・大域の下界・開いたノードの数。
- 台本 `diag.py` (1 スレッド・種 1・120 秒、def と long = rootstop の LONG (第 2 段階へ必ず進み合わせて 100 巡、時間の枠 30 倍)、mc11 は `CMIRGEN=u` の
  cmu・cmu_long、停滞の側は stall30 = `ENOMOTO_T_MIP_CUT_STALL=30`)。結果 `diag.jsonl`、ログは `logs/` (コミットしない)。
- 見積り `est.py` → `est.txt`・`est_stall.txt`: 各ラウンド k で
  - 損 = そのラウンドの手間 c_k + (非零の増え / 根の終わりの非零) × T_node × N (足したカットで以後の 1 ノードが重くなる分。1 ノードの手間は非零に比例とみなす)
  - 得 = N × (1 − exp(−Δz_k / κ)) × T_node、κ = G / ln N (木の大きさ N ∝ exp(G / κ)、G は根の終わりの間隙)
  - T_node・N・U は事後の答え (TREETK の最後の 2 点、最終のノード数、最終の暫定解)。止め時の判定は直近 5 巡の 得 / 損 < 1。
- 比べ `pairs.txt`: 時間・ノード・根の最後の LP の非零の比・1 ノードの手間の比・ラウンド数。

## 3. 読み

- 損の側の「足したカットで 1 ノードが重くなる分」は、非零の比では neos17 を 1/3 ほどにしか見積もれない (非零 +16%、1 ノード +52%)。
  LP の反復の増え方 (退化・カットの密度) は行・非零の数から読めない。
- 得の側の「下界が上がると木が小さくなる」は、roll3000 では逆 (ノードが増える)、swath1 では間隙の 6% の伸びでノードが 1/6 になる。
  木の大きさの間隙への効き方は問題と道筋しだいで、根の中の量からは決まらない。
- 事後の答えを入れた見積りでも分けられないので、根の中だけで取れる量に置き換えた判定 (実際の試作) が分けられる見込みは低いと見る。
  既定の止め方 (第 1 段階 25 巡・停滞の判定) を変えない。
