# ノードの密なカットで遅くなっている問題の調べと、得と手間を比べて外す試作 (DENSECUT、2026-11-13〜14)

道具・生の結果は `analysis/densecut_20261113/`。土台はどれも束 cand1114 (`analysis/cand1114_20261113/cfg.py`)、4 スレッド。
c = cand1114、c0 = c + `ENOMOTO_T_MIP_TREE_SEP_ROUNDS=0` (木の分離のラウンドを 0 にし、ノードの新しい分離を止める。プールのラウンドは残る)。
どの回にも診断 `ENOMOTO_MIP_DENSECUT_DIAG=1` を付けた (下)。

## 結論 (先に)

- **58 問には「ノードの密なカットで遅くなっている問題」はない**。ノードで足したカットが元の行の平均の 10 倍を超える問題は 0 (最大 9.8 倍・4 本)。
  ノードの分離を止める (c0) と 2 種そろって速いのは misc07 (0.94/0.90)・noswot (0.87/0.91) だけで、どちらもカットは疎 (元の行の 0.6〜3.2 倍) で本数で重い。
  全体の SGM c0/c は +0.6% [−3.0%, +4.6%]。
- **rmatr100-p10 の i 形・KROOT** のノードのカット (約 340 本、元の行の 44 倍) を `nca_dense` は**一度も密と判定していない** (木の分離の密の下限
  0.05×列数 = 368 非零の下)。「密と判定されているのに深さの規則で入る」のではなく、効いた割合で毎回分離している。害は LP の重さではなく
  解き直しの回数 (+30%) と分離の時間で、ROUNDS=0 で 53 → 49 秒 (c の k ではノードのカットは 0〜1 本で害はない)。
- 「密と判定されているのに深さの規則で入る」形は Mittelmann の fastxgemm-n2r6s0t2 (8.5 倍、密の判定 2〜5 千回、それでも 1400〜4100 本) と
  mcsched・pg5_34 にある。ただ fastxgemm は同じ設定・同じ種でも 30〜290 秒と揺れ、種 1〜6 では c0 の得は一貫しない (SGM c 94 秒・c0 77 秒、種ごとの比 0.29〜1.46)。
- Mittelmann の重い組で、止めるとギャップが良くなったのは rocI-4-11・supportcase33・mcsched・sct2 (種 1・300 秒) だが、同じ種の c を回し直すだけで
  sct2 0.061 → 0.029%、traininstance6 の下界 1020 → 319 と動き、1 種では言えない。止めると悪いのは neos-4722843-widden (2 種そろって 1.26〜1.32 倍)・
  neos-911970・binkar10_1・neos5・rout。
- 得と手間を比べて外す試作 `ENOMOTO_MIP_DENSECUT` (a: 密なカットを基底なら年齢 10 で外す、g: 伸びの小さかった密なラウンドのカットを基底になり次第外す) は、
  58 問 × 種 1・2 で a が SGM **−0.8% [−3.0%, +1.6%]**、解けた数 83 対 83、食い違い 0 (揺れの内)。a が 1 行も外さない問題でも
  0.68〜1.38 倍動く (nu25-pr12・pk1・physiciansched6-2) ので、差は揺れと区別できない。候補の問題でもそろった得はない (fastxgemm 種 3〜6 の SGM: c 94・a 100・ag 113 秒)。
  g は noswot を 2 種とも時間切れにした (60 秒)。
- **提案: 既定は変えない。密度で罰する・外す方向はこれで打ち止めにしてよい** (該当がほとんどなく、ある問題も揺れの方が大きい)。試作と診断はソースに残す (既定では使わない)。
  ノードの分離の害が出るのは「疎だが本数が多く LP が重くなる」問題 (noswot・misc07) と「解き直しの回数」(rmatr の i 形) で、密度は手がかりにならない。

## 診断 `ENOMOTO_MIP_DENSECUT_DIAG` (1215202d)

木のスレッドごとに、終わりに 1 行 `DENSECUT tid ...` を stderr に出す (部分 MIP では出さない)。既定は変わらない。
- `ncuts`・`nnz/cut`: ノードの分離 (`node_cut_round`) で LP に加えたカットの本数と非零の平均、`rowavg`: 元の行の非零の平均
- `post rows/lp`・`post nnz/lp`: ノードの LP 1 回あたりの、根の後に LP に入ったカットの行 (木の分離で足したものとプールから戻したもの、番号が `ts2_id0` 以上) の数と非零の和
- `lpsecs`・`lps`: ノードの LP の秒と回数 (1 回の ms はこの比)、`cutsecs`: ノードの分離の秒 (解き直しを含む)
- `gain`: 木の分離のラウンドの後の解き直しで、LP の値の伸び / 打ち切り値までの差 (打ち切りは 1) の平均と回数、`hist` はその分布 (打ち切り / <0.02 / <0.1 / <0.3 / ≥0.3)
- `dense depth`・`dense hits`: `nca_dense` が密と判定した回数 (`tree_sep_start` で)、そのうち深さの規則で分離を始めた回数

集計は `summ.py` (2 つの設定の時間比と診断の表)・`diag.py` (1 つの設定の診断の表)。表の「比率」= 非零/本 ÷ 元の行の平均、
「後の非零/元」= ノードの LP 1 回あたりの根の後のカットの非零の和 ÷ 元の行の非零の和。

- **i 形・KROOT で入る密なカット (元の行の 44 倍) を `nca_dense` は一度も密と判定していない**。木の分離 (既定) では密の判定の下限が

## 4. 試作 `ENOMOTO_MIP_DENSECUT` (既定では使わない)

作り (`src/mip/solver.rs` の `densecut_has`、`src/mip/separation.rs` の `remove_aged_cuts`)。密 = カットの非零が元の行の平均の
`ENOMOTO_T_MIP_DENSECUT_RATIO` 倍 (既定 5) を超える。外すのは基底にある (効いていない) 行だけで、外したカットはプールに残り、違反すれば戻る。
- `a`: 根の後に LP に入った密なカットを、年齢が `ENOMOTO_T_MIP_DENSECUT_AGE` (既定 10) を超えたら外す (ほかのカットの年齢の上限は今のまま。rmatr のように m が大きいと 300)。
- `g`: 木の分離のラウンドで加えたカットの平均が密で、解き直しの LP の値の伸びが打ち切り値までの差の `ENOMOTO_T_MIP_DENSECUT_GAIN` 倍 (既定 0.02) 未満
  (打ち切りは届いたと数える) なら、そのラウンドのカットを年齢 `ENOMOTO_T_MIP_DENSECUT_WEAK_AGE` (既定 1) を超えたところで外す (「残すのは上がりを確かめてから」)。
- 診断の行の末尾 `dcut [a で外した行, g で外した行, 伸びの小さかった密なラウンド, 密なラウンド]`。cargo test --release --lib 415 通過 (pyo3 のため libpython を明示してリンク)。
