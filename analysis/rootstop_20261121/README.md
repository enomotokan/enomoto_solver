# 根のカットのループの止め方 (ROOTSTOP、2026-11-21)

根のカットのループがどう止まっているかを数え、続けたら・早く止めたらどうなるかを測り、止めるか続けるかを決める試作
`ENOMOTO_MIP_ROOTSTOP` (既定オフ) を作って比べた。

## 0. 結論

**今の止め方 (既定) を変えない。広い計測 (P/M の分担) は回さない。** 試作 `ENOMOTO_MIP_ROOTSTOP` は既定オフのまま残す。

- **続ける (`long`) は損。**
  - 根の下界はよく上がる。203 問の根だけの計測で、閉じた割合が良い 44 問・悪い 3 問、平均 +1.3 ポイント。
  - それでも、P 58 問の通しは 1.006 倍 (95% [0.970, 1.043]) で差がなく、解けた数は 76 → 74 に減った。
  - 第 1 段階の上限 (25 巡) で止まっていた問題は、種 1〜3 でそろって遅くなる (neos5 1.41・mc11 1.26・neos17 1.23・timtab1 1.18・roll3000 1.10・mik-250-20-75-4 1.10)。
  - 下界が上がっても木は小さくならない。そのうえ LP が大きくなり、1 ノードが遅くなる (neos5: ノード 215k → 262k、1 ノード 0.18 → 0.23 ms)。
- **早く止める向きも、得はあっても小さく、はっきりしない。**
  - 上限を 15 巡にした `short` は 0.980 倍 (95% [0.952, 1.009])。問題ごとにばらつく (roll3000 0.90・neos-860300 0.91、h80x6320d 1.24・mc11 1.11)。
  - 試作 `rs` は P 58 問で 1.004 倍 (95% [0.979, 1.029])、指定の 9 問で 0.995 倍 (95% [0.986, 1.003])。
  - `rs` で根が変わった問題はやや遅い (mc11 1.23・eil33-2 1.11・exp-1-500-5-5 1.10・timtab1 1.08)。
- **続けて得な問題と損な問題を分ける特徴は見つからなかった。**
  - 次のどれでも分かれなかった: 上限での直近 5 巡の伸びの割合、残りのギャップに対する伸び、手間あたりの伸び、根の LP の手間の割合、行の増え方。
  - 根で強く伸びる問題 (neos17: 閉じた割合 81 → 95%、roll3000: 73 → 80%) ほど、続けると遅くなる。
  - 第 2 段階に入って得をする beasleyC3 (gentype_20261121 の glc) は、既にある「強いカット」の判定 (伸び ≥ 0.3 × |目的値|) で分けられている。
  - 手間あたりの伸びで止める判定 (直近の速さ < 全体の速さ) は、sepalloc_20261121 の `s` で既に閉じている。伸びが次第に鈍る道のりでは早く止まりすぎるため。
- **確かめ:** `rs` の fuzz 7 本は bad 0。cargo test は既定・`rs` とも 419 通る、失敗 0、無視 19。

## 4. 試作 `ENOMOTO_MIP_ROOTSTOP` (`rs`、src/mip/separation.rs)

**判定:** 外側の主の根で、毎巡次の 2 つを比べ、伸びの割合が行の増えた割合を下回ったら止める (理由 `rootstop`)。

- 直近 5 巡の下界の伸びが、ループ全体の伸びに占める割合。
- 同じ 5 巡で LP の行が増えた割合 (今の行数に対して)。

ねらいは、下界を上げる得と、LP が大きくなって以後のノードが遅くなる損 (§2) を、どちらも割合で比べること。新しい閾値はない。続ける向きは損なので (§2)、止めるだけにした。

**根だけの計測 (203 問、cmp_rs.md):**

- 判定で止まったのは 64 問。
- 閉じた割合は、良い 3 問・悪い 22 問 (10% 点 −0.3 ポイント、平均 −0.5 ポイント)。
- 手間は幾何平均で 0.92 倍。
- 大きく下がった問題: timtab1 −18、neos-3381206-awhea −17、mc11 −13、lotsize −8、rococoB10-011000 −5.9、tr12-30 −5.6。
- 上がった問題: p200x1188c +8 (no_cands で止まる)。

**指定の 9 問 (種 1〜3。P の問題は 60 秒、M の問題は 120 秒、res_N_s0.jsonl):**

- 0.995 倍 (95% [0.986, 1.003])、解けた数は 21 / 21。
- 根が変わったのは mc11 と p200x1188c だけ。beasleyC3・tbfp-network・istanbul-no-cutoff・qiu・nw04・roll3000 はほぼ同じ。

**P 58 問 (種 1 は全問、根が変わる 14 問は種 2・3 も):**

- 1.004 倍 (95% [0.979, 1.029])、解けた数は 72 / 72 (その回に両方そろった分)。
- 根が変わった問題: mc11 1.23、eil33-2 1.11、exp-1-500-5-5 1.10、timtab1 1.08、fiber 1.06、p200x1188c 1.05、mas76 0.96、sp150x300d 0.95、khb05250 0.98。

## 5. 置き場所

- `cfg.py`: 設定 def・long・short・rs。
- `run_root.py`: 根だけの計測 (1 スレッド、NODE_LIMIT=1、CUTSTOP_LOG=1)。`root_<設定>.jsonl` に足していく。問題は vsscip_20261120 の P・M。
- `cmp.py`: 根だけの比べ (sepalloc_20261121 の写し)。結果は `cmp_root.md` (long) と `cmp_rs.md` (rs)。
- `run.py`・`ci.py`・`shards_L.json` / `L2` / `L3` / `N`: 通しの計測と区間。結果は `res_*_s0.jsonl`、出力は `run_*.out`。
  - L: P def・long の種 1。
  - L2: short の種 1 と、種 2・3 の def・long・short。
  - L3: rs。
  - N: 9 問。
- `fuzz.sh`・`fuzz_rs.out`: rs の fuzz と cargo test。
