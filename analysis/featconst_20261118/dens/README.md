## 読み

- **止める側 (qiu・rout)**: 今の既定では密の判定はほとんど掛からず (4・9 回)、判定を外しても 1.07・1.14 倍。10 月の記録 (ρ 21〜67) の
  密なカットは今の版ではもう出ない (qiu は木の分離のカットが 1 本、rout は ρ 3.7)。「止めないと遅い」側の証拠が消えている。
- **続ける側 (neos-911970・drayage-25-23・beasleyC3)**: neos-911970 は ρ 1.1〜1.2 で、判定の閾値 (10 倍) からはるかに遠い。57.5 / 16.6 秒の差は
  判定が一度も掛からない回同士で、揺れ (種 2 では 25.4 / 23.4)。drayage-25-23 (S3.md の反例: 0.05 × 自由な列で止めると時間切れ) は今は根で
  閉じて 0 ノード、beasleyC3 (10 倍で誤って止まった例) もノードのカットが 0 本で、どちらも判定に関わらなくなった。
- **neos-1445765**: 木の分離の費用はまだある (分離なし 75 秒、既定 132・195 秒)。φ ≈ 0.2 のカットを密と判定する既存の試作 `S3_TSDENSE=0.2` は
  148・104 秒 (既定 132・195) と揺れの中で、分離なしには届かない。φ で止める向きの問題はこの 1 問 (と S3.md の nubu 1 回) で、反対向き
  (φ の大きいカットの分離が効く問題) の例が今は手元にないので、φ0 や傾きを選ぶ材料がない。
- densecut_20261113.md の結論 (58 問ではノードのカットが元の行の 10 倍を超える問題は 0、密度で罰する・外す方向は打ち止めでよい) とも合う。

## 判断

シグモイドにする対象 (問題によって良い閾値が逆向き) が今の既定にはない。neos-1445765 だけを見るなら「木の分離の費用」の側
(群 2 の vsscip_slow で扱っている木の効率) の問題で、密度の閾値の形ではない。`S3_TSDENSE=0.2` を単純な候補として広く測る価値は低い
(効く問題が 1 問で、その問題でも揺れの中)。
