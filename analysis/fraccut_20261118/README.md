# fraccut 段 1 (測る) の記録 (2026-11-18)

BRIEF.md の段 1。試作 `ENOMOTO_MIP_FRACCUT` (src/mip/separation.rs、既定は不変、外側の根のカットのループだけ) を足して測った。
- `d` 診断: 毎ラウンド `MIP: FRACCUT round r: dobj … nfrac a -> b fsum a -> b active k/カット数 prev_viol … 種類`。
  種類は `up` (相対の伸び > 1e-4)、`face` (伸びがなく、今の LP 解が前のラウンドの終わりの LP のカットの行をすべて満たす
  = 前の最適面の上の別の頂点に移っただけ)、`flat_tight` (伸びはないが前のカットの行を破る = 最適面の側で多面体が締まった)。
  前のラウンドの写しは効いていないカットを外す前のものなので、`flat_tight` はやや多めに出る側。
- `o`: 非整数の列の数の減りで停滞を打ち消さない (目的値だけで数える、早く止める側)。
- `c`: 非整数の度合い Σ min(f, 1−f) が `ENOMOTO_T_MIP_FRACCUT_FDROP` (0.1) の割合以上減ったラウンドも停滞と数えない (長く続ける側)。

計測: stage1.sh (9 問 × d/o/c × 種 1・2、120 秒、4 スレッド、ビルド 72f367420)、unitcal_7 は種 3・4 の d/c を追加。集計 summ1.py → summ1.txt、ログ logs/*.log.gz。

## 結果
- (a) 下界がほぼ動かないラウンドは多い (beasleyC3 で 129 中 46、sp150x300d で 68 中 33)。その中で `face` (頂点が移っただけ) は
  p200x1188c・mik-250-20-75-4・misc07 で多く、ほかの問題は `flat_tight` が多い。ただし「下界が動かず非整数が 1 割以上減った」ラウンドは
  どの問題でも 0〜17 回と少ない。
- (b) o・c が止まるラウンドを変えたのは、beasleyC3・roll3000・unitcal_7・mc11 種 1・sp150x300d 種 2 だけ。misc07・p200x1188c・
  neos-1445765・mik-250-20-75-4 は根がまったく同じ (ラウンド数・根の下界が同じ)。
- 時間の幾何平均比 (時間切れは 120 秒): o/d 0.966、c/d 0.942 (18 組)。ただし差の多くは根が同じ問題の木の揺れ:
  neos-1445765 は根が 3 設定とも同じなのに d が 2 種とも時間切れ、o は 104・118 秒、c は 時間切れ・61 秒。
  根が変わった問題でも向きはそろわない: beasleyC3 は o・c とも速い (24→21・20、18→14・14) が、roll3000 は種 1 で o・c とも遅く
  種 2 で速い、mc11 種 1 は c で根の下界が下がって同じ時間。ノード数も一貫して減らない。
- unitcal_7 (4 種、時間切れ): c は根の下界を種 1〜3 で上げ (1.9532e7 → 1.9579e7 など)、120 秒の時点の下界も種 1〜3 で上、種 4 は逆。
  ノード数は減る (根に時間を使う分)。600 秒で解けるかは見ていない。

## 判断
非整数の減りが木の小ささ・時間につながる様子は見えない (根が同じ問題の揺れの方が大きい)。「下界を上げず非整数だけ減る」ラウンドは
もともと少なく、止め方を変えても止まるラウンドが変わる問題は一部だけ。BRIEF に従い段 1 で区切り、段 2 (点数に非整数の台の項)・
段 3 (連続の止め方) には進まない。残る候補は unitcal_7 (c で根の下界が上がる側が 3/4 種) で、根のループを長く回す効き目として
featconst 3 (ループの長さ) の側で扱う方が筋。
