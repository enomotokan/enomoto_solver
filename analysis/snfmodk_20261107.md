## 1. 方法

### 1.1 理論 (Gomory の群緩和、Caprara–Fischetti 1996・Caprara–Fischetti–Letchford 2000 の mod-k)

- 余裕 0 の行 `a_i x' <= b'_i` (x' は LP 値に近い方の境界で置き換えた変数、b' は置き換えた右辺) と、LP 値 `x̄'_j > 0` の整数列の集合 N について、
  重み `u ∈ [0,1)^m` で `u A_N` が整数なら CG カット `floor(u A') x' <= floor(u b')` の LP 点での違反はちょうど `frac(u b')`
  (使う行の余裕が 0 で N の外の列は x̄' = 0 なので `u A' x̄' = u b'`)。
- そうした u は (A_N の左の核の部分を除き) 有限アーベル群 G をなす。整数の行・列の変形で `L A_N R = diag(e_1, …, e_r)` (L・R はユニモジュラ) にすれば
  `G ≅ ⊕ Z/e_i`、生成元は `g_i = L_i / e_i` (mod 1)。割り切れの鎖 (Smith 標準形そのもの) は要らない (同型ならよい。統計は素数べきの因子 = 基本因子で数える)。
- `χ(u) = frac(u b')` は G から Q/Z への準同型で `χ(g_i) = c_i / e_i` (`c_i = L_i b' mod e_i`)。違反の上限は χ の像の位数 D について `1 − 1/D`。
  素数 k の mod-k は G の k 部分 (位数 k の元) しか見ないので、Z/4 の位数 4 の元 (違反 3/4) や Z/2 × Z/3 の位数 6 の元 (違反 5/6) は見つからない。

### 1.2 実装 (`src/mip/snfmodk.rs`)

- `snf_group(行列, 列の数, 核の上限, 非零の上限, 期限)`: 行列だけを受け取る (zerohalf の連立にも MODKVB の連立にも使う口)。
  1. ±1 の要素を軸にした疎な消去 (列の出る数の少ない順、行の長さ + 組み合わせの長さの最も小さい軸)。行の組み合わせ (L の行) を持ち歩き、
     消した行・列は捨てる (因子 1)。行が空になったら核 (違反に効かない) として捨てる。
  2. 残った核を密な i128 の対角化 (絶対値の最も小さい非零を軸にした行・列のユークリッドの互除)。R は持ち歩かない。
  3. 算術はすべて `checked_*` で溢れを検査し、溢れたら諦める (それまでに確定した生成元も捨てる)。核の 行 × 列 が 250000 を超える・非零が 2e7 を
     超える・期限 (既定 0.3 秒) でも諦める。
  4. 生成元ごとに `Σ w_i A_i ≡ 0 (mod e)` を確かめてから返す。
- `group_elements`: 生成元 1 つの倍数 (位数 12 以下は全部、それより大きければ χ を最大にする倍数と 1 倍) と、χ の位数の最小公倍数が両方より大きくなる
  2 つの生成元の組 (中国剰余定理での組み合わせ、それぞれ χ を最大にする倍数。台の小さい生成元 60 個まで) を作り、違反の上限の大きい順に 200 個。
- `snfmodk_cg_cuts`: zerohalf と同じ行・列の選び方 (整数列だけ・整数係数・整数右辺の元の行、整数の境界、LP 値に近い方の境界で置き換え) で、余裕が
  `1e-6 (1 + |活動量|)` 以下の行の向き (等式は 1 本) を行、`x̄' > 1e-6` の列を列とする。カットは元の係数から i128 で厳密に作り (溢れた元は捨てる)、
  LP 点で違反するものを効き目の順に 50 本まで返す。
- 呼び出し (`separation.rs`): 根の分離で zerohalf の後 (ノードの分離 `light` では `t` を付けたときだけ)。サブ MIP では使わない。
- MODKVB の口 (`modkvb.rs`): `ENOMOTO_MIP_SNFMODK` に `v` があれば、MODKVB の連立 (変数上下限で置き換え、行を整数にした空間) を `snf_group` に渡し、
  群の元を分母ごとに GF(k) の解と同じ形 (重み w / 分母) で集約して `vb_cover_cut`・`generate_cuts` に渡す (分母 65535 まで)。`k` も付けたら、群の元で
  カットが出なければ GF(k) (k = 2, 3, 5, 7) も試す。

### 1.3 単体テスト

- `random_group_order_matches_determinant`: 乱数の正則な正方行列 (1〜5 次) 300 個で、群の位数 (因子の積) = |det| と階数を確かめる。
- `group_of_diag`・`mod6_element`: 小さな例 (diag(2,3,6)、6 x = 5 で χ = 5/6 の元)。
- `random_validity`: 乱数の小さな整数の行 (係数 −7〜7、LP 点は分母 6 か 4 の有理数で、行の値が整数の行は右辺をそれに合わせて余裕 0 にする) 3000 問で、
  カットが全ての整数の実行可能点で成り立つことを総当たりで確かめる (カット 50 本以上・新しい位数のカット 5 本以上が出ることも確かめる)。
