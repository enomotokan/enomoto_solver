# 対称性の検出の同点の行の ±1 倍 (SYMSIGN) と右辺 0 の向き (SYMZERO) を既定にする (2026-11-06)

既定にした (それぞれ `=0` で以前の形。まとめて戻すには run.py の `presymsign` = `ENOMOTO_MIP_SYMSIGN=0 ENOMOTO_MIP_SYMZERO=0`):

| 環境変数 | 中身 |
|---|---|
| `ENOMOTO_MIP_SYMSIGN` | 対称性の検出に渡す写しで、-1 倍しても形が同じ行 (同点の行) に -1 倍した行を足す (二重にする)。行が -1 倍で対応する対称性も、係数をそのまま比べる今の細分化・探索・確かめで見つかる。見つけた置換は写しの上の確かめを必ず通る。同点の行があるときは検出の手間・時間の上限を写しの大きさの比で広げる |
| `ENOMOTO_MIP_SYMZERO` | 向きのそろえで -0.0 を 0.0 にそろえて比べる (`HO3_SYMNORM` は `total_cmp` で比べるので、右辺 0 の等式は係数によらず全部反転され、向きがそろわなかった) |

どちらも `ENOMOTO_MIP_HO3_SYMNORM=0` (向きをそろえない) のときは既定では働かない。`ENOMOTO_MIP_SYMSCALE` (行の正の倍率をそろえる) は既定にしていない (どの問題でも生成元を変えなかった)。

## 根拠 (`analysis/symsign_20261106.md`)

- 検出だけの数え (58 問・Mittelmann 186 問): 生成元が増えたのは SYMSIGN の 3 問だけ。neos-827175 57 → 66、neos-2746589-doon 31 → 33、
  neos859080 0 → 1 (80×2 のオービトープ、160 列)。SYMZERO・SYMSCALE はどの問題でも生成元を変えなかった。
- neos859080 (実行不能、60 秒 5 回): 既定 2/5 回 (2.5・21.2 秒)、SYMSIGN 5/5 回 (1.0〜15.7 秒)。neos859080 は根の LP の頂点で大きく揺れる問題で、
  今日の Mittelmann 600 秒の測り直しでも 118 → 262 秒だった。
- 58 問 (60 秒、2 回、SYMSIGN + SYMSCALE): 15.35 → 15.55 秒 (+1.3%)、88 → 87 問。検出の結果が変わるのは neos-827175 だけで、差は揺れとみる。食い違い・異常終了 0。
- 検出の時間の合計は 58 問 4.3 → 5.0 秒、Mittelmann 49.6 → 48.4 秒 (並べて走らせた値で揺れる)。
