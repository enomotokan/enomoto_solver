## 3. 試作 `ENOMOTO_MIP_SPARSIFY_LATE=s` (既定は変えない)

`src/mip/mod.rs` の `SPARSIFY_LATE` の所。疎化の後に f = 縮んだ行 / 書き換えた行 を数え、f ≥ `ENOMOTO_T_MIP_SPL_C` (0.5) のときだけ疎化した問題を
使う (そうでなければ疎化の前の問題のまま、既定と同じ)。

- 最初は σ((f − 0.5)/0.1) ≥ 1/2 の形で書いたが、問題につき 1 回の入り切りなので f ≥ 0.5 のしきい値と同じ。利用者の方針の訂正
  (「普通の if で充分ならそれでいい」) を受けて if の形に書き換えた (動きは同じ。`ENOMOTO_T_MIP_SPL_W` はなくなった)。
- 文字 `b` も付けると (`=sb`)、書き換えた行のうち 0-1 列だけの行の割合 b ≤ `ENOMOTO_T_MIP_SPL_BMAX` (0.5) のときに限る (8 節)。
- 計数の行 `MIP: sparsify-late stats ... gate 1.000|0.000 (f .. b ..)` (`ENOMOTO_MIP_LOG=1`)。

前処理だけの回で確かめた (`pre.jsonl` の `spls`): air03 122 行・nubu 444 行は既定と同じ大きさに戻る。kasai 1190 行・physiciansched6-2 8373 行・
neos-860300 568 行は疎化を使う。P の 58 問で既定と違う解き方になるのは physiciansched6-2・neos-860300 の 2 問、M の 48 問では kasai だけ
(widden は f = 0.497 で使わない)。

## 10. 結論とおすすめ (親の採否の基準: 入る問題で全種 1.25 倍超の遅れなし・誤答 0・入る問題の SGM が明確に改善)

- **おすすめは案 A: `ENOMOTO_MIP_SPARSIFY_LATE=s` + 中心 0.6 (f ≥ 0.6、b の条件なし)**。入るのは 240 問中 13 問 (14 問から physiciansched6-2 が外れる)。
  - 解ける 4 問 (種 1〜8): kasai 0.35 倍 (全種で速い)・neos-860300 0.96・nursesched-sprint02 1.10・decomp2 1.23。比の SGM は 0.82 (4 問で重みを等しく)。
    全種で 1.25 倍超の遅れなし。改善は kasai 1 問が担っている。
  - 時間切れの 9 問: 時間は変わらず、ギャップは良い向き 2 問 (turama・huahum)・混ざる 1 問 (irish)・揺れ/比べられない 6 問。
  - 誤答 0 (fuzz 4 種・I/J の照らし合わせ)。入らない 226 問は前処理の後が既定と一致 (6 節)。
- irish-electricity (b = 0、どちらの案でも入る) は揺れとして扱う: 4 種で spls が良い 2 種 (ギャップ 0.32 → 0.03・0.06)、悪い 2 種 (0.07 → 解なし、
  0.33 → 0.34)。どちらも 600 秒で根の近く (ノード 0〜4) で終わっていて、解が出るかどうかが種で入れ替わる。採否の判断には使わない。
- 発動の条件は普通の if (f ≥ 0.6) で足りる: 0.6 の上下に問題がなく (次点は 0.585 と 0.917)、境目がはっきりしている。
- 案 B (`=sb`) は physiciansched6-2・sprint02・decomp2 の遅れも外すが、入るのが 5 問に減り、9 問では b の根拠が確かめられなかったので推さない。
- 中心 0.6 は 0.5 の近くの 1 問 (physiciansched6-2、f = 0.585) を外すために結果を見て選んだ値。0.5〜0.6 の間にほかの問題はなく、次点は f = 0.917 (crypt) と
  0.373 (brazil3) なので、0.6〜0.9 のどこに置いても入る問題は同じ。
- 既定にするなら `ENOMOTO_T_MIP_SPL_C` の既定を 0.6 にし、`ENOMOTO_MIP_SPARSIFY_LATE` を既定で `s` にする形 (この試作では既定を変えていない)。
