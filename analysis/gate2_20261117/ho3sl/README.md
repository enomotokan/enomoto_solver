# gate2 候補 10: HO3_ENUM・SMALL3_SUBMIP_LIGHT・LOCALMIP の入り切り (2026-11-18、見込みの段で区切る)

BRIEF.md の候補 10。過去の記録と手元の確かめで、効く群と遅れる群を分ける特徴を探した。**3 つとも見込みが薄いので、試作は作らず (2) で区切った。**
ビルドは 2bde58103 (既定 = 0.1.9 + rtc + LPINF の確かめ)。

## HO3_ENUM (`ENOMOTO_MIP_HO3_ENUM`)

- 記録: analysis/presolve2_20261111.md (種 1〜6)、analysis/enumab_20261117/summ_P.txt・summ_P2fix.txt、analysis/treeclose_20261114.md 9.53〜9.60 節。
- 効くのは net12 の根の下界 (84 → 130、同値な組 154 + 締め付け 6) だけ。60 秒では net12 も解けない。presolve2 で解けた数が増えた
  h80x6320d・physiciansched6-2 は enumab の種 1〜3 では再現しない (def・ab・ho1 とも 134、取り直しでは 134・131・132)。
- 遅れる問題は 2 種類で、どちらも静的な特徴では net12 と分けられない:
  - neos8・nu25-pr12: 列挙の時間 (何も見つけない)。これは既にある `a`・`b` (空振りでやめる) で手当て済み。
  - neos-960392: 正しい締め付け 84 本で解く道筋が変わる揺れ (全種 1.7〜2.0 倍、絶対値は 2〜3 秒)。列挙は 0.02 秒。
- treeclose 9.57 節の見立て (net12 と neos-960392 を分ける素直な特徴がなく、作ると net12 合わせの規則になる) と同じ結論。
  シグモイドで入り切りする量の候補 (列挙で見つけた同値な組の数・締め付けの数) は前処理の中でしか分からない実行時の量で、
  「同値な組があるときだけ使う」形 (`e`) は net12 の効き目が消えることが 9.57 節で確かめ済み。

## SMALL3_SUBMIP_LIGHT (`ENOMOTO_MIP_SMALL3_SUBMIP_LIGHT=1`)

- 記録: analysis/small_overhead3_20261102.md (58 問 × 1 回だけ、1102 時点のコード)。
- 速い: nubu・neos-911970・10teams・pk1。遅い: physiciansched6-2・qiu (時間切れ)・noswot・h80x6320d・neos-860300・binkar10_1・mas76。
- 大きさで分けられない (遅い側に qiu 840 列・noswot 128 列の小さい問題、速い側に 10teams 2025 列)。1 回なので、qiu・noswot・
  neos-911970 は既定でも道筋で大きく揺れ、効く群自体が揺れと区別できていない。遅れの元は、打ち切り値つきのサブ MIP の中の
  ポンプ・ダイビングが出す解 (推測) で、問題の特徴でなく実行時の当たり外れ。種を重ねた記録がなく、特徴を数える材料がない。

## LOCALMIP (+ CHAIN) (`ENOMOTO_MIP_LOCALMIP=1`・`_CHAIN=1`)

- 記録: docs/improvement_history.md 9964〜9991 (10/23)、analysis/lmip1_cand_20261105.md。
- 記録の上の手がかり: 効く 30n20b8・neos-1456979・roll3000・physiciansched6-2 は FJ が 3 秒で解を出せない問題、遅れた neos-960392 は
  FJ が解を出す問題で、「FJ が解を出せないときだけ」は分ける特徴になりうる。
- **ただし今の既定は既に FJ のスレッドで Local-MIP + 連鎖を回している** (`ENOMOTO_MIP_FJ_LMIP_MIX`、既定、solver.rs:9766)。
  手元 (4 スレッド・60 秒・種なし 1 回、`lmc_check.sh`) で既定と LOCALMIP=1 + CHAIN=1 を比べた:

| 問題 | 既定 (状態・秒・値・最初の解の秒) | LOCALMIP + CHAIN |
|---|---|---|
| 30n20b8 | 時間切れ・302 (最初 6.0 秒) | 時間切れ・302 (最初 5.6 秒) |
| neos-1456979 | 時間切れ・342 (最初 4.3 秒) | 時間切れ・290 (最初 2.2 秒) |
| roll3000 | 時間切れ・12890 (下界 12622) | 時間切れ・12890 (下界 12515)。別スレッドの Local-MIP は解なし |
| physiciansched6-2 | 最適 30.9 秒 | 最適 31.2 秒 |
| neos-960392 | 最適 2.3 秒 | 最適 2.5 秒 |

- 10/23 の動機だった 30n20b8 (既定は暫定解なし → 302) は既定で既に 302 に届き、既定のログにも Local-MIP の解が受け付けられている。
  別スレッドを足す差は neos-1456979 の値 (1 回、揺れの範囲か不明) くらいで、入り切りを作る対象が残っていない。

## 判断

3 つとも、試作 → 広い計測に進む見込みは薄い。HO3_ENUM は net12 の 1 問合わせになり、SMALL3 は種を重ねた材料がなく、
LOCALMIP は既定 (FJ_LMIP_MIX) に吸収済み。
