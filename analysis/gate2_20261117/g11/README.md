  連続列の割合 0.9) では使わないという特徴による入り切りをすでに持つ。h80x6320d の遅れは `1` (固定費用型でも使う) のときの話で、`auto` では起きない。
  prune (analysis/prune_20261112.md:97) で止めた形は −0.2% [−6.1, +6.4]、2 種とも遅れる側は nu25-pr12 (止めると遅い) だけで、
  「入れると遅い」群が無い。

  BRIEF の neos-860300・nubu の損は 2026-10-27 の古い `TREE_RESTART` (inc 型、ガードなし) のもの。
