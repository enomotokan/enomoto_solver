## 1. 今の既定の上で何が残っているか (事実、コード)

- 元の試作 `ENOMOTO_MIP_NODELP2=pbxg` の部品のうち、`p` (木のノードの LP の費用の摂動) と `b` (保存した非基底の置き場所) は
  後に `ENOMOTO_MIP_NODELP_PERTURB=phg`・`ENOMOTO_MIP_BASIS_NB=t` として既定になった (analysis/revisit_20261112/inventory.tsv の 475 行)。
  `phg` の `g` の境 (`ENOMOTO_T_MIP_NODELP_HEAVY` 100) も同じ。今の既定の上で `pbxg` が足すのは `x` だけ
  (取り出したノード (兄弟でない) の最初の LP を、厳密な DSE 重みから解くか保存した重みから解くかを、スレッドごとの時間の移動平均で選ぶ)。
- 元の記録の効き (ns1830653 が 600 秒で 2 回とも解ける) と害 (traininstance6・tr12-30 の下界) は `p`+`b`+`x` を合わせた回で、
  厳密な DSE 重みがまだ密な計算 (traininstance6 118 ms/回) だった頃の wheel。今は超疎の計算 (7.7 ms/回、同じ記録の 8 節) が既定。
- 今の既定 (0.1.9 系) の ns1830653 は 363 秒で最適・600 秒で時間切れ (analysis/objint_20261112/logs_T の def)。

## 2. 分ける特徴 (記録から、楽観的)

ノードの LP の平均の反復 (120 秒・4 スレッドの計数、nodelp2_20261107.md の 3.1・3.2 節):

| 問題 | 平均の反復/LP | pbxg の向き |
|---|---|---|
| ns1830653 | 520〜670 | 効く (600 秒で 2 回とも最適) |
| rococoC10-001000 | 250〜290 | 揺れの範囲 |
| supportcase33 | 160〜180 | 揺れの範囲 (少し悪い向き) |
| traininstance6 | 80〜110 | 害 (下界) |
| tr12-30 | 60〜70 | 害 (下界) |

- 害の 2 問は境 100 の上下を行き来する (記録の推測)。平均の反復の対数のシグモイドで、中心を境より上 (150) に置けば分かれる。
- ただし効く 1 問・害 2 問から選んだ中心で楽観的。P の 58 問の多くは平均 100 未満でどちらでも何もしない。

## 3. 試作 `ENOMOTO_MIP_NODELP2=xs` (既定は変えない)

`src/mip/solver.rs` の `Solver::nl2x_gate`。文字 `s` を付けると、`x` の入り切りを段 (`g`) でなく連続関数にする:

- このスレッドのノードの LP の平均の反復 a (`node_iters / node_lps`) から w = σ((ln a − ln C) / W)、C = `ENOMOTO_T_MIP_NODELP2S_C` (150)、
  W = `ENOMOTO_T_MIP_NODELP2S_W` (0.3)。a = 100 で w ≈ 0.20、150 で 0.5、300 で 0.91、60 で 0.05。
- 取り出したノードのうち割合 w で `x` を使う (w を積算し、1 を越えたら 1 回使う。乱数は使わない)。
- ノードの LP が `ENOMOTO_T_MIP_NODELP2S_MIN` (32) 回に満たないうちは使わない (`avg_node_iters` は 0 回のとき 1000 を返し、`g` では
  起動直後が「重い」扱いになっていた)。
- 予算は時間でなく回数 (積算の割合) で決める。`x` の腕の選びは元のまま時間の移動平均 (重みの計算の時間と LP の時間を比べる部品なので残した)。
- `p`・`b`・`X` には効かない (`p`・`b` は既定で入っている)。
