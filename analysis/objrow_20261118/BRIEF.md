# 目的関数の打ち切りの行を伝播とカットの材料に使う (2026-11-18、利用者「目的関数の項を等式制約で置き換えて伝播やカット生成で有利にならないか」→「進めて」)

## 方針
- 暫定解 UB があれば `cᵀx ≤ UB − δ` (δ は目的の整数性があれば刻み) は正しい行。LP に行として入れるのは双対退化と密な行で不利になりやすいので入れず、
  伝播とカットの材料にだけ使う。目的の値が整数の問題では z = cᵀx を整数とみなす。
- 今あるもの: `Solver::global_obj_prop` (src/mip/solver.rs 14961 行付近、大域の範囲での打ち切りの行の伝播。`all` が偽なら目的の列が多い問題では回さない)、
  `ENOMOTO_MIP_TREEFIX` の `p` (src/mip/treefix.rs)、目的の整数性による下界の切り上げ (analysis/objint_20261112)。カットの材料としての打ち切りの行はない。

## 進め方 (段ごとに親へ短く報告、効かなければ区切る)
1. 測る: 今の打ち切りの行の伝播がどの問題で回り、何本締めているか (目的の列が多くて回していない問題がどれだけあるか)。根の下界と暫定解が近い問題
   (P と M のログから、根の終わりの間隙が小さく木が大きい問題) を選ぶ。
2. 試作 A (伝播): 目的の列が多い問題でも、手間 (非零の数) に見合う間隔で打ち切りの行の伝播を回す (間隔は手間の関数)。
3. 試作 B (カット): 根の分離で、暫定解があるときだけ打ち切りの行を集約 (CMIR)・被覆 (ナップサック型の目的) の材料の候補に足す (LP には入れない)。
   目的が整数の問題では z の整数性を使った丸めのカットも。根の下界・カットの本数・時間を種 2 つで手元で確かめる。
4. 効けば cargo test・fuzz で誤答 0、P・M の台本を用意して親に計測を依頼。
