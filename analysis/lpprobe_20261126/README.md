# lpprobe: 根の前処理の LP プロービングを速くする (2026-11-26、親の依頼)

背景: analysis/rootpar_ph_20261126 の診断 (根の重い 37 問・4 スレッド) で、前処理は計 105 秒・CPU 平均 1.99 本。LP プロービングは 32.9 秒
(cod105 21.9 秒、CPU 2.83)、プロービング (同値の巡まで) は 28.8 秒 (mzzv42z 8.7・supportcase7 5.0・30n20b8 3.8)。
プロービングの並列 (`PROBE_PAR`) は analysis/rootpar_20261122 3 節で閉じた (含意を使うプロービングは 1 回の試しが 0.2 ミリ秒前後と軽く、
窓の写しの分だけ遅くなる。速くするなら繰り返しを減らす方がよい、という見立て)。

## 0. LP プロービング ([`lp_probe`]、src/mip/mod.rs) の中身

1. **最初の LP**: 前処理の後の問題の LP 緩和を基底なしで解く (4 スレッドなら単体法と内点法の同時実行)。上限は手間
   (`ENOMOTO_MIP_PRESOLVE_WORK`、反復 × (行 + 列 + 非零) が 1.25e9) と安全網の時間。止まったら固定を試さずに終える (基底は捨てる)。
2. **子の LP**: 最初の LP の解で分数の整数列を、分数部分が 1/2 に近い順に並べ、列ごとに上の子 (x ≥ ⌈v⌉) と下の子 (x ≤ ⌊v⌋) を
   最初の LP の最適基底から双対単体法で解く (温め: 基底・LU・DSE 重みの写しを持つ状態を保存し、子ごとに戻す)。
   1 本の反復の上限 `per_lp` = 最初の LP の反復 / 4 (200〜2000)。**実行不能になった子だけが結果を生む** (反対側に締める。両方なら実行不能)。
   最適・反復の上限で終わった子からは何も得ない (打ち切り値による固定はしない)。
3. **打ち切り**: 固定が 0 のまま 8 列 (`PRESOLVE_WORK_LP_GIVEUP_COLS`) を試すか、子の反復が「最初の LP の反復 + 2e7 / (行 + 列)」を
   越えたらやめる。固定が出たら最大 3 巡。4 スレッドでは候補の窓を塊に分けて写しの LP で並べて解く (`PREPAR` の `l`、結果はスレッドの数によらない)。
4. 固定が出たら前処理をかけ直す。最初の LP の基底は「固定が出た」か「最初の LP が重い」ときだけ根の LP に渡す。

### 1.4 子の LP 1 本の手間の内訳 (`ENOMOTO_MIP_XPROF` の区間計時、cvs16r128-89・physiciansched6-2、1 スレッド、窓なし `ENOMOTO_MIP_PREPAR=pe`)

- 子の LP は反復によらず 1 本に固定の手間がかかる: cvs16r128-89 (4633 行) は 14 反復で 0.13 秒、physiciansched6-2 (12095 行) は 21 反復で 0.07 秒。
- 区間を分けると (cvs16r128-89、子 8 本): 主ループ 1.20 秒、**厳密な DSE 重みの作り直し 0.97 秒** (主ループの前の重みの初期化、
  1 本 0.12 秒)、LU の写し 0.07 秒。physiciansched6-2: 主ループ 0.12 秒、DSE 重み 0.33 秒。
- 理由: 子は保存した状態 (最初の LP の最適基底) に戻してから解く。その LU は FT 更新が 64 回を超えているので `mip_lp` は使わず
  (`n_upd64`)、引き継いだ DSE 重みは既定では使わない (`ENOMOTO_WARM_DSE` は閉じた)。そこで `ENOMOTO_MIP_DSE_INIT` の `u` (既定) の
  「温めた始動で重みが渡らなければ、その基底の厳密な重み (m 回の BTRAN) から始める」に毎回入る。**どの子も同じ基底・同じ LU から
  同じ重みを m 回の BTRAN で作り直している** (無駄の型: 同じものの作り直し)。

### 1.5 無駄の大きい所 (まとめ)

| 型 | どこで | 大きさ |
|---|---|---|
| 同じものの作り直し | 子の LP ごとの厳密な DSE 重み (同じ基底・同じ LU) | 子の LP の時間の 3〜7 割 (cvs16r128-89 0.97 / 2.4 秒、physiciansched6-2 0.33 / 0.5 秒) |
| 結果の出ない子 | 反復の上限まで走る子 (P で 41 本・11441 反復、cod105 で 7 本・11 秒)。結果を生む子 (実行不能) は `per_lp` の 0.55 倍以内で終わる | P 1.2 秒、cod105 11 秒 |
| 結果の出ない列 | 55 問中 50 問は固定 0 (8 列試してやめる) | P の子の時間の大半 (10.7 秒中) |
| 捨てる最初の LP | 止まった最初の LP の基底を捨て、根で一から解き直す (ns1116954 6.8 + 13.0 秒、cod105 1 スレッド 36.4 秒) | 問題による (`ROOTCAP p` で渡す形は逆効果で閉じている) |
| 根の LP の解き直し | 行の変わった後の「列だけ」の基底 (physiciansched6-2 6623 反復) | 0.5〜2.8 秒/問 |
