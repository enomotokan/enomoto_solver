# TUBR: TU の部品を逆向きに使って「分枝しなくてよい整数列」I' を見つける (2026-11-12)

bench に使う環境変数: `ENOMOTO_MIP_TUBR` (試作、既定では使わない。`1` 使う、`h` ネットワークの判定なしで 2 色塗りだけ、`F` 診断: どのノードでも
I' 以外を丸めて固定した繊維の LP を解き、I' が整数かを数える (刈り込まない))、`ENOMOTO_T_MIP_TUBR_MIN_SHARE` (整数列に対する I' の割合の下限、既定 0)、
診断 `ENOMOTO_MIP_TUBR_COUNT` (`=stop`、前処理の後の問題で I' を数えて終える)。計測の設定の名前: `def`・`tubr` (`ENOMOTO_MIP_TUBR=1`)。

## 結論 (途中)

- 数え (段階 1): 58 問と Mittelmann 186 問 (重なりを除き 203 問) の前処理の後で、I' が 1 本以上あるのは 67 問。割合が大きいのは neos-787933 94.5%、
  neos-4722843-widden 93.1% (ネットワークの判定で。2 色塗りだけなら 0.4%)、sing326・sing44 33%、dcmulti 20%、neos-2746589-doon 17%、
  radiationm 13%、fiball 12%、piperout-27 12%、nexp-150-20-8-5 11%、drayage 10%。全部の整数列が I' になる問題は 0。58 問で I' があるのは 16 問で、
  どれも 10% 以下 (`count_v1.jsonl`)。
- 試作 (段階 2): 分枝の候補から I' を外す。ノードで分数の整数列が全部 I' なら、I' 以外を固定しカットを外した繊維の LP を解いて、頂点が整数で
  刈り込めればノードは解けた扱い、だめなら I' でも分枝する (安全網)。
- 事実: 繊維の LP の道 (分数の列が全部 I') は、12 問の 60 秒・fuzz 6000 問のどれでも 1 度も起きなかった。I' 以外が整数の LP の頂点では、
  カットが I' の部分に触れない限り I' も自動的に整数になるので、起きにくいのは理屈どおり (推測ではなく、TU の頂点の性質から)。効き目は
  「分枝の候補から外す」だけで、12 問 x 種 1 では差は揺れ程度 (`panel.jsonl`)。
- 誤答: 0 (fuzz_tubr 1000 + 3000 + 2000 問、fuzz_tiny 400、mip_fuzz_vs_highs 300)。`F` の確かめ (繊維の LP の頂点で I' が整数か) は fuzz で 262 回、
  dcmulti・blend2 で 14 回、外れ 0。cargo test 409 通過。
- 58 問 x 種 1〜3 (60 秒・4 スレッド、3 分担、コミット 2b372e98 の `1` = 分枝の候補から外すだけ、`tubr58_s0〜2.jsonl`、`summ_tubr58.txt`): SGM 17.67 → 17.71
  (+0.2%、95% 区間 [−2.5%, +2.9%])、解けた回 126 → 127、誤答 0。I' のある 16 問だけでは +3.1% [−0.2%, +7.4%] (解けた 36 → 36、5% 超の遅れ 3 問・
  速い 0 問)。分枝の候補から外すだけでは得がない (I' のある問題で少し遅い向き)。

## 判定 (src/mip/tubr.rs)

- 候補 = 固定されていない整数列と、境界が整数か無限の連続列 (S には連続列も入る)。行を候補の係数で割り (連続の候補があればその係数、なければ候補の
  係数の絶対値の最小)、±1 でない整数の候補は I' 以外 (固定する側) に回す。候補でない列の係数・有限の左辺右辺が整数でない、ほかの連続列を含む、なら
  行の候補を全部外す。候補の部分の行列の連結成分ごとに TU (剥がし + 2 色塗り、だめならネットワーク行列かその転置) を確かめ、だめな成分は丸ごと外す。
  変わらなくなるまで繰り返し、最後に外さずに全部の行と全体の TU を確かめ直す (安全網。203 問で落ちたのは 0)。
- 単体テスト 3 件 (施設の開設 y と流量 x で x だけが I'、奇閉路は空、端数の右辺は空)。

## 次の一手

- 58 問の対の結果を見て判断。繊維の LP の道が起きないので、効き目は分枝の候補の絞り込みだけ。害 (強分岐・疑似費用の候補が減る) が見えれば、割合の
  しきい (`ENOMOTO_T_MIP_TUBR_MIN_SHARE`) を試す。成分ごとに丸ごと外す判定を、成分の中の一番出現の多い整数列だけ外す形 (`detect_opt` の `greedy`)
  にすると I' が増えるかは、まだ数えていない (数えの診断には入れた)。
