- ppi (2 スレッド以上でだけ働く) は原因ではない。既定に足しても def 並み、抜いても遅いまま。
- **原因は sbpb**。抜くと 3 回とも def 並み (99〜133)、既定に足すだけで 349・431 (def の 2〜4 倍)。
  sbadapt_20261124 で見た 30n20b8 の sbpb の害 (ノード 2 の正しい伝播の推論で木の道筋が変わる) が 4 スレッドでも出ている。
  1 スレッドで combo が良かったのも同じ道筋の運の側 (1 スレッドの def は 600 s で解けず、両方とも道筋次第)。
- 1 つ抜いて 1 回だけの行 (−nra 時間切れ・−tie 517 など) は sbpb が入ったままの揺れと見る。修正入り combo の 133・122 も sbpb 入りで、当たりの回と見る。
- 試作は作らない。既存の `ENOMOTO_MIP_SB_ADAPT=1` (sbpb を f_B = σ(11.9 (0.185 − deg)) の確率で効かせる。30n20b8 は deg ≥ 0.37 で f_B が小さい) に
  置き換えると 127・175 で def 並み。combo に入れるなら sbpb を SB_ADAPT=1 に替えるのが筋。
