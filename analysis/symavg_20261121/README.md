# SYMAVG: 対称性のある問題で根の下界を上げる (2026-11-21、親の依頼・利用者の了承)

依頼: analysis/disj_20261119.md 8 節で「1 列の離接でも上がる余地なし」(A < 0.1%) だった問題の多くは対称性が原因とみて、(1) 当方が検出している群と
働いている部品を調べ、(2) 根のカットを軌道で平均した 1 本を足す試作 (既定オフ) を作り、(3) 根だけで下界と手間を比べる。新しい閾値は作らない。
ビルド: d882b0772 以降の既定 (0.1.10)。台本: `one.sh`、`scipsym.py` (SCIP の検出だけ)、`rootcmp.py` (根の比べ)、`fuzz.sh`。

## 1. 材料: 停滞する問題に対称性はあるか (事実)

- 対象: disj 8.3 節で A < 0.1% の問題と P の停滞の問題、計 55 問 (`stalled.json`)。当方の検出は analysis/scipsym_20261120/pplexscan.jsonl
  (1 スレッド・前処理の後)、SCIP 10.0.2 の検出は `scipsym.py` (前処理だけ、`dispsyminfo`)。
- **55 問中、当方が対称性を見つけるのは 24 問だけ**。名前の挙がった問題のうち:

| 問題 | 当方 | SCIP (生成元、log10 群の大きさ) | 根で使う部品 |
|---|---|---|---|
| gmu-35-40・gmu-35-50 | なし | **なし** (前処理後 652・953 列) | — |
| bppc4-08 | なし | **なし** | — |
| markshare2・markshare_4_0 | なし | **なし** | — |
| chromaticindex512-7 | 3 生成元 | 4 生成元、**10^1.68 (約 48 元)** | orbital fixing (動的) |
| chromaticindex1024-7 | 4 生成元 | (同じ型) | orbital fixing |
| graph20-20-1rand | 36 生成元・52 軌道 1924 列 | 36、10^43.1 (37x37 の詰め込みオービトープ) | 静的なオービトープ (ORBPP、666 列固定 + REPROBE) |
| cod105 | 11 生成元・1 軌道 1024 列 | 11、10^10.6 | PPLEX (静的な orbisack 66 本、既定) |

  ほかに対称性のある停滞の問題: lectsched-5-obj (180 生成元、144 を orbital fixing、18 のオービトープ)、sct2 (82、19 のオービトープ)、brazil3 (77、静的 2)、
  neos-2746589-doon (65)、uccase12 (34)、neos-911970 (17、7 のオービトープ)、supportcase18 (17、静的 1)、mcsched (15)、wachplan・neos-2978193-inde (5)、
  rout・ns1208400・fastxgemm (4)、misc07・mas74・mas76 (2)、noswot (3)、nu25-pr12・glass4 (1)。
- 読み: **「1 列の離接で上がらない」停滞の主因は、多くの問題で対称性ではない** (gmu・bppc・markshare は SCIP でも対称性なし。chromaticindex の群は 48 元程度で
  小さい)。強い退化 (別の列で同じ LP 値を作れる) や、ほぼ対称 (係数が少しずつ違う) の方が近い (推測)。graph20・cod105 は群が大きいが、既に静的な扱いで
  根を大きく固定している (graph20 の根 −11、最適 −9。cod105 は根で最適)。
- 根の LP の最適面の「対称な点」: LP の行・目的・境界が群で不変なら、最適解 x* の群平均 (各列 = その軌道の上の x* の平均、Reynolds の作用素) は常に
  実行可能で目的値も同じなので、**対称な点は必ず最適面にある** (調べるまでもない事実)。逆に、静的な対称性の扱い (ORBPP・PPLEX・SST・lex-leader の行) が
  入った根の LP は不変でないので、この議論は使えない。

## 2. 試作 `ENOMOTO_MIP_SYMAVG` (既定はオフ、src/mip/separation.rs・mod.rs)

- 根のカットのループで選んだカット `a x <= r` ごとに、群平均 `ā x <= r` (列 k の係数 = k の軌道の上の a の和 / 軌道の大きさ) を作る。群の元の像の凸結合
  なので、像が正しいとき (既存の `ENOMOTO_MIP_SYM_CUTS` と同じ条件: 根の時点で対称性を崩す処理がない = 生成元を `SYM_CUT_GENS` に置く条件。
  静的なオービトープ・PPLEX・SST・lex-leader の行があるときは使わない) 正しい。軌道は生成元の union-find (群の軌道と同じ)。
- 理屈: LP の行が群で不変なら、平均の 1 本を足した LP の値は、像を全部足した LP の値と同じ (不変な LP の最適値は対称な点で取れ、対称な点では
  `a x = ā x`)。なので軌道の像を全部足さずに 1 本で同じ下界に届く (根で不変な LP のときだけ)。
- `=1`: 平均したカットを次のラウンドで必ず LP に入れる (forced)。`=v`: 次のラウンドで今の LP の解を破るときだけ候補にする。比べに既存の
  `ENOMOTO_MIP_SYM_CUTS=1` (選んだカットの生成元の像をプールに入れ、破るものを候補に)。新しい閾値はない (像の上限は既存の `SYM_CUTS_MAX`)。
- 正しさ: cargo test 419 通過。fuzz (`fuzz.sh`・`fuzz/`) は全部 bad 0: mip_fuzz_symmetric 規模 1・2 (オービトープあり・なし、=1・=v、4・1 スレッド)、
  fuzz_pplex (PPLEX を切る)、mip_fuzz_vs_highs。平均したカットを作った求解は 153 回。

## 3. 根だけの比べ (1 スレッド・ノード上限 1・600 秒・種 1、`rootcmp.jsonl`・`rootcmp_summ.txt`、事実)

試作が働く 18 問 (対称性があり、根で対称性を崩す処理がない)。閉 = (下界 − 既定の下界) / (参照値 − 既定の下界)。

| 問題 | 既定の下界 → 参照値 | avg1 | avgv | symcuts (既存) |
|---|---|---|---|---|
| rout | 990.5 → 1077.6 | **+25.1%** (2.6 → 7.1 秒) | **+22.3%** (2.0 秒) | +23.5% (4.5 秒) |
| neos-911970 | 46.86 → 54.76 | **+5.0%** | 0 | 0 |
| lectsched-5-obj | 14.67 → 24 | +3.6% (62.5 → 50.7 秒) | 0 | +3.6% (38.1 秒) |
| uccase12 | 11507.37 (残り 1e-4 未満) | +1.7% | +1.7% | +2.4% |
| mas76 | 39042 → 40005 | **−2.0%** | 0 | 0 |
| nu25-pr12 | 53901.9 → 53905 | **−86 (残りの 28 倍下がる)** | 0 | 0 |
| ほか 12 問 (misc07・noswot・mas74・fastxgemm・mcsched・sct2・wachplan・ns1208400・chromaticindex512-7/1024-7・doon・inde) | | 0 (±0.1%) | 0 | 0 |

- 下がった 2 問は、`=1` で強制した平均のカットが LP の行の枠を使い、カットのループ全体 (再開を含む) の道が変わったため (nu25-pr12 はループの始めの値から
  53812 と違う、mas76 は 102 本 vs 193 本のプール)。カットは正しいので LP の値が下がる理由は道の違いだけ。
- 手間: `=1` は平均のカットを全部入れるので rout で LP の行 41 → 644 本、時間 2.6 → 7.1 秒。`=v` は増えない。
- **読み**: 効くのは rout (25%) くらいで、既存の SYM_CUTS (像をプールに) とほぼ同じ。停滞の問題の大半 (chromaticindex・doon・sct2・wachplan・mcsched・
  fastxgemm など) は 0。1 節のとおり停滞の主因が対称性でないか、群が小さい・根の LP が対称性を崩す前提を満たしても「1 本の平均」が今の LP の解を
  切らない (平均のカットは対称な点を切るときだけ効く) ため。**既定にする根拠はない**。`=v` は害がなく rout で効くので、試すなら `=v`。

## 4. 軌道で縮めた問題 (orbital shrinking) の見込み (案、作らない)

- 根の LP (不変なとき) の値は、軌道ごとの和の変数に縮めた LP の値と同じ (Reynolds) なので、**LP のレベルでは何も得ない**。得があるのは縮めた問題を
  整数として解く場合 (Fischetti・Liberti の orbital shrinking: 縮めた変数の整数性・ナップサックの集約で LP より強い緩和になる) だけ。
- 見込みのある型: 軌道が大きく、軌道の和に整数性の意味がある問題 (詰め込み・分割の行の列が 1 つの軌道に揃うもの)。1 節の材料では、大きな群の
  graph20・cod105 は既に静的な扱いで根が強い。lectsched-5-obj (563 列の軌道)・neos-2746589-doon (65 生成元)・sct2 (984 列の軌道) が候補だが、
  どれも根の下界の残りは対称性より別の理由 (3 節で平均・像のカットがほぼ 0) とみられ、縮めた MIP を根で解いても大きく上がる見込みは薄い (推測)。
- 作るなら: 根の時点の不変な問題 (対称性を崩す前) を軌道の和で縮め (行も軌道で集約)、サブ MIP の予算 (手間) で解いた下界を大域の下界にする。
  正しいのは目的が線形で群で不変・可行領域が凸のとき (MIP の緩和として: 元の整数解の群平均の和は縮めた問題の整数解)。
