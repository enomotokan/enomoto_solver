# SCIP との比べの測り直し (2026-11-20、利用者の依頼、分担表だけ先に用意)

analysis/vsscip_20261117 (0.1.9 の既定と SCIP 10.0.2 の比べ) と同じ問題・種・形で、今の既定を測り直す。
回す時期は親が決める (vbce・LPFACE・再スタートの直しの採否が済んでから)。

## 設定 (cfg.py)

- def: 当方の既定 (環境変数なし)、4 スレッド。
- def_t1: 当方の既定、1 スレッド (run.py の TH)。
- scip: **回さない**。11/17 の scip の行 (同じ機械・同じ種、SCIP 10.0.2・pyscipopt 6.3.0、逐次) を summ.py で読み込んで使い回す。

## 問題と分担 (plan.py)

- 分担は見積りの最大が 1.8 時間に収まるように切った (2 時間に余裕を残す)。作り直しは `python plan.py [時間]`。
- 見積りは 11/17 の同じ設定の時間 (解けなければ上限) に、1 回ごとに M は +30 秒、P は +8 秒を足したもの。
- 同じ (問題, 種) の 2 設定は同じ分担で続けて解き、順は組ごとに入れ替える。

| 集合 | 問題と種 | 設定 | 上限 | 回し方 (K) | 分担 | 見積り | 計 |
|---|---|---|---|---|---|---|---|
| M | Mittelmann 186 問 × 種 1 | {def, def_t1} | 600 秒 | `python run.py M K` (0〜24) | 25 | 各 1.73〜1.75 時間 | 43.5 時間 |
| P | MIPLIB の 58 問 × 種 1〜3 | {def, def_t1} | 60 秒 | `python run.py P K` (0〜1) | 2 | 各 1.6 時間 | 3.2 時間 |

## 集計 (summ.py)

`python summ.py M > summ_M.txt`、`python summ.py P > summ_P.txt`。11/17 の summ.py の写しに次を足した:
- 11/17 の scip の行を読み込む。
- 11/17 の当方の def・def_t1 を `def@1117`・`def_t1@1117` として読み込み、前の版との比べ (def / def@1117・def_t1 / def_t1@1117) も出す。
- 比べは def / scip・def_t1 / scip・def_t1 / def。SGM は shift 1 秒、時間切れは上限で数える。CI は問題単位のブートストラップの 95%。
- 食い違い (最適値の不一致・最適と実行不能の衝突) は、11/17 の scip・vshighs の HiGHS も含めて見る。
- 台本の確かめ: 11/17 の def・def_t1 の行を新しい結果に見立てて P で流し、集計が動くことを確かめた (結果はコミットしない)。

## MPS 読み込みの切り替えの確かめ (2026-11-20、a7e9d28e8 の後)

計測の台本のモデル読み込みを HiGHS 経由からこのクレートの MPS 読み込み (`PyModel.read_mps`) に切り替えたので、
`.miplib_cache` の全 204 問 (M の 186 問・P の 58 問を全部含む) で両方の読み方のモデルを比べた
(`python scripts/check_mps_reader.py .miplib_cache/*.mps* --out analysis/vsscip_20261120/mps_reader_check.jsonl`、3c0625a82 のビルド)。

- **203 / 204 が一致** (変数の上下限・整数性、目的、行数・非零数)。読めない問題・負の UP の違いはなし。
- 一致しないのは **momentum1** (M に入っている) だけ: 行数は同じ 42680、非零が 103191 (HiGHS 経由) vs 103198 (このクレート)。
  差の 7 個は MPS ファイルの絶対値 1e-9 以下の係数 (x42/c32597 −6.31e−10、x56/c32560 −3.16e−10、x57/c32560 −1e−9、x86/c32538 −3.98e−10、
  x90/c32569 −2.51e−10、x131/c32552 −3.16e−10、x146/c32552 −3.98e−10)。HiGHS は読むときに |a| ≦ 1e-9 (`small_matrix_value`) を捨て、
  このクレートはファイルのとおり残す。11/17 の結果と比べるとき、momentum1 だけは解いた行列がわずかに違う (7 係数) ことに注意。
