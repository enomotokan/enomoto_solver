## 1. 実装 (`src/mip/symdyn.rs`、既存のファイルへの差分は小さく)

### (a) 動的な辞書式の縮小 `ENOMOTO_MIP_SYMDYN` (van Doornmalen・Hojny「A Unified Framework for Symmetry Handling」2022/2024、SCIP 9 の lexred)

- 各ノードで、根からそのノードまでの分枝の並び (`OpenNode::changes`、親の対称性の固定 `sym` の印を除く) の、列が最初に
  分枝された順 σ を辞書式の比べの順にする ([`symdyn::branch_order`])。子の順は親の順を延ばすだけ (両方の子が同じ列を足す)。
- 生成元 γ ごとに `σ(x) ≥_lex σ(γ(x))` (`γ(x)_v = x_{g(v)}`) を伝播する ([`DynSym::prop_one`]): 先頭から、両辺が同じ値に
  固定されている位置を飛ばし、最初に差が出うる位置 v で `x_v ≥ γ(x)_v` になるよう両方の列の境界を締める。締めて等しく固定
  されたら次の位置へ進む。等号が 1 つの値 c でしか成り立たないときは、等号を仮に置いて後ろの位置を境界だけで見て
  (`peek_equal_feasible`)、破れるなら等号を除く (整数列なら `x_v ≥ c + 1`、像の側 `≤ c − 1`。SCIP の lexred の peek と同じ考え)。
  真に大きいと決まった位置で止まる。締めたら行の伝播を回し、変わらなくなるまで繰り返す (最大 20 回)。
- 0-1 以外の整数列・連続列にもそのまま使える (連続列は等号を除く締めはしない)。
- 締めは「外から来た変更」(理由 tag 3、オービトープ・orbital fixing と同じ) として定義域に置くので、衝突解析はこれを文字として
  残し、学習した衝突は大域的に成り立つ。親の締めは子に渡さず、子で数え直す (順が延びるだけなので同じ締めが再び出る)。
- 生成元の出どころと使い分け:
  - 既定の orbital fixing (HiGHS 流、`SYM_OF_GENS`) の生成元をそのまま使い、**orbital fixing の代わりに**呼ぶ
    (`Solver::orbital_fixing_checked` の頭で分ける)。同じ群に、違う規則の代表を残す 2 つの処理を重ねると、両方に切られて
    最適解が全部消えることがあるので、両方は使わない。
  - オービトープ (動的な orbitopal fixing) とは混ぜる: orbital fixing の生成元は、もともとオービトープの列 (と、オービトープの
    生成元が動かす列) を動かさないものだけなので、群は直積に分かれ、成分ごとに別の処理を使ってよい (van Doornmalen・Hojny の
    枠組みの、直積の成分ごとの組み合わせ。論文本文は届かず未確認、SCIP 9 も成分ごとに orbitopal reduction と lexred を
    使い分ける)。
  - `ENOMOTO_MIP_NO_ORBITOPE=1` と合わせる (`dynall`) と、全ての生成元を辞書式の縮小で扱う。
  - lex-leader の行 (`ENOMOTO_MIP_NO_SYM_OF`) とは混ぜない (行は列の番号の順の代表を残す)。このときは `SYM_OF_GENS` が
    置かれないので試作は何もしない。
- サブ MIP では使わない。木の並列の従には `TreeSnapshot` の `of_gens`・`refl_gens` で渡し、従も同じ順の規則で数える。
  再スタートの後は orbital fixing と同じく生成元を確かめ直したもの (`sym_of_reverify`、反転は `symdyn::reverify`) を使う。

### (a'') 軌道の比べ `ENOMOTO_MIP_SYMDYN=o` (47 問の cod105 を見て足した)

- 生成元ごとの比べ `x ≥_lex γ(x)` は、生成元の数しか比べない。cod105 (推移的な群、生成元 11 個) では既定の orbital fixing が
  分枝 x_v = 0 の子で v の軌道全体 (1454 本) を 0 に固定して 14 ノードで解けるのに、`refl` (生成元ごとの比べだけ) は
  8653 ノードで時間切れになった (事実)。
- そこで、順の位置 i ごとに、先頭 v_1..v_{i-1} を動かさない部分群 H_i (既存の `OrbitalGens::schreier_stabilizer` を順に重ねて
  求める。軌道 4096・生成元 64 で打ち切れば部分群) での v_i の軌道 O_i について `x_{v_i} ≥ x_u` (u ∈ O_i) を締める
  (`DynSym::orbits_for`、先頭の並びごとに固定群と軌道を控える)。H_i の元 γ は先頭の位置を動かさないので、`x ≥_lex γ(x)` は
  位置 v_i の比べを含み、同じ「順で辞書式に最大の代表」の規則の一部になる (生成元ごとの比べ・反転と混ぜてよい。証明は自前で、
  論文の orbital reduction と同じものかは未確認)。推移的な群で v_1 を 0 に分けると軌道の全ての列が 0 になる。
- 2 本目のビルド: 計測の途中で入れたので、計測に使っていた版 (661a44ca) に `symdyn.rs` だけを載せて組み直した
  (既定・`dyn`・`refl` の動きは同じ)。`reflo` (`SYMREFL=1` + `SYMDYN=o`) の回はこのビルド。

### (b) 反転の対称性 `ENOMOTO_MIP_SYMREFL` (Hojny「Detecting and Handling Reflection Symmetries in Mixed-Integer (Nonlinear) Programming」2024)

- 検出 ([`detect_reflections`]): 有限の境界を持ち固定されていない列 j ごとに反転した列 x̄_j (同じ境界・整数性、費用 −c_j) を
  足し、各行を中心 ((lo + up)/2) からのずれで書いて x_j に係数 a、x̄_j に −a を置き、区間を中心の分だけずらした行と、その
  −1 倍の行の両方を置いた写し Q を作る。x_j と x̄_j は右辺が他と重ならない 2 列の行で結ぶ。Q の列の置換は組を組に写し、
  x_j → x̄_k は「x_j を x_k の反転に写す」と読める (論文の「各変数に x と −x の 2 頂点を置き、間に辺を張るグラフ」と同じ考え。
  検索の抜粋で確認、細部は未確認)。既存の検出 ([`symmetry::detect`]、色の細分化と探索) で Q の生成元を求める。
- 確かめ ([`verify_signed`]): 見つけた符号つきの置換 T (`(Tx)_v = r_v ? (lo_v + up_v − x_{g(v)}) : x_{g(v)}`) を元の問題で直接
  確かめる (動かす位置で境界・整数性が同じ、反転する位置で境界が有限、`c_v s_v = c_{g(v)}`、各行に T を代入した行が −1 倍を
  許して同じ区間で問題にある)。通らなければ逆元を試す。反転を 1 つも含まない生成元は捨てる (置換は既存の検出が持つ)。
- 扱い: (a) の辞書式の縮小に、`γ(x)_v = lo_v + up_v − x_{g(v)}` として足す (`SYMREFL` は `SYMDYN` も入れる)。0-1 列 v を自分の
  反転に写す生成元なら、v を最初に分枝したノードで `x_v ≥ 1 − x_v` から `x_v = 1` が出て、0 の側の子が刈られる (lex-leader と
  同じ考えで 1 本を 1 に固定するのに当たる。根では順が空なので何もしない)。
- オービトープの列を動かす反転の生成元は捨てる (直積の条件)。再スタートで境界が片側だけ締まると反転は崩れるので確かめ直す
  (乱数の max-cut では再スタートで全て落ちることがある)。サブ MIP・再スタート後の探し直し (HO6) では検出しない。
- 上限: 非零 200 万 (`ENOMOTO_T_MIP_SYMREFL_MAX_NNZ`)、検出の時間 1 秒 (`ENOMOTO_T_MIP_SYMREFL_TIME`)。
