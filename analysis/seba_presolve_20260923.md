# seba の前処理が HiGHS ほど縮まない原因 (調査のみ、2026-09-23)

基点: `1c11ae1` (stocfor2 対策後)。計測用の計装は別クローンに入れ、本体には入れていない。

## サイズ

| | 行 × 列 |
|---|---|
| 入力 (範囲制約 7 本を 2 行ずつに分解) | 522 × 1028 |
| 当方 (stocfor2 対策の前後とも同じ) | 226 × 121 |
| HiGHS | 2 × 8 |

## HiGHS の経路 (規則別の削除数)

| 規則 | 列 |
|---|---:|
| Dominated col (双対値の上下限による固定) | 439 |
| Free col substitution (暗黙自由の列シングルトン代入) | 271 |
| Aggregator | 118 |
| Doubleton equation | 104 |
| Fixed column | 58 |

Aggregator だけを切ると 193 × 274 に戻る。

## 当方の経路

```
round 0: A=507 → (fold) 441 → doubleton 3 列 → colsingleton 436 列を消去し、
         境界保存行 535 本を追加 → A=2, 実不等式行 550
         (dualfix 0 列、dualpropagate は 9 列を固定)
round 1: dualfix 467 列を固定 → 実不等式行 225
以降:    aggregator の候補 6〜7 列はすべて fill-in 超過 (正味 +430〜+1200、上限 10) で見送り
```

- 等式行のほとんどは colsingleton が不等式行の組 (範囲制約) に変えてしまい、aggregator が使える等式が残らない。
- 最終的に残る 121 列のうち **86 列が「範囲制約 1 本だけに現れる列シングルトン」**
  (G 上では `a·x_j + r ≤ U` と `-(a·x_j + r) ≤ -L` の 2 行に現れる)。すべて費用 < 0、両側の境界が有限。
  残りは 2〜3 行に現れる列 19 と、唯一の等式行 (長さ 16) の列。
- これらを消せるパスが当方には無い:
  - colsingleton は等式行のシングルトンしか扱わない (不等式行版は「行が効くかの符号場合分けが要る」として保留中)。
  - dualfix は範囲制約が上下両方向をロックするので固定できない (これ自体は正しい)。
  - dualpropagate は境界が文字どおり ±∞ の列しか双対伝播に使わない。暗黙の境界を使う版は
    80bau3b で目的関数を誤らせたため外されている。seba の列シングルトンは両側有限なので寄与しない。

## 対処案 (未実装)

1. **不等式/範囲行の列シングルトン** (HiGHS の colSingleton の不等式版、Andersen & Andersen)。
   x_j が行 `L ≤ a·x_j + r ≤ U` だけに現れ c_j < 0 (a > 0 の場合) のとき:
   - `(U − r_hi)/a ≥ u_j` なら、x_j を上げても上側は決して破れない → x_j = u_j に固定 (双対固定)。
   - `(U − r_lo)/a ≤ u_j` なら、u_j は行の上側から冗長 → 最適解では行の上側が必ず等号
     (x_j < u_j なら x_j を増やして目的が改善する、x_j = u_j でも上の不等式から等号) →
     行を等式 `a·x_j + r = U` にして x_j を代入消去し、下限 l_j は必要なら境界保存行 1 本で残す。
   - 両方とも成り立たないときは何もしない。
   正味で列 1・行 1〜2 本が減る。seba の生き残り 86 列はこの形。
2. **範囲制約を 1 行として扱う**: G の上下組を出現回数 1 と数えるようにし、colsingleton・dualfix・aggregator が
   範囲行を 2 行として扱わないようにする (1 の前提としても必要)。
3. **dualpropagate に暗黙境界を戻す** (HiGHS の isLower/UpperImplied に相当)。ただし、境界を締めるのに使った
   行が propagate で削除されても辻褄が合うように、どの行で締めたかの記録が必要 (Fable 案 C15 と同じ土台)。
   HiGHS の Dominated col 439 列に相当する。
4. **round 0 で双対固定を colsingleton より先に効かせる**: colsingleton が等式行を不等式行の組に変える前に列を
   固定できれば、等式のまま残った行を doubleton/aggregator が使える。3 が無いと固定できる列が少ない。

効果の見積もり: 1 だけで生き残り列の約 7 割 (86/121) が対象。seba は現在 4.4ms の小問題なので時間への影響は小さい。
同じ形 (範囲行の列シングルトン) は他の問題にもある可能性があり、採用するかは 93 問の A/B で判断が必要。
