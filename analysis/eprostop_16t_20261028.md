## 3. 悪くなった問題の切り分け (`benchmarks/eprostop_split_16t_20261028.jsonl`、ログは `analysis/eprostop_diag.jsonl`)

2 つのスイッチを 1 つずつ (epr = `PROBE_EARLY_REPRESOLVE`、ostop = `SUBMIP_OUTCOME_STOP`)、各 2 回 (秒、`t(値)` は時間切れとその暫定解):

| 問題 | 既定 | epr | ostop | eprostop |
|---|---|---|---|---|
| physiciansched6-2 | 17.2 / 16.9 (ログつき 18.8) | 35.6 / t(49324) (ログつき 37.2) | t(51327) / t(49524) (ログつき 17.1 / 17.1 / 35.2) | t(49524) / t(49524) |
| mc11 | 25.4 / 49.8 (ログつき t) | t / 55.7 (ログつき 23.7) | 21.1 / 59.5 | 58.5 / t |
| neos-860300 | 37.0 / 32.4 / 34.0 / 33.6 | 35.8 / 36.6 | 38.5 / 35.6 | 33.8 / 32.3 / 46.4 / 45.2 |

- **mc11**: ログつきの 1 回は既定が時間切れ・epr が 23.7 秒と逆で、既定でも 25〜60 秒に散る。揺れ。
- **physiciansched6-2** (ログつき 5 回): 速い回と遅い回を分けるのは、根の並列の RENS のサブ MIP (どの回も 0 ノード) が 49324 (最適値) を
  当てるかどうか。当たれば 10 秒前後に 49324 が出て 17〜19 秒で終わる。当たるかは、その時点の Local-MIP の暫定解 (49524・49624・
  50227 なら当たる、49425・49724 なら外れる) とカットの進み方で変わる。外れると、再スタートの後は RENS が「解なし」として飛ばされ、
  Feasibility Pump が 49324 を見つける (13〜17 秒後) まで待ち、60 秒の回では時間切れになる。
  - epr は physiciansched6-2 では「早めのプロービング: 64 本、固定 0 列、使わない」で、問題を変えない (`quick_probe_fixings` は使わない
    ときは `prob` に書き戻さない)。ostop の打ち切りは、サブ MIP が 0 ノードで終わるので働く前。2 つとも、この分かれ目を直接は変えていない。
  - ただし今の既定は 6 回 (今回の 3 回と、`analysis/restart_cuts_fix_20261028.md` 5 節の (d) の 3 回) のうち 5 回が 17〜19 秒
    (1 回 35.9 秒) で、試作を入れた回は 10 回中 4 回だけ速い。時間のずれで
    根の経過が外れ側に寄る可能性は否定できない。再スタートの後に RENS を飛ばすこと (前に「解なし」だった印) がこの差を大きくしている
    ので、その扱いの修正 (`ENOMOTO_MIP_PAR_HEUR_FOUND`・`ENOMOTO_MIP_RESTART_LIGHT_HEURS`、次に計測) で見直す。

## 4. 判断

既定にした (`ENOMOTO_MIP_NO_PROBE_EARLY_REPRESOLVE`・`ENOMOTO_MIP_NO_SUBMIP_OUTCOME_STOP` で止める)。

- 21 問・40 問とも SGM が良く (21 問 −2〜3%、40 問 ±0 / −7%)、不一致 0。効いた問題 (neos8 2.5 倍・drayage-100-23・neos17・nu25-pr12・
  binkar10_1・mik-250-20-75-4) は 4 スレッドの機械の結果と一致する。
- 悪く見えた 3 問は、どれも 2 つの試作が直接変えた所では起きていない (上)。physiciansched6-2 は再スタートの後のヒューリスティクスの扱いと
  合わせて追う。
