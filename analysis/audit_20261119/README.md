# 既定の「運への対策」の洗い出し (2026-11-19、計測なし)

利用者の問い: 「既定にしているもので、運 (探索の道が変わって偶然速くなった・遅くなった) への対策のようなことをやっているものはないか」。

- 範囲: docs/improvement_history.md の「採用」の節のうち 2026-10-27〜11-18 (0.1.9 の前後から今まで、約 40 件)。採用の根拠・閾値・場合分けは
  各節と、そこから参照される記録で確かめた。src の `env_def!` の全部 (数百) を一つずつ当たってはいない。採用の節に出てくる閾値・場合分けだけを見た。
- 使った計測: analysis/ablate_20261118 (最近の既定を外した対の読み直しと clique のシグモイドの段階 2)・analysis/final_20261118 (今の既定 対 0.1.9、M 186 問 × 種 1)。
  コードは変えていない。新しい計測もしていない。

## 先に: 揺れの大きさ (判定の物差し)

- final の M で、**同じ 0.1.9 を 2 回測った v019 / o019 が SGM +8.2% (区間 −4.7%〜+23.1%)**。1 種だけの比は comp07-2idx 24.2 倍・fiball 7.0 倍・
  neos-933966 3.1 倍・swath3 3.0 倍まで出る (summ_M.txt)。4 スレッド・1 種の M の差は、問題単位では数倍まで揺れる。
- 同じく今の既定 / 0.1.9 は −2.9% (区間 −19.1%〜+13.6%)。解けた数は def 88 / v019 90 で、片方だけ解けたのは def 7 問・v019 9 問。
- このため「1〜2 問の 4 スレッドの差」「1 種だけ解けた」は、それだけでは効き目の根拠にならない。逆に「働く問題を数えて、働かない問題は同じ道」と
  確かめた既定は運の疑いが低い。

## 疑いの度合いの基準

- **高**: 効き目の根拠が 1〜2 問の 4 スレッドの差、または「道が変わって重い所を避けた」型で、全体の計測は揺れの範囲 (区間が 0 をまたぐ・上端が +5% を超える)。
- **中**: 仕組みは筋が通るが、閾値や場合分けが 1〜3 問に合わせて決まっている。または束で入れて部品ごとに確かめていない。または全体の得が確かめられていない。
- **低**: 働く問題で構造上の理由がはっきりしていて、働かない問題は既定と同じ計算 (コードの上か 1 スレッドで確かめた)。誤り・メモリ・期限の直しも低。

## 疑いが高いものと、外したときの見込み

0.1.9 より前に入ったもの (cs2・S4・QIU_FIND_STOP_GAP・cand1108zd) は 0.1.9 にも入っているので、final (今 / 0.1.9) では外した効果が見えない。
ablate (2026-11-18) は 0.1.9 の後に入った機能と cand1108zd を対の計測で読み直したもの。

1. **SUBWAIT=2** (11-18): 全体の計測は P・M とも悪い向き (上端 +7.0%・+9.7%) で、得の根拠は「1 種だけ解けた」2 件。働く 5 問のうち
   **neos-662469 と ran14x18-disj-8 は final で 0.1.9 だけ解けた** (今 600 秒 / 0.1.9 291.5・239.8 秒)。csched008・doon は両方時間切れ、
   neos-1456979 は 260.7 / 226.9 秒、unitcal_7 は 317.9 / 391.4 秒。→ 外しても悪くならない見込みが高い。確かめるなら、働く 5 問 + unitcal_7 を
   種 3〜6 で {def, SUBWAIT=0}。
2. **S4_RINSRATE・S4_BGZERO** (11-06): 閾値が cod105 1 問から。final の cod105 は今 174.4 / 0.1.9 190.7 秒 (どちらも S4 入り)。ablate では読んでいない。
   → 外して悪くなるかは分からない。確かめるなら P 58×3 と cod105 を種 1〜4 で {def, S4_RINSRATE=0, S4_BGZERO=0}。
3. **QIU_FIND_STOP_GAP** (11-04): qiu 1 問の時刻の競争に合わせた形。ablate・final では見えない。→ 確かめるなら P 58×3 (qiu を含む) で {def, =0}。

5. **cand1108zd の束** (中〜高): 部品の中で道を変えるだけの疑いがあるのは NODELP_PERTURB (ノードの LP の摂動) と SUBFIX。NO_ZEROHALF の遅れは
   ablate で本物と確かめ、使い分けの特徴は見つかっていない (vsscip_slow_20261118/cmz)。→ 部品ごとの ablate は未実施。

## 低いとしたものの共通点

- 働く問題を数えてあり、働かない問題は既定と同じ計算 (S3GAP・SPARSIFY_LATE・VUBAGG・ORBPP・DOMCOL・FOLD・G5CANCEL・G5SEQ・G5FIN)。
- 運への依存をむしろ減らす直し (CUT_LP_CAP_ROBUST・canddet・cs2 の反復で数える部分): 時間・機械の速さで道が分かれるのを、反復・手間で決める形に
  変えたもの。これは「運への対策」ではあるが、偶然速くなった道に合わせたのではなく、道の分かれ目を取り除いた形。
- 正しさ・メモリ・期限の直し (PROP_RELTOL_CONT・POSTSOLVE_CLIP・CONFLICT_INT_TOL・memall・ZH_DEADLINE・G5FIN)。
