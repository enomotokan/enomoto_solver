# objprobehull: 根の打ち切り値つきプロービングで両側の共通の境界を大域的に締める試作 (2026-11-24、親の依頼)

親の依頼 (利用者の案): 根の打ち切り値つきプロービング (`root_obj_probe` → `obj_probe_core`、既定で使用) は、x_j = 0・1 の
両側とも成り立つとき定義域を戻すだけで、両側の共通の境界 (弱い方) を捨てていた。強分枝の子の伝播 (`ENOMOTO_MIP_SB_PROBEBD`、
analysis/treegap_20261123・sbadapt_20261124) がノードに置く「両方の子の共通の境界」と同じ考えを、根の打ち切り値つきプロービングにも入れる。
**既定は変えない** (`ENOMOTO_MIP_ROOT_OBJ_PROBE_HULL=1` で使う)。

## 1. 中身 (src/mip/solver.rs の `obj_probe_core`、src/mip/mod.rs の `probe_hull_bounds`)

- 各側 (x_j = 0・1) の伝播 (行・目的 (打ち切り値)・被約費用の行・カットの行) が成り立ったら、その側で変わった境界を記録から集める。
- 両側とも成り立てば、前処理のプロービング (`probe_derive`) の締め付けの規則をそのまま使う: 両側の弱い方 (下限は小さい方、上限は大きい方) が
  今の境界より締まる列を返す。この部品を `probe_derive` から `probe_hull_bounds` として切り出して共用した (`probe_derive` の結果は前と同じ)。
- 締める列は 0-1・一般整数・連続のすべて。`tighten_global` (整数列は丸める) で大域的な境界に入れ、入った値を今の定義域にも置いて伝播する
  (固定と同じ扱い。後の列の試しに効く。伝播が矛盾したら「打ち切り値より良い解なし」(両側矛盾と同じ))。
- ループの中の試し (`ENOMOTO_MIP_OBJPROBE` の `p`、`o.in_loop`) では使わない。一般整数の二分探索 (`..._GENINT`) は元のまま。
- 診断 (`ENOMOTO_MIP_LOG`): `root objective probing hull (...)` の行に、締めた境界の数・列の数 (整数・連続の内訳)・締めで固定された整数列の数・
  幅の縮みの合計 (有限から有限)・無限の境界が有限になった数・後述の基準と同じだった整数列の締め付けの数・置かなかった連続列の締め付けの数。
  `ENOMOTO_MIP_ROOT_OBJ_PROBE_HULL_DEBUG=1` で締めた境界を 1 本ずつ出す。

### 1.1 大域的に置いてよい理由

各側の伝播は「目的値 <= 打ち切り値」の伝播を含むので、各側で出た境界は「その側の、打ち切り値より良い解」で成り立つ。x_j は 0 か 1 なので、
打ち切り値より良い解はどちらかの側にあり、その側の境界を満たす。よって両側の弱い方は打ち切り値より良い全ての解で成り立つ。
これは片側が矛盾したときの固定 (「打ち切り値より良い解はその側にない」) と同じ根拠 (打ち切り値より良い解だけを残せばよい) なので、
固定と同じく大域的に置く。打ち切り値が後で良くなっても、締めた境界は「より良い解」の集合を小さくするだけで、成り立ったまま。

### 1.2 連続列: x_j を置かない伝播より締まらない境界は置かない

最初の版 (全部置く、結果は `res_v1.jsonl`) では mas76 が 3 種とも約 2 倍遅くなった (27.8 → 56.4 秒、15.9 → 56.8 秒、27.1 → 48.6 秒、ノード 1.3〜2.9 倍)。
締まったのは連続列 1 本だけ: 目的の係数 1 の x150 の上限 1e12 → 40005.05 (打ち切り値)。これは x_j の試しから来たものでなく、
「目的値 <= 打ち切り値」を列の境界に言い直しただけ (x_j = 0 の側の値が、x_j を置かずに目的の伝播をした値と同じ)。LP に入ると根の下界が下がり
(39042 → 39020)、木が大きくなる (目的の切りを LP に入れると悪くなるのと同じ形と見られる。推測)。

そこで締め付けが出たとき (締める列があるときだけ)、**x_j を置かずに今の定義域で同じ伝播をした境界** を基準として求め、連続列は基準より真に締まるものだけを置く
(比べの許容は `probe_hull_bounds` と同じ相対 1e-9。新しい閾値は作らない)。整数列は基準と同じでも置く: 固定・幅の縮みは探索を減らし、
LP の言い直しの害の形にならない (fiber の 113 本の固定のうち 106 本は基準と同じ = 目的の伝播だけで出る固定で、ノードを 9 → 3・13 → 5 に減らす)。
基準の伝播そのものが矛盾した (数値の際どい場合だけのはず) ときは連続列を置かない。
直した版で mas76 は既定と同じ道筋 (ノード同じ) に戻った (2 節)。

付記 (別の課題): fiber で「x_j を置かない目的の伝播」で固定される整数列が 106 本あったことは、根のこの時点で目的の伝播の固定が大域的な境界に
入っていないことを示す。試作とは別に、根の定義域で目的の伝播をして整数列の固定を大域的に置くだけでも同じ固定が得られるはず (未確かめ)。

### 1.3 見切り (GIVEUP)・回りの繰り返し・再スタートの判定

- 再スタートの判定 (`maybe_restart`) は、大域的な境界で固定された整数列の数 (根の始めからの差) を数える。締め付けで固定された整数列は大域的な境界に
  入るので、そのまま数えられる。固定でない締め付け (幅の縮み・連続列) は数えない (HiGHS の割合も動かなくなった整数列で数える)。
  よって判定には新しい数え方を足さない (足すと閾値の意味が変わる)。
- 見切り (最初の `ENOMOTO_T_MIP_ROOT_OBJ_PROBE_GIVEUP` 列で得がなければやめる) と回りの繰り返し (`..._PASSES`、前の回りで得があればもう一回り) の
  「得」には、片側の固定の数に、締め付けで固定された整数列の数を足す。同じ物差し (再スタートが数えるもの) にそろえた。固定でない締め付けを得に数えると、
  連続列の小さな縮みで見切りが延び続けうる。
- 時間の上限 (`..._TIME_FRAC`) はそのまま。締め付けの手間は、締める列があるときの基準の伝播 1 回と、各側の変更の記録の写し。

## 5. (A) の調べ: 既存の入れ物

| 入れ物 | 中身 | 木のノードの伝播で効くか |
|---|---|---|
| 含意の表 (`Domain::impl_adj`、`add_implications`) | 0-1 列の文字どうしの衝突 (x_j = v ⇒ x_c = w と、その対偶) | **効く** (`dom.propagate` の最初で伝播)。根の打ち切り値つきプロービングは既定で (`learn`、`..._NO_IMPL` で切る) 各側で固定された 0-1 列をここに入れている。 |
| 前処理のプロービングの `ProbeDerived::implied` → `MipProblem::implied_bounds` | 0-1 列 y の値 ⇒ 連続列などの境界 | 効かない。分離 (cmir の変数上下限 `VB_IMPL`、`IMPLBD` のカット) だけが使う (analysis/vbimpl_20261122)。 |
| `ProbeDerived::equiv` → 前処理の代入 (`PROBE_EQUIV`) | 0-1 列の同値な組 | 列を置き換える (前処理の中だけ。根の後に見つけたものを入れる口はない) |
| clique の表 (`conflict_edges`) | 0-1 列の衝突の組 | 分離 (clique カット) と、含意の表の種 |
| リテラルの衝突のプール (`lit_prop`) | 境界の文字の組 (no-good) | 効くが、年齢で外れる。連続列の「y < b」(真に小さい) は文字で書けない |
| 木の行・目的の伝播 (`dom.propagate`・`propagate_objective`) | 元の行 (目的の伝播は既定では切 (`ENOMOTO_MIP_OBJ_PROP`)) | — |

- **y が 0-1 列の関係 (同値を含む) は、既定の含意の学習で既に含意の表に入っていて、木で効いている。** 同値 (x_j = 0 ⇒ y = 0 かつ x_j = 1 ⇒ y = 1 など) は
  含意 2 本と同じで、含意の表は対偶も伝播するので、伝播としては完全。
- **0-1 でない y (一般整数・連続) の関係を木の伝播に入れる入れ物はなかった。** そこで定義域に表 `BoundImpl` (`Domain::bimpl`、src/mip/domain.rs) を足した:
  文字 x_j = v ごとの (y, 上限か, b) と、y ごとの逆引き。変数の境界の式 y >= l0 + (l1 − l0) x_j は、x_j が 0-1 なので含意 x_j = 0 ⇒ y >= l0 と x_j = 1 ⇒ y >= l1 の 2 本と
  伝播として同じ。うち弱い方 (min(l0, l1)) は共通の境界として大域的に置く (=1 の部分) ので、表には **片側が真に強い向きだけ** を入れる。等式 (両側で y が固定) は
  下限と上限の含意の組。
  - 伝播 (`dom.propagate` の中、含意の表の次・行の前): x_j が v に固定されたら y を締める (向き)。y の範囲が b を外れたら (下限の含意で up[y] < b、上限の含意で lo[y] > b。
    許容は定義域の既存の `bound_tol`) x_j = 1 − v に固定する (対偶)。理由は含意の表と同じく記録しない。締めた回数を向き・対偶に分けて数える (`Domain::bimpl_stats`)。
  - **向きの側は、木の伝播でもともと出る値に近い**: 根で x_j = v として行・目的の伝播で出た境界は、ノードで x_j = v のとき (定義域はより狭く、打ち切り値は同じかより良い)
    同じ伝播を不動点まで回せば出る (伝播の単調性)。ただし既定の木では目的の伝播を切っているので、目的の伝播から来た境界は木では出ない。また手間の上限やカットの行で差が出る。
    **新しい情報は主に対偶の側** (y の範囲から x_j を固定。行の伝播では、プロービングしないと見えない)。
- 関係も打ち切り値の伝播を含むので「打ち切り値より良い解」に対して成り立ち、片側の固定と同じ根拠で木全体 (表は定義域に持つので、その求解の全ノード) で使ってよい。
  再スタートすると新しい問題の定義域には持ち込まない (含意の表と同じ。新しい根で打ち切り値つきプロービングをやり直すと、また作る)。
- 診断: `root objective probing hull` の行に `=2: N bound implications added (等式の列, 表の合計), binary equivalences (含意の表に入る), tightened by them during this probing [向き, 対偶]`、
  求解の終わりに `ROOT_OBJ_PROBE_HULL=2: 表の本数; tightened after the root objective probing: from x_j to y 向き, contrapositive 対偶` (根の打ち切り値つきプロービングの後 = 主に木)。

### 5.1 0-1 の同値: 列の置き換えか、伝播の関係か

- 伝播としては、既定で含意の表に入る 2 本の含意で足りる (上記)。置き換えで増えるのは (1) LP の列が減る・LP の緩和が締まる (LP では x_j と y が別の値を取れる) と、
  (2) 前処理の連鎖 (代入の後の行の簡約)。
- 置き換えは再スタートの前処理に渡す形になる。打ち切り値に依る関係なので、暫定解 (打ち切り値ちょうど) が新しい問題で実行不能になりうる (今も、打ち切り値による大域的な固定で
  同じことが起き、`the start solution is not feasible in the presolved problem; dropped` として捨て、打ち切り値は残る)。つまり置き換えても正しさは保てる。
- 数 (`binary equivalences`、根の回ごと。組 (j, y) と (y, j) を両方試すと 2 回数える): beavma 48・4+16・92、fiber 8+4・2・8+6、drayage-25-23 4 (種 1)、nu25-pr12 2、
  ほか (mzzv42z・qnet1・dcmulti・mas76) 0。0-1 でない列の等式 (両側で固定) は 8 問とも 0。同値が多い beavma は根で 0.4 秒・0 ノードで解け、置き換えで縮む余地がない。

## 7. (B) 根の目的の伝播の固定: 確かめと試作 `ENOMOTO_MIP_ROOT_OBJPROP_GLOBAL=1`

### 7.1 コードの確かめ

- 目的の伝播 (`Solver::propagate_objective`、`目的値 <= 打ち切り値` を 1 本の行として伝播) は **既定では切ってある** (`ENOMOTO_MIP_OBJ_PROP` で入る。
  analysis/mip_opt_eval_20261011.md で +0.6%、gap1_tree_20261109・treeclose_20261114 で効かないと記録)。木のノードの伝播 (`node_prop_fixpoint` など) でも、根でも呼ぶが、
  既定ではすぐ戻る。
- 打ち切り値で使っているのは、根の打ち切り値つきプロービング (`propagate_objective_with` を直に呼ぶ。各側の試しの中だけで、結果は戻す)・被約費用による固定 (大域的)・
  `probe_bound_infeasible` だけ。**根の定義域そのものに目的の伝播をかけて大域的な境界に入れる所はない。** fiber で =1 の締め付け 113 本のうち 106 本が
  「x_j なしの伝播と同じ」だったのはこのため。
- 木の中でも目的の伝播は切なので、根で入れておかないと、この固定はどこでも使われない (再スタートの前処理にも渡らない)。

### 7.2 試作 (src/mip/solver.rs の `root_objprop_global`)

- 根の打ち切り値つきプロービングの直前 (再スタートの判定の前、暫定解があるとき。根の打ち切り値つきプロービングの見切りとは別に毎回) に、根の定義域で行と目的の伝播をかけ、
  締まった **整数列** の境界を `tighten_global` で大域的に置き、今の定義域にも入れて伝播する。打ち切り値より良い解に対して成り立つので大域的に置いてよい (1.1 節と同じ根拠)。
- 連続列は置かない (目的の切りを列の境界に言い直しただけになり、LP に入ると害がある: 1.2 節の mas76)。
- 伝播が矛盾したら打ち切り値より良い解はないので、根の打ち切り値つきプロービングの証明と同じく、自分の暫定解を最適として終える (定義域を実行不能にして後に任せると、
  問題が実行不能と扱われる恐れがあるため)。
- 再スタートの判定は、締めで固定された整数列を大域的な境界でそのまま数える (1.3 節と同じ)。
- 診断: `ROOT_OBJPROP_GLOBAL: N integer bounds tightened globally, M integer columns fixed, width shrink ...`。

## 8. まとめ (追加の依頼)

- (A) =2: 0-1 でない列への関係を定義域の新しい表に入れ、木の伝播 (向き・対偶) で使う形を作った。8 問で =2 / 既定 0.970、効いたのは mzzv42z (対偶が 3194 回)。
  0-1 列どうしの関係 (同値を含む) は既定の含意の学習で既に木で効いている。同値の置き換えは、数が少ない (多い beavma は 0 ノードで解ける) ので試していない。
- (B) 根の定義域での目的の伝播は既定では切で、その固定は大域的にどこにも入っていなかった。入れる試作 og で 10 問 og / 既定 0.97 (見切りのまま・外した形とも)、
  mzzv42z が 3 種とも約 20% 速い。見切りに関係なく効くので、=1・=2 より先に広い集合 (M・240 問) で計る候補。
- どれも既定は変えていない。誤答の確かめ: `HULL=2 OG=1 bash analysis/objprobehull_20261124/fuzz.sh` で fuzz 7 本とも誤答 0、cargo test 424 通過・失敗 0。
  試作オフで check_default 6 問一致 (=2・og を入れた後のビルドで)。
