## seed 9981 (と試作の seed 378): 代入で空になった行を伝播が実行不能と判定する

- 0-1 列 x5 が 1 に固まり、大きい M の行 `x0 + x2 + 2e7 x5 ≥ 20041580.786137946` と `x0 + x2 + 1e6 x5 ≤ 1041580.7861379447`
  (と同じ値の ≥ の行) から、代入で x0 + x2 が消えると、変数のない行 `0 ≤ −1.28e-9` が残る (2e7 の大きさでの丸め)。
- この行は次のラウンドの最初の伝播 (`propagate_split`) で見られ、許容 `PROPAGATE_EPS (1e-9) × (1 + |右辺|)` ≈ 1e-9 で実行不能と
  判定されていた (`src/presolve.rs` の伝播の後の判定)。固定列の折り込み (`foldfixed`) には同じ形の空の行に 1e-7 の下限を置く既存の手当て
  (seed 3470、analysis/wrong3470_20261114.md) があるが、伝播が先に見るので効かなかった。
- 直し: 伝播の実行不能の判定 (`violation_exceeds_tol`) で、項のない行の許容を `EMPTY_ROW_FEAS_TOL` (1e-7) より厳しくしない
  (`ENOMOTO_T_EMPTY_ROW_FEAS_TOL=0` で従来)。試作 `ENOMOTO_AGG_DUALFREE_INEQ` だけに入れていた手当て (集約の直後に空の行を取り除く) は
  これに含まれるので外した。
- 診断を足した (振る舞いは変えない): `ENOMOTO_DEBUG_PRESOLVE_INFEAS` で、前処理が実行不能と判定した箇所と、伝播で判定した行・交差した列を出す。
