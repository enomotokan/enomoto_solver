## 段階 1: LP (`ENOMOTO_LP_FOLD`)

### 実装 (src/simplex/lp_fold.rs、src/solver.rs の入口に 4 行)

- 行ごとにスラック列 (係数 −1、境界は行の範囲) を足した等式形で、行と列の等分割を色の細分化で求める (論文の第 2.2 節の命題 4 の形。
  スラックが構造の列とまとまることもある)。和は相対 2^-32 ほどに丸めた鍵で比べ、行と列を交互に止まるまで細分化する
  (Paige-Tarjan の速い形ではなく、毎回全部の行・列の鍵を作り直す素朴な形)。
- 畳んだ問題は列の組ごとに平均の変数 z_Q (x_w = δ_w + λ_w z_Q、境界は元のまま)、行の組ごとに代表の行 1 本。スラックだけの組で
  畳んだ行列の非零が 1 つのものは行の範囲に戻す。(列 + 行) が元の 95% (`ENOMOTO_T_FOLD_MAX_RATIO`) 以下のときだけ畳む。
- 反転 (`r`): 論文の第 3 節。境界の中央 δ^C に移し、分割形 (x' = x'^+ − x'^−、行も ± の写し) の対称な等分割を、元の行列の上で
  単極・双極の組と符号 λ・γ を持つ「符号つきの細分化」として求める (第 3.7 節の実装の方針)。双極の列は中央に固定、双極の行は消える。
  δ は組ごとに λ ν だけずらして多くの列で 0 にする (Theorem 20、第 3.7 節の工夫)。組の符号は多数が +1 になる向きに揃える。
- 安全網 (いつも): 細分化が止まった後に、全部の行・列で組の和・右辺・境界・費用が許容誤差 (相対 1e-9) の内で等しいかを確かめ、
  外れたら畳まない。解いた後、配った解の元の LP での違反 (尺度で割った値) が 1e-6 以下で、目的値が畳んだ問題の値と相対 1e-7 で
  一致するかを確かめ、外れたら元の LP を解く。畳んだ LP が最適で終わらなければ (実行不能・非有界も) 元の LP を解く。
- 検査 (`v`): 畳んだ LP を MIP の LP の実装 (TwoStageLp) でも解いて行の双対値を取り、π_v = γ_v π'_P / |P| で元の行に配り、
  弱双対の下界 g(π) = min_箱 (c − Aᵀπ) x + min_範囲 π r と主の目的値の差 (= 相補性のずれ) を確かめる。ENOMOTO の LP の入口は
  双対値を返さないので、この検査は既定の求解とは別の LP の実装を使う (時間の計測では付けない)。
- 単体テスト: 割当の LP (9 列 → 1 列)、論文の例 (3) (x1・x2 が反転でまとまり x3 が中央 1 に固定、最適値 −1)、fuzz の seed 5 の
  反転で配った双対値が元の最適な双対値になること。

## 段階 2・3: MIP (`ENOMOTO_MIP_FOLD`)

### 実装 (src/mip/fold.rs、src/mip/mod.rs の `solve_mip` の振り分けを包む 10 行)

- 畳むのは `solve_mip` で作った元の問題 (ENOMOTO の MIP の前処理の前。論文は PaPILO の後)。畳んだ問題を今までの振り分け
  (ポートフォリオか `solve_problem`) でそのまま解き、解を元に戻す (hnflat と同じ「書き直して解いて戻す」形)。時間の上限は畳む時間を引く。
- 段階 2 (`1`・`r`): 整数列はどれも 1 列だけの組 (論文の Lemma 28)。整数列は双極にしない (中央が整数とは限らない)。単極の整数列の
  δ は整数になる ν を選ぶ (境界が整数なら δ^S は整数)。畳んだ MIP と元の MIP は整数解が行き来でき、最適値も下界も同じ。
- 段階 3 (`i`、論文の Algorithm 1 を簡単にしたもの):
  1. V_R = 連続列を含む行と、係数・有限の左辺右辺が整数でない行 (論文は連続列の連結成分がネットワーク行列なら V_R に入れないが、
     ここでは全部入れる。狭い)。
  2. 整数列の初めの鍵 = V_R の行の係数 (符号を揃えて) と、ほかの行の ±1 でない係数の位置と値 (論文の ntmask の条件)。
  3. 反転つきの細分化で組を作り、2 列以上の整数の組ごとに、行の中で組の列の係数が λ に比例する行を打ち消し (U)、残り S が
     V_R の行に残らないことと、[S; 組の和の行] を今までに認めた組と並べた行列が TU であることを確かめる。TU の判定は剥がしと
     Heller-Tompkins の 2 色塗り (列の非零が 2 つ、またはその転置) の十分条件だけ (`fold::simple_tu`。PAPER7 の判定と同じ考え方で、
     ネットワーク行列の一般の判定 (Bixby-Wagner、論文の [52] MATREC) は入れていない)。だめな組は 1 列ずつに分けて細分化し直す。
  4. 2 列以上の整数の組は和の変数 y_Q = Σ λ_w (x_w − δ_w) (整数) にする。畳んだ MIP は元の緩和 (Theorem 26 (i)) なので下界は
     そのまま使える。元に戻すには、1 列だけの整数列の値と組の和を固定した元の問題 (繊維) の LP を MIP の LP の実装で解き、
     頂点が整数なら元の整数解 (Theorem 32)。著者の実装 (github の rolfvdhulst/folding の postsolve.cpp) も組の和を等式で固定した LP を
     SoPlex で解いて整数性を確かめる形。
- 安全網 (全部の回): 戻した解を元の問題で `is_feasible(x, 1e-6)` (整数性も) で確かめる。段階 3 では、畳んだ問題が最適で終わったのに
  戻した解の目的値が畳んだ問題の値より悪ければ最適の証明にならないので、元の問題を残りの時間で解く。戻せない (繊維の LP が
  最適でない・整数でない・実行不能) ときも元の問題を解く。畳んだ問題が実行不能なら元も実行不能 (緩和なので)。
- 数えるモード (`c`) で MIPLIB 2017 benchmark 240 問を数えた (`mip_count_r.jsonl`・`mip_count_ri.jsonl`、`summ_count_*.txt`):
  段階 2 (`rc`) で畳めるのは 25 問、段階 3 (`ric`) では 48 問、そのうち整数の組がまとまるのは 29 問 (fiball 34219 → 5337 列、
  neos-1582420 10100 → 3718、drayage-25-23・drayage-100-23 11090 → 4421、neos-3004026-krka 17030 → 8451、decomp2・atlanta-ip・
  bnatt400/500・neos-631710・neos-960392・seymour・nw04 など)。
