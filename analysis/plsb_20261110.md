## 実装 (`src/mip/plsb.rs`、`src/mip/solver.rs` の `select_branch_inner` の打ち切りの判定)

文献: Mexi・Shamsi・Besançon・Le Bodic「Probabilistic Lookahead Strong Branching via a Stochastic Abstract Branching Model」(CPAIOR 2024、
arXiv 2312.07041。本文を読んで確かめた)、SCIP の `src/scip/branch_relpscost.c` (GitHub の master、2026-11-10 に取得) の
`updateMinMaxMeanGain`・`expectedTreeSize`・`continueStrongBranchingTreeSizeEstimation`。

- 利得: 強分岐した候補の左右の利得 g⁻・g⁺ から g = √((g⁻ + 0.01)(g⁺ + 0.01)) − 0.01 (SCIP の `GEOMMEANSHIFT`)。1e-5 未満は 0 とみなす。
  子が打ち切られた候補 (片側・両側) は標本にしない (ENOMOTO ではそこで次の候補に移るので)。
- 分布: P[g ≤ x] = p₀ + (1 − p₀) F(x)。p₀ は 0 とみなした標本の割合。F は既定でパレート (下限 g_min、形 λ = n / (Σ log g_i − n log g_min))、
  `l` で対数正規 (対数の平均・標準偏差。SCIP は分散を標準偏差の位置に入れているように読める: 未確認の不具合の候補)、`e` で指数 (率 = 1/平均)。
- 木: 今の最良 g* でギャップ G (= 打ち切り値 − ノードの LP 値) を閉じる深さ d = ⌈G/g*⌉、T(d) = 2^(d+1) − 1。
  もう 1 本強分岐した後の深さは min(d, ⌈G/g⌉)、P(⌈G/g⌉ ≤ k) = 1 − F(G/k)。E[T'] = Σ_k P(深さ = k) T(k)。
- 判定 (論文の命題 1・定理 1): 強分岐 1 本は子 2 ノードの費用なので、t_i = T(d*) + 2i と E[t_{i+1}] = E[T'] + 2(i+1) を比べる。
  SCIP は E[T'] + 2 ≤ T(d) − 1 なら続ける。既定はこれ。`c` では費用を (強分岐の LP 1 回の平均反復 × 2) / (ノードの LP の平均反復) ノードにし、
  E[T'] + 費用 ≤ T(d) で続ける (論文・SCIP にはない、ENOMOTO の強分岐の LP は反復の上限つきで安いことがあるため)。
- 深さを 1 減らす確率 1 − F(G/(d−1)) が 1e-5 未満なら止める (SCIP と同じ)。
- 判定しない (従来の打ち切り) とき: 正の標本が 10 未満 (SCIP の `minsamplesize`)、暫定解がない、g* = 0、d ≥ 50 (SCIP と同じ。`u` で上限 1000)。
- 判定する時: 既定は SCIP・論文の Algorithm 1 と同じく、改善のない強分岐の数 (従来の `no_improve`) が従来の lookahead の 0.6 倍に達してから、
  打ち切るだけ (従来より長くは続けない)。`x` では従来の lookahead を外し、判定できるときは PLSB だけで決める。
- 統計の範囲: 既定はノードごと。SCIP の master は `branchExeclpRelpscost` の頭で `maxmeangain`・`minmeangain`・`sumlogmeangains`・
  `logstdevgain`・`nzerogains` を戻すが `currndualgains` と `currmeandualgain` は戻さない (issue #247 の不具合。数だけ木全体で増え、
  パレートの λ の計算が崩れる)。ノードごとが意図と読める。`g` で木全体 (そのスレッドの求解の全ての強分岐。ただし g* はノードの中の最良)。
- サブ MIP では使わない。逐次でない強分岐 (`ENOMOTO_MIP_PAR_SB`) の束ね方は変えていない。`ENOMOTO_MIP_SB_OLD` の古い選び方 (lookahead 8) は変えていない。
- 診断: 求解の終わりに `MIP: PLSB (tid ..): undecided .. (few samples, no gap, depth>=50), continue, stop, continued past lookahead, stopped before lookahead` を出す。

| 値 | 範囲 | 判定の時 | 深さの上限 | 費用 |
|---|---|---|---|---|
| `1` (表では p) | ノード | 0.6 × lookahead から、打ち切るだけ | 50 | 2 ノード + 1 |
| `gu` | 木全体 | 同上 | 1000 | 同上 |
| `gxu` | 木全体 | 置き換え (延ばすこともある) | 1000 | 同上 |
