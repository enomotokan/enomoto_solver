# cs2 を既定にする (2026-11-01)

- cs2 = 外側の根のカットのループで、1 回の LP の上限を反復で決め (`ENOMOTO_T_MIP_CUT_LP_WORK=0.1`、このループで解けたカットの LP の反復の最大の
  `ENOMOTO_T_MIP_CUT_LP_WORK_PREV=5` 倍より小さくしない)、根の LP の値から動いていないループでは 1 回外したら止め (`ENOMOTO_MIP_CUT_LP_CAP_STOP=flat`)、
  根のカットの時間の上限をループの始めから数える (`ENOMOTO_MIP_CUT_CAP_FROM_LOOP`)。`analysis/neos960392_cutstop_20261101.md` の lpwpc。
- 根拠: `halve_submip_20261030.md` の bench12 (58 問 2 回で SGM −3.5%・解けた数 83 → 87、Mittelmann −0.6%・46 → 46、neos-960392 0/3 → 3/3)。
  bench12 で既定だけが解けた neos-1171448・neos-1171737 は揺れ (`cs2_check_20261101.md`、6 回ずつで cs2 5/6・3/6、既定 3/6・0/6)。

## 既定にした内容と戻し方 (`src/mip/separation.rs`)

| 設定 | 新しい既定 | 元の振る舞いに戻す |
|---|---|---|
| `ENOMOTO_T_MIP_CUT_LP_WORK` | 0.1 | `=0` |
| `ENOMOTO_T_MIP_CUT_LP_WORK_PREV` | 5 | `=0` |
| `ENOMOTO_MIP_CUT_LP_CAP_STOP` | `flat` (`env_def!`) | `=0` |
| `ENOMOTO_MIP_CUT_CAP_FROM_LOOP` | 使う (`env_def!`) | `=0` |

- 4 つ全部を戻す並びは `analysis/halve_submip_20261030/run.py` の `"precs2"`。これからの記録の `"def"` は cs2 を含む新しい既定。
- どれも外側の根のカットのループだけに効く (サブ MIP・裏のカットの求解は変えない)。
