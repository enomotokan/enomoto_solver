### piperout-27 の ENUM_ADAPT: 規則の代償 (仕組みの害ではない)

  - 列挙 2.2 秒 (途中で止める規則 `s` で、3614 行のうち 992 行で止めた)。
  - 1 回目のプロービングが +2.4 秒 (列挙で増えた衝突の組 412・同値の組 20 で含意が増えた)。
  - 前処理のプロービングが 1 回増えて +3.6 秒。
  - 同値の検出 +1.6 秒。
- 繰り返しの判定は、1 周目の後に正しく stop を出している (時間の割合 c = 12.8)。時計の数え違いはない。

- 直す案 (親の判断で記録だけ): 1 周目の列挙の得 (固定・締め付け・同値な組) が列の数に比べて小さければ、その後のプロービングのかけ直し (含意の増えた分の 1 回目の重さと、前処理の周の追加) を弱める。新しい閾値を置かずに、繰り返しの判定と同じシグモイド (g = 得 / 列の数、c = 秒 / 経過) で決める形が候補。

## 4. 利用者の問い: 伝播で締まった子の伸びも擬似費用として正しいはずなのに、なぜ害になるのか

### 同じ子を、伝播の境界つきと境界なしで解き直して並べた (診断 `ENOMOTO_MIP_SB_PROP_TWIN`、`twin.py`、`pclog/n85_twin_s*.log.gz`)

| 種 | 強分枝の子 | 伝播が効いた子 | 伝播つきの伸びのほうが大きい子 | 伸びの合計 (単位あたり) 伝播つき / なし |
|---|---:|---:|---:|---|
| 1 | 217 | 170 | 2 | 177.7 / 8.7 |
| 2 | 269 | 241 | 2 | 178.7 / 9.7 |
| 3 | 180 | 131 | 2 | 177.7 / 8.7 |

- 伸びが変わったのは、どの種でも根 (深さ 0) の 2 つの子だけ (列 31・71 の上の子)。伝播つきは単位あたり 86.5、境界なしは 2.0 (43 倍)。
- その 2 つで、強分枝で観測した伸びの合計の 95% を占める。

### その後、木の中で実際に分枝したときの伸び (診断 `ENOMOTO_MIP_PCLOG` の PCO の行、`pcpred.py`・`pcpred.txt`)

- 子の LP の伸びは、既定でも SB_PROBEBD でも 96〜100% の分枝で 0 (双対退化した実行不能の問題)。
- 分枝の 99% は双対退化のために強分枝を使わず、擬似費用だけで選ぶ (既定 1095 回のうち 1053 回、SB_PROBEBD 11873 回のうち 11785 回)。

### 答え

- 伝播で締まった子の伸びは、その子 (根の子) の値としては正しい。
- しかし擬似費用は「その列を単位だけ動かしたときの伸び」を、ほかのノードへ持ち越して使う予測。伝播による分は列そのものの性質ではなく、そのノードで生きていた含意 (締まった別の列の境界) の効き目。
- neos859080 では、根の 2 つの子で伝播の分が 43 倍の伸びを作り、それが強分枝で観測した伸びの 95% を占めた。木の中での実際の伸びはほぼいつも 0 なので、この 2 つの過大な観測は後の観測で薄まらず、擬似費用の表 (その列と、観測の平均) を支配し続ける。
- 擬似費用だけで選ぶ分枝が 99% なので、強分枝で正されない。PSKIP でこの観測を入れないと、ノードは 1.5〜5.6 万から 0.5〜1 万に戻った。
- 親の見立て (伝播の分は局所の境界に依存し、持ち越すと過大になる) は合っている。ただしこの問題では、深さとともに広く偏るのではなく、根の少数の観測に集中して効いていた。
  - 予測 / 実際 の比の偏りを深さごとに出しても (`pcpred.txt`)、実際の伸びがほとんど 0 なので、比はほぼ予測の大きさで決まる。伝播の観測が入った列とそうでない列で、目立つ差は出なかった。

## 7. 観測を捨てずに入れ直す形 (`ENOMOTO_MIP_SB_PROP_PSKIP` の `l`・`t`、`res7.jsonl`・`summ7.txt`)

- `l` (案 2、LP を足さない): 伝播つきの子の双対解は、締まった境界を戻した LP でも双対実行可能。戻す幅だけ双対の目的値が下がるので、
  伝播なしの値 ≥ 伝播つきの値 − Σ |d_c| Δ_c (d_c は締まった列の被約費用、Δ_c は被約費用の向きの境界を戻す幅)。この下界で観測を入れ直す。
- `t` (案 1、LP を 1 本足す): 締まった境界をノードの値に戻して子の LP を解き直し、その伸びで観測を入れ直す (解き直しの前の LP に戻す)。
- どちらも新しい閾値はない。
