# ROOTCAP: 根のサブ MIP・ヒューリスティクス・カットの LP の時間の上限 (2026-11-12)

課題 (HILOSS の直す順 3 と 5): 根のサブ MIP・FP・ダイブ・interior rounding・カットの LP に時間を使いすぎて木に入るのが遅い
(neos-873061・neos-3216931-puriri・unitcal_7・net12・neos-4722843-widden)。

## 結論 (先に)

- 試作 `ENOMOTO_MIP_ROOTCAP=<文字>` (既定では切) を足した。**どの組み合わせも既定候補ではない。**
- 事実: 同じ機械の 600 秒・種 1 で、木に入る時刻は 5 問中 4 問で早くなる (puriri 354→257 秒、unitcal_7 148→77 (hd)・49 (hdw)、
  net12 64→53・39、neos-873061 は既定で木に入らない → 306〜366 秒)。**しかし 600 秒で解けた問題は 0** (既定も 0。HiGHS は 4 問を 240〜544 秒で解く)。
  終わりの下界は unitcal_7・widden で hd・hdw とも既定より低く、net12 は hd で高く hdw で低い (1 回なので揺れを含む)。
- `p` (LP プロービングの止まった基底を根の LP に渡す) は**逆効果**: 根の LP が 9536 反復・20 秒 → 40006 反復・162 秒。
  止まった LP をそのまま続ける `q` も +60 秒・+22000 反復でまだ解けない。
- 新しい事実: **neos-873061 の LP プロービングの最初の LP と根の LP は、同じ種・同じビルドで道が大きく揺れる** (最初の LP は 10.9 秒・9984 反復で解ける回と
  90 秒・38000 反復でも解けない回、根の LP は 11584 反復・14 秒の回と 43926 反復・163〜180 秒の回)。この問題ではこの揺れが根の段のどの手当てより効く
  (LUCLOCK の「道そのものの揺れ」と同じ型と見る。推測)。
- 推測: 対象の 5 問は根の時間を縮めても、木 (ノード LP の重さ・木の大きさ) と根の下界が残るので 600 秒では閉じない (hiloss §6 の見立てと同じ)。
  ROOTCAP 単独で 58 問を回す価値は低い。回すなら `hd`。

## 試作 (`src/mip/solver.rs` の `rootcap`、外側の根だけ)

| 文字 | 中身 |
|---|---|
| `h` | 根のヒューリスティクス全体を min(max(0.05 × 時間の上限, 20 × T), 0.15 × 残り時間 (暫定解なしは 0.25)) まで、1 本 (FP・ダイブ・局所探索・interior rounding・根のサブ MIP の時間の上限) を max(1 秒, 0.02 × 時間の上限, 5 × T) まで (全体の上限以下)。T = 根の LP の秒と LP プロービングの最初の LP の秒 (止まったものも) の大きい方。全体の期限を過ぎたら重いもの (FP・ダイブ・RINS・RENS (more nodes)・局所探索など、`rootcap_heavy`) は飛ばし、安いもの (locks・clique・vbounds など) は 1 本 max(1 秒, T) までで回す |
| `w` | 根のヒューリスティクスの後に裏のカットを待つのも `h` の期限の残り (最低 1 秒) まで |
| `d` | T ≥ 2 秒の問題の根のカットのループ (裏のカットの写しも) で、1 ラウンドに足すカットの非零の和を max(0.05 × nnz(A), 1000) まで (選んだ順、最初の 1 本は残す) |
| `p` | LP プロービングの最初の LP が期限で止まったら、その基底 (行の状態・DSE 重みつき) を根の LP に渡す |
| `q` | `p` の前に、止まった LP を同じ状態のまま 2 × 止まるまでの秒だけ続ける |

係数は `ENOMOTO_T_MIP_ROOTCAP_*` (EACH・EACH_MIN・EACH_TL・TOT・TOT_TL・REM・REM_NOINC・LATE・BGWAIT_MIN・DENSE_LP・DENSE_FRAC・P_MULT)。

参考にした取り方 (記憶による。今回ソースは読み直していない): HiGHS は根と木のヒューリスティクスの LP 反復を全体の 5% (`mip_heuristic_effort`) に抑え、
サブ MIP はノード・葉の数で止める (時間は残り時間)。SCIP はダイブを LP 反復の 5% + 1000 (`maxlpiterquot`・`maxlpiterofs`)、RENS をノード 500 + 0.1 × 木のノードで止める。
どちらも「LP の手間に比べた上限」で、今回の `h` は時間でその形をまねた (決定性はない)。

## 事実 (600 秒・種 1・4 スレッド、同じ機械。HiGHS 1.15.1、`mip_rel_gap=0`)

生データ: `rootcap_20261111/res.jsonl`、ログ `rootcap_20261111/logs/` (widden の hdw のログは書きかけをコミットして失った。結果の行は残る)。
hd・hdw の最初の 2 問 (neos-873061・puriri の hd) は `h` の直し (期限の後も安いものを回す) の前のビルド。

| 問題 | HiGHS | 既定: 木に入る秒 / 暫定解 / 下界 | hd | hdw |
|---|---|---|---|---|
| neos-873061 | 337 秒で最適 113.66 | 入らない / 121.26 / 104.41 | 306 / 118.01 / 105.00 | 366 / 121.62 / 105.21 |
| neos-3216931-puriri | 時間切れ 81350 / 70478 | 354 / 81380 / 59428 | 257 / **解なし** / 59494 (直す前のビルド) | 284 / 81460 / 59503 |
| unitcal_7 | 240 秒で最適 | 148 / 19635558 (最適値) / 19617712 | 77 / 19635617 / 19596738 | 49 / 19637363 / 19601724 |
| net12 | 544 秒で最適 214 | 64 / 214 / 101 | 53 / 214 / 138 | 39 / 214 / 84 |
| neos-4722843-widden | 257 秒で最適 | 136 / 25009.66 / 17231 | 160 / 25009.66 / 12396 | - / 25009.66 / 11426 |

ログから:
- neos-873061: 既定は根の LP 163 秒 (43926 反復)、カット 3 ラウンド、根の RENS 300 秒で木に入らない。hd は根の LP 14 秒の回で、`d` でカットの非零を
  1 ラウンド 1.7 万までにすると 16 ラウンド回り (1 ラウンド 2〜12 秒。既定は 17〜37 秒)、根の下界 104.62。RENS を 59 秒で止め、根のヒューリスティクスは 72 秒。
  ただしその後 **裏のカットを 97.5 秒待つ** (決定的な待ち、安全網 118 秒) ので木に入るのは 306 秒。`w` はこの待ちを切るために足した。
- puriri: `h` で FP 75 秒・分数ダイブ 36 秒で止め、残りのダイブを飛ばす。最初の版では期限の後の locks (既定で唯一の暫定解 81380 を 7.7 秒で出す) まで飛ばして
  解なしで終わった → 安いものは回すように直し、hdw では locks が 81460 を出した。`d` は 1 ラウンドに足すカットを 7〜11 本から 2〜5 本に減らし、根の下界は 59391 → 59460〜59493。
- unitcal_7: RENS は既定 82 秒 (解なし)、`h` で 12 秒に。木に入るのは 148 → 49〜77 秒。`w` は裏のカットの待ちを 165 → 9 秒に切り、根の下界が 19579948 → 19532021 に下がる。
- net12・widden: interior rounding は 28〜30 秒 → 12 秒 (net12)。widden は hd でも木に入るのが既定より遅い回 (160 対 136 秒) で、終わりの下界も低い。

## 次の手 (推測)

- neos-873061 は LP の道の揺れを LUCLOCK・「根の LP を 3 本同時実行」の側で扱う。LP プロービングの最初の LP が止まったときは、基底を渡すより捨てる今の既定が正しい。
- `d` (密なカットの非零の上限) は neos-873061・puriri で根のカットのラウンドを増やし下界を上げた唯一の手。単独 (`ROOTCAP=d`) で根の LP が重い問題 (satellites2・tbfp-network を含む) を確かめる価値がある。
- 根の時間を縮めても対象の問題は閉じない。木の側 (TREEEFF) と根の下界 (CLIQFB) が先。
