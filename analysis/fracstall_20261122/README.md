## 1. 試作 `ENOMOTO_MIP_CUT_STALL_FRAC` (既定では使わない)

- F = Σ_{j ∈ 整数列} min(x_j − ⌊x_j⌋, ⌈x_j⌉ − x_j) (LP 解の整数列の、最も近い整数からの距離の総和)。比べる相手はこのループでのこれまでの最小 F (Fmin)。
- `s`: 本数の条件を F の条件 F ≥ (0.9 − 0.1·stall)·Fmin に置き換える。+2 は F が Fmin を更新しないとき、+1 は更新したとき。係数・10 はそのまま (新しい閾値なし)。
- `c`: 本数の条件と F の条件の両方が停滞のときだけ数える。+2 は本数も F も減らないとき。
- サブ MIP では使わない (既定のまま)。
- 診断: `ENOMOTO_MIP_CUTSTOP_LOG=1` で各ラウンド `CUTFRAC round k obj … nfrac … F … Fmin … stall …` を出す。
- 近い既存の試作 `ENOMOTO_MIP_FRACCUT` の `c` (analysis/fraccut_20261118) は「直前の回から F が 10% 以上減ったら停滞と数えない」(新しい閾値 0.1) で、
  根が変わる問題が少なく、得・損の向きもそろわなかった。
