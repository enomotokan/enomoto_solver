## 2. 問題ごとの所見

- **graph20-20-1rand**: SCIP を 1 つずつ切ると (`logs/graph20-20-1rand_scipabl.jsonl`)、orbitope_pp の伝播 (`constraints/orbitope_pp/propfreq=-1`) で
  6.5 秒 → 時間切れ (下界 −12.5、前処理後の列 343 → 472)、対称性なし・双対の縮小なしも時間切れ。カットを切ると 2.5 秒と速く、衝突解析を切ると 21.8 秒。
  当方も ORBPP で同じ 666 列を 0 に固定し、木では詰め込みの固定 (`packing_fixing`) もするが、根に残る自由な列は 748 (SCIP 343)、根の LP −25.7 (SCIP −12)。
  固定の後の問題を書き出して (DUMP_PRESOLVED3) 対称性なしで解くと、当方も SCIP も 120 秒で解けない (前処理だけでは足りず、伝播が要る)。
- **10teams**: SCIP は lpface (LP の最適面のサブ MIP、目的 0・LP の行を使う・木の深さ 4) が 2.2 秒で最適解 924。当方の根の LP face は 1600 列中
  535 列だけ固定 (面が広い) で 250 ノード・6.6 秒で解なし。目的を 0 にする試し (`LPFACE_Z`、コードは戻した) も、カットの行を足しても (`SUBMIP_CUTS`) 解なし。
  当方の根の 18 秒のうち約 16 秒は解のないサブ MIP 3 本 (被約費用 6.6・LP face 6.7・RENS 2.5 秒)。
- **hypothyroid-k1**: SCIP の knapsack の前処理が大 M の行「45y + Σ x_i ≤ 45」(2512 行) を y + x_i ≤ 1 に分解 (123154 行を足す) し、gate extraction で
  and 制約 264 本にまとめる。試作 `ENOMOTO_MIP_BIGM_SPLIT=1` (分解だけ) は LP が 113122 行になり、根の LP 54 秒・−2885、全体 28.5 → 115.8 秒と悪い
  (SCIP の強さは and 制約へのまとめ直しにある)。
- **neos8**: 当方は早いプロービングで 21400 列を固定した後、プロービングを 4 周 (2.88・2.25・0.68・0.38 秒、固定 0、同値な組で 1660 → 560 列)。
  2 周目は CLQPRB の `g` (既定の形の後に含意の形でやり直す)。`ENOMOTO_MIP_CLQPRB` を変えると 1 スレッド・種 1 で 既定 `1dgrs` 9.1 秒、`1dgr` 8.6、
  `1dr` (やり直さず最初から含意の形) 5.4、`1drs` 5.6、`0` 10.4 秒。`g` の元の目的 (puriri の害を避ける) のための最初の既定の形のプロービングが、
  含意の形が残る問題 (neos8・mzzv11・mzzv42z) では丸ごと余分になる。
- **air03**: プロービングに約 3.5 秒 (512 列を試して固定・締め付け・同値な組とも 0、含意は 92 万本と数える。同値探し 0.55 秒)。SCIP は air03・mc11・
  hypothyroid-k1・10teams・graph20 で「50 回続けて全く役に立たない試し」でプロービングを打ち切る (0.1 秒以下)。CLQPRB を切っても air03 は 3.6 秒で変わらない。

## 4. graph20-20-1rand: 対称性の固定の後の伝播・プロービング (試作 `ENOMOTO_MIP_ORBPP_REPROBE`、親の依頼)

- SCIP の切り分け (双対の前処理を全部切る: 各制約の dualpresolving・domcol・dualagg・dualcomp・dualinfer・dualsparsify・stuffing・dualfix、さらに vbounds の集約も
  切る): それでも 3.6〜7 秒で解け、前処理後 326 列、最初の根の LP −12。固定の出どころは対称性 666・logicor 458・probing 164 (+ まとめ 130)・trivial 114・
  orbitope_pp 67・linear 37 (`logs/` ではなく scratchpad の統計、要点だけここに)。→ 双対の縮小なし (主の推論だけ) で SCIP の根に届く。
- **安全の方針**: 前処理のかけ直し (まとめ・置き換え・双対の縮小) はしない。列の対応 (オービトープの行列) に触れず、固定と締め付けだけにする
  (主の推論は実行可能な点を消さないので、木のオービトープの固定はそのまま正しい)。双対の縮小と対称性の組み合わせは p0201 の誤答 (SYMDYN=f) の元でもあった。
- 中身 (`orbpp_reprobe`、src/mip/mod.rs、静的なオービトープの固定の直後): (1) 行の伝播、(2) 静的なオービトープの固定 (`orbitopal_fixing`、詰め込みの固定を含む)、
  (3) 自由な 0-1 列のプロービング (片側が「行の伝播 + オービトープの固定」で矛盾すれば反対側に固定。値 `r` なら行の伝播だけ) を、変わらなくなるか 5 回まで。
  手間の上限は伝播で走査した行の長さの合計で 200 x 非零。
- graph20 (1 スレッド・種 1): 伝播 547 列・オービトープ 98 列・プロービング 225 列を固定、根の自由な 0-1 列 1295 → 425 (0.08 秒)、根の LP −25.7 → **−11**
  (SCIP −12)。プロービングを行の伝播だけにすると (`r` に当たる最初の版) プロービングの固定は 0 で 650 列・−19。
- ただし全体は速くならない (1 スレッド、計測と同時に nice 19):

| 種 | 既定 | ORBPP_REPROBE |
|---|---|---|
| 1 | 52.5 秒・3940 ノード (根 −16.76) | 49.0 秒・2931 ノード (根 −11) |
| 2 | 54.9 秒・3940 ノード | 57.6 秒・6194 ノード |
| 3 | 54.3 秒・3940 ノード | 86.5 秒・5558 ノード |

  根の下界 −11 から最適 −9 まで、当方は 3000〜6000 ノード、SCIP は 156 ノード。差は木の側に移った (SCIP は衝突解析を切ると 6.5 → 21.8 秒)。
- 確かめ: cargo test 409 通過。`ENOMOTO_MIP_ORBPP_REPROBE=1`・`ENOMOTO_T_MIP_ORBPP_MIN_COLS=2`・`_MIN_ROWS=2` (小さい問題でも静的にする) で
  mip_fuzz_symmetric 0/300・fuzz_tiny 0/400。誤答 0 (この fuzz で固定の後の処理が何回働いたかは数えていない)。
- 判断 (親に提案): graph20 の根は SCIP 並みになったが全体は速くならないので、P・M の計測はしない。差は木 (衝突解析など) の側。

## 10. PROBE_USELESS の結論 (2026-11-19)

- **不採用** (既定は変えない。`ENOMOTO_MIP_PROBE_USELESS` は環境変数の試作のまま残す)。1 版目 (含意を数えない) は P +3.2% で全種で遅い問題 4 つ、2 版目 (新しい含意を
  数える) は P −1.5% だが neos-827175 が全種 1.54 倍、3 版目 (詰め込みの行の含意だけを新しくないとする) は害が消えるかわりに得も air03・neos8 で
  0.4〜0.5 秒しか残らず、既定にする根拠にならない。3 版目の P は測らない (親の判断)。
- 分かったこと: 当方のプロービングの含意は、詰め込みでない行 (ナップサック・変数上下限) から出るものも後の木で効く (drayage-25-23・neos-827175)。
  SCIP の「役に立たない試しで打ち切る」は、含意をクリーク表で数えるので同じ形にすると得がほとんど残らない。

## 11. Mittelmann 186 問の ORBPP の洗い出し (2026-11-19)

- 台本は `orbscan.py`、結果は `orbscan.jsonl` (1 問 1 行、186 問すべて止まった・エラー 0)。各問の前処理だけを流し、symmetry のログ (オービトープ・ORBPP・ORBPP_REPROBE) を拾った。
- オービトープが見つかる問題は 29 問。そのうち ORBPP の静的な固定が働く (固定 > 0) のは 2 問だけ。
