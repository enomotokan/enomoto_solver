## 1. 作ったもの (事実)

`src/mip/hnfsubst.rs` と `src/mip/mod.rs` の `hnf_subst`。

- **場所**: `hnf_presolve` (HNFPRE、前処理の後の整数列だけの等式の Hermite 標準形) の直後、クリーク行の拡張・前処理の LP による固定 (クリーク行の拡張の後)・
  対称性の検出の前。選んだ理由:
  - 合同式は前処理の後の問題の格子から出るので、前処理の後でないと分からない。HNFPRE は上下限が詰まれば前処理をかけ直して解析し直す (最大 4 回) ので、
    その不動点の後に置く。
  - クリーク行の拡張は 0-1 列だけを見るので、置き換え (一般整数列だけ) の前でも後でも同じ。対称性の検出は置き換えた後の問題で探す (検出した対称性・
    オービトープ・対称性の行は置き換えた後の列の上の話になり、写し直しが要らない)。
  - 置き換えの後に前処理をかけ直すことはしていない (前処理は列の尺度 d を新しく掛けることがあり、置き換えと尺度の順の約束が増える)。割った行の丸めや
    上下限の伝播を前処理に使わせる余地は残っている (§6)。
- **置き換え**: HNFPRE の解析 (`hnf::analyze`) をもう一度かけ、合同式 x_j ≡ r_j (mod g_j) が出た列のうち、整数列 (尺度の掛かっていない列)・固定されていない・
  0-1 列でない・1 < g_j ≤ 1000 のものを x_j = r_j + g_j y_j (y_j は整数) にする。r_j は下限が有限なら下限以上で合同式に合う最小の値 (下限は HNFPRE が
  合同式に合うよう詰めてあるので r_j = 下限、y の下限は 0)、上限だけ有限なら上限以下の最大の値、両方無限なら [0, g) の代表。
  行の係数 a → a g、行の下限・上限から a r を引く、費用 c → c g・目的の定数に c r を足す、y の上下限は ceil((l - r)/g)・floor((u - r)/g)。
  プロービングの含意 (`implied_bounds`) の相手が置き換えた列なら値を y に直して丸める。値は 2^52 未満の整数だけ扱い (超えたら置き換えない)、
  置き換えで係数の絶対値が 1e9 を越える列は置き換えない。
- **行を割る**: 置き換えた列を含む行のうち、列がすべて整数列 (尺度なし) で係数が整数のものを係数の最大公約数で割り、下限を切り上げ・上限を切り下げる
  (等式で右辺が割り切れなければ割らない)。例: flugpl の `2 x1 + 3 x2 = 12` 型の行は置き換えると `6 y1 + 6 y2 = 6` で、割ると `y1 + y2 = 1`。
- **列の番号を保つ前処理の約束 (事実、コードを読んで確かめた)**: 前処理の結果は (問題, 後処理の手順 `PostsolveStep` の並び, 列の尺度 `scaling.d`) で、
  元の空間の解は「手順を逆順に適用してから x = d x'」で戻す。尺度の形 x = d x' は定数のずれ r を表せないので使えない。代わりに
  **自己参照の代入** `PostsolveStep::Sub { var: j, terms: [(j, -g)], rhs: r, coeff: 1 }` (値 = (r - (-g) x_j)/1 = r + g y_j。`Substitution::value` は
  書き込みの前に読む) を手順の最後に足す。逆順に戻すので置き換えが最初に戻り、それから前処理の手順が戻る。新しい手順の種類は要らなかった。
- **整合 (事実、コードを読んで確かめた)**:
  - 再スタートのカットの写し (`map_restart_cut_subst`): 手順を前から辿って代入するので、自己参照の代入では a x_j → a r + a g y_j になり正しい。
    尺度だけで写す経路 (`ENOMOTO_MIP_NO_RESTART_CUTS_SUBST`) は置き換えがあれば使わずカットを捨てる。
  - 再スタート: 再スタートの後の求解は解いている (y の) 問題を元の問題として `solve_problem` を呼ぶので、その中の前処理・HNF・置き換えは y の空間で閉じる
    (y の格子でさらに合同式が出れば重ねて置き換える)。暫定解・カットプールも y の空間のまま渡る。
  - 暫定解の写し (元の空間 → 前処理の後の空間): x/d の後に y = (x - r)/g (`hnfsubst::forward`)。前処理の中の早めの FJ の解 (`FEAS_FJ_SOL`) も写す。
  - pseudocost の写し (`ENOMOTO_MIP_RESTART_PC`): y の 1 刻みは x の g 刻みなので尺度に g を掛けて渡す。
  - 根の基底 (前処理の LP による固定の最後の LP): 列の状態はそのまま使える (有限の上下限は合同式に合わせてあるので、x が下限 ⇔ y が下限)。行は並びが
    同じで係数・右辺が変わるだけなので、行の指紋が置き換えの前の行と合っていたら置き換えの後の行の指紋に付け替える。最初の版は基底を捨てていて、
    snp-02-004-104 の根の LP が基底なしで 6 秒を越えた (既定は基底から 626 反復・0.66 秒) ので直した。DSE の重み・行の中身の写しは捨てる。
  - カットの共有 (`ENOMOTO_MIP_BISECT_SHARE_CUTS`、既定では使わない) は尺度 d で元の空間に戻すので、置き換えたときは尺度を渡さない (共有しない)。
  - サブ MIP は解いている (y の) 問題から作るので触らない。HNFPRE=1 と一緒に使うと、分枝の丸めの表は置き換えの後の問題で作り直される (`hnf_register_final`)。
  - 安全網: 後処理した解が元の問題で実行不能なら前処理なしで解き直す既存の仕組みがある。計測のログでこれが働いた回はない (§4)。
- 単体テスト `mip::hnfsubst::tests::subst_roundtrip` (置き換え・行の割り算・後処理・暫定解の写し)。
