# 過去の試作の洗い直し: 一部の問題だけに入れる・割合を決めると効くものを探す (2026-11-18、利用者の承認済み)

新しい計測はせず、手元の記録 (analysis/ の res_*.jsonl・summ_*.txt・README、docs/improvement_history.md) だけで、
「全体では効かない・害があったが、効く問題が種をまたいで安定している」過去の試作を探し、条件付き (if) で入れる候補を絞る。

## 手順

1. 対の計測 (def と試作が同じ問題・同じ種で並んだ res_*.jsonl) が残っている過去の試作を列挙する。
   (analysis/revisit_20261112 の 745 件の洗い出しが手がかり。今日の計測中・判断中の試作と、analysis/cleanup_20261118 で削除済みのものは除く。)
2. 試作ごとに、問題 × 種の時間の比 (shift 1 秒、時間切れは上限で数える) を集め、
   - 全種で 0.8 倍未満の問題 (安定して速い)・全種で 1.25 倍超の問題 (安定して遅い) を数える、
   - 種をまたいだ順位の相関 (Spearman) を出す。
3. 「安定して速い問題だけに入れた」場合の伸びしろを、種を分けた交差検証 (選ぶ種と評価する種を分ける) で見積もる
   (今日の analysis/cutcoef_20261118 の summ.py の方法と同じ。選び過ぎの見かけの得を除く)。
4. 残った試作について、速い問題と遅い問題を問題の特徴 (行数・列数・非零・整数の割合・一般整数の数・密度・集合被覆/分割型か・対称性・
   根の間隙など。既存の特徴量の出し方 (feat.py など) を使ってよい) で分けられるかを見る。
   境目がはっきり分かれるなら普通の if、境目の近くに問題が多いときだけ連続の形 (利用者の方針)。割合や上限のパラメータで効く試作は、その値の案も。
5. 結果を `analysis/remine_20261118/README.md` に表で: 試作・記録の場所・全体の効き・安定して速い/遅い問題・交差検証の伸びしろ・分ける条件の案・見込み (高中低)。
   上位 5 件程度について、条件付きの形の実装と短い計測の案 (問題・種・設定) を書き、親に報告する。
