### 9.3 条件付き候補の特徴 (効いた・害の出た問題を分けられそうなもの)

既定 def_t1 の行 (結果の dict の root_bound・first_solution_time・nodes) と各調査の記録から。

- **enum (1・4 スレッド)**: 全種で遅れた neos8・nu25-pr12・air03・neos-960392 は、どれも既定では**根で解ける (ノード 0) 6 秒以下の問題**で、
  遅れは前処理の固定費 (neos8 4.6〜6.1 → 8.5〜11.0 秒)。neos-960392 は enum で根で閉じなくなり木に入る (82〜350 ノード)。効いた rout は木の問題 (6000〜9500 ノード)。
  - 特徴の候補: 列挙・プロービングの繰り返しの得 (固定・締め付け・同値な組) と、その時間の「根の LP までにかかる時間」に対する割合。
  - 適応形 `ENUM_ADAPT` との突き合わせ: neos8 を 1 回だけ回した (種 1・1 スレッド、feat.py --env ENOMOTO_MIP_ENUM_ADAPT=1): 4.6 → **8.9 秒で、ENUM_ADAPT でも遅れは消えない**。
    最初の周の s = 0.205 (b = 0.41 より下) でも続けている (続ける 2 回)。列挙の得は 0 だが、プロービングの同値な組 (602・3239 組) が得に数えられ、時間の割合 c は
    残り時間 (60 秒) で割るので小さく、f 以下になる。ENUM_ADAPT の時間の物差し (残り時間) は、根で解ける問題の固定費を測れない。
- **h1t (1 スレッド)**: 効いた 10teams は**根の下界がすでに最適値 (root_gap 0) で、木が 6000〜7000 ノードで時間切れ**になる問題 (heur1t_20261123 の見立てと同じ)。
  害の出た noswot・eil33-2・swath1・mas76・markshare_4_0・blend2・misc07 は、どれも root_gap > 0 (0.024〜1.0) で下界を閉じる木。
  - 求解中に測れる特徴の候補: 暫定解と下界の差のうち、木の中で縮んだ分の主 (暫定解の改善) と双対 (下界の上昇) の割合、または下界の止まり方 (一定のノードで下界が動かない割合)。
    根の下界が最適かどうかはその場では分からないので、その代わりになるもの。physiciansched6-2 も root_gap 0 だが h1t は効かない (根の 1 回目の LP が重く木が 100 ノード台)。
