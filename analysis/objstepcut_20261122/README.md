# 目的の刻みの行をカットの材料にする試作 ENOMOTO_MIP_OBJSTEPCUT (2026-11-22、利用者の案・親の依頼)

案: 目的値に刻み g があるとき (費用のある列が全て整数か整数値に固定され、費用が g の整数倍。`MipProblem::objective_step_bounds`)、根の LP の値 z を
刻みに切り上げた L = ⌈z/g⌉ g について、不等式 c·x ≥ L はすべての整数解で成り立つ。これをカット生成に使う。

作り (src/mip/separation.rs、既定は使わない、新しい閾値なし):
- 行は Σ k_j x_j ≥ lk。k_j = c_j / g (整数)、lk = ⌈z/g − 1e-6 max(1, |z/g|)⌉ で、z は根の LP の解の目的値。係数・右辺とも整数で、活動量は整数。
- 外側の根 (裏のカット・サブ MIP・ノードを除く、ノード数 1 以下) の分離のたびに作り直す。
- `a`: カットとして LP に入れる。lk がこのループで前に入れた値より上がり、LP 解を切るときだけ入れ、選択は通さない。
- `b`: LP には入れない。分離に渡す行の写しの最後に足し、活動量の変数 (整数、下限 lk) を CutVars に足す。
  経路集約 (path・path_highs) と、その出発行からの cmir の材料になる。tableau 行・mcf・hnfcut は元の行だけを見る。
- 診断 `ENOMOTO_MIP_OBJSTEPCUT_LOG=1`: 分離のたびに `OBJSTEP g … zk … lk …`。
