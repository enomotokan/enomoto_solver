# RSTDEN: 根の再スタートの割合の分母を自由な整数列にする (2026-11-13〜14)

依頼: 根の再スタートの判定 (`maybe_restart`・`restart_expected`・`proto_restart_ok`) は、割合の分母を全部の整数列 (`p.nint`、根の始めに
固定済みの列も含む) にしている。HiGHS (`percentageInactiveIntegers`) は前処理の後の自由な整数列に対する割合。分母を自由な整数列にする形を
cand1114 (analysis/cand1114_20261113/cfg.py) の上で比べる。RSTCRIT=n (cand1114 に入っている) とあわせて、縮みの小さい再スタートが増えないかも見る。
別のセッションの RSTCRIT `a` (連続列の固定も非零で数える) とは重ならないよう、こちらは分母と回数の上限だけを扱う。

台本・ログ: `analysis/rstden_20261113/` (`run.py` は rstcrit_20261111/run.py の写し。`screen.py`・`summ_screen.py` = 1 節、`bench.py`・`summ_bench.py` = 2 節、
結果 `screen.jsonl`・`bench.jsonl`、詳細ログ `logs/`)。この機械 (4 コア)、4 スレッド、ソルバーは 1 本ずつ。コードは 50926943。

  (`0` 本の強制の再スタート = TREEEFF の木の再スタート) だけ。上限を変える形は測っていない (分母を広げた形が得になっていないので、上限を上げる理由がない)。

## 0. 作ったもの (既定の振る舞いは変えない)

試作 `ENOMOTO_MIP_RSTDEN` (`Solver::restart_denom`・`proto_restart_denom`、src/mip/solver.rs)。文字:

- `1`: 1 回目の根の終わりの再スタート (`maybe_restart`・ROOTSTOP b の `restart_expected`) の割合の分母を、根の始めに自由だった整数列にする。
- `2`: 2 回目以降で同じ (`ENOMOTO_MIP_RESTART_FRAC_FREE` の 2 回目以降だけの形)。
- `p`: 早めの再スタート・木の中の再スタート (`proto_restart_ok`) と LOSE6_3_CUTRESTART の「全部の整数列の FIRST_FAC / FAC」の条件にも同じ分母を使う。

`ENOMOTO_MIP_RESTART_FRAC_FREE`・`GR_RESTART=ff` は前のまま (1 回目・2 回目以降とも自由な列。早めの再スタートには効かない)。

## 3. 判断と残したこと

- 分母を自由な整数列にする形は採らない。HiGHS と数え方を揃えても、ENOMOTO の 2 回目以降の根は重く (treeproof_20261023 の 1-3 と同じ)、
  小さな再スタートを重ねる分だけ損になる問題の方が多い。
- mzzv42z の 2 回目の再スタートの効き (300 秒で 25% 前後速い) は残る。取るなら、分母ではなく「2 回目以降の再スタートを、下界の伸びの見込みが
  大きいときだけ許す」形 (例: 一般整数のある問題だけ、既存の `GR_RESTART=ff` と同じ条件) で、mzzv42z と h80x6320d・nubu・p200x1188c を分ける要がある。
  今回は作っていない。
- 試作 `ENOMOTO_MIP_RSTDEN` はコードに残す (既定では使わない)。`cargo test --release --lib`: 415 件通過・19 件無視・失敗 0
  (この機械では pyo3 の extension-module のためテストのリンクに libpython が要る: `RUSTFLAGS="-C link-arg=-L/usr/local/lib -C link-arg=-lpython3.13" CARGO_TARGET_DIR=target/test_py`)。
