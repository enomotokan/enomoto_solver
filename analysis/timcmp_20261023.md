# timtab1: HiGHS 1.15.1 と ENOMOTO の証明までの道筋の比較 (2026-10-23)

- 土台は `claude/enomoto-solver-heuristic-survey-xjlnol` の 9acab4b。
- この機械は 4 CPU。4 スレッド、mip_rel_gap 0 で回した。
- 台本・ログは `analysis/timcmp_20261023/` に置いた。
  - `run.sh`: ログの各行の頭に壁時計の秒をつける。
  - `batch1.sh`: 200 秒・60 秒・打ち切り値つき・対称性の形。
  - `batch2.sh`: 60 秒で 3 回ずつと、副作用を見る問題。
  - `symscan.sh`: 55 問で対称性の検出を比べる。
  - `timeline.py`: 時刻ごとのノード数・下界・暫定解。
- mixoc は `ENOMOTO_MIP_FJ_LMIP_MIX=1 ENOMOTO_MIP_SYM_ORIG_CUT=1`。

## 結論

- **timtab1 の「強い対称性」は偽物だった。**
  - 前処理の後も、固定された空の列が 196 本残っている (397 列のうち、自由な列は 201)。
  - 対称性の検出は、この列どうしを入れ替えられるとみていた。
  - その結果、互換 194 個、lex-leader の行 170 本 (どれも 0 >= 0)、1x25 のオービトープが出ていた。
  - 意味のない行が LP に入り、ノード LP の行は平均 973〜1050 行になっていた (除くと 640〜680 行)。
  - オービトープは 1 つも固定しない (`orbitopes 1: fixed 0 bounds, pruned 0 nodes`)。
  - HiGHS は前処理で固定列を消すので、対称性を検出しない (ログに対称性の行がない)。
- 手当て: **`ENOMOTO_MIP_SYM_SKIP_FIXED=1`** (既定は切)。
  - 対称性の検出で、固定列 (下限 = 上限) に 1 列ずつ別の色をつけて動かさない (`src/mip/symmetry.rs` の `detect`)。
- 同じ偽の対称性は 55 問のうち 20 問以上にある (`symscan.out`)。
  - lex-leader の行が全部消える問題: beasleyC3 (332 本)、binkar10_1 (350)、10teams (169)、qnet1 (123)、roll3000 (63)、dcmulti (45)、h80x6320d (37)、timtab1 (170) ほか。
  - physiciansched6-2 は、検出の時間 (0.3 秒) を偽の互換に使い切らなくなり、本物の 8x5〜8x6 のオービトープが見つかるようになる。
- この機械では、証明の速さは HiGHS と ENOMOTO でほぼ同じ。
  - HiGHS: 63〜71 秒。
  - ENOMOTO 既定: 52〜78 秒。
  - 打ち切り値を与えた場合: HiGHS 83〜87 秒、ENOMOTO 79〜86 秒、SKIP_FIXED 62〜81 秒。
  - 基準の機械の HiGHS 59.9 秒は、60 秒のぎりぎりにある。
- SKIP_FIXED を足すと、60 秒で最適値に届く回が増え、下界も上がる (batch2 の 60 秒で、足した側は 6 回のうち 5 回、足さない側は 6 回のうち 1 回)。
  - 証明の回数は変わらない (両側とも 6 回のうち 1 回)。
  - 副作用の 4 問 (1 回ずつ) では、悪くなった問題はない。
  - 既定にする候補。ただし 40 問 + 16 問での確認が要る。偽の対称性の問題が多いので、影響は timtab1 に限らない。

事実:
- ENOMOTO の下界は、どの時刻でも HiGHS と同じか高い (30 秒で 704〜718k、HiGHS 664k)。
- どちらも最後の 10〜20 秒で一気に閉じる。証明の時刻は、最後に残った部分木の大きさで決まる。
- ENOMOTO はノードを HiGHS の 3〜8 倍使う。4 本の木では 1 本あたりおよそ同じ数で、1 本あたりの効率は HiGHS と同じ程度。
- SKIP_FIXED で LP の行が 3 分の 2 になり、ノード LP の反復は 1〜2 割減った。1 秒あたりのノードは 3〜6 割増えた。
- 木のノードの総数は、回ごとの揺れの方が大きい (SKIP_FIXED で 3.1 万〜7.4 万)。

## 3c. 対称性

- HiGHS: 前処理で固定列を消すので、対称性は検出されない (オービトープ・軌道の固定の行はログにない)。
- ENOMOTO: 上の通り、対称性はすべて固定列どうしのもの。
  - lex-leader の行 170 本は意味がなく、LP を重くしている (3b の行数・反復)。
  - オービトープの固定は 0。
- `ENOMOTO_MIP_NO_SYMMETRY=1` と SKIP_FIXED は、timtab1 では同じ問題になる (検出は none)。
  - 証明は、NO_SYMMETRY が 61.5 秒、SKIP_FIXED が 45.5・83.7 秒。
- オービトープだけ (`SYM_DETECT_ONLY`): lex の行は足さず、オービトープを登録する。56.9 秒。

## 3d. 解と証明の切り分け

- HiGHS は、いつも同じ道筋 (ノード数 9156 で決定的) で最適値に届く。
  - sub-MIP (L) で 816264 (2.3 秒)・804458 (3.3 秒)。
  - 木 (T) で 802574 → 768796 (31〜36 秒)、766577 (45.6 秒)、764772 (46.2 秒)。
  - 証明は、そこから 17〜25 秒後。
- ENOMOTO が 764772 を見つける時刻と出どころ (60 秒の回):
  - 10.7〜58.5 秒と散る。木の中の丸め・ランダム丸め・crossover・RINS が多い。
  - batch2 の 60 秒の回で 764772 に届いたのは、既定 1/3 (17.0 秒)、mixoc 0/3、SKIP_FIXED 2/3 (13.8・51.4 秒)、mixoc + SKIP_FIXED 3/3 (12.9・16.7・56.4 秒)。
- 打ち切り値 764772.5 を与えたとき (200 秒):

| | 1 回目 | 2 回目 |
|---|---|---|
| HiGHS (`objective_bound`) | 83.2 秒・9649 ノード | 86.7 秒・9649 ノード |
| ENOMOTO 既定 (`ENOMOTO_MIP_CUTOFF`) | 85.7 秒・35911 | 79.1 秒・26329 |
| ENOMOTO SKIP_FIXED | 62.4 秒・39789 | 81.3 秒・55038 |

- 打ち切り値を与えても、どちらも速くならない (HiGHS は遅くなる)。
  - 推測: 暫定解がないとヒューリスティクス・刈り込みの流れが変わる。打ち切り値を与えても、ENOMOTO は 764772 の解そのものを 22〜76 秒にようやく見つける。
- 推測: 60 秒に間に合うかは、解よりも証明 (木の大きさ) で決まる。どちらも 60〜85 秒が中心で、揺れが大きい。

## 推測と次の手

- 偽の対称性は、検出の時間 (0.3 秒) と LP の行を無駄にし、本物の対称性の検出も邪魔する (physiciansched6-2・ns1116954・nursesched-sprint02)。
  - 以前の beasleyC3 の「生成元の数で根の下界が揺れる」(analysis/beasleyC3_r3_20261020.md) も、固定列どうしの生成元の数の揺れだったとみられる。
- 次の手:
  - `ENOMOTO_MIP_SYM_SKIP_FIXED` を 40 問 + 16 問で既定と mixoc に足して確かめ、悪くならなければ既定にする。
  - あるいは前処理の後に固定列を問題から消す。
- HiGHS との差として残るもの:
  - ENOMOTO の木の大きさ (HiGHS の 3〜8 倍のノード)。
  - HiGHS の 15 秒の木からの再スタート。
  - ノード LP の反復 (HiGHS 約 40、ENOMOTO 85〜127)。
  - timtab1 では証明の速さは並んでいるので、60 秒の内か外かは揺れで決まる。
- 目的値の不一致: なし。最適と報告した回はすべて 764772 (HiGHS と同じ)。副作用の問題の最適も既知の値 (neos-960392 −238、beasleyC3 754)。
