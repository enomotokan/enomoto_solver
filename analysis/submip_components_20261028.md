# サブ MIP は独立な変数群 (連結成分) に分かれるか (2026-10-28)

RINS・RENS などで現れるサブ MIP が、互いに行でつながらない列の塊 (連結成分) に分かれるか、また行の多い整数列を先に固定すれば
分かれるか (多く現れる列を分枝で優先する案) を数えた。

- 診断 `ENOMOTO_MIP_DEBUG_SUBMIP_COMPONENTS` (既定では使わない): 外側の根・木から出したサブ MIP ごとに、自由な列の連結成分を前処理の
  前と後で出す (`SUBMIP_COMP:` の行)。行は自由な列を 2 本以上含むものだけがつなぐ。あわせて、自由な整数列のうち行の数の多い上位
  1%・5% をつながりから外したとき (分枝で先に固定したと思ったとき) の成分も出す。結果 (状態・ノード数) の行も出す。
- 計測: 負けている 21 問、今の develop の既定 (cd92da1)、16 スレッド・60 秒・1 回 (`submip_components_20261028/comp_loss21.jsonl`)。
  集計は `submip_components_20261028/summarize.py`、分かれるものだけの表は `split.md`、全部は `all.md`。
- 「成分」は 2 列以上のものだけ数える (1 列だけの成分は前処理で消えるか、ほかと分枝を掛け合わせない)。表の括弧は、最大の成分が
  自由な列に占める割合。

## 結果

- サブ MIP 300 本のうち、前処理の後に 2 列以上の成分が 2 つ以上あるのは **56 本 (19%)**。行の多い上位 5% の整数列を外しても
  **61 本** で、ほとんど増えない。ノード・時間の上限で止まった 131 本のうち、分かれるのは 27 本 (上位 5% を外して 28 本)。
- 分かれる 56 本の多くは **大きい 1 つ + 小さいもの** (最大の成分が 90% 以上): mc11 (根・木の RINS・mutation・crossover、2〜5 成分で
  最大 93〜99%)、neos-911970 (木の RINS・crossover、最大 79〜98%)、drayage-25-23 (根の被約費用・LP face、最大 100%、4 秒の時間切れ)、
  physiciansched6-2 (RENS・RINS、98%)、mzzv42z の根 (最大 93〜95%)。小さい成分は列が数本〜数十本で、分けて解いても木はほとんど
  小さくならない。
- 釣り合って分かれる (最大 65% 以下) のは数本だけ: mzzv42z の RINS (最大 28%・62%、どちらも 0〜1 ノード)・木の LNS (46%)、
  nu25-pr12 の LP face (5 成分・最大 45%、83 ノードでノード上限) と RINS (42〜48%、1〜3 ノード)、exp-1-500-5-5 の vbounds (実行不能で 0 ノード)、
  neos-911970 の DINS (40%、実行不能)。ほとんどは今でもすぐ終わる。
- **行の多い列を外しても分かれ方はほとんど変わらない**: 上位 5% を外して最大の成分が数 % 小さくなる程度 (例: exp-1-500-5-5 の RENS 100% → 84%、
  neos-3083819-nubu の locks 1 → 5 成分・最大 71% が目立つ程度)。この 21 問のサブ MIP では、少数の列が大きな塊どうしをつないでいる形は
  ほぼない。
- 前処理の前と後で成分が変わるものがある (sp150x300d の LP face: 前 7 成分 → 後 2 成分、mc11: 前 1 → 後 2〜5)。前処理が行・列を消して
  分かれる場合と、1 列だけの成分を消す場合の両方。

## 判断

- 成分ごとに解く (SCIP の components のような) 処理は、この 21 問では効く余地が小さい。分かれるサブ MIP の多くは大きい成分がほぼ全部で、
  上限で止まっているのもその大きい成分のせいと考えられる。効きうるのは nu25-pr12 の LP face (83 ノードで止まる、5 成分・最大 45%) の
  ような形だけ。
- 行の多い列で分枝して分けやすくする案も、外しても分かれないので、この 21 問では見込みが薄い。
- MIPLIB 40 問や Mittelmann の残りの問題では形が違うかもしれない (確かめていない)。
