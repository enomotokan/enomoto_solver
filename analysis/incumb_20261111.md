# INCUMB: 最適解・良い暫定解が HiGHS より遅い問題 (2026-11-12、途中)

HILOSS (analysis/hiloss_20261111.md) の直す順 8・分類 H の問題について、HiGHS の最良解の出どころと ENOMOTO の暫定解の出どころ・時刻を並べ、
差がどのヒューリスティクスにあるかを調べた。試作 2 つ (`ENOMOTO_MIP_INCUMB` の `r`・`a`、既定では使わない) を入れて 2 問で試した。

## 結論 (先に)

- **事実**: 7 問のうち、HiGHS の最良解が「根 (再スタートの後の根を含む) のサブ MIP (`L`)」から来るのは widden・mzzv11 (の途中まで)・hypothyroid-k1 の 3 問。
  csched008・supportcase33・satellites2-60-fs は **木のノードの解 (`T`・`B`)**、fiball は **木の中のサブ MIP (`L`)**。
- **事実**: 試作 2 つ (再スタート後の RENS をダイブにする `r`、根の RINS が良くしたら繰り返す `a`) は、mzzv11・widden (種 1・600 秒・1 回) でどちらも既定より良くならなかった。
  **既定候補ではない**。58 問の害の計測はしていない (候補にならないため)。
- **推測**: 7 問の暫定解の遅れは、ヒューリスティクス単体の差より、主因 (mzzv11 の下界 C/P、satellites2 の固定 F、hypothyroid-k1 の根のカットのループ C/R、
  csched008・supportcase33 の木 T) の結果として出ているものが多い。INCUMB だけで勝ちを増やせる見込みは小さい。残る手は §4。

## 2. 試作 (`ENOMOTO_MIP_INCUMB=<文字>`、既定では使わない)

| 文字 | 中身 | 場所 |
|---|---|---|
| `r` | 再スタートの後の根で、再スタート前の暫定解が前処理後の問題から外れて参照解だけがあるときも、根の RENS を `SUBFIX` の `r` のダイブ (目標の固定率で止め、根で実行不能なら半分でやり直す) にする | `src/mip/heuristics.rs` `rens` |
| `a` | 外側の根の RINS が暫定解を良くしたら、新しい暫定解で RINS をもう一度 (最大 `ENOMOTO_T_MIP_INCUMB_RINS_REP` = 2 回、良くならなければやめる) | `src/mip/solver.rs` 根のヒューリスティクスの並び |

## 3. 結果 (種 1・600 秒・1 回、`incumb_20261111/res.jsonl`・`logs/`、同じ機械で続けて)

| 問題 | 既定 (def) | `ra` |
|---|---|---|
| mzzv11 | 時間切れ、−21718 を **346 秒** (木) | 時間切れ、−21718 を **376 秒** (木)。再スタート後の RENS ダイブは 0.43 (4646 列) で 0 ノード実行不能、0.22 (6379 列) で 6 秒の時間切れ・0 ノード。木に入るのが 13 秒遅い (146 対 133 秒) |
| neos-4722843-widden | 時間切れ、25010 を **345 秒** (木の乱択丸め) | 時間切れ、25010 を **537 秒**。根の RINS の繰り返しは 26389 → 26148 (2 回目、212 ノード)、3 回目は改善なし (計 +10 秒)。根の後の暫定解は既定 26614 より良いが、木の中の改善が遅い |

読み方: どちらも 1 回で、木の中の解の時刻は回ごとに大きく揺れる (widden の既定は hiloss の回で 441 秒、この回で 345 秒)。
`a` は根の後の暫定解を 1〜2% 良くするが、最適解 (25010) には届かず、HiGHS の 96・172 秒の解 (再スタートの後の根) の代わりにならない。
`r` の近傍 (再スタート後の LP 解に寄せて 22〜43% 固定) は打ち切り値 −21568 のもとで実行不能か、0 ノードで時間切れ。HiGHS の再スタート後の `L` が
どの近傍で −21708 を出したかは、HiGHS のログからは分からない (未特定)。

## 4. 次の手 (推測)

1. widden: HiGHS は 0.2% の固定でも根で再スタートし、前処理をかけ直した問題で根のサブ MIP を回して最適解に着く。ENOMOTO の再スタートの基準
   (新たな固定 ≥ 1% 程度) では再スタートしない。再スタートの基準は RSTCRIT の受け持ちなので、widden を RSTCRIT の対象に入れてもらうのがよい。
2. mzzv11: 暫定解より根の下界・前処理 (C・P) が主因。600 秒で最適解を見つけても閉じない (既定 346 秒で最適解、終わりの下界 −21902)。
3. supportcase33・csched008: 木のノードの解。TREEEFF (分枝・潜りの順) に回す。
4. hypothyroid-k1: 根のカットのループ (47 秒) の前に、根の LP の解の乱択丸め (HiGHS の `R`) とサブ MIP を回せば暫定解は早くなるが、
   終わりの証明は根の下界 (−2880 → −2851) で決まるので、時間は ROOTCAP・CLIQFB の手当て次第。
5. 再スタート後の根で暫定解が前処理後の問題から外れる件 (mzzv11) は、打ち切り値の行による正しい扱い。ただし再スタート後の根の丸め系が
   「再スタート前に解なし」の印で飛ばされ、サブ MIP も参照解しか使えない。ここを直すなら、暫定解を打ち切り値の分だけ緩めた問題で受け取る形が要る (未試作)。

## 5. 確認
