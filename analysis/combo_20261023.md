## ぶつかったところ

- ソースのぶつかりはなかった (9 本とも自動で merge できた)。treeproof は roll3000 の TREE_POOL_BASIS を
  cherry-pick 済み (c7d786c) で、中身が同じなので二重には入っていない。
- ログのファイル名だけがぶつかった: `analysis/heur_ls_20261023/logs/roll3000_e_def_{1,2,3}.log` を roll3000 と treeproof の
  両方が別の中身で足していた。roll3000 側をそのままの名前で残し、treeproof 側は `roll3000_e_def_tp_{1,2,3}.log` に移した
  (`analysis/treeproof_20261023.md` に出てくる `e_def_1〜3` は、この `_tp_` のログのこと)。

## 同じ箇所を触る切り替えを両方付けたときの意味

- CUT_STRONG_WIN5 と CUT_INTOBJ_STALL (どちらも根のカットのループ `separation.rs`): 互いに独立。WIN5 は強いカットの判定の
  窓を変えるだけで、INTOBJ_STALL は停滞の数え方を足すだけ。両方付けると、整数刻みの問題では INTOBJ_STALL で先に止まり、
  WIN5 の判定まで進まないことがある。
- GR_RESTART と LATE_NO_RESOLVE (どちらも `mod.rs` の `solve_problem_inner` の再スタートの後のところ): GR_RESTART は
  `ref_shift` (再スタートの前後の目的値のずれ) を作る条件を広げ、LATE_NO_RESOLVE は時間切れのとき解き直さずに返す。
  返すときも `ref_shift` を下界に足すので、両方付けても下界はずれない。
- WORKER_HALT と HEUR_MU_ROLE_OBS (どちらも木の探索の従のスレッド): 止める合図は役のサブ MIP の LP にも届くので、
  ROLE_OBS で役が長く続いても、終わりに待たされることはない。
- FJ_NOSOL_EXTEND とまぜる形 (FJ_LMIP_MIX): =1 は FJ2 の種のループと、混ぜる形の解のない間の両方を延ばす。=2 は混ぜる形で、
  FJ の解しかない間も延ばす (混ぜる形がないときの動きは =1 と同じ)。
- TREE_POOL_BASIS と SB_BUDGET_HIGHS (treeproof の中で組み合わせて試した): 独立 (基底の選び方と強分岐の予算)。

## 計測で使う環境変数の組

```
CAND_DEF="ENOMOTO_MIP_WORKER_HALT=1 ENOMOTO_MIP_LATE_NO_RESOLVE=1 ENOMOTO_MIP_LP_PROBE_FIRST_FULL=1 ENOMOTO_MIP_GR_RESTART=1 ENOMOTO_MIP_FJ_NOSOL_EXTEND=1 ENOMOTO_MIP_CUT_STRONG_WIN5=1 ENOMOTO_MIP_CUT_INTOBJ_STALL=1"
CAND_MIX="ENOMOTO_MIP_FJ_LMIP_MIX=1 ENOMOTO_MIP_SYM_ORIG_CUT=1 ENOMOTO_MIP_WORKER_HALT=1 ENOMOTO_MIP_LATE_NO_RESOLVE=1 ENOMOTO_MIP_LP_PROBE_FIRST_FULL=1 ENOMOTO_MIP_GR_RESTART=1 ENOMOTO_MIP_FJ_NOSOL_EXTEND=2 ENOMOTO_MIP_CUT_STRONG_WIN5=1 ENOMOTO_MIP_CUT_INTOBJ_STALL=1 ENOMOTO_MIP_HEUR_MU_ROLE_OBS=1"
```

- CAND_DEF: 既定にする候補の全部。
- CAND_MIX: mixoc (FJ_LMIP_MIX=1・SYM_ORIG_CUT=1) に CAND_DEF を足し、FJ_NOSOL_EXTEND を =2 にして HEUR_MU_ROLE_OBS=1 を足したもの。
- 候補に入れないもの (別に測るなら足す): `ENOMOTO_MIP_SB_BUDGET_HIGHS=1` (treeproof)、`ENOMOTO_MIP_TREE_POOL_BASIS=1` (roll3000)。
