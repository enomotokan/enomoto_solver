# traininstance6 の誤答 (28350 を optimal) の調べ (2026-11-18)

## 事象

analysis/slow2_20261117/res_MVBR_s4.jsonl: ビルド fd33f9dd0、`ENOMOTO_MIP_VB_IMPL=r`・4 スレッド・種 1・600 秒で、目的値 28350 (下界も同値) を optimal と返した

## 分かったこと

- vbr は traininstance6 では何もしない: 根で「MIP: VB_IMPL: 0 variable bounds from 16269 probing implications (mode r)」
  (含意はどれも 0-1 列どうしで、連続列への含意がない)。カットの計算は def と同じ。違いは 4 スレッドの時間の揺れだけ。
- 過去の traininstance6 の optimal は全設定で 46 回あり、28350 はこの 1 回だけ (def は 14 回とも 28290)。
  → 既定の経路の稀な非決定的な誤答と見ている (widden の誤答 (analysis/wrong_widden_20261117) と同じく約 1/数十〜数百)。
