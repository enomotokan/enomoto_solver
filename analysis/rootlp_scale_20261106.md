## 3. 悪くなった問題の原因

- map10・map16715-04: 最初の LP は base でも写しでもほぼ同じ時間 (数えの回の base 10.2・11.9 秒、fix 10.8 秒) で、根の LP は 0.2〜0.3 秒、
  根の下界もほぼ同じ (-587.6 / -588.2、-296.27 / -296.27)。違うのは着く頂点 (最初の解の時刻 32.5 → 41.1 秒、34.8 → 40.5 秒)。
  base 同士の差 (-364 / -425、-85 / -56) と fix の差は同じくらいで、map16715-04 は 2 回目に向きが入れ替わる。推測: 尺度の調整の費用ではなく
  頂点の違いによる揺れ。map10 は 2 回とも fix が悪いが、2 回では揺れと分けられない。
- 尺度の調整の費用 (事実、`SIMPLEX_SCALE:` の行): 写しから元の尺度へ戻す反復は 1〜6 反復・0.1 秒前後 (neos-1367061 の閾値 1e3 だけ 336 反復)。
  基底があるときの写しの求解は、元の尺度で最適に近い基底でも写しの尺度では最適でないことがあり、反復が増える (satellites2-60-fs 9902 反復、
  neos-4722843-widden 8136 反復、neos-1367061 (幅 1e3) 2924 反復)。根の LP がもともと軽い問題の根の LP の増え (0.1〜1.6 秒) はこれ。

## 5. 次の手の案 (今回は手を付けていない)

- 基底があるとき (前処理の LP による固定の基底・再スタート) は、まず尺度なしで少しだけ (例: 数百反復または行数の数 %) 回し、終わらなければ
  その基底から写しへ移る。尺度なしで最適に近い基底を写しで解き直す費用 (3 節、neos-1367061 の 9 秒) を避けつつ、momentum1 のように
  尺度なしで詰まる問題は数秒の損で済む。
- 競争 (二段解法と内点法) では写しは二段解法の側にしか効かない (momentum3・triptim1)。内点法の側の尺度は別に見る。
- 根の LP 以外 (サブ MIP・潜り・ノードの LP) も尺度なしのまま。momentum1 の根の後が遅いのはこれ (`momentum1_rootlp_20261106.md` 4 節)。
