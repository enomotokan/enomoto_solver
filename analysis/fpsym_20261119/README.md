# FPSYM: Feasibility Pump に動的な対称性の処理を足す価値の調べ (2026-11-19、段階 1)

依頼 (親、利用者の発案): Feasibility Pump (src/mip/heuristics.rs の `feasibility_pump`・`propagate_rounding`) の伝播は `Domain::propagate` だけで、
木の節点の動的な対称性の処理 (`orbitope_propagate`・`orbital_fixing`) を使っていない。足すと Pump が解を見つけやすくなるか。
段階 1 で回数を数え、対称性のある問題で Pump が多く失敗しているときだけ段階 2 (試作) に進む。

## 道具

- 診断 `ENOMOTO_MIP_FP_STATS=1` (既定の動きは変えない): 外側の求解の終わりに `MIP: FP_STATS` の行 (全スレッドの和)。呼んだ回数・解を見つけた回数・
  回した回 (pass)・伝播の丸めが矛盾で止まった回・手間で止まった回・全部固定できたが解にならなかった回 (連続部分の LP が実行不能か、解が受け入れられない)、
  終わり方 (LP 解が整数・伝播の丸めで解・循環・予算・LP が最適で終わらない・100 回)、矛盾した列の位置 (丸めの順の千分率) の平均。
- `count.py SET 秒`: 既定のまま 4 スレッド・種 1 で回し、`res_count_SET.jsonl` に書く。P = MIPLIB の 58 問 (60 秒)、M = sstx_20261119 の M の対称な 19 問 (120 秒。
  Pump は根と再スタートの後の根で暫定解のないとき・木の中の一部でしか回らないので 600 秒にしない)。生成元の数は hang_20261117 の symscan。

## 読みと判断 (推測を含む)

- 1 回あたりの成功の割合は、対称な問題 (0.14〜0.22) と対称でない問題 (0.18) で同じ程度。対称な問題で Pump が多く失敗しているとは言えない。
  失敗の多い対称な問題 (mas74・mas76) は生成元 2 つの orbital fixing だけでオービトープがなく、失敗は大きい係数の行での終わり近くの矛盾
  (対称でない markshare・pk1 と同じ形) で、対称性とは別の理由に見える。
- 既定 (orbital fixing と動的なオービトープ) では、Pump の解く問題に対称性の行はない。Pump の解が対称性の行に反して捨てられることはなく、
  動的な対称性の固定を足すと、目標の値と逆向きに締める分、伝播の矛盾を増やす側に働きうる (依頼の注意のとおり)。
- 判断の提案: **段階 2 (Pump の丸めに orbitope_propagate を足す試作) には進まない**。対称な問題でも Pump の失敗は対称性と関係が薄く、最初の解は
  他のヒューリスティクスが早く出している。
