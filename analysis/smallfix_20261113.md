## 結論と既定化の提案

1. **C3 (`CLQFB_CAP=st`)**: 誤答 0。狙いの重い試し (puriri 24 秒など) は省けるが、58 問では +2.9% [−1.2%, +8.4%] (区間は 0 をまたぎ、
   省いて浮くのは 1 回 1 秒未満で、比の動きは道筋の揺れ)、12 問でも勝ち負けは揺れの範囲。**既定にはしない** (害は示されていないが、効きも測れない)。
   根の時間を詰める束 (ROOTCAP など根の段の時間の対策) と合わせて入れるなら、`s` (効き目 0.2 未満で省く) だけで足りる。`t`・`i` は今の土台では働く回がない
   (cand1113 の hypothyroid の退化した回だけが対象)。
2. **D1 (`TRNOFIX=1`)**: 誤答 0。base の木の中の再スタートの 3/4 (24 回中 18 回) が固定 0 列で、3 問 (noswot・supportcase26・timtab1) に集まる。
   supportcase26 には確かな効き (60 秒の下界が 2 回の計測とも 3 種そろって上がる) があるが、rococoC10-001000 では 1 回目の再スタートの効きを
   消す害がある。58 問は +1.2% [−2.3%, +5.3%]。**既定にはしない**。
3. **d1a1 (`TRNOFIX=1` + `ENOMOTO_T_MIP_TRNOFIX_ALLOW=1`)**: rococo の害は消えるが supportcase26 の効きも消える。これも既定の候補にしない。
4. 次に見るなら: 固定 0 列の再スタートの後の根で下界が伸びたか (rococo は 9669 → 10993、supportcase26 は?) を記帳し、「前の固定 0 列の再スタートで根の下界が
   伸びなかったら次は止める」形 (1 回目は通し、効かなかったときだけ 2 回目以降を止める)。supportcase26 で 1 回目の再スタートの後の根の下界の伸びを見るのが先。

## 追加: D1 の新形 d1g (`ENOMOTO_MIP_TRNOFIX=g`、利用者承認の次の候補、5632a70b)

中身: 固定の少ない (`TRNOFIX` のしきい未満の) 木の中の再スタートは 1 回目は通す。2 回目からは、前に通した再スタートの後の根の下界の伸び
(今の求解の根の下界 − 通した時点の求解の根の下界) が、通した時点のギャップ (暫定解 − 根の下界) の `ENOMOTO_T_MIP_TRNOFIX_GAIN` (0.05) 倍に
満たなければ止める (一度止めたらその後も止める。値は前処理の定数を足した元の問題の尺度)。ログは `MIP: TRNOFIX g: ... gain ...; pass/stop`。

閾値の根拠 (P・L の base のログの `TRSTAT` の root_lb): rococoC10-001000 の固定 0 列の再スタートの伸びは 1 回目 26%・2 回目 12%・3 回目 1.7%、
supportcase26 は 1.5%・0.9%・1.4%。再スタートの直後の木の始めの下界は、捨てた木の下界より低い (supportcase26 1381 → 1298、rococo 9771 → 8577) ので、
比べるのは根どうし。
