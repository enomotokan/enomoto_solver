# プロービングでの代入 (HiGHS の probing substitutions) の調べ (2026-11-17)

## 1. HiGHS の規則 (1.15.1 の源を読んだ)

- `HighsImplications::runProbing(col)`: 0-1 列 x を 1 と 0 に固定して伝播し (`computeImplications`、大域の定義域・クリークの表を使う)、
  両側の含意 (列ごとの境界の変化) を列の番号の順に突き合わせる。列 y が x = 0 で a に、x = 1 で b に固定され (a ≠ b、差が許容より大きい)、
  y がまだ代入も固定もされていなければ、代入 `y = a + (b − a) x` を記録する (`substitutions`)。そうでなければ両側の弱い方で y の境界を締める。
- y の種類は問わない (0-1・一般の整数・連続)。代入は前処理 (`HPresolve`) が `substitute(substcol, staycol, offset, scale)` で当てる。
- これとは別に、クリークの表が 0-1 列どうしの同値 (`cliquetable.getSubstitution`) を持ち、プロービングの前に確かめる。

当方: 0-1 列どうしの同値 (x_k = x_j か 1 − x_j) だけを集め、等式の行として足して前処理をかけ直す (`probe` の `equiv`)。
0-1 列以外の y の代入はない。

## 2. sat_rens での数え上げ (診断 `ENOMOTO_MIP_DEBUG_PROBE_SUBST`、振る舞いは変えない、`sat_rens_diag.txt`)

プロービングの後の定義域で、各 0-1 列の両側を伝播し、両側で違う値に固定される列を種類別に数えた (4 スレッド、既定と試作 `ENOMOTO_AGG_DUALFREE_INEQ`)。

| 形 | 0-1 | 一般の整数 | 連続 | 当方の同値な組 |
|---|---|---|---|---|
| 既定 (1 回目のプロービングの後) | 119 | 0 | 0 | 154 |
| 既定 (かけ直しの後のプロービング) | 0 | 0 | 0 | 0 |
| 試作 (1 回目) | 119 | 0 | 0 | 154 |

- sat_rens では 0-1 列以外の代入の候補が 0 本。0-1 列どうしの候補は既存の同値の検出が拾っている (154 組 ≥ 119)。
  → **HiGHS の probing の代入を移しても sat_rens は変わらない見込み**。差は代入ではなく固定の数にある
  (HiGHS の最初のプロービングは 1435 列を消す、当方の 1 回目は固定 299)。
- HiGHS の伝播はクリークの表を使う (`computeImplications` は大域の定義域の伝播でクリークも当てる)。当方の試作 `ENOMOTO_MIP_PRB_TABLE=ab` では固定 499。
