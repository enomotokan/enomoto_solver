## 1. 結論

事実:

1. **どの設定も遅れを生んでいない**。mc11 の道は 2 つしかなく、どの設定でも同じ値の道に入る:
   - 道 A: 主の根のカットのループの終わり 11003.7 → 写しの 1 ラウンド目 11054.8 → **51 ラウンド・11666.0** (今までの停滞の判定で終わる) →
     木 800〜2000 ノード、**24〜39 秒**。
   - 道 B: 主のループの終わり 11097.6 → 写しの 1 ラウンド目 11126.6 → **48 ラウンド・11683.3** (窓の判定で終わる) → 木 67〜104 ノード、**14〜15 秒**。
   - 本番 1 の 32 回 (8 設定 × 4 回) で道 B は 6 回: def 1/4 (本番 2 と合わせて 1/8)、n_pdse 2/4、n_fj 1/4、n_lw 1/4、n_pbf・n_det・n_p・n_all 0/4。
     道 A の中の時間は設定によらず同じくらい (def 25.8〜34.6、n_all 23.7〜35.6)。待ちの長さは道 A 2.6〜3.2 秒、道 B 3.6〜4.1 秒 (道 B のほうが長い)。
   - bench18 の生データ (`halve_submip_20261030/bench18_s*.jsonl`) も同じ: canddet 前の def は 3 回中 2 回が道 B (13.9・13.0 秒、ノード 103・87)、
     1 回が道 A (27.3 秒)。canddet・cand は 6 回とも道 A。bench20 の def (canddet) 3 回も道 A、`po` の 1 回だけ道 B (17.6 秒)。
     「canddet 前は 13〜27 秒」は道 B を 2/3 引いた結果で、canddet が道を変えたのではない (このコンテナの n_all は 0/4)。
2. **道の分かれ目は主の根の LP の同時実行 (二段解法 と 内点法 + クロスオーバー) の勝ち負け** (`race.py`、`ENOMOTO_DEBUG_RACE=1`、24 回):
   - 二段解法が先に最適で終わる (1220 反復) と道 B、内点法 + クロスオーバーが先 (二段解法は途中で止められ `Error`、768〜1216 反復で止まった
     ところが表示される) だと道 A。24 回で 1 対 1 に対応し、二段解法の勝ちは def 1/12、n_all 2/12。
   - mc11 の根の LP (大きさ 行 + 列 + 非零 = 11030) は両方 0.04〜0.06 秒でほぼ同着。勝ち負けはその時点の機械の混み具合 (FJ・解探索の
     スレッドなど) で決まる。前処理の LP の探り (`LP probing`) の根の LP も同じ同時実行で、こちらの勝ち負けは道に効かない
     (例: `race` の def 0 は探りで内点法が勝ち、根で二段解法が勝って道 B)。
   - 二段解法の勝ちでも、写しの 1 ラウンド目以降 (11126.6 → 11683.3) は毎回同じ値。勝ち負けの後は決まった道。
3. **停滞の判定 (5 ラウンドで 1e-4) は原因ではない**。道 A の 11666 は今までの停滞の判定 (`own stall`) で 51 ラウンド目に止まり、
   直近 5 ラウンドの伸びは 11664.6 → 11666.0 (相対 1.2e-4 で、窓の判定にはまだ当たっていない)。道 A のまま続けても伸びはほとんどない (robust_stall の `alo` で 57 ラウンド
   回して 11667.1)。道 A と道 B の差 (17) は止め方ではなく、写しの最初のラウンドから違う頂点を通る道の差。
   (もう 1 つのセッションの `MC11FIX2` (止め方) で道 A の下界を 11683 まで上げるのは難しいと見られる。道 B は 48 ラウンドで窓の判定で止まる。)
4. 試作 **`ENOMOTO_MIP_MC11FIX1_RACE=s`** (小さい LP では同時実行をやめて二段解法だけ、下の 2.) で **mc11 は 4/4 で道 B (13.8〜14.3 秒、ノード 70〜91)**、
   `=i` (小さい LP では内点法の頂点を待って採る) は 4/4 で道 A (25.0〜29.8 秒)。どちらも道が 1 つに決まる。

## 2. 試作 `ENOMOTO_MIP_MC11FIX1_RACE` (既定では使わない。既定の経路は変えない)

src/simplex/mip_lp.rs の `TwoStageLp::solve`・`solve_race_ext`。基底のない LP を同時実行で解くところ (`COLD_RACE_THREADS` が 2 以上: MIP の主の

## 4. 次の手 (提案)

- mc11 の bench の時間は道 A・道 B のくじとして読む (根の下界 11666.0 か 11683.3 かで分かる)。canddet・p を戻す理由はない。
