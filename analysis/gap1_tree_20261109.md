# GAP1: 木の効率 (HiGHS より何倍もノードを回しても下界を閉じられない問題) の調べ (2026-11-09、途中)

bench に使う環境変数: `ENOMOTO_MIP_LOG=1 ENOMOTO_MIP_THREADS=4 ENOMOTO_T_MIP_SEED=s ENOMOTO_MIP_TREE4_TRACE=10` (4 スレッド)。
`bench.py` の `CFG`: `cw` = `ENOMOTO_T_MIP_CONFLICT_WEIGHT=0.01`、`ch` = `ENOMOTO_MIP_CHILD_HIGHS=1`、`nocut` = `ENOMOTO_MIP_NO_CUTS=1`、
`nors` = `ENOMOTO_MIP_NO_RESTART=1`、`t1*` = 1 スレッド、ほかは `ENOMOTO_MIP_GAP1=<文字>` (試作、下の 3 節)。
`NC_TREELOG=1` の回は `ENOMOTO_MIP_TREE_LOG=1` (`EBR`・`ENODE` 行)。HiGHS は highspy 1.15.1 (`hrun.py`、4 スレッド・`mip_rel_gap=0`)。
生データは `analysis/gap1_tree_20261109/` (`*.jsonl`、`logs/`)。

## 結論 (先に、途中)

1. **neos-957323 では ENOMOTO の木は下界を全く動かさない**(事実): 既定・試作のどの設定でも、300 秒の終わりの下界は根 (再スタートの後) の
   LP の値そのまま。カットなし (`nocut`) では 8205 ノードを回して根の値 -237.7574079 から 1 刻みも動かない。HiGHS は同じ根の値から
   104 ノードで最適値に達する。ENOMOTO が解ける回は、根の再スタートが 3 回進んで根の LP がほぼ閉じる回だけ (`t`・`rq` の回、158 秒・150 秒、
   ノード 3)。根の動きは LP probing の反復数などの揺らぎで回ごとに変わる。
2. **原因 (事実と推測)**:
   - (事実) 分枝の点数が平ら: 2963 回の分枝のうち 2799 回で、最良から 1e-6 以内の同点の候補が平均 170 本。擬似費用はほぼ 0
     (下の子の LP が動かないので観測が 0) で床の値に張り付き、推論の点数も未観測の列は平均で同じ。同点は候補の順 (列の番号の順) で、
     実際に分枝した列は 0, 560, 246, 249, 954, … とほぼ昇順。子は擬似費用の見積りの小さい側 (小数部 0.0002 の列なら下) に潜り、
     深さ 400〜700 まで LP の値が動かない。
   - (事実、HiGHS の LP で確かめた `dive.py`) 最も分数の列を上に固定して潜ると 2 段で LP が -237.75791 → -237.75672 に上がり、16 段で
     打ち切り値を越える。下に固定する潜り・列の番号の順の潜りは 25 段で 1e-7 も動かない。**下界を動かすのは上の子の打ち切り**。
   - (事実、`upfix.py`) 打ち切り値を最適値にして、根の LP で「上の子 (x_j = 1) の LP が打ち切り値を越える列を x_j = 0 に固定」を
     繰り返すと、3 回り (固定 31 + 6 + 7 本) で根の LP が最適値 -237.7566815 に上がる。HiGHS の木の 168 ノード (深さ 1 の葉が 1 つで
     探索済み 50% になる、など) はこの固定を木の中で得ているのと数が合う (推測。HiGHS の計装はビルドが拒まれて確かめられない)。
   - (事実) ENOMOTO の打ち切り値つきの根のプロービング (`root_obj_probe`) は伝播だけで LP を解かず、分数の 0-1 列が 500 本以上のとき
     だけ動く (neos-957323 は 214〜386 本で skipped)。
   - (事実) ENOMOTO の双対証明の破れ・刈り込みの判定は `1e-6 (1 + |rhs|)` で、目的関数の証明の右辺が 238 程度の neos-957323 では
     2.4e-4 を越えて破れないと証明にならない。ギャップ全体が 1.7e-4 なので目的関数の証明は通らない (HiGHS は絶対値の `feastol`)。
3. 試作 `ENOMOTO_MIP_GAP1` (既定では使わない) の効き目 (neos-957323、300 秒・種 1): 下の表。分枝の点数・子の選び方・同点の扱い・証明の
   許容誤差のどれも、木の下界を動かさない (どれも根の値で止まる)。`r` は開いたノードを 1 万 → 2300 に減らし、`p` は証明で刈るノードを
   27 → 166 (`pr` で 2635) に増やすが、下界は同じ。
