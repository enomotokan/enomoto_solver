# 根のカットのループの止まり方を数える: 離接カット (lift-and-project 型) を停滞時に足す案の 1 段目・2 段目 (2026-11-19)

> **区切り (2026-11-20)**: 離接カット (1・2 段目)・強分枝 (3 段目、9 節の `ENOMOTO_MIP_ROOTSB`)・擬似費用 (4 段目、11 節の
> `ENOMOTO_MIP_PCL`) の線はここで区切る。試作と診断 (`ENOMOTO_MIP_CUTSTOP_LOG`・`ENOMOTO_MIP_SBCAND_LOG`・`ENOMOTO_MIP_PCLOG`) は
> 既定オフのまま残す。効かなかった理由の見立て (推測): 根の分枝の質を上げても木全体の一部でしかなく、予測の外れが大きい問題は
> どの列で分けても子の LP が動かない型 (退化・対称) で選べる良い列がない。外れの小さい問題はもともと予測が 2 倍以内に収まっていて
> 改善の余地が小さい。再開するなら、M の観測のない列の多い問題 (mzzv11・neos-4738912-atrato・unitcal_7 など) で、似た列で
> 擬似費用を埋める `PCL` の `b` と、強分枝の候補の絞り (9 節の原因 (a)) をゆるめる `ROOTSB` の `l` を組み合わせて試すのがよい。

親セッションからの依頼 (DISJ1)。「根のカットのループが停滞で止まったときに離接カットを足す」案の対象がどれだけあるかを、
**試作はせず数えるだけ** で確かめる。データ・台本は `analysis/disj_20261119/`。

bench に使う環境変数: `ENOMOTO_MIP_THREADS=4`・`ENOMOTO_MIP_LOG=1`・`ENOMOTO_T_MIP_SEED=種`・`ENOMOTO_MIP_CUTSTOP_LOG=1`
(今回足した診断)。M は `ENOMOTO_MIP_NODE_LIMIT=1` (根だけ)。それ以外は既定。

## 結論 (先に)

- **停滞で止まる問題は多い** (事実)。P (MIPLIB 58 問、60 秒、種 1・2) では 58 問中 **25 問** (24 問は 2 種とも) の最初の根の
  ループが停滞 (`stall`・`intobj_stall`) で止まり、そのうち **21 問は残りギャップ (根の LP からの初めのギャップのうち閉じて
  いない割合) が 10% を超える**。M (Mittelmann 186 問、根だけ、種 1) では **111 問** が停滞で止まり、**86 問** が
  残りギャップ > 10%。
- **ただし「カットがほとんど何も閉じない」問題がその 3〜4 割を占める** (事実)。残りギャップ > 10% の停滞のうち、閉じたギャップ
  < 1% が P で 6 問 (pk1・markshare_4_0・noswot・bppc4-08・graph20-20-1rand・misc07)、M で 33 問 (markshare2・mad・glass4・
  chromaticindex・gmu・bnatt400 など)。知られている性質からは、ここは split 型のカット (離接カットもその仲間) でも閉じにくい問題が
  多い (推測)。
- **根の時間は求解全体に比べて小さい** (事実)。P で根のカットのループの時間の和 / 求解時間の和は 0.115 (1 回ごとの割合の中央値 0.141)、
  停滞で止まった回だけでは 0.054 (中央値 0.047)。M (根だけの回の時間 / 0.1.9 の求解時間、参考) は 0.055、停滞は 0.031。停滞で
  止まる問題ほど根が軽い。根に時間を足す余地はある。
- **解けない・遅い問題と停滞の重なりは大きい** (事実)。P で 60 秒で解けない 12 問のうち 7 問 (gen-ip002・gen-ip054・mas74・30n20b8・
  ran14x18-disj-8・bppc4-08・neos-1456979) が停滞かつ残りギャップ > 10%。M で 600 秒で解けない 95 問 (0.1.9 の def の結果) のうち
  54 問が停滞、46 問が停滞かつ残りギャップ > 10%。
- reduce-and-split が効いた 6 問の止まり方: flugpl・gen-ip054・30n20b8 は停滞、qiu は**候補切れ** (`no_cands`、まだ 1 ラウンドに
  0.1〜0.5% 伸びているのに分離の候補が尽きる)、qnet1・timtab1 はラウンドの上限 (停滞ではない。qnet1 は再開の後のループで停滞)。
- **次の段 (強分枝の子 LP の双対からの離接カットを停滞時だけ足す試作) の意見 (推測)**: 対象の数は十分あり、根の時間も安いので
  試す価値はある。ただし親の指摘どおり、1 つの離接のカットで上がる下界はその離接の min(子の LP 値) を超えない。なので
  **先に「根の強分枝の候補ごとの min(子の LP 値) の最大が、残りギャップのどれだけか」を数える診断** を足し、上がり幅の上限を
  確かめてから試作に進むのがよいと考える (今回は既存のログで取れないので数えていない。5 節)。

### 2 段目 (8 節、根の強分枝の候補の子の LP 値) の結論 (先に)

- **1 列の離接 (x_j ≤ ⌊v⌋ ∨ x_j ≥ ⌈v⌉) で根の下界が上がる幅の上限 A = (max_j min(子の LP) − z_LP) / 残りギャップ は、
  停滞で止まる問題の大半で小さい** (事実)。根で小数の列を f(1−f) の大きい順に 200 本まで反復の上限なしで解いた値 (full モード) で:
  - P (停滞の 25 問のうちデータのある 22 問、種 1): A < 0.1% が 10 問、0.1〜1% が 6 問、1〜3% が 3 問、3〜10% が 2 問
    (binkar10_1 6.2%・neos-3083819-nubu 3.5%)。10% 以上は khb05250 だけで、これは残りギャップがもともと 0.1% の問題。
  - M (停滞かつ残りギャップ > 10% の 71 問のうちデータのある 67 問): A < 0.1% が 35 問、0.1〜1% が 5 問、1〜3% が 6 問、
    3〜10% が 16 問、10% 以上が 5 問 (comp07-2idx 42%・dano3_3 39%・neos-5195221-niemur 13%・neos-4722843-widden 13%・mzzv11 12%)。
- **A がほぼ 0 の問題は、カットのループがほぼ何も閉じない問題とほぼ重なる** (事実)。markshare・pk1・mad・glass4・gmu・
  chromaticindex・graph20-20-1rand・bppc4-08・noswot・misc07・neos-911970・30n20b8 など。1 列の離接ではどの子の LP も根の LP から
  上がらない (双対退化・対称) ので、強分枝の双対から作る離接カットは、何本重ねても根の下界を上げない (推測ではなく、
  上がり幅の上限が 0 であることからの帰結。ただし 200 本・60 秒で打ち切った問題は評価していない候補が残る)。
- **(b) 選ばれなかった候補で両方の子が根より上がる数**: P では 22 問中 15 問、評価した 1168 本のうち 382 本。M では 67 問中 35 問、
  8538 本のうち 2752 本。ただし上がり幅の中央値は残りギャップの 0.1% 前後で小さい。上がり幅の和 Σ_j (min(子) − z) / 残りギャップ
  が 0.5 を超える (「小さな離接が多数ある」型) のは P で binkar10_1、M で 13 問 (neos-662469 2.8・cmflsp50-24-8-8 2.1・mzzv11 1.8・
  unitcal_7 1.75・dano3_3 1.46・rococoB10-011000 1.39・widden 1.32・air05 1.11・seymour1・neos-1582420・neos-1445765・seymour・niemur)。
- **試作に進む価値 (推測)**: 「停滞した全部の問題に効く」見込みはない。進むなら対象は M の **A ≥ 3% か Σ ≥ 0.5 の 20 問前後**
  (大きな集合分割・スケジューリング・ネットワーク設計の型: air05・rail507・fast0507・seymour・sp97ar/sp98ar・unitcal_7・
  rococoB10・mzzv11・widden・neos-662469・cmflsp50・dano3_3/5・trento1・atlanta-ip など) に限られ、効き目の上限は 1 回の
  重ね合わせで残りギャップの数 %〜十数 % と見込む。P の 58 問ではほぼ効かない (binkar10_1・neos-3083819-nubu の数 % だけ)。
  費用対効果の面から、**試作するなら M の上の型を対象に、まず 1 ラウンド分 (A の大きい順に 10〜50 本) を根で足して下界の
  伸びを測る小さな試作** に留めるのがよいと考える。
- 副産物 (事実): M の 20 問で、既定の強分枝が分枝に選んだ列の上がり幅は A の半分未満 (例 icir97_tension 0 対 5.1%、
  neos-5195221-niemur 0 対 13%)。既定の強分枝は子の LP の反復を最大 500 で打ち切り、評価する候補も絞るので、上がる列を
  見逃している可能性がある (推測。分枝の質の別の調べの種)。

## 1. 診断 `ENOMOTO_MIP_CUTSTOP_LOG=1` (src/mip/separation.rs、既定の動作は変えない)

`root_cut_loop` のループの `break` (29 か所) の直前で理由のラベルを入れ、ループを抜けた後 (と、2 回失敗した LP で途中で返る所・
clique の fallback で 2 回目のループに入る所) で 1 行の JSON を stderr に出す (`CUTSTOP {...}`)。サブ MIP では出さない。
裏のカットの写し (`job`) のループは `"bg":true` で出す (集計では除く)。

出す値: `reason`・`restarts`・`bg`・`second` (clique の 2 回目のループ)・`rounds`・`max_rounds`・`phase2`・`stall`・`intobj_stall`・
`obj0` (ループの始めの LP の値)・`obj1` (終わりの LP の値)・`lp_ok`・`inc` (暫定解)・`nfrac` (LP の小数の整数列の数 = 離接の候補の数)・
`fsum` (Σ min(f, 1-f))・`nint` (固定されていない整数列の数)・`ncuts` (LP のカットの行)・`t_loop` (ループの壁時計)・`t` (求解の始めから)・
`sense`。値は内部の向き (最小化、前処理の定数項込み)。

理由のラベル (既定で起こるものは太字):

| ラベル | 判定 (separation.rs) |
|---|---|
| **`stall`** | SCIP 流の停滞: 目的値の相対変化 ≤ 1e-4 かつ小数の列の数が十分減らないラウンドを数え (まったく動かなければ 2 回分)、10 に達した |
| **`intobj_stall`** | 目的値が整数刻みの問題で、一度上がった後に 3 ラウンド全く動かない (`ENOMOTO_MIP_CUT_INTOBJ_STALL`、既定) |
| `phase2_stall` | 第 2 段階 (HiGHS のスコア) で 10 ラウンド停滞 |
| **`round_limit`** | ラウンドの上限 (既定 25、延長・第 2 段階の判定の後) |
| **`time_cap`**・`phase2_time`・`time_limit`・`stopped` | 根のカットの時間の上限・第 2 段階の時間の上限・求解の時間切れ・写しの停止 |
| **`gap_closed`**・`cutoff` | 根の下界が打ち切り値に届いた |
| **`lp_integral`** | LP 解に小数の整数列がない |
| **`no_cands`**・`no_chosen` | 分離の候補が 0・選ばれたカットが 0 |
| `lp_fail` | カットの LP が 2 回解けなかった (途中で返る) |
| その他 | `early_restart`・`race_lost`・`bg_round_cap`・`phase2_work_cap`・`work_cap`・`cutlen`・`clique_second_cap`・`sep_deadline`・`lp_cap_stop`・`flat_stop`・`cutrnd_s`・`progress_win`・`highs_stall`・`stall_old`・`rootstop_rate`・`zerocap`・`robust_ext_stall` (既定では使わない試作のもの) |

`src/mip/rootstop.rs` の `Rate` (`rootstop_rate`) は試作 `ENOMOTO_MIP_ROOTSTOP` で、既定では使わない。今回の計測でも 0 回。

`cargo test --release` (`RUSTFLAGS="-L /usr/local/lib -l python3.13" LD_LIBRARY_PATH=/usr/local/lib`): 411 passed, 0 failed。

## 2. 定義

- 根のループ = `CUTSTOP` の行のうち `bg` でないもの。最初のループ = 再開の前。停滞 = 最初のループの理由が `stall`・`intobj_stall`・
  `phase2_stall`。
- 閉じたギャップ = (根の下界 - 最初の LP) / (参照値 - 最初の LP)。根の下界は全ループの終わりの LP の値の最大 (再開の後を含む。
  最初のループだけの値は `summ_*.txt` の `cl1`)。参照値は `scripts/miplib2017-v31.solu` の =opt=/=best= (今回の停滞の問題では
  すべて solu にあった)。**残りギャップ = 1 - 閉じたギャップ**。ギャップ 0 (根の LP が参照値) の問題は数えない。
- 根の時間 = 主のループの `t_loop` の和 (根のヒューリスティクス・再開の前処理は含まない)。

1. **対象の数は十分**。P で 21 問、M で 86 問が「停滞で止まり、残りギャップ > 10%」で、その多くが解けない・遅い問題と重なる。

2. **時間の余地もある**。停滞で止まる問題の根のループは求解時間の 3〜5% (中央値) しか使っていない。停滞時に数ラウンド分の

3. **効き目の上限に注意**。親の指摘どおり、離接 x_j ≤ ⌊v⌋ ∨ x_j ≥ ⌈v⌉ から作る 1 本のカット (またはその離接だけから作る
   カットの集まり) で上がる下界は min(子の LP 値) を超えない。複数の離接のカットを重ねれば各々の min を超えうるが、上がり幅の目安は

   GMI も reduce-and-split もほぼ何も閉じない問題では、この量も小さいと考える (知られている split 閉包の弱さから)。

   違う種類のカットが効く余地がある。
4. **勧める次の一歩**: 試作の前に、根の強分枝 (信頼性分枝の初期化) の候補ごとに (小数の値、子の LP 値 2 つ、分枝に選ばれたか)
   を出す診断を足し、上の停滞の問題で
   - max_j min(z_j−, z_j+) − z_LP が残りギャップの何割か (1 本の離接で届く上限)、
   - 選ばれなかった候補で両方の子が根より上がる数 (親の (a))
   を数える。この割合が多くの問題で数 % 未満なら、強分枝の双対からの離接カットは試作しても下界はほとんど動かないと判断できる。

### 8.1 診断 `ENOMOTO_MIP_SBCAND_LOG` (src/mip/solver.rs、既定の動作は変えない)

- `=1`: 根 (深さ 0、サブ MIP でない) の分枝の選択で、既定の強分枝が評価した候補ごとに `SBCAND {...}` (列、LP 値、根の LP の値 z、
