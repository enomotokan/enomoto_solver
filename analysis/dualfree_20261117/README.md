# 双対で陰に自由な不等式行の等式化 (試作 `ENOMOTO_AGG_DUALFREE_INEQ`、2026-11-17)

調べ C (P3) の続き。HiGHS 1.15.1 の集約は、sat_rens の時刻の連続列 930 本を「双対で陰に自由な ≦ 行」(大きい M の行) を
等式とみなして代入で消す (analysis/primal_20261117/README.md 第 19 節)。その規則を当方に移した。既定では使わない。

## 1. 作り (`src/presolve/dualfreeineq.rs`、`src/presolve.rs` の集約の直前)

- 規則: 連続列 j が等式の行に現れず、上下限が行から導ける (非厳密、許容 1e-9) とき、j の被約費用は 0 としてよい。
  j が現れる ≦ 行のうち、係数の符号が 1 本だけ違う行 r (正の行が 1 本で他が負なら c_j ≤ 0、負の行が 1 本で他が正なら c_j ≥ 0) は、
  双対の符号 y_r ≤ 0 が他の行の符号から決まる → 行 r を等式に変えても双対は同じで、最適値は変わらない。
- 当方は行を等式 (A) に上げるだけにし、代入は既存の集約 (v2) に任せる。上げた問題の解は元の問題で実行可能なので後処理は要らない。
- 整数最適化: 整数列を固定した各連続緩和に同じ議論を当てる (陰の境界は整数列の箱で計算するので、固定しても陰に自由のまま)。
  j は連続列に限るが、行には整数列が混ざってよい。
- 同時に上げるときの注意: 行 r の根拠は j の他の行の双対の符号なので、その行を後から上げると根拠が崩れる。
  貪欲に 1 本ずつ選び、根拠に使った行は上げない・上げた行を根拠に使う列は選ばない。
- 既知の限界: 整数を固定した連続緩和が非有界になる場合、等式にした問題が実行不能になりうる (HiGHS と同じ規則)。
- 手当て: 試作のときだけ、代入で項が打ち消し合って空になった不等式行を集約の直後に固定列の折り込みと同じ許容
  (空の行は 1e-7 より厳しくしない) で取り除く。下の seed 378 (次のラウンドの伝播が −2e-9 の右辺を実行不能と判定した)。
- 診断: `ENOMOTO_DEBUG_DUALFREE_INEQ` (上げた行と根拠の列)、`ENOMOTO_DEBUG_PRESOLVE_INFEAS` (前処理が実行不能と判定した箇所)。
