# 疎行列の要素の添字型 (f8cfeb8..2310dcd) の判定: 不採用

- 内容: 標準形の制約行列 (CsrMat/CscMat) を添字 u32 + 値 f64 の別配列 (16 → 12 B/要素) に。u16 (次元 ≤ 65,535) も試作したが
  効果が揺れの範囲 (square41 −0.7%、fome13 +2.4%、ex10 −1.8%、Netlib −0.08%) で、単相化による主ループの肥大 (2〜3 倍) に
  見合わないため入れず u32 に一本化。LU と PRICE 用の行コピーは元から u32 + f64 だった。
- 実装担当の計測: Netlib93 はビット一致、合計 +0.78%、shifted +0.01%。Mittelmann 11 問 −3.3〜+1.6% (揺れ)、shifted −1.0%。
  104 問の shifted geomean (100 ms) **−0.10%**。退行なし。極小問題で主ループの I1 ミス +10〜15% (時間は揺れの範囲)。
  効かない理由: 1 本ずつの実行では疎行列の走査がメモリ帯域律速になっていない。
- 判定: 基準 (−2%) に届かないので、リポジトリ所有者の判断により**不採用**。src を f8cfeb8 に戻した。
  実装は履歴 (2c489f4..2310dcd) に残る。制約行列のメモリ 25% 減 (stormG2_1000 で 104 → 78 MB) は、メモリ不足の問題で再利用の余地あり。
