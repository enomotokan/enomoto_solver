## 1. どこで深さ 2・3 の RENS が呼ばれているか (コードで確かめたこと)

入れ子の深さは `SUBMIP_DEPTH` (`src/mip/heuristics.rs`、外側の求解は 0、深さ 1 のサブ MIP の中は 1)。作るサブ MIP の深さは
`SUBMIP_DEPTH + 1` で、`SMT begin` の `depth` と同じ。根のヒューリスティクス (`src/mip/solver.rs` の `heur!`) はサブ MIP の根でも
同じ並びで回り、`RENS`・`RENS (LP before cuts)` (暫定解がなく、カット前の LP 解が分数のとき)・`RENS (more nodes)` (RENS のサブ MIP が
ノード上限で止まったとき) の 3 か所で `Solver::rens` を呼ぶ。`rens` の中の道:

| 道 | 条件 | 深さ |
|---|---|---|
| 旧来の RENS (`rens_old`、`h` の `submip_rens_old`) | 今の深さが 1・打ち切り値が有限 (外側に暫定解がある)・`h` | 深さ 2 だけ (`RENS`・`RENS (LP before cuts)`・`RENS (more nodes)` の 3 か所とも、深さの判定なし) |
| 暫定解なしの RENS (ダイビング式、固定率 0.6 から半分ずつ 4 回まで) | 暫定解がない (打ち切り値も無限) か FJ の解が悪い・根・その求解で 1 回目 (`noinc_rens_done`)・`nested_rens_ok` (`h` で、今の深さが `ENOMOTO_T_MIP_SUBMIP_RENS_DEPTH` = 2 以下) | 深さ 2・3 (`RENS` の 1 か所。やり直しの 4 本は全部 `RENS` の名で数える) |
| 上のどれでもない入れ子 | | 呼ばない |

- 深さ 3 の RENS は、打ち切り値のない深さ 2 のサブ MIP (= 暫定解なしの RENS が作ったもの) の根の `RENS` から出る、暫定解なしの RENS だけ。
  `RENS (LP before cuts)` は同じ求解の 2 回目なので `noinc_rens_done` で止まり、`RENS (more nodes)` は旧来の RENS のときだけ立つので、深さ 3 には出ない
  (58 問の表でも深さ 3 は `RENS` だけ)。
- 深さ 2 の RENS (LP before cuts) は、打ち切り値が有限の深さ 1 のサブ MIP (RINS など) で、暫定解がないままの根から旧来の RENS で出る。
- `submip_highs` (`src/mip/mod.rs`) の `h` の説明には深さの上限は書かれておらず、上限は `nested_rens_ok` の `ENOMOTO_T_MIP_SUBMIP_RENS_DEPTH`
  (既定 2 = 深さ 3 のサブ MIP まで作る) にある。ただしこの上限は暫定解なしの道だけに効き、旧来の RENS の道は見ない (今は深さ 1 からしか入らないので結果は同じ)。

## 2. 入れた試作 (既定では使わない)

- `ENOMOTO_MIP_RENS_MAX_DEPTH=N`: 作る RENS のサブ MIP の深さが N を超えるなら `Solver::rens` の入口で止める (`rens_depth_ok`)。
  上の全部の道 (3 か所・旧来・暫定解なし) に効く。`2` で深さ 3 の RENS を作らない、`1` で入れ子の RENS を全部止める。
- `ENOMOTO_MIP_RENS_LPBC_MAX_DEPTH=N`: `RENS (LP before cuts)` のサブ MIP の深さが N を超えるなら呼ばない。`1` で深さ 1 のサブ MIP の中の
  `RENS (LP before cuts)` (深さ 2) を止める (外側の根の `RENS (LP before cuts)` は残る)。
- ログ: `ENOMOTO_MIP_SUBMIP_VERBOSE` のときだけ `MIP: SMT rooth tag=<道筋> restarts=<回> secs=<根のヒューリスティクスの秒>` を出す
  (`MIP: after root heuristics` の行はサブ MIP の中の行と混ざり、外側のものか分からないため)。下の「rh」は `tag=M restarts=0` の秒。

形: `def` (既定)・`d2` (`ENOMOTO_MIP_RENS_MAX_DEPTH=2`)・`lp1` (`ENOMOTO_MIP_RENS_LPBC_MAX_DEPTH=1`)・`d2lp1` (両方)。

### 読み方の注意: この 11 問のほとんどで試作は何も変えていない

深さ 3 の RENS が出るのは 11 問のうち mas76 (16 本・0.03 秒の回がある) と qiu (2〜19 本・0.01〜0.04 秒) だけ、深さ 2 の RENS (LP before cuts) が

## 4. 分かったこと

1. **解は失われていない。** 深さ 2 の RENS が最終解を出す問題では、どの形でも同じ道で最終解が出る: physiciansched6-2 (`RINS(d1) > RENS(d2) > 根のヒューリスティクス`、
   d2 で 3/3・d2lp1 で 2/3、残りは Local-MIP が同じ 49324 を先に出した回)、dcmulti (`RINS(d1) > RENS(d2) > tree@20`、全 12 回)、drayage-100-23 (`RENS(d1) > RENS(d2)` の回がどの形にもある)。
   今回の mas76・blp-ar98 の最終解は外側の根 (LP が整数) で、深さ 2 の RENS からではなかった。2 つの試作が止めるのは深さ 3 の RENS と深さ 2 の
   `RENS (LP before cuts)` だけで、深さ 2 の `RENS`・`RENS (more nodes)` (`rens_old`) は変わらない。
2. **深さ 3 の RENS は一度も解を出さなかった。** 既定・lp1 の 78 回で深さ 3 の RENS は計 211 本、解を見つけた本数 0。秒は neos-1456979 の 1 回 3.8 秒
   (16 本、深さ 1 のサブ MIP の時間を食う) 以外はほぼ 0 (mas76・qiu・supportcase26 で 1 回 0.01〜0.09 秒)。止めても時間はほとんど浮かないが、失うものも見えない。
   neos-1456979 では d2 で sub が 24.4 → 21.2 秒になったが、最初の解が出るかどうか (60 秒の終わり近く) の揺れが大きく、目的値の比べはできない。
3. **深さ 2 の RENS (LP before cuts) も一度も受け入れられなかった** (既定・d2 の回で計 69 本、acc 0)。効くのは supportcase26: 1 回 4〜5 本で 14.1〜14.8 秒、
   止めると外側の根のヒューリスティクスが 47.2 → 32.7 秒 (lp1)・26.7 秒 (d2lp1) になり、木の時間が増えて目的値が 3 回とも良くなる (d2lp1 で 1768〜1777、
   既定は 1806〜1849)。neos-1582420 では 1 回 1 秒前後浮き、外側の根のヒューリスティクスは 14.9 → 10.4 秒 (lp1)。
   (supportcase26 の既定の 1 回目では、深さ 2 の LP before cuts は外側の根の `RENS` (並列)・`RENS (more nodes)`・`RINS` (どちらも主のスレッド) の中で 1 本 4.4〜5.0 秒、
   木の中の LNS の中で 0.05〜0.1 秒。主のスレッドのサブ MIP と、並列のサブ MIP の終わりを待つ分が、そのまま外側の根の時間になる。)
4. 損の問題 (n5-3・neos-2978193-inde) の重さは深い RENS から来ていない: n5-3 は深さ 3 の RENS も深さ 2 の LP before cuts も出ず、深さ 2 の `RENS` が
   1 回 11 本・25 秒 (旧来の RENS と `RENS (more nodes)`)。neos-2978193-inde も同じく深さ 2 の `RENS` が 4.5 秒。これを減らすのは別の話
   (別のセッションの RENS のやり直しの試作 `ENOMOTO_MIP_RENS_MORE_NODES_SUB` など)。
5. 得の問題 (h80x6320d・qiu・mc11) は、止める対象が少なく (h80x6320d の LP before cuts 1 本 0.03 秒、qiu の深さ 3 が 0.01 秒)、どの形でも目的値・最終解の
   出どころは同じ。

## 5. 58 問で確かめる形 (提案)

**1 つ: `d2lp1` = `ENOMOTO_MIP_RENS_MAX_DEPTH=2 ENOMOTO_MIP_RENS_LPBC_MAX_DEPTH=1`**

- 両方とも、58 問 1 回と今回の 13 問 3 回で解を 1 つも出していない (深さ 3: 前回 135 本で 1 本、今回 211 本で 0 本。深さ 2 の LP before cuts: 前回 41 本・今回 69 本で外側に届いたもの 0)。
- 時間が浮くのは supportcase26 (根のヒューリスティクス 約 −20 秒、目的値も良くなる)・neos-1456979 (約 −3.8 秒)・neos-1582420 (約 −1 秒) と、前回の表で深さ 3 の RENS・
  深さ 2 の LP before cuts が出ていた問題 (markshare_4_0・mas74・neos5・noswot・pk1・timtab1・roll3000・swath1 など 27 問) に限られる。それ以外の問題は動きが同じなので、
  58 問の SGM の差はほぼこれらの問題と揺れで決まる。
- 2 つ目を回す余裕があれば `lp1` = `ENOMOTO_MIP_RENS_LPBC_MAX_DEPTH=1` だけ (浮く時間の大半は LP before cuts の方なので、深さ 3 を止める分を切り分ける)。
