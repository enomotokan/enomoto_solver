# 停滞の判定を「始めからの伸び」と「窓」で見る (gainstall、2026-11-22)

根のカットのループ (src/mip/separation.rs) の停滞の判定は、今は 1 ラウンドの伸び Δ を stall_scale で割った値 ≤ 1e-4 を停滞として数え、
伸びれば 0 に戻す。これを (1) ループの始めからの伸び G で割る形、(2) 直近 w ラウンドの窓で見る形に替えて比べた。

## 結論 (先に)

- 18 問・1 スレッド・120 秒の通しでは、どの形も解けた数は同じ (15 / 18)。SGM の def 比は w1e-2 0.973・w3e-2 0.988・g3e-2 0.985。
  - 差は問題ごとに両向きで、回ごとのぶれ (同じ設定で 1 回目と 2 回目に 5〜10%) と同じくらい。はっきり良いとは言えない。
- P (58 問 × 種 1〜3、4 スレッド、60 秒) の def と w1e-2 の分担表を作った (`shards_P.json`、6 本、1 本 0.47 時間)。回すかは判断を待つ。

## 1. 試作 `ENOMOTO_MIP_STALL_GAIN=x[s][w]` (既定では使わない)

- `x`: G = (今の LP の値) − (ループの始めの LP の値)。G > 1e-9·|値| なら、そのラウンドの伸び Δ について Δ/G ≤ x を停滞とする
  (今の判定の reldiff を 0/1 に置き換える)。G = 0 (根の下界が動かない問題) は今の判定のまま。
- `s`: サブ MIP の中でも使う (なければ外側だけ)。
- `w`: 窓の形 (外側の根だけ、3 節)。窓 w = `ENOMOTO_T_MIP_BG_DETERM_WIN` (既定 5)。ラウンド k ≥ 2w から:
  - 伸びの停滞: (値 − w ラウンド前の値)/G ≤ x (G = 0 なら w ラウンド分の伸びに今の stall_scale ≤ 1e-4 の規則)。
  - 分数の停滞: 直近 w ラウンドの分数の列の数の平均 ≥ 0.9 × その前の w ラウンドの平均。
  - 両方なら止める (段 2 なら cutstop `phase2_stall_win`)、そうでなければ停滞の数を 0 に戻す。k < 2w は今の判定。
- ログ: `ENOMOTO_MIP_CUTSTOP_LOG=1` で `MIP: STALLGAIN round …`・`MIP: STALLWIN …`。
