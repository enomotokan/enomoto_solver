# 強分枝まわりの試作を問題の特徴でシグモイドに効かせる (試作 `ENOMOTO_MIP_SB_ADAPT`、2026-11-24)

利用者の方針「問題によって効き方が違う試作は、却下せずシグモイドで効き方を変える」に沿って、強分枝まわりの 3 つの試作を
1 つの試作にまとめ、強さを解いている途中の特徴から連続に決める。既定では使わない (`ENOMOTO_MIP_SB_ADAPT=1` で有効)。

対象の試作 (いずれも 30n20b8 で害が出ていた):

| 試作 | 効いた問題 | 出どころ |
|---|---|---|
| 退化のノードでも強分枝をする (`SB_NO_DEGEN_SKIP`) + HiGHS 並みの予算 (`SB_BUDGET_HIGHS`) | satellites2 | highsonly_20261123 |
| 強分枝の子の伝播と両方の子の境界 (`SB_PROBEBD`) | swath1・dano3_5 | treegap_20261123 7 節 |
| 衝突の重みの床 0.01 | mcsched・swath1 | treegap_20261123 5 節 |

前例は src/mip/separation.rs の `CLIQUE_CUTS=sigmoid` (f = σ(a (s − b)) で割合を連続に決める)。

## 1. 形 (src/mip/solver.rs `sbad_f`・`select_branch_inner`、src/mip/pseudocost.rs `cw_floor`)

2 つの強さ f_A・f_B を、根より後でノードごとに計算し直す。

- **f_A = σ(5.05 (cpn − 1.7))**。cpn = 1 ノードあたりの衝突の数 (`multi_stats[1] / (nodes + 1)`)。
  - 退化のノードで強分枝を省く判定を、確率 f_A で外す。
  - 強分枝の予算 (反復の上限 `maxsb` と 1 回の上限 `quot`) を、いまの値から HiGHS 並みの値へ割合 f_A だけ寄せる。
- **f_B = σ(11.9 (0.185 − deg))**。deg = 強分枝を考えたノードのうち双対退化だった割合 (`(sb_degen_stats[1] + 1) / (sb_degen_stats[0] + 2)`)。
  - 強分枝の子の伝播と両方の子の境界 (`SB_PROBEBD` と同じもの) を、確率 f_B で使う。
  - 衝突の重みの床を 0.01 × f_B にする (`ENOMOTO_T_MIP_SBAD_CW`)。CW_RAMP の重みとは大きいほうを取る。
- 確率の判定はノード番号から作る擬似乱数 (`sbad_u`) で行うので、同じ種なら同じ木になる。
- 割合はラプラスの補正つきで数えるので、観測がない始めは f_A が小さく、f_B は deg = 0.5 から始まり小さい。どちらも控えめな側から始まる。
- 部分 MIP では使わない。並列の強分枝 (`ENOMOTO_MIP_PAR_SB`) とは一緒に使わない。
- 診断 `ENOMOTO_MIP_SBADAPT_DIAG=1` で 200 ノードごとに `SBADAPT_FEAT` の行 (deg・infl・cpn・sbpn・sbinf・fa・fb) を出す。

## 2. 特徴と係数の決め方

6 問を既定 (300 秒、`res.jsonl` の tl 300) で回し、200 ノード時点の特徴を見た。

| 問題 | deg (退化の割合) | infl (閉じた葉のうち実行不能の割合) | cpn (1 ノードあたりの衝突) | 効いた試作 |
|---|---|---|---|---|
| satellites2-60-fs | 0.99 | 0.90 | 2.15 | 退化でも強分枝 + 予算 |
| 30n20b8 | 0.37 (2000 ノードで 0.92) | 1.0 | 1.28 (2000 ノードで 0.20) | (3 つとも害) |
| dano3_5 | 0 | 0.10 | 0.76 | 子の伝播 |
| mcsched | 0 | 0.01 | 1.16 → 0.8 | 衝突の重み |
| swath1 | 0 | 0.92 | 1.41 → 0.26 | 子の伝播・衝突の重み |

satellites2-40 は 300 秒で 21 ノードしか進まず、窓がなかった。

- **f_A を cpn で決めた理由**: satellites2 (2.15) と 30n20b8 (1.28) を分けられるのは cpn だけ。deg は両方とも始めは低くなく、
  infl は両方とも 0.9 以上。中点 b = (1.28 + 2.15) / 2 ≈ 1.7、傾き a は両者が 0.1・0.9 になる値 ln 9 / 0.435 = 5.05。
- **f_B を deg で決めた理由**: 子の伝播と衝突の重みが効いた 3 問は deg = 0、30n20b8 は 0.37 以上。中点 b = 0.37 / 2 = 0.185、
  傾き a = ln 9 / 0.185 = 11.9。
- **使わなかった特徴**: infl (SCIP の dynamicweights と同じ物差し) は 30n20b8 (1.0) と satellites2・swath1 (0.9 以上) を分けない。
  強分枝の子が伝播で切れた割合 (sbinf) は既定では強分枝の子の伝播をしないので測れない。擬似費用の信頼度・根のギャップは 6 問で分かれなかった。
- **注意 (合わせすぎのおそれ)**: 害の出た問題は 30n20b8 の 1 問だけで、中点はその 1 点で決まっている。P・M の計測で確かめる必要がある。

特徴の推移 (`logs/ad600_*`・`logs/adcut_*` の `SBADAPT_FEAT`):

- satellites2: f_A は 200 ノードで 0.4〜0.94、cpn が下がる 400 ノード以降は 0.01〜0.1。f_B は 0.0001。
- 30n20b8: 200 ノードで f_A 0.24・f_B 0.04、400〜600 ノードで f_B が 0.2〜0.37 に上がる回があり、2000 ノード以降は f_A・f_B とも 0.001 未満。
- dano3_5・mcsched・swath1: f_B ≈ 0.89〜0.90 (deg = 0)。f_A は mcsched・dano3_5 で 0.02〜0.09、swath1 で始めだけ 1。

読み:

- mcsched は試作で時間切れから 171〜190 秒になり、treegap の衝突の重みの床 0.01 (303 秒) より速い。子の伝播と床の両方が f_B ≈ 0.9 で効いている。
- swath1・dano3_5 も子の伝播が効いた形 (treegap 7 節と同じ向き)。dano3_5 の打ち切り値つきだけ 1 割遅い。
- 30n20b8 は 2000 ノード以降で試作がほぼ働かないので、害 (treegap の時間切れ) は出なかった。打ち切り値なしで速く、つきで遅いという逆向きの差は、
  始めの数百ノードの判定で木が変わった揺らぎと見ている。
- satellites2 は f_A が始めの数百ノードでしか大きくならず、ACFIX=d つきの既定と比べた差ははっきりしない (打ち切り値つきの 60-fs は 18% 遅い)。

## 5. 30n20b8 での子の伝播 (`SB_PROBEBD`) の害の仕組み

親の依頼で、30n20b8 (打ち切り値 302.000302 つき、1 スレッド、600 秒) で害の出どころを切り分けた。診断の変数 (いずれも既定では働かない、src/mip/solver.rs `select_branch_inner`):

- `ENOMOTO_MIP_SB_PROP_NO_LP=1` (既存): 伝播で締まった境界を子の LP に渡さない。
- `ENOMOTO_MIP_SB_PROP_BT_EARLY=1`: 伝播は子を切る判定と境界の記録だけに使い、子の LP の前に定義域を戻す (子の LP と子の証明は伝播なしの定義域で作る)。
- `ENOMOTO_MIP_SB_PROP_NOCUT=1`: 伝播で矛盾しても子を切らず、LP で決める (切るかどうかと子の証明は既定と同じ)。
- `ENOMOTO_MIP_SB_PROP_NOCONF=1`: 伝播の矛盾から衝突を作らない。
- `ENOMOTO_MIP_SB_PROP_NOPSC=1` (試作、利用者の案): 伝播で切った子を擬似費用の打ち切りの回数に数えない。
  NOPSC を足す前の回の NOCONF は両方を外していた (表では「NOCONF+NOPSC」と書く)。
- `ENOMOTO_MIP_SBTRACE=N`: 始めの N ノードの分枝の選びを 1 行ずつ出す (振る舞いは変えない)。

### 5.1 今の扱い (擬似費用・点数)

- 伝播で切った子では、擬似費用の値と観測の回数 (信頼度の数え) は更新しない。更新するのは打ち切りの回数 (`pc.add_cutoff`) だけで、
  LP で実行不能だった子と同じ扱い。打ち切りの回数は点数を (1 + 0.01 × 回数) 倍する項と、hybrid の打ち切り率の項 (重み 1e-4) にだけ効く。
- 片側が切れた候補は点数を無限大にせず、その列をノードで固定し (`bound_changes`)、固定がたまれば強分枝をやり直す (`Resolve`)。
  SCIP (実行不能な子では擬似費用を更新せず、向きを閉じてノードで固定し、LP を解き直して強分枝をやり直す) とほぼ同じ。
- 既定と違うのは、既定では LP が「実行可能だが打ち切り値を超えた」子で擬似費用の観測 (大きな伸び) を足すこと。伝播で切るとこの観測はなくなる。

### 5.3 見立ての確かめ

- **CW_RAMP の重みの経路ではない。** 害の出た形は始めの 200 ノードの「作った衝突 / ノード」が 1.29〜1.37 (既定 1.98、害のない形 2.12) で、
  600 ノードで重みが 0.005 前後まで下がる (`cw_windows.py`)。しかし、中点を下げて重みを既定並みに保っても害は残り、既定で重みを早く下げても解ける。
  伝播で切った子は窓あたり 0〜3 個で、これを衝突の数えに足しても r は 0.06 → 0.08 程度にしかならない (親の案 `CW_RAMP_PROPCNT` は作らなかった)。
- **衝突の汚れ (長く弱い衝突がたまる) は数字に出ない。** 衝突の平均の長さは 95〜118 (既定 112)、プールの大きさ・伝播の手間も害の出た形で目立って増えない (`harm_stats.py`)。
- **擬似費用の打ち切りの回数 (NOPSC) は効かない。**
- **分かれ道は 2 番目のノード (根の最初の子、深さ 1)。** `SBTRACE` の始めの行 (ノード 深さ ノードの値 候補 強分枝LP 伝播で切った子の累計 結果):

  | 形 | ノード 2 | ノード 3 |
  |---|---|---|
  | 既定 | 144.3898、強分枝 38、列 11938 で分枝 | 144.4631、列 11937 |
  | `SB_PROBEBD=1` | 強分枝 39 で子が 1 つ伝播で切れ、列を固定して解き直し (resolve) → 144.4689、列 11938 | 144.5562、一般整数の列 14743 (値 105.45) |
  | + NOCONF+NOPSC | 同上 (固定して解き直し) | 144.5562、列 14743 |
  | + NOCUT | 144.3898、列 11938 (既定と同じ) | **144.5562**、列 6233 |
  | + NOCUT + BT_EARLY + NOCONF+NOPSC | 既定と同じ | 既定と同じ (144.4631、列 11937、以降も同じ) |

  ノード 2 で、ある候補の片方の子が伝播だけで実行不能と分かる (既定では同じ子の LP は実行可能のまま)。これは正しい推論で、
  (i) 子を切ればその列がノード 2 で固定され、(ii) 切らなくても矛盾から作った衝突がプールに入り、ノード 3 の伝播で同じ固定が起きる
  (NOCUT のノード 3 の値 144.5562 が `SB_PROBEBD=1` と同じ)。**「切ること」と「衝突を作ること」は同じ推論をノードに届ける 2 つの道**なので、
  片方だけ外しても害が残り、両方外すと既定と同じ道になる。
- したがって 30n20b8 の害は誤った推論や評価のゆがみではなく、**根のすぐ下で正しい (既定より強い) 推論が入ると、木の道筋が変わり、その後の道が悪い**ことから来ている。
  ノード 3 以降、`SB_PROBEBD=1` は一般整数の列 (14743・8118) を大きな値で分枝し、ノードの値が 145 → 170 と上がるが、全体では閉じない。
  なぜその道が悪いのか (一般整数の分枝の選び方) は未確かめ。

### 5.4 SB_ADAPT の f_B への含意

- 害は「子の伝播の評価が変わる」部分 (親の情報、HsTC の treegap 9 節) の中でも、根の近くで強い推論が入って道が変わることから来ていて、
  双対退化の割合 (deg) とは仕組みの上でつながらない。deg で絞るのは 30n20b8 1 問に合わせた形で、P の 10teams・noswot (deg 0.87〜0.89 で 4 スレッドの得) を消す。
- 害の消える形 (NOCUT + BT_EARLY + NOCONF+NOPSC) は swath1 の得も消す (下表)。得と害は同じ部分 (伝播で子を切る推論) から来ていて、仕組みで分けることはできなかった。

| 問題 (打ち切り値つき) | 既定 | `SB_PROBEBD=1` | 害の消える形 | NOCUT + NOCONF+NOPSC (BT_EARLY なし) |
|---|---|---|---|---|
| swath1 | 9041 / 61 秒 | **3459 / 38 秒** | 7621 / 56 秒 | 5261 / 48 秒 |
| dano3_5 | 254 / 381 秒 (別ビルド) | 289 / 508 秒 | 254 / 486 秒 | 289 / 478 秒 |

## 6. 結論 (親の判断、2026-11-24)

- **SB_ADAPT のシグモイドの絞りは使わない。** 双対退化の割合 (deg) と 1 ノードあたりの衝突 (cpn) は、30n20b8 の害の仕組み (5.3 節) とつながらず、
  シグモイドで絞る根拠がない。deg・cpn で効いた問題と害の出た問題が分かれて見えたのは、害の出た問題が 30n20b8 の 1 問だったためで、
  P では f_B が 10teams・noswot (deg 0.87〜0.89) の得を消し、f_A は木の問題の cpn がどれも 1 未満でほぼ働かない (親の protoscreen README 9.5 節)。
  コード (`ENOMOTO_MIP_SB_ADAPT`) は既定オフのまま残す。
- **30n20b8 の分かれ道 (5.3 節):** 2 番目のノード (根の最初の子) で、強分枝の候補の片方の子が伝播だけで実行不能と分かる (既定の LP では見えない、正しい推論)。
  子を切るか、矛盾から衝突を作れば、その列がノード 2〜3 で固定され、木の道筋が変わる。変わった後の道 (一般整数の列 14743・8118 を大きな値で分枝) が閉じない。
- **swath1 の得と 30n20b8 の害は同じ部分から来る。** 両方とも「伝播で子を切る推論 (と同じ推論を届ける衝突)」から来ていて、それを外すと 30n20b8 の害は消えるが
  swath1 の得も 38 秒 → 56 秒 (既定 61 秒) に減る (5.4 節)。
- 組み合わせの計測では、子の伝播 (`SB_PROBEBD=1`、protoscreen で 1・4 スレッドとも通過した sbpb の形) を絞らずにそのまま使い、
  30n20b8 の害は「正しい強い推論が入ったときの道の運」として受け入れ、P・M の総合で判断する (親)。
- 衝突の重みの床 0.01 は sbpb と別の部品として扱う。この調べでは床だけを P で回しておらず、P での単独の得失は分かっていない
  (分かっているのは treegap 5 節の 4 問: mcsched 時間切れ → 303 秒、swath1 65 → 46 秒、30n20b8 は時間切れになる、dano3_5 は変わらない)。
