## 結論 (先に)

- **reduce-and-split (b) は根の下界を上げる。向きは Andersen・Cornuéjols・Li (2005) の報告 (MIPLIB 3 で reduce-and-split の
  カットが GMI より多くのギャップを閉じる) と合う** (事実)。58 問のうちギャップが 0 でない 54 問の、最初の根のループ (再開の前)
  の閉じたギャップの平均は 既定 0.475 → b **0.494** (種 1)、0.472 → **0.491** (種 2)。HiGHS (highspy 1.15.1) は 0.568。
  2 回とも b が良い問題 15・2 回とも悪い問題 5 (差 1e-3 で)。60 秒の求解でも根の下界のずれ (log10) が −0.115 (p=0.026)。
- **効く問題**: flugpl (閉じたギャップ 0.15 → 0.68〜0.88)・qnet1 (0.70 → 0.87)・timtab1 (0.68〜0.74 → 0.79〜0.80)・
  gen-ip054 (0.04 → 0.09)・qiu (0.02 → 0.07)・30n20b8 (0.09 → 0.12〜0.13)。求解の時間では timtab1 (300 秒: 97・171 秒 →
  68・87 秒)、30n20b8 (300 秒: 2 回とも時間切れ・下界 140 → 1 回 181 秒で解け、もう 1 回は下界 149)、gen-ip054 (300 秒の下界
  6807.9 → 6809.6〜6811.4)。
- **害**: 58 問・60 秒・2 回の SGM は 16.59 → 16.64 (+0.4%、区間 [−4.4%, +5.3%]) で全体では区別できないが、揺れの大きい 12 問を
  除くと +5.2% (p=0.03) 遅い。2 回とも揃って遅いのは qnet1 (3.3 → 8.8 秒: 下界は上がるが根の縮約とカットの時間で負ける)。
  根の下界が下がる問題もある (binkar10_1 0.48 → 0.40、blp-ar98 0.60 → 0.49〜0.52、fiber 0.96 → 0.93)。
- **k-cuts (a) は効かない**: 根の下界・時間とも既定と区別できない。既存の単体表の行の CMIR がもともと k = 1, 2, 4, 8 の
  k-cuts になっている (δ の候補が基底の列の係数 1 の 1, 1/2, 1/4, 1/8) ため、足されるのは k = 3, 5, 6, 7, 9, 10 だけ (事実)。
- 誤答の検査は通った (乱数の問題 600 問で不一致 0、fuzz_tiny の 13 件は既定でも同じ)。既定は変えていない。

## 1. ENOMOTO の「GMI」の作り方 (事実)

- 根の分離 (`separation.rs` の tableau の部分) は、基底にある小数の整数列 (f(1-f) の順、行の数の上限あり) について、
  基底逆行列の行 w で LP の行を論理変数つきの等式 `Σ_i w_i (a_i x - s_i) = 0` として集約し、`generate_cuts` (CMIR、HiGHS の
  `HighsCutGeneration` の簡略版) に両方の向きで渡し、向きごとに質の最良の 1 本を残す (`keep_best`)。根では 4 スレッドで並列に作る。
- 数値の検査: w の非零の最大/最小 > 1e6 の行は使わない、1e-11 以下の集約の係数は捨てる、カットは `finish_cut` (小さい係数の吸収、
  係数の締め付け) を通す。CMIR の側で f0 が [0.005, 0.995] の外、|β/δ| > 1e6 なら作らない。
- CMIR の置き換えで LP 値が境界の内側にある整数の項は基底の列だけ (非基底は境界にある) なので、δ の候補は 1・1/2・1/4・1/8
  で、効き目の最良を採る。これは「行を k 倍してから GMI を作る」(k = 1, 2, 4, 8) と同じ。連続列は変数上下限の置き換えも使う
  (純粋な GMI より少し強い)。

## 2. 試作 (`src/mip/redsplit.rs`、`cuts.rs` の `cmir_with_deltas`、`separation.rs` の tableau の部分に小さな差分)

- `a` (k-cuts、Cornuéjols・Li・Vandenbussche 2003): 同じ集約行から δ = 1/k (k = 1..10) の CMIR を作り、既存の候補と一緒に
  `keep_best` にかける (向きごとに 1 本残す)。根だけ (ノード・サブ MIP では使わない)。
- `b` (reduce-and-split、Andersen・Cornuéjols・Li 2005): 根の分離で使った単体表の集約行 (最大 100 本) の**連続の列 (論理変数を
  含む、`is_int` が偽の列) の係数ベクトル** c_i を、他の行の整数係数の組み合わせで短くする。
  1. Andersen らと同じく、行 i ごとに min ||c_i + Σ_{k≠i} λ_k c_k|| の実数解を Gram 行列の逆行列から一度に求め
     (λ_k = H_ki / H_ii、H = (G + 1e-9 max G_ii I)^{-1}、Cholesky)、丸めて短くなれば採る。
  2. 続けて対ごとの縮約 (c_i -= round(c_i·c_k / ||c_k||^2) c_k、行 i 自身の係数 1 を保つ) を 3 回まで。
  3. 組み合わせの係数は i64 で持ち、`checked_mul`・`checked_sub` で溢れたら、または |λ| > 1000 なら諦める。
  4. 組み合わせた行の数値の検査: 既存と同じ w (論理変数の係数) の最大/最小 ≤ 1e6、1e-11 以下を捨てる。加えて打ち消し
     (Σ|λ_k| max|行 k| / max|組み合わせた行|) ≤ 1e6。実際の連続の部分のノルムが元の (1 - 1e-3) 倍より小さい行だけ使う。
  5. 短くなった行から δ = 1, 1/2, 1/4, 1/8 (`ab` なら 1/k、k = 1..10) の CMIR を両方の向きで作り、`finish_cut` を通して
     候補に足す (カットの選択は既存のまま)。根だけ。
- 正しさ: 単体表の集約行はどれも LP の等式の線形結合なので、どんな実数の組み合わせも妥当な等式で、CMIR はそれを一般の混合整数の
  1 行として扱う。組み合わせの係数が整数であることはカットの強さ (基底の整数列の係数が整数になり δ = 1 が効く) にだけ効く。

## 7. 次の一手 (推測を含む)

- 害の多くは根の時間 (縮約は 4 スレッドの分離の呼び出しごとに走り、1 ラウンドに何回も走る: blp-ar98 で 18 ラウンドに 61 回)。
  縮約を 1 ラウンド 1 回にし、行の組み合わせを次のラウンドに持ち越す、または縮約の候補を「連続の部分のノルムが大きい行」に
  絞る (Andersen らは連続の部分の長い行ほど GMI が弱いと述べている) と、qnet1 のような小さい問題の負けが減ると見込む。
- 縮約で作ったカットは既存のカットの選択にそのまま渡している。縮約の行から作ったカットの選ばれた数は測っていない
  (選択の後の内訳を取ると、どの問題で効いているのかが分かる)。
- 根の下界が下がる問題 (binkar10_1・blp-ar98・fiber) は、縮約のカットが選択の枠を取って元の GMI を押し出している可能性
  (未確認)。元の行の候補と縮約の行の候補を同じ `keep_best` で比べて 1 本だけ残す形も試す価値がある。
- 既定に入れるなら、効く問題 (連続の列が多く、根の下界の伸びが大きい) に絞る条件 (例: 縮約で連続の部分のノルムが大きく減った
  行の割合) を作ってから、Mittelmann の問題と 58 問で害を見る。k-cuts (a) はこれ以上追わない。

### 結論 (先に)

- **`ENOMOTO_T_MIP_REDSPLIT_TFRAC=0.05` (縮約とそのカットの生成の時間の累計を、求解の経過時間の 5% までにする) で、58 問の害が
  消えた** (事実): 58 問・60 秒・種 1・2 の SGM 15.15 → 15.02 (−0.8%、区間 [−6.4%, +4.9%])、揺れの大きい 12 問を除いて +0.3%
  (区間 [−4.0%, +5.0%]、11-07 の `b` は +5.2%、p=0.03)。解けた回 86 → 87。根の下界のずれ (log10) は −0.138 (p=0.001) で、
  11-07 の `b` (−0.115) と同じだけ良い。
- 効き目が残る問題: qnet1 (根の閉じたギャップ 0.70 → 0.87、求解 2.8 → 2.3 秒。11-07 の `b` は 8.8 秒)・flugpl (0.15 → 0.68)・
  timtab1 (0.69 → 0.79、60 秒で 1 回解ける)・gen-ip054 (0.04 → 0.08)。消える問題: 30n20b8 (縮約が根の後半のラウンドで効いて
  いたが、時間の上限で後半は止まる)。fiber は根の下界が少し下がる (0.958 → 0.933)。
- 既定化の判断: **まだ既定にしない** (推測を含む)。58 問で害はないが速くもなく (−0.8% は揺れの範囲)、効く問題は少ない
  (根の下界が上がっても時間が縮む問題は qnet1・timtab1 くらい)。Mittelmann の問題で害を見てからにしたい。600 秒の結果は下。

### 何が時間を使っていたか (事実)

- qnet1: 縮約そのものは 1 ラウンド 0.01〜0.05 秒と軽い。根の前のカットの選択の比べ (`cut selection probe`、6 ラウンドを 2 通り)
  でも縮約が走り、根のループの始まりが 0.20 → 0.46 秒に遅れる。縮約の行から作ったカットは非零が平均 500〜700 (列 1541) と密で、
  採られるのは根のループの後半のラウンドが多く、後半のカットの行の非零の平均が 30 → 100〜240 になって LP が重くなる。
  ただし元の単体表の行の GMI もこの問題では同じくらい密で、密さの上限 (`DENS`、元の行のカットの非零の 1・2 倍) では根の時間は
  減らなかった (1.26 → 1.36・1.43 秒)。
- 時間の割合の上限 `TFRAC=0.05` では、縮約は根の前の比べと最初の数ラウンドだけで走り (qnet1 で 112 回 → 8 回)、縮約の行の
  カットが採られたのは 91 本 → 9 本だが、根の閉じたギャップは 0.872 → 0.866 とほぼ同じ。**効くのは最初の数ラウンドの少数の
  カット**で、後半のラウンドの縮約は時間を使うだけ (推測を含む)。
- ラウンドの上限 `ROUNDS=5` は根の前の比べの 6 ラウンドにも効くので弱く (flugpl 0.68 → 0.30)、時間で切る方が良かった。

### 根の下界が下がる問題の理由 (binkar10_1・blp-ar98・fiber)

- binkar10_1 (0.478 → 0.402): **縮約の行のカットは 1 本も採られていない** (`REDSPLIT chosen` がすべて 0)。それでも候補が増えると
  1 ラウンドに採る本数が増え (ラウンド 1 で 1 → 10 本)、根のループの追加の本数の上限 (42 本) に 1 ラウンド早く届いて、ループが
  5 ラウンドで終わる (既定は 6 ラウンド)。候補の数で選択の枠が変わる既存の仕組みとの組み合わせ (事実、ログから)。元の行の
  カットより効き目の大きいものだけ足す `c` でも同じく下がる (候補は減っても枠は変わる)。`TFRAC=0.05` では縮約が根のループの
  前に止まり、既定と同じになる。
- blp-ar98 (0.595 → 0.52〜0.57): 縮約が 1 回 0.5 秒の上限まで走り、根のループの時間 (12 → 21 秒) が延びて、根のループの時間の
  上限に早く届く (推測、ラウンド数 18 → 18 で、1 ラウンドが重い)。`TFRAC=0.05` で既定と同じ。
- fiber (0.958 → 0.933): `TFRAC=0.05` でも下がる。縮約は最初のラウンドで走っていて、早いラウンドの縮約の行のカットが後の
  ラウンドの流れを変える (理由は確かめていない)。

### 既定化の判断と次の一手 (推測を含む)

- 既定にはしない。`bt` は 58 問で害がなく根の下界を確かに上げるが、60 秒の時間は区別できず (−0.8%)、600 秒の効く問題でも
  そろって速くならない。既定に入れる価値は「根の下界の伸びが探索に効く問題」が見つかってから。
- 効くのは最初の数ラウンドの少数の縮約の行のカット。縮約を最初のカットのループの前半 (時間で切る形) に限ったうえで、
  binkar10_1 のような「候補が増えて選択の枠が変わる」副作用をなくすため、縮約の行のカットは選択の枠の数え (候補の数) に入れない
  形を試すとよい (今は候補の数でラウンドあたりの本数が増え、追加の上限に早く届く)。
- Mittelmann の問題 (連続列の多い問題) で `bt` を見る。Andersen らの効いた例は連続列の多い問題なので、58 問より効く問題が
  多い可能性がある。
