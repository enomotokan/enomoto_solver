## 1. 計測の仕方

- 機械: 4 CPU、ソルバーは同時に 1 つ。ビルドはこのブランチ (e75f2a8c + この記録の試作。試作は既定では動かない) を `maturin build --release`。
- 1 回: `gap2_rootcost_20261109/run1.py ours|highs 問題 名札 種 秒 [環境変数=値 ...]` (ログは `logs/<問題>_<ours|highs>_<名札>_s<種>.log`、結果は `res.jsonl`)。
  並びは `queue.txt` (既定と HiGHS)・`queue2.txt` (試作 1 つずつ)・`queue3.txt` (組)、`queue.sh` で 1 つずつ回した。
- 段ごとの時間: `stages.py` (ログを読む)・`table.py` (表)。ENOMOTO の MIP の時計は前処理の後から数え、再スタートのたびに 0 に戻るので、区間 (根 1 回分) ごとに積む。
  「前段」= `solve returned` の全体の秒 − 区間の合計 (前処理・早めの FJ・LP プロービング・プロービング・同値の巡・クリーク行の拡張・対称性・HNF など)。
  「カット」は根の LP の後〜`cut loop done` (選び方の比べ・clique の fallback の試しを含む)。「発見法」は `cut loop done`〜`after root heuristics`
  (並列のサブ MIP の待ちを含む)。「裏のカットの待ち」は `background cuts: determ: waited`。「根のその他」は根の強分枝など、木に入るまで。
  HiGHS は `Timing` の Presolve と、木の表で処理済みのノードが 0 でない最初の行の時刻 (根の終わり)、`subMIP time`。
- 計測の不備 (事実): `cargo check` が 3 回の計測に重なった (neos-960392 の既定・種 1 (97.7 秒)、cod105 の既定・種 1、cod105 の HiGHS・種 1 (204.9 秒))。
  neos-960392 と cod105 の既定は回し直した (`defr`)。cod105 の既定は回し直しても 192.6・191.6 秒で同じ。HiGHS の cod105 の種 1 は回し直していない。

## 3. 試作 (どれも既定では使わない)

| 環境変数 | 場所 | 中身 |
|---|---|---|
| `ENOMOTO_MIP_GAP2_FLAT=k` | `src/mip/separation.rs` `root_cut_loop` | 目的値が整数刻みでない問題でも、既存の `CUT_INTOBJ_STALL` と同じ「一度上がった後に k ラウンドまったく動かない」で止める |
| `ENOMOTO_MIP_GAP2_ZEROCAP=m` | 同 | 外側の根で、ループの始めから目的値がまったく動かないまま、経過 (壁時計) が max(m × 根の LP の秒, `ENOMOTO_T_MIP_GAP2_ZEROCAP_MIN` = 1 秒) を超えたら止める |
| `ENOMOTO_MIP_GAP2_PROBE1=1` | 同 | clique の fallback (と zerohalf の試し) の 2 回目のループで、カットの選び方の比べをやり直さず 1 回目の選択を使う |
| `ENOMOTO_MIP_GAP2_LPPGIVE=g` | `src/mip/mod.rs` LP プロービング | 固定 0 のまま、最初の LP の後の子の LP に g × 最初の LP の秒を使ったらやめる (既定の反復の手間の見積もりは密な行で軽く出る) |

### 3.3 効かなかったもの (事実)

- `GAP2_FLAT` (physiciansched6-2 25.1・23.4): ループは 2.7 秒早く終わるが、内点法の丸めが最適解を出さなくなり、根の RENS が 2.7 秒かけて出す (種 1)。
  カットを続けると LP 解が整数に近づき丸めが当たる、という形で「動かないラウンド」にも働きがあった。
