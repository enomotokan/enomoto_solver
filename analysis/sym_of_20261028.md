# orbital fixing の試作 (`ENOMOTO_MIP_SYM_OF`) (2026-10-28)

オービトープにならない対称性を、lex-leader の行 (`x_i - x_k >= 0`) の代わりに探索中の orbital fixing で扱う試作を入れ、
4 コアの機械 (Linux) で既定と比べた。既定は変えていない。

## 仕組み (HiGHS の `StabilizerOrbits::orbitalFixing` の移植)

- 前処理の後の対称性の検出 (`add_symmetry_rows`) で、オービトープに使わない生成元のうち、オービトープの生成元が動かす列
  (オービトープの外の列を含む) を動かさないものを orbital fixing の生成元にする (`SYM_OF_GENS`)。lex-leader の行は足さない。
  群が直積に分かれるときだけ、オービトープの固定と混ぜてよい (HiGHS もオービトープの成分の置換を落とす)。
- ノード (`Solver::orbital_fixing`、オービトープの固定の直後と `PROP_FIXPOINT` の中): 分枝で 1 にした 0-1 列 (上向き) と分枝した
  一般整数列 (向きによらず) を動かす生成元を除き、残りの生成元の軌道 (0-1 列だけ) を求める。軌道のどれかの列が固定されていれば、
  軌道の列を全て同じ値に固定し、行を伝播する。伝播で新たに固定されたら軌道を見直す。軌道は除く生成元の組が同じ間は使い回す。
- 固定はそのノードの部分木で成り立つので、子の分枝の列 (`OpenNode::changes`) に `BoundChange::sym` の印を付けて足す
  (HiGHS は定義域の変更の記録に残る)。印のある変更は、子の固定群を決める分枝に数えない。
- 固定の理由は外からの変更 (オービトープと同じ tag 3)。衝突解析は理由 < 0 の変更を置き換えずに文字として残すので、学習した
  衝突は行だけから導いたもので大域的に成り立つ。
- 再スタートの後の問題では、前の求解の生成元を確かめ直し (`symmetry::verify_generators`)、成り立つものだけを使う
  (前処理が片方の列だけを固定・代入したり、対称でないカットを行にしたりすると崩れる)。
- サブ MIP では使わない。木の並列の従には写し (`TreeSnapshot::of_gens`) で渡す。

## 分かったこと

- **良くなる理由は 2 つ**: (1) lex-leader の行がなくなり LP が軽くなる (drayage は 1599 行)。(2) ヒューリスティクスの解が
  対称性の行に反して捨てられる (`SYM_ORIG_CUT` で値だけ使う) ことがなくなり、見つけた解がそのまま暫定解になる (nw04 はノード 0 で
  速くなっており、こちらの効果と見られる)。
- **悪くなる理由**: lex-leader の行は根の LP も強める (qiu: 根の下界 -879 → 行なし -919、physiciansched6-2: 48774〜49274 →
  48684〜48724)。orbital fixing は木の中でしか効かず、HiGHS 流の固定群 (分枝した列を動かさない生成元だけ) は小さくなりやすい:
  qiu (生成元 3 本が 652 列を動かす) は 1 本の上向きの分枝で生成元が使えなくなり、約 2000 ノードのうち固定したのは 42 ノードだけ。
  physiciansched6-2 は 60 秒でノードをほとんど処理せず、固定は 0 回 (根の LP を弱めただけ)。
- 行の数などの単純な量では、どちらが良いかを分けられない (assign1-5-8 は 12 行で SYM_OF が良く、physiciansched6-2 は 14 行で悪い)。

## Schreier 生成元 (`ENOMOTO_MIP_SYM_OF_SCHREIER`)

分枝した列を動かす生成元を捨てる代わりに、その列を固定する部分群の Schreier 生成元 `u_{s(x)}^{-1} s u_x` を作る
(固定する列の先頭の部分ごとに控え、軌道の大きさ 256・本数 64 で打ち切り。打ち切っても部分群の生成元なので正しい)。
単体テストで S4・D5・C6・S3xS3 の点の固定群と全数で一致を確かめた。
- 乱数問題 (fuzz_of 100 問) で固定したノード 23 -> 157、刈ったノード 13 -> 46。乱数問題 580 問で不一致 0。
- 20 問・4 スレッド (`ab_4t_schreier.jsonl`): SYM_OF 20.61 秒 (28/40) -> SCHREIER 20.32 秒 (30/40)、不一致 0。qiu TL/28.1 -> 43.8/21.1 秒、
  neos5 55.9/TL -> 51.0/47.0 秒。差は揺れと同じくらい (同じ SYM_OF が前の計測では 19.84 秒)。

## 次の候補

- 固定群を大きくする: 分枝した列を動かす生成元を捨てる代わりに、Schreier 生成元 (軌道の代表への写しで作る固定群の元) を足す。
  qiu のように生成元が少なく多くの列を動かす問題で、木の中の固定が増えるはず。
- 16 スレッドの機械で、40 問・負けている 21 問 (対称性があるのは上の 20 問のうちの一部) を確かめてから既定にするか決める。
