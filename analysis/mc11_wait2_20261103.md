## 1. 結論

事実:

1. **mc11 の遅れは止め方では直らない**。道 A (51 ラウンド・11666) では `a`・`c` を足しても根の下界は 11666.4〜11667.5 にしか上がらない
   (裏は 39〜51 ラウンドで 11662 → 11666 と本当に頭打ち)。時間は def 4 回 SGM(+1) 15.5 秒に対して a 16.1・b 14.8・c 16.3・ac 17.7・c10 19.4 秒で、
   どれも差は回のばらつきの中。道 B (48 ラウンド・11683.3、木 7〜97 ノード、7〜10 秒) は def 1/4・b 1/4 で、a・c・ac・c10 は 0/4。
2. 道の分かれ目は裏のカットより前にある: 主の根のカットのループが 25 ラウンドの上限で終わるとき、すでに 11003.67 (道 A) と 11097.64 (道 B) に分かれている
   (根の LP の反復も 1088 と 1220 で違う)。もう 1 つのセッションの切り分け (mc11_wait1) で、これは主の根の LP の同時実行 (二段解法と内点法 + クロスオーバー) の
   勝ち負けで決まり、canddet・p のどの設定も原因ではないと分かった。こちらの見立てと合う。
3. `b` は暫定解との差が小さい問題で待ちを短くする (6 問 × 2 回、`summ_6.md`):
   - h80x6320d: def 0/2 (最初の段で上限まで 14.7 秒待つ) → b 2/2 (35.0 秒、最初の段は 6 ラウンドで止まる)。
   - hypothyroid-k1: 29.0 → 21.4 秒 (裏 20 ラウンド・待ち 7.9 秒 → 6 ラウンド・待ち 0)。分離の重い問題で待ちが短くなる側。
   - neos-911970 (8.5 → 8.1)・roll3000 (26.6 → 26.1)・neos-3083819-nubu は同じくらいで、根の下界は少し下がる (51.98 → 51.79、12650.2 → 12639.2)。
   - physiciansched6-2 は 20.1 → 21.9 (32.6 の 1 回はヒューリの終わりが 28.3 秒と遅かった回で、裏のカットとは関係が薄い)。
4. `a` は重い分離の問題で遅くする: hypothyroid-k1 29.0 → 34.7 秒 (続き 10 ラウンド)、neos-911970 8.5 → 12.8 秒。h80x6320d は再開の後の段の続きで 0/2 → 2/2 (46.9 秒)。
5. **58 問 1 回ずつ (`agg58.md`)**: def 44 問・SGM(+10) 14.50、a 44・14.92 (+2.9%)、b 45・14.78 (+1.9%)、ab 45・15.04 (+3.8%)。
   b・ab が多く解いた 1 問は h80x6320d (def 時間切れ → b 38.9)。a は timtab1 を落とす (48.7 → 時間切れ)。mc11 は def 21.2・a 20.1・b 17.9・ab 18.5 (道 A)。
6. 待ちが長すぎた回・時間の上限の超過はない (58 問の最長は blp-ar98 の 60.13 秒で時間切れ。hypothyroid-k1 の待ちは最長 12.75 秒 (ac の上限での打ち切り)、
   b では 0)。`cargo test --release --lib` は 333 件通る。

推測・判断:

- mc11 は止め方の側では直せない。直すなら mc11_wait1 の根の LP の同時実行の側 (試作 `MC11FIX1_RACE=s`) だが、そちらも 58 問 +1.0% で出していない。
- `b` は h80x6320d・hypothyroid-k1 で効くが、58 問の SGM は +1.9% (mas76 7.5 → 12.6・noswot 12.5 → 25.9 など、根の下界を少し捨てる問題で遅くなる) で、
  今は既定にしない。1 回ずつなので回のばらつきの中かもしれず、出すなら `GAP_EPS` を 0.003 などに下げて 58 問 × 3 回で確かめる。
- `a`・`c` は採らない (下界はほとんど上がらず、重い分離の問題で遅い)。
