# 裏のカットの写しに列の値を渡す形 (`ENOMOTO_MIP_BG_CUTS_BASIS_X=lpw`) を広く確かめる (調査 2、2026-11-02)

flbgx の既定化 (commit 89e721bb、analysis/flbgx_default_20261102.md) の確かめで、physiciansched6-2 の 1 回に、列の値を渡すと裏のカットの写しが
約 17 秒の間にラウンドの記録 0 (`rounds so far []`) になる回があった。physiciansched6-2 の深掘りは調査 1 がしているので、ここでは
58 問 + Mittelmann で `lpw` が働く問題を洗い出し、既定と `ENOMOTO_MIP_BG_CUTS_BASIS_X=0` を並べた。直すのは調査 1 の結果を待つので試作はしていない。

## 要点

- **58 問 + Mittelmann (重複を除き 202 問、physiciansched6-2 を除く) のうち、`lpw` が働く (主の根の LP が 1 秒以上) のは 17 問**。
  そのうち seymour1 (1.05 秒)・neos-662469 (1.09 秒)・neos-1171448 (1.16 秒) は境目で、seymour1 は比べの 2 回とも渡らなかった
  (neos-873061 も 1 回は渡らない)。反対に peg-solitaire-a3 (0.98 秒) は比べの 2 回とも渡った。
- **結果 (状態・解・時間) に `lpw` の効きの差は見えない**。17 問 + peg-solitaire-a3 のうち最適まで行くのは neos-960392・neos-1171448 だけで、
  どちらも既定と `=0` で時間は揺れの範囲 (25〜31 秒・38〜45 秒)。ほかは両形とも時間切れで、根の下界はほぼ同じ。写しの結果を主が使ったのは
  mzzv42z (両形 3/3)・neos-662469 (両形 2/2)・neos-957323 (両形 2/2)・seymour1 (列の値は渡らず)・**atlanta-ip (既定 3/3、`=0` 0/3)** だけ。
- **列の値を渡すと写しのラウンドが 0 になる (`N rounds` は数えるが目的値の記録がない) 問題は多い**: neos-960392 (3/3)・neos-933966 (3/3)・
  brazil3・neos-3656078-kumeu・comp07-2idx・academictimetablesmall・neos-4722843-widden。ただし後ろの 4 問は `=0` でも同じように
  0〜1 ラウンドで止まり (主の根のカットのループも LP が上限に当たって 0 本しか残らない問題)、**列の値のせいと言えるのは neos-960392 と
  neos-933966 (と comp07-2idx)**。neos-933966 は `=0` で 6〜7 ラウンド回るのに既定は 0 ラウンド、comp07-2idx は `=0` の写しが 3.67 → 4.29
  まで上げるのに既定は 3.67 のまま。どちらも主の根のヒューリスティクスが長く (comp07-2idx は 57 秒)、写しの結果は使われないので、
  今回の 60 秒では結果に出ない。
- **見当 (診断のログ、`ENOMOTO_MIP_BG_CUTS_LOG=1`)**: 列の値を渡すと写しの根の LP は 1 反復で終わるが、写しの 1・2 ラウンド目のカットの
  LP が **1 回の LP の時間の上限 (`TimeLimit`) に当たって外され、2 回外すとループを抜ける** (`lp_failures >= 2`)。これが
  「`2 rounds, ... not above ...; not used`、`rounds so far []`」の形。同じ既定に既存の試作 `ENOMOTO_MIP_CUT_DSE_EXACT=1` (カットを足した
  LP を出発の基底の厳密な DSE 重みから解く) を足すと、neos-960392 は写しの 1 ラウンド目 778 反復・2 ラウンド目 249 反復で通り、
  neos-933966 は 7 ラウンド中 6 ラウンドが 233〜672 反復で通る。写しは主の LP の基底 (と列の値) しか受け取らず、DSE 重みは
  受け取らない (`BG_ROOT_BASIS`・`BG_ROOT_X`)。基底から warm start して重みを引き継がないときは単位重みで始まる
  (`slope_intercept_dual.rs` の DSE の初期化) ので、根の LP が 1 反復で終わる写しは**ほぼ単位重みのままカットの LP に入り、価格付けが
  悪くて上限に当たる**と見られる。`=0` で写しの根の LP を数千反復解き直す形では、その間に重みが育つのでカットの LP が通る。
  `=0` でも写しの根の LP が 1 反復で終わる問題 (neos-4722843-widden・neos-873061) は同じように 0 ラウンドで、この見当と合う。
  physiciansched6-2 の確かめの 1 回 (根の LP 1 反復、0 ラウンド) も同じ形の可能性が高い (調査 1 に渡す)。
- **反対に渡すと良くなる問題**: atlanta-ip は既定だと写しが 1〜4 ラウンド記録して 3/3 で使われ (`=0` は写しの根の LP が 8〜12 反復で
  始まるのに 0 ラウンド・0/3)、mzzv42z は既定のほうがラウンドがやや多い (11〜13 対 7〜11)。ただし根の下界・解はどちらも揺れの範囲。
  写しの根の LP の時間は既定で 0.01〜0.23 秒、`=0` で最大 8.2 秒 (neos-3656078-kumeu) 縮むが、それで結果が変わった問題はない。
- まとめると、`lpw` のねらい (写しの根の LP を短くする) はどの問題でも働いているが、**根の LP が 1 反復で終わると DSE 重みが単位のまま
  残り、写しのカットの LP が上限に当たる回が増える** (neos-960392・neos-933966 は 3/3、physiciansched6-2 の 1 回)。直し方の候補は
  写しに主の DSE 重みも渡す、または写しの最初のカットの LP (か根の LP) だけ厳密な重みから始める (`DSE_EXACT_ONCE` を写しにだけ立てる)。
  `ENOMOTO_MIP_CUT_DSE_EXACT` を全体に入れると主の根のカットのループの道も変わる (neos-4722843-widden で主の 1 ラウンド目の LP が
  外れたまま解が 27733 → 58074) ので、写しだけに限る形がよい。

- 写しの根の LP が 1 反復で終わる形 (既定の `lpw`、または `=0` でも主の基底がそのまま最適になる問題) では、DSE 重みが単位のまま残る
  (`set_basis`・`set_basis_cols` は重みを渡さず、`slope_intercept_dual.rs` は引き継ぐ重みがなければ単位重みで始める)。カットを足した LP は
  その重みで解くので反復が増え、写しの 1 回の LP の時間の上限 (`cut_lp_time_frac × 残り時間` が元。写しは主のヒューリスティクスと
  CPU を分け合い、暫定解が FJ の解なら 1 スレッド) に当たる。厳密な重みから始めると通ることが neos-960392・neos-933966 で確かめられた。

## 判断

- `lpw` を既定のままにするかは、調査 1 (physiciansched6-2) の結果と合わせて決める。今回の 18 問では、`lpw` で結果が悪くなった問題も
  良くなった問題もない (写しの結果が効く問題が少ない)。ただし neos-960392・neos-933966 (と comp07-2idx) では写しのラウンドが毎回 0 に
  なっていて、physiciansched6-2 の 1 回と同じ形。
- 直すなら、列の値を渡すときに **写しに主の DSE 重みも渡す、または写しの最初のカットの LP だけ厳密な重みから解く**。全体に
  `ENOMOTO_MIP_CUT_DSE_EXACT` を入れる形は主の道を変える (neos-4722843-widden) ので採らない。
