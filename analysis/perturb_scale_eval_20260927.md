# 費用摂動の総量を真の費用の尺度に合わせる (57cd940) の判定: 不採用

- 内容: 摂動の総量 (Σ 摂動×幅) が真の費用の尺度 (Σ|c|×幅) の 0.1 倍を超える問題 (cont1・perold・pilot4 の 3 問) だけ、総量を 0.01 倍に縮める。
- 実装担当の計測: cont1 の主単体法への引き継ぎ 1,819 → 761 反復 (31.0 → 12.9 s)、除去後の双対実行不能列は 788 → 778 (大半は許容誤差程度の真の双対退化)。
  ただし主ループが 306.8 → 333.6 s (反復 +0.5%、1 反復 +8%: 主実行不能行 4.5 万 → 5.8 万、再分解 68 → 74 回)。摂動の大きさを変えても同じ形 = 系統的に重い経路。
  cont1 の総時間 +2.7%。他の 10 問は経路不変。Netlib で経路が変わったのは perold (−4.8%)・pilot4 (+3.0%)。104 問の shifted geomean −0.11%。
- 一律に摂動を縮める案 (費用 0 の列の +1 を小さく、base を 0.1 倍、基準を非零費用の中央値に) は、退化問題で反復が系統的に増えた (grow15 +23〜63%、pilot87 +5〜21% など)。
- 判定: リポジトリ所有者の判断により**不採用**。src を 3177ed7 に戻した。
