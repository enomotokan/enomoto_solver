### 1.2 試作

- `ENOMOTO_MIP_FEAS_NORETRY=1` (新規、src/mip/mod.rs の `feas_noretry_on`・`FEAS_EARLY_DRY`、solver.rs の `robust_fj_retry`): 目的が全て 0 の問題で、
  前処理の早めの探索 (最初の 1 回) が解なしで上限まで回ったら、根の後のやり直し FJ を回さない。閾値は無い (「解なしで上限まで回ったか」の真偽だけ)。
  hang_20261117 の F (7 問 × 3 種 × 4 設定) でも、解ける問題を解いたのは全て早めの探索で、やり直しが見つけた記録は無い。
- `ENOMOTO_MIP_FEAS_EARLY_LMIP_NO_CHAIN=1` (既存): 早めの探索 (とやり直し) の Local-MIP で連鎖の手を使わない。
- fhnw-binpack4-4 (種 1): 4 スレッド 108.5 → NORETRY 81.9 → 両方 81.6 秒、1 スレッド 393.6 → NORETRY 273.9 → 両方 **114.1 秒** (木は同じ 12961 ノード)。
- 確かめ: cargo test 414 通過。両方の環境変数で fuzz_tiny 0/400・mip_fuzz_vs_highs 0/300・fuzz_slack 0/1000 (乱数の問題はほぼ目的が 0 でないので、
  働くのは目的 0 の問題だけ。ヒューリスティクスの解は元の問題で実行可能性を確かめてから使う)。

## 2. neos-3988577-wolgan・neos-2746589-doon

- **wolgan** (実行不能、SCIP も 600 秒で解けず 15 ノード): 今の版の 1 スレッドでは根の LP は 34877 反復・142 秒で終わる (「終わらない」は再現しない)。
  その後カット約 60 秒、根のヒューリスティクス約 260 秒 (飛び込み 3 種 102.6・46.6・31.5 秒、FP 67.3 秒、interior rounding 10.1 秒) で解なし、466 秒で木に入り 4 ノード。
- **doon** (最適 2008.2、誰も解を見つけない。SCIP も 600 秒で解なし): 今の版では根で止まらない (4 スレッド 6778 ノード、1 スレッド 1587 ノード)。
  根のヒューリスティクスに 4 スレッド 183 秒・1 スレッド 167 秒 (1 スレッドは RENS のサブ MIP 61.7 秒で打ち切り・FP 17 秒・飛び込み 50 秒)。
  大域の下界は根の 1988.5 から動かない。SCIP の根 (`limits/nodes=1`、`logs/neos-2746589-doon_root.log`) は 1992.43 で、根に 257 秒、うち強分岐 120.8 秒 (585 回)、
  分離は gomory 146・impliedbounds 255・zerohalf 32・clique 24・cmir 16 本を採用。
- 2 問の根のヒューリスティクスの秒は、既定の `ENOMOTO_MIP_RHEUR=es` の共有予算 (根の LP の反復の 4 倍 + 4000、rootheur_20261114) どおり。
  根の LP が重い問題ではそのまま秒が膨らむ (SCIP の飛び込みは木全体の LP の反復の 5% ほど)。予算を変えると P・M 全体に響くので、手を入れていない (親に判断を仰ぐ)。
