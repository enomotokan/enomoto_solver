# heuradapt: 1 スレッドの解探しの試作をシグモイドで連続に効かせる (2026-11-24、親の依頼)

親の依頼 (利用者の方針「問題によって効き方が違う試作は、却下せずシグモイドで効き方を変える」): 1 スレッドの解探しの試作
`ENOMOTO_MIP_HEUR1T=fl` (analysis/heur1t_20261123) と `FP_STAGE3` + `POOR_NOINC` + `P2RIT=a` + `FJSYNC_LABEL` の組 (analysis/presym_20261123、以下 fps) を、
問題の特徴から決める割合 f で強さを変える形にする。前例は `ENOMOTO_MIP_CLIQUE_CUTS=sigmoid`。既定は変えない。

## 0. 台本

- `one.sh 問題 種 秒 スレッド 札 [K=V ...]`: 当方を 1 回解き (`ENOMOTO_MIP_LOG=1`)、`logs/<問題>_<札>_s<種>_t<スレッド>.log` (コミットしたものは gzip で .log.gz) と `res_one.jsonl` に残す。
- `cmp.sh 札 ...`: 対象の 5 問 (10teams・neos-1171448 120 秒、CMS750_4 200 秒、noswot・pg 60 秒) を 1 スレッド・種 1〜3 で回す。
  `SET=h` なら protoscreen (P の 1 スレッド) で HEUR1T=fl の害が出た 8 問 (eil33-2・swath1・mas76・markshare_4_0・blend2・misc07・pk1・roll3000、60 秒)。
  札: def (既定)・fl (`HEUR1T=fl`)・fps (4 つの組)・ad (`HEUR_ADAPT=1`、診断 `ENOMOTO_MIP_HEUR_ADAPT_DEBUG=1` 付き)。
- `tab.py 札 ...`: 表と、全部の札がそろった回のずらし幾何平均 (ずらし 10 秒、時間切れは上限の秒)。
- `fuzz.sh`: fuzz 7 本と cargo test (`HEUR_ADAPT=1`)。
- 札 ad0・ad1・ad2・ad3・dbg は途中の版 (2 節〜4 節)。

## 1. 害の出どころ (事実、1 スレッド)

- noswot 種 3 (60 秒): 既定 14.8 秒、`fl` 54.2 秒、`f` だけ 13.9 秒 (既定と同じ 17639 ノード)、`l` だけ 28.7 秒。pg 種 2: 既定 14.2、`f` 14.3、`l` 17.3 秒。
  → 害は `l` (1 スレッドの木の大近傍探索の時間の割合を 0.25 に上げる)。noswot は最適解 −41 を 0.14 秒で見つけ、残りは下界を閉じる木
  (大近傍探索に回す時間がまるごと無駄)。pg も 13 秒目に最適解で、木は 15 秒で閉じる。
- misc07・blend2 (P で `fl` が全種 1.25 倍超の遅れ): `f` が、実行不能な RENS のサブ MIP の中で robust FJ を約 3 秒空回りさせる
  (misc07: 根の RENS 0.25 秒 → 2.96 秒、blend2 0.05 → 3.00 秒)。

## 2. 特徴と係数 (`ENOMOTO_MIP_HEUR_ADAPT=1`、src/mip/solver.rs の `heur_adapt`)

3 つの割合をそれぞれの効く所で測る。どれも大きさによらない比。

| 割合 | 特徴 | 式 | 掛ける所 |
|---|---|---|---|
| f_t | 1 スレッドの外側の木の完了の見込みの秒 / 残りの秒 = r (未処理のノードの重み Σ 2^−深さ ÷ 完了率の平均の速さ) | sigmoid(4 (ln r − 2)) | 木の大近傍探索の時間の割合を、既定 (2〜10%) から 4 スレッドのヒューリスティクス役の割合 0.25 へ f_t だけ寄せる (`l`) |
| f_g | 暫定解の根の LP からの相対ギャップ g | sigmoid(11 (g − 0.5)) | FP・ダイビングの予算の物差し (`P2RIT=a`)、FP の第 3 段のノード・時間の上限。暫定解なし用のヒューリスティクス (`POOR_NOINC`) は f_g > 1/2 (= g > 0.5、既存の基準) |
| f_s | 外側の根から出したサブ MIP にここまで使った秒 e / robust FJ の上限 | sigmoid(2 ln(e / 上限)) | サブ MIP の中の robust FJ の時間の上限 (`f`) |

- `FJSYNC_LABEL` (同期の FJ の解の名札) はそのまま有効。
- f_t は木を始めて 1 秒・全体の時間の 5% (4 スレッドの役の起動の判定と同じ温まり) までは 0。64 ノードおきに測り直す。
- 係数 (データから。新しい閾値を作らない方針で、境は既存の基準か、効いた問題と害の出た問題の測った値の中ほど):
  - f_t: 診断で測った ln r は、害の出た noswot −3〜−4 (木は数秒で閉じる見込み)、pg 最大 1.50 (木の初めの 5〜10 秒)、
    効いた neos-1171448 最小 2.57 (完了率 0.008 のまま動かない)、CMS750_4 は完了率 0 で r = ∞。b_t = 2 は pg の 1.50 と neos の 2.57 の中ほど、
    a_t = 4 は両端で f_t が 0.1・0.9 になる ln 9 / 0.535 ≈ 4.1 を丸めた。境 r = 1 (期限ちょうど、役の起動の判定と同じ) の最初の版 (ad0) では pg の f_t が
    0.5〜0.8 になり 14.2 → 17.0 秒。
  - f_g: b_g = 0.5 は既存の `ENOMOTO_T_MIP_FJ_POOR_GAP`。a_g = 11 は、害の出た側で g のいちばん大きい noswot (0.07) で f_g が 1% になる
    ln 99 / 0.43 ≈ 10.7 を丸めた。CMS750_4 の FP の第 3 段の時点 (暫定解 604、根の LP 250、g 0.59) で f_g 0.73。
  - f_s: b_s = 0 (FJ にそれまでサブ MIP に使った時間と同じだけ使うところが 1/2)。a_s = 2 は、害の出た swath1・misc07 の ln(e / 上限) −1.35・−1.6
    (サブ MIP の根の LP 1〜2 ミリ秒、e 1.1〜1.5 秒、上限 5.6〜6 秒) で f_s が 0.1 を切る ln 9 / 1.35 ≈ 1.6 を切り上げた。効いた 10teams 種 3 は
    +0.17 (e 7.1 秒) で 0.58。

## 3. 途中の版 (事実)

- ad1 (f_g を `f` にも掛けた): 10teams 種 3 が時間切れ。同期の FJ の 1016 (根の LP 924、g 0.09) で f_g 0.01 になり、根の被約費用のサブ MIP の中の FJ が回らなかった。
  `fl` は 3.3 秒で解く。→ `f` には f_g を使わない。
- ad2 (f_t の温まりにノード数 100 の下限): neos-1171448 種 2・3 が時間切れ (`fl` は 37.3・101.9 秒)。1 ノード 0.17 秒で 100 ノードまで 15 秒かかり、
  その間の最初の大近傍探索 (`fl` では 101 ノード目の RINS が −309) が既定の割合になった。→ ノード数の下限を外した。
- ad3 (`f` は常に有効): misc07 1.9〜2.5 倍 (5.4 → 11.1・10.2・13.5 秒、1 節の FJ の空回り)。→ f_s を足した (今の版 = ad)。
