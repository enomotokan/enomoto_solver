## 1. HiGHS の判断 (事実、v1.15.1 `HighsMipSolver.cpp` の `checkRestart`・`performRestart` を読んだ)

- 固定の割合のしきい値は無い。`activeIntegerRatio` = (1 − 不活性な整数列の割合)² を全体に掛ける。
- 「巨大な木」の票: ギャップの縮み `gapReduction < 1 + 0.05/ratio` かつ 木の見込みのノード数 `≥ ratio·20·この回のノード数`。
- 票の数 + 見込みの票が `round(ratio·(10 + 葉/1000)·1.5^再スタート回数)` に届いたら再スタート。巨大の票が出たときだけ次の確かめを 100 ノード後にする。
- 最初のノード数の下限・回数の上限は無い (1.5^n で遠のくだけ)。worker の 25% 以上が票を入れると強制する。
- `performRestart` は LP のカットをモデルに足し (`appendCutsToModel`)、下界とカットプールを持ち越す。
- つまり HiGHS は「木がまだ大きいと見込まれる」ときだけ再スタートし、木がほぼ閉じたとき (損の型) は票が入らない。

## 2. 再スタートの時点の量 (事実、`summ_all.md` から抜粋)

「後の根 − 前の根」は再スタート後の根の LP 値と根の終わりの値から、前の根の終わりの値を引いたもの。

## 3. 分ける条件 (推測、上の表から)

損の型は 2 つに分かれる:

- **(A) 木がほぼ閉じている**: q ≥ 0.75、木の残りの見込みが根のやり直しの秒に届かない (÷根 < 1)、presolve で行が減らない、後の根の伸びが gap の数 % (neos-860300・eil33-2・drayage tr1 s1)。根をやり直す費用が、残りの木を解く費用を上回る。
- **(B) 持ち込むものが無い**: 新たな固定 0・カットも数本、行が減らず後の根もほぼ伸びない (neos5・pk1・sct2/csched008 の force)。木を捨てて同じ根を解き直すだけになる。

得の型は「持ち込むもの」がある:

- 固定が多く presolve で行が大きく減る (drayage 807→596、mc11 2949→2416)、または
- カットが問題の行に比べて多い (pg5_34 1316/1541、kasai 623/2275、mc11 1033/2949)、または
- 木がまだほとんど閉じていない (q ≈ 0、swath3 ÷根 数百) で、少しの固定でも以後の木が軽くなる。

ただし (A) の目安 (q・残り見込み÷根) だけでは分けきれない: mc11 inc s1 (÷根 0.46) と drayage inc s7 (÷根 0.15) は木が閉じかけでも得だった。
この 2 つはカットか行の減りが大きい。「残り見込み < 根 でも、カット/行 が大きい (mc11 は 0.6) なら通す」とすると分けられそうだが、試していない。

## 4. 試作: `ENOMOTO_MIP_TREE_RESTART_GUARD` (`src/mip/solver.rs` の `tree_restart_guard_ok`)

`due` (モード 1・force) と `inc` の両方の入口で、再スタートの前に呼ぶ。文字ごとに 1 つの見送り条件で、どれかが当たれば見送り (`tr_last` を今に置き直す)。

- `l`: 根のやり直しの見込みの費用 (この求解で木に入るまでの秒 × `..._GUARD_ROOT` 1) が残り時間の `..._GUARD_LEFT` (0.25) を超える。
- `c`: 木の残りの見込みの秒 (木の秒 × (1−q)/q) が根のやり直しの費用の `..._GUARD_COST` (1) 倍に満たない。 → 型 (A)
- `g`: 相対ギャップが `..._GUARD_GAP` (1e-3) 未満。
- `q`: q ≥ `..._GUARD_Q` (0.5)。
- `k`: 新たな固定が `..._FIX_FRAC` (0.01) × 自由な整数列に満たず、かつ LP のカットの行が max(`..._GUARD_KCUTS` 50, `..._GUARD_KFRAC` 0.1 × 問題の行) に満たない。 → 型 (B)
- `n`: この求解の木のノード数が `..._GUARD_NODES` (300) 未満。

(設定名の頭は `ENOMOTO_T_MIP_TREE_RESTART`)。主に試したのは `force` + `kc` と `inc` + `c`。
記帳 `TRSTAT:` の行 (ログのときだけ) に、上の表の量 (q・残り見込み・HiGHS 式の見込み・gap・新たな固定・カット・残り時間・pass/stop) を出す。
