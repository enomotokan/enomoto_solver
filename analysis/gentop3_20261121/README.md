**閉じた (2026-11-21、利用者の判断) → 2026-11-22 に利用者の判断で広い計測を再開 (既定化の方向で P と M を同時に、§5)。** `ENOMOTO_MIP_GEN_TOP3` は既定オフのまま。

- 広い計測のビルドは CMIRGEN=u が既定になった後 (186e9f076 以降) なので、def・t3 とも u の上で比べる。

試作 `ENOMOTO_MIP_GEN_TOP3` (src/mip/separation.rs の `keep_best`、既定オフ) を作り、8 問で既定と比べた。

**試作の中身**

- 今の `keep_best` は、集約行 1 本の向き 1 つから作った候補のうち最良 1 本だけを残す。試作では次のように変える。
  - その中で最良の質 (`cut_quality`) の `ENOMOTO_T_CUTSEL_MIN_REL` (既定 0.5) 倍以上のものを選ぶ。0.5 倍は全体の選択 `select_cuts_hybrid` の質の下限と同じ値。
  - その中から、良い順に最大 `ENOMOTO_T_MIP_GEN_TOP3_N` (既定 3、利用者の指定) 本を残す。
- 平行度と本数は全体の選択に任せる。
- 効く範囲は GEN_TYPE と同じで、`keep_best` を使う所すべて。
- `ENOMOTO_MIP_GEN_TYPE` より優先する。
- `ENOMOTO_MIP_GEN_TOP3_LOG` をつけると、`keep_best` に 2 本以上の候補が来た回に `GENTOP3 候補の数 0.5倍以上の数` を出す (診断)。

## 6. GEN_TOP3 の倍率の掃引 (2026-11-22、利用者の案)

  `ENOMOTO_T_CUTSEL_MIN_REL` (0.5) だった。そのまま掃引すると全体の選択まで変わるので、GEN_TOP3 専用の `ENOMOTO_T_MIP_GEN_TOP3_REL` を足した
  (src/mip/separation.rs の `keep_best`)。未指定なら今と同じく `ENOMOTO_T_CUTSEL_MIN_REL` の値。
- 確かめ:
  - cargo test: 419 passed。

    後のビルドで、REL 未指定・REL=0.5 のとき、状態・目的値・ノード数がすべて同じ (28・3968・1363・4263・148993 ノード)。
