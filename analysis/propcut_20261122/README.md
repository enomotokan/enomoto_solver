# PROPCUT: LP 解を切るかでなく、伝播で固定を生むかで不等式を見る (2026-11-22、利用者の案)

背景: analysis/rootcutoff_20261121 §5。目的関数の行から集約したカットは LP 解を切らず 0 本で、余裕 0 とみなしても固定は増えなかった
(固定はほぼ全部が被約費用の固定)。今の分離は違反しない候補を返さず違反で選ぶので、伝播に強い不等式を取りこぼしていないかを見た。

## 0. 結論

- **余地は見えない。試作は作らない (P の分担表も作らない)。** 12 問 (打ち切り値なし・最適値を渡す) の根で、
  - (b) 被約費用の不等式 (目的関数の行 + 双対 × 行) に MIR の丸めをかけた行: 固定は (a) と全く同じで、丸めの分の上積みは 0。
  - (c) LP の行と目的関数の行の MIR (LP 解を切るかは見ない、1 問あたり 0〜839 本): 固定の上積みは全部の回で 0。
  - (a) 根のカットの各ラウンドの LP の被約費用: 7 回で +1〜+22 列 (p200x1188c +20・+22・+14・+8、neos-1582420 +21、h80x6320d +10、swath1 +2、mas76 +1)。
  - どの回も、固定を足した境界で根の LP を解き直した値は変わらない (固定された列は LP で境界にいる)。
- 1 本の行の丸めは、その行の伝播 (各列の ⌊b/a_j⌋) を越える単独の固定を生まない (1 行のナップサックの伝播は MIR で強まらない)。行どうしの組み合わせの
  伝播でも上積みが出なかった。被約費用の固定は LP の双対で目的の行と行の最良の組み合わせをもう使っていて、別の掛け方の余地は (a) の小さな上積みだけ。
- (a) の別の双対は analysis/slowm_20261119 §15 (`ENOMOTO_MIP_DIAG_OBBT`) で広く数えてあり (77 問、OBBT の天井との差のうち、カットのラウンドの双対 0.00・
  乱した LP 0.07〜0.09・内点法 0.17・PDLP 0.12、全部で 0.26)、既存の試作 `ENOMOTO_MIP_TREE4_RCUNION`・`ENOMOTO_MIP_FIXMORE=u` がある
  (RCUNION は tree_close4_20261104・highs_only G6 で固定が増えず、FIXMORE=u は 58 問 +1.4% [−1.1%, +4.4%] で保留)。今回の +1〜+22 列も LP の値を変えない。
- 強分枝の LP の双対は数えていない (別の頂点の双対で、乱した LP の双対 P・X と同じ種類。§15 では小さかった)。

## 1. 診断 `ENOMOTO_MIP_DIAG_PROPCUT` (src/mip/propcut.rs、解き方は変えない)

外側の主の根の、カットのループの後 (早めの被約費用の記録の直後・固定の前、objagg と同じ所) で、打ち切り値が有限なら 1 行を出す。
基準 `ab` = 元の行 + LP のカットの行 + 目的関数の行 `c x ≤ U` + 根の被約費用の締め、の伝播で固定される整数列。それに足して数える:

- `a`: 根のカットの各ラウンドの LP の被約費用の締め (この診断の間だけ別の表 `propcut_rc` に集め、解き方には使わない)。
- `b`: 被約費用の不等式 `Σ d_j x_j ≤ (U − z) + Σ d_j 境界_j` (非基底の整数列。根と各ラウンドの表から) に MIR の丸めをかけた行。
- `c`: LP の行 (500 列以下) と目的関数の行の両側の MIR の行。
- MIR: 連続列は係数の向きの有限の境界で置き換えて落とし、整数列は係数の符号で下限・上限から補い、δ (係数から大きい順に最大 4 個) で割って
  `Σ (⌊α_j⌋ + max(0, f_j − f0)/(1 − f0)) y_j ≤ ⌊β⌋`。f0 が 0・1 に近い (1e-6) δ は飛ばす。
- 伝播の境界 (`ab`・`all`) で根の LP (元の行 + カットの行 + 目的関数の行) を解き直した値も出す。

台本 `diag.py` (根だけ `ENOMOTO_MIP_NODE_LIMIT=1`、1 スレッド、種 1、120 秒。`inc` は打ち切り値なし (根の暫定解の値)、`opt` は最適値 + 1e-6·max(1,|opt|)
を `ENOMOTO_MIP_CUTOFF` に渡す)、結果 `diag.jsonl` (ログは `logs/`、コミットしない)。
