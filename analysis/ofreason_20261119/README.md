# orbital fixing の固定に衝突解析の理由を付ける案の検討 (2026-11-19、作らない)

依頼 (親、利用者との議論から): orbital fixing (src/mip/solver.rs の `orbital_fixing`) の固定は外部の固定 (`set_external_tag(3)`) として置かれ、
衝突解析が理由を遡れない。SST のカットが fhnw-binpack4-4 で強いのは、行として衝突解析・伝播の連鎖に入るためと見て、
orbital fixing の固定に理由 {代表 x_f の値, 群を決めた分枝の決定} を付ける試作 (`ENOMOTO_MIP_OF_REASON`) を作る案。

## 懸念 (実装前に止めた)

- orbital fixing の固定は含意ではなく、探索の順に依る支配 (dual) の刈り。x_f = 0 の部分木で軌道の x_j を 0 にしてよいのは、兄弟の部分木 (x_f = 1)
  に像があるから。
- 理由を付けると、衝突解析は「B1 ∧ x_f = 0 ⇒ x_j = 0」を推論の一歩として使い、できた衝突は衝突プールで大域的な制約として残る (再スタートの後も)。
- この形の節は一緒には成り立たない。別の部分木で役が入れ替わった「B1 ∧ x_j = 0 ⇒ x_f = 0」も学ぶと、解 s と像 g(s) が両方とも切られ、
  最適解の像を全部失いうる。orbital fixing (経路ごとの順) と LexRed (大域的な順) の併用で最適解を切った誤答 (analysis/wrong_widden_20261117 の
  12・13 節、8f4a55ebd) と同じ形で、理由の選び方では防げない。fuzz で bad 0 でも保証にならない。
- (SCIP も対称性の固定を衝突解析で遡らない扱い (dual reduction 扱い) と記憶しているが、確かめていない。)

## 代わりの案と判断

1. 学んだ衝突を局所 (群を決めた分枝の節の部分木) に限り、プールに入れない: 正しいが大域的な再利用が効かず得が小さい → 見送り。
2. SST と同じく大域的に一貫した順の行で対称性を扱う形を目的のある問題に広げる (行は大域的に正しいので衝突解析に入っても誤答の芽にならない。
   同じ成分で orbital fixing と混ぜない): P2-HEUR に SST=x として依頼済み (親)。
3. 依頼どおりの形: 作らない。

判断 (親、2026-11-19): (3) は作らない、(1) は見送り、(2) は P2-HEUR が担当。このディレクトリは記録だけ。
