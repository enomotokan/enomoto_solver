- 背景: `analysis/mitt600_20261103.md` の「新しい既定での測り直し」で、roll3000 が前の既定 35 秒 → 新しい既定 80 秒 (どちらも 1 回、別の機械)。

  def (新しい既定) と preall4bs (前の既定、6 つとも戻す) を交互に 3 回ずつ (def → preall4bs → def → …、順は `roll3000/run_order.log`)。

## 結論

- **事実**: 時間の幅が重なる (def 29.8〜34.1、preall4bs 27.4〜33.3)。def の 3 回はどれも 35 秒以下で、80 秒は再現しなかった。
  平均の差は約 2 秒 (+7%) で、回ごとの揺れ (約 5〜6 秒の幅) より小さい。よって **揺れ** と結論し、1 つずつ戻す設定 (nomem3 など) は回していない。
- 最大 RSS は def が 20〜40 MB ほど多い (mem3 などの持ち物の差か。時間には効いていない)。
- **推測**: 80 秒の回はノード数 2842 で今回の def より 1〜7 割多いだけなのに時間は 2.4 倍なので、探索の違いより、
  25 の並列セッションで回した機械の遅さ (または混み具合) が主な原因と思われる。
