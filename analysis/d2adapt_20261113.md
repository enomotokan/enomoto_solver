## 試作 `ENOMOTO_MIP_HL2_D2=B` (D2b の適応版)

- 始めは D2b を使わない。保護のデータ (ノードの効いていたカットの番号) は作り、消した行の中身 (`d2b_store_deleted`) も始めから取っておく
  (使い始めてから取ると、kasai では使い始める前に消えた行が多く、足し直しは成功 3 回・行がなく失敗 323 回だった)。
- 待ち行列から取って基底の復元を試みたノードの最初の LP の後に、スレッドごとに判定する (`Solver::d2b_adapt_check`)。
  待ち行列のノードが `ENOMOTO_T_MIP_D2B_MINQ` (30) 以上、不一致の割合が `ENOMOTO_T_MIP_D2B_FRAC` (0.1) 以上、不一致のノードの最初の LP の
  反復の平均が潜り・兄弟の子の平均の `ENOMOTO_T_MIP_D2B_K` (6) 倍以上かつ `ENOMOTO_T_MIP_D2B_MINIT` (100) 以上なら、そのスレッドで D2b を使い始める
  (一度入れたら戻さない)。反復の下限 100 は少ない標本で比が大きく出る eil33-2 (最初の 30 本で 67 / 7.8 = 8.6 倍) を外すため。
- 使い始めた後、足し直しで LP のカットの行が使い始めたときの `ENOMOTO_T_MIP_D2B_ROWCAP` (2) 倍 (少なくとも 50 本) を超えるなら足さない
  (noswot のような行の膨らみの歯止め)。
- 終わりの統計 (`ENOMOTO_MIP_LOG`): `MIP: D2BADAPT: threads switched on N (all); this thread: ...`、使い始めたときに
  `MIP: D2BADAPT: tid .. on at ..s nodes ..`。
- cargo test --release --lib: 既定・`ENOMOTO_MIP_HL2_D2=B`・`B` を常に入れる (しきい値 0) の 3 通りとも 415 通過・0 失敗・19 無視。
  (この環境では pyo3 の extension-module のため `RUSTFLAGS="-C link-arg=-L/usr/local/lib -C link-arg=-lpython3.13"` が要る)

下調べでの判定 (4 スレッド・種 1): noswot・mc11・eil33-2 は入らない、kasai (120 秒) は 25〜57 秒で 4 スレッドとも入り、足し直し 1246 回成功、
主スレッドの待ち行列のノードの LP は 116 反復 (入れないと 213〜285)。
